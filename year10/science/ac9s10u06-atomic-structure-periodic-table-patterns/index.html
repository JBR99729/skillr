Atomic Structure and Periodic Table Patterns

The periodic table is ordered by proton number. Repeating outer-electron arrangements help explain why elements in a group show recurring chemical properties.

Topic GuideTeacher SlidesHomeworkPracticeTest
What you need to know

Atomic number equals proton number and determines element identity. In a simplified shell model, period relates to occupied shells and main-group position relates to recurring valence-electron patterns. The Bohr-style shell diagram is a useful model, not a literal picture of electron paths.

Periodic-table cheat sheet

Atomic number

Number of protons; identifies the element.

Neutral atom

electrons = protons.

Period

In a simple shell model, number of occupied electron shells.

Group pattern

Main-group elements share recurring outer-electron arrangements and similar chemistry.

Worked examples

Identify the element

An atom with 11 protons is sodium regardless of neutron count.

Neutral electron count

Chlorine atomic number 17 has 17 electrons when neutral.

Shell arrangement

Sodium 2,8,1 has one valence electron; chlorine 2,8,7 has seven. Their different outer arrangements help explain different chemical tendencies.

Period

2,8,1 occupies three shells, so it is in period 3 in the simplified model.

Group similarity

Lithium and sodium each have one outer electron in simple shell models, helping explain recurring group-1 reactions.

Flame tests and spectra

Different elements emit characteristic wavelengths because electron energy changes produce characteristic photon energies. Line spectra are more diagnostic than colour alone.

Atomic models

Spectroscopic evidence showed discrete energy interactions that simple earlier models could not fully explain, helping drive refinement of atomic theory.

Common misconceptions
  • The periodic table is ordered by atomic mass rather than proton number.
  • Elements in a group are identical rather than similar in recurring properties.
  • Electrons orbit like planets in fixed literal paths.
  • Period number always equals valence electron number.
  • Flame colour alone is perfect identification.
