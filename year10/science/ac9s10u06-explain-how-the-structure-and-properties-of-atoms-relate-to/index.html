Atomic Structure Explains Periodic Patterns

Electron arrangements repeat across the periodic table, helping explain group patterns and element properties.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

We are learning to explain atomic structure explains periodic patterns using models and evidence.

Success criteria

  • Identify and connect proton number, electron shells, valence electrons.
  • Use a model to explain rather than only describe the concept.
  • Apply the central idea to a curriculum example and justify the connection.
  • Evaluate one model limit, misconception or evidence boundary.
Concept boundary and prerequisites

Must teach

  • Elements are organised by increasing proton number.
  • Periods relate to occupied electron shells and groups to recurring outer-electron patterns.
  • Atomic structure helps explain trends in physical and chemical properties.

Prerequisites

  • Read a labelled scientific diagram or data display.
  • Distinguish an observation from an explanation.
  • Use evidence to support a short scientific statement.

Do not overteach

  • Do not teach orbital notation or quantum numbers as the target.
  • Do not claim the simple Bohr model is a literal view of electrons.
Teaching progression
  1. 1. Read atomic structure
    Use the shared model to foreground proton number.
    Students: Annotate or explain the link involving proton number.
  2. 2. Locate the element
    Use the shared model to foreground electron shells.
    Students: Annotate or explain the link involving electron shells.
  3. 3. Compare a group
    Use the shared model to foreground valence electrons.
    Students: Annotate or explain the link involving valence electrons.
  4. 4. Explain the repeating pattern
    Use the shared model to foreground groups and periods.
    Students: Annotate or explain the link involving groups and periods.
Worked examples

Observe → connect → conclude

Sodium has electron arrangement 2,8,1 and chlorine 2,8,7.

Common misconceptions
  • Elements in a group are identical.
  • The periodic table is ordered by atomic mass.
