Atomic Structure and Periodic Table Patterns

The periodic table is ordered by proton number. Repeating outer-electron arrangements help explain why elements in a group show recurring chemical properties.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What you need to know

Atomic number equals proton number and determines element identity. In a simplified shell model, period relates to occupied shells and main-group position relates to recurring valence-electron patterns. The Bohr-style shell diagram is a useful model, not a literal picture of electron paths.

Periodic-table cheat sheet

Atomic number

Number of protons; identifies element.

Neutral atom

electrons = protons.

Period

In simple shell model, number of occupied electron shells.

Group pattern

Main-group elements share recurring outer-electron arrangements and similar chemistry.

10 important worked examples

1. Identify element

Atom with 11 protons is sodium, regardless of neutron count.

2. Neutral electron count

Chlorine atomic number 17 has 17 electrons when neutral.

3. Shell arrangement

Sodium 2,8,1 has one valence electron; chlorine 2,8,7 has seven. Their different outer arrangements explain different chemical tendencies.

4. Period

2,8,1 occupies three shells → period 3 in the simplified model.

5. Group similarity

Lithium and sodium each have one outer electron in simple shell models, helping explain recurring group-1 reactions.

6. Metal/non-metal properties

Metals often conduct and are malleable; non-metals have different recurring property patterns. Physical tests can help classify but exceptions exist.

7. Periodic pattern

As atomic number increases, outer-shell patterns repeat after shells fill; the periodic table organises this recurrence.

8. Flame tests

Different elements can emit characteristic colours because electron energy changes produce characteristic photon energies; flame colour is evidence, not an element's “normal colour”.

9. Emission spectrum

A line spectrum is more diagnostic than a single visual flame colour because wavelengths can be measured precisely.

10. Spectroscope and atomic models

Spectroscopic evidence showed discrete energy interactions that older simple atomic models could not fully explain, helping drive refinement of atomic theory.

Common misconceptions
  • Periodic table ordered by atomic mass rather than proton number.
  • Group elements are identical rather than similar in recurring properties.
  • Electrons orbit like planets in fixed literal paths.
  • Period number always equals valence electron number.
  • Flame colour alone is perfect identification.
