Exponential Relations: Tables, Graphs and Equations

Recognise exponential change by a constant multiplicative ratio, connect y=abˣ to its graph, and solve exponential equations exactly when possible or approximately using tables and digital tools.

Topic GuideTeacher SlidesHomeworkPracticeTest
What you need to know

For equal increases in x, an exponential relation multiplies y by a constant ratio. A common form is y=abˣ, where a is the initial value and b is the multiplier. If b>1 there is growth; if 0<b<1 there is decay.

Exponential cheat sheet

Table test

Constant first difference → linear.

Constant ratio → exponential.

Rule

y=abˣ

a=y when x=0.

b=consecutive-value ratio for step size 1.

Graph clues

Positive-base exponential graphs stay above/below their horizontal asymptote and curve rather than form a straight line.

Equation strategy

Rewrite both sides with the same base where possible; otherwise use a table/graph/digital solver and state an approximation.

10 important worked examples

1. Identify from a table

y-values 5,10,20,40 have ratio 2 each step, so the relation is exponential.

2. Distinguish linear from exponential

7,11,15,19 has constant difference +4, so it is linear, not exponential.

3. Build a rule

If y=3 at x=0 and doubles each step, y=3·2ˣ.

4. Interpret parameters

For y=120(0.8)ˣ, initial value is 120 and each step retains 80%, a 20% decay.

5. Solve with equal bases

2ˣ=32=2⁵, so x=5.

6. Solve after rearranging

3·2ˣ=24 → 2ˣ=8=2³ → x=3.

7. Compare graph and equation

y=4·2ˣ crosses the y-axis at 4 and doubles over each unit increase in x. Those graph features match a=4 and b=2.

8. Approximate an intersection

To solve x²=2ˣ, graph both functions and zoom near a crossing. An intersection x-coordinate is an approximate solution because both outputs are equal there.

9. Threshold

P=500(1.1)ᵗ. Values: t=7 gives about 974; t=8 gives about 1072. Population first exceeds 1000 at t=8.

10. Population context

A native population growing by 4% per year can be modelled P=P₀(1.04)ᵗ for a limited period. The constant 4% assumption must be checked against habitat and resource constraints.

Common mistakes
  • Calling any curved graph exponential.
  • Checking differences instead of ratios.
  • Confusing 20% growth with multiplier 0.20; the multiplier is 1.20.
  • Reading a as the multiplier in y=abˣ; a is the value at x=0.
  • Reporting a graph solution without saying it is approximate.
10 important questions to solve
  1. Are 6,12,24,48 exponential? State the ratio.
  2. Classify 4,9,14,19.
  3. Write a rule with initial value 7 and multiplier 3.
  4. Interpret y=200(0.65)ˣ.
  5. Solve 3ˣ=81.
  6. Solve 5·2ˣ=40.
  7. For y=6·1.5ˣ, find y when x=2.
  8. Explain why an intersection of y=x² and y=2ˣ solves x²=2ˣ.
  9. For P=1000(1.05)ᵗ, determine whether P exceeds 1200 by t=4.
  10. Give one limitation of constant-percentage population growth.
Solutions with explanations
  1. Yes; ratio 2.
  2. Linear; difference +5.
  3. y=7·3ˣ.
  4. Initial 200; retains 65% each step, so 35% decay.
  5. x=4.
  6. x=3.
  7. 13.5.
  8. At an intersection both functions have the same y-value, so x²=2ˣ.
  9. t=4 gives about 1215.5, so yes.
  10. Resources, carrying capacity or reproduction rate may change over time.

  • E3: use symbolic/digital tools to explore exponential relations and equations. Examples 8–9.
