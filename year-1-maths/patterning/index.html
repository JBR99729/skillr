Parent and teacher guide

Patterning helps younger students notice structure before formal algebra begins. Start with repeating patterns using colours, shapes, sounds or actions, then ask students to describe the rule in words. Once they can copy and continue a pattern, move to missing elements and simple growing patterns. A common mistake is guessing the next item by looking only at the previous item instead of finding the repeating unit. Encourage students to circle or say the core pattern before continuing.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
