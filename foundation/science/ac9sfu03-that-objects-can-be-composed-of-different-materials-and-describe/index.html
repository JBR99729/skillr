AC9SFU03: Objects and Materials

recognise that objects can be composed of different materials and describe the observable properties of those materials

Start lessonTeacher slidesWorksheetPracticeTest
🎯 Learn the key ideaStart here

Learning intention: Objects can be made from one or more materials. Materials can be described using observable properties such as hard, soft, smooth, rough, bendy, stiff, shiny or dull.

Success looks like: Name materials; Describe observable properties; Compare materials; Separate object from material; Match property to use.

Learning routine: Observe object → Name material → Describe property → Compare → Match to use

👀 Model and worked examplesLearn

Object, material and property are different ideas

chair → wood → hard / stiff
cloth → fabric → soft / bendy
spoon → metal → hard / shiny

Think aloud: Describe what is observed first, then use that evidence to explain the idea.

Choose a material because of its properties

towel → absorbent fabric
window → transparent glass
raincoat → water-resistant material

Describe the property you can observe or test.

📚 Key words4 words

object

a thing made for a purpose

material

what an object is made from

property

a feature that can be observed or tested

compare

notice similarities and differences

🧠 Try it in different waysApply

1. Material hunt

Find three classroom objects. Name the material and one observable property of each.

2. Touch and compare

Compare wood and fabric using words such as hard, soft, rough, smooth, bendy or stiff.

3. Best material

Choose a suitable material for a towel, spoon or raincoat and explain using a property.

⚠️ Common mistakes and fixesFix errors
  • Object = material: Say the object name first, then the material it is made from.
  • Using only colour: Use material properties such as hard, soft, rough, smooth, bendy or stiff.
  • Guessing without observing: Touch, look or perform a safe simple test before describing the property.
✅ Quick checkCheck
  • Name one material used to make classroom objects.
  • Which word describes a property: soft or chair?
  • Why might fabric suit a towel?
  • Can one object be made from more than one material?
