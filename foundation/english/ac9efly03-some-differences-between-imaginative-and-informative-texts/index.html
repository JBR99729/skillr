FOUNDATION ENGLISH

Compare imagined events and real information AC9EFLY03

Learning intention: I can compare an imaginative text and an information text using their words, pictures and purpose.

An adult can read and model the examples. Use a short turn or return to a section later.

More examples ↓Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Pictures can support two different text jobs

The supplied imaginative frog scene shows a crowned frog inviting the moon to tea. The information diagram shows labelled frog life stages. The story drawing develops an invented event; the diagram helps explain real information. Both are drawings, so the drawing style cannot decide the text type.

Learn the skill

1. Look for what the text is doing

An imaginative text creates events or ideas. An information text mainly explains a real topic with checkable information. Stories can include realistic details, and information can be enjoyable.

Story: “The frog king invited the moon to tea.” Information: “Frogs hatch from eggs.”

Try it · Which statement gives checkable real-world information?

Frogs hatch from eggs. The frog king inviting the moon is an invented event. A story need not contain magic to be imaginative.

2. Choose information that answers your task

Read the question before choosing a text. A relevant heading, label or fact can lead to the answer. A text about the right animal still needs to contain the needed information.

Question: What do many tadpoles eat? Supplied fact: “Many tadpoles eat algae and other plant material; diets vary.”

Try it · Which text helps, and what answer does it supply?

The supplied frog information helps. It says many tadpoles eat algae and other plant material, while noting that diets vary. Do not turn many into every.

3. Compare the jobs of the pictures

Use the words with each picture. A story image can show a character or event; an information diagram can label stages or parts. Neither photographs nor drawings guarantee a purpose by themselves.

Compare the crowned-frog scene and labelled life-cycle diagram supplied here.

Try it · How does each image help its text?

The crowned frog develops the imagined story event. The labelled stages help explain a frog’s development. The surrounding text and purpose make the difference clear.

Common mistakes

“Realistic stories are information texts.” A story can invent an ordinary event. Look at what the whole text does.

“All drawings are imaginative texts.” Diagrams can explain checkable information.

“One real object makes a text factual.” A real frog can appear in invented events.

10-MINUTE ACTIVITY

Same animal, two text jobs

Read the supplied frog examples. Identify one invented event and one stated fact. Explain what each picture adds. Make an original sentence for each purpose and keep the fact checkable.

Adjust the challenge Starter: point to a fact or invented event. Core: compare word and picture clues. Stretch: explain how a realistic story could still be imaginative.

Adult: read and model when needed. Accept speech, sign, AAC, pointing or a drawing with explanation. Use short turns. A page answer does not prove an actual conversation, reading performance or physical action.

Three tricky questions

1. Does a talking fox in boots suggest imagination?

Yes, in that story those character actions are invented. It is a useful clue together with the surrounding text.

2. A book gives koala facts with labelled photos. What is its likely main purpose?

To inform. Check its actual content; photographs alone are not proof.

3. Must an information page be boring?

No. Enjoyment does not decide the category. The page can be interesting while explaining facts.

FAQ

Can a story teach something real?

Yes. Purposes can overlap. Explain what is mainly happening in the particular text.

Should children memorise photograph equals fact?

No. Use the words, labels, image job and overall purpose together.

More teaching examples and curriculum coverage
Key vocabulary
  • imaginative text — a created story, play or poem that can entertain
  • informative text — a text that gives facts or explains a real topic
  • character — a person, animal or being in a story
  • fact — information that can be checked
  • purpose — the main reason a text was made
Key concept

I can tell some differences between imaginative and informative texts.

Learning goal: I can tell some differences between imaginative and informative texts.

I am ready when I can

  • I can name the two text types.
  • I can find a character or event clue.
  • I can find a fact or explanation clue.
  • I can name the main purpose.
  • I can use more than a picture to justify the decision.

Australian Curriculum elaborations

E1: Distinguish real information from imagined events

Texts can describe checkable real-world information or create imagined characters and events, and some stories mix realistic details with invention.

Think: Read a frog fact and a sentence about a talking frog king. Name what could be checked in the real world. Name the created event and classify each text with a reason.

Try: Which idea can be checked as real information, and which event has been imagined?

A strong answer: Listen to both frog extracts, sort the checkable fact from the imagined event, then state the clue that supports each decision.

Check: The learner identifies a checkable fact and an invented character or event, then links each to the appropriate text type.

If you are stuck: Use one Fact card and one Created event card, and let the learner place each sentence before explaining it.

E2: Select an information text for a task

An informative text can help complete a task by supplying relevant facts, labels, explanations or directions.

Think: Set the task: find what a tadpole eats. Compare a frog story with a labelled frog information page. Select the useful text and point to the fact, heading or label that will help.

Try: Which text will help with this task, and where would you look inside it?

A strong answer: Choose the text that can answer the tadpole question, point to its useful heading, label or fact and explain the choice.

Check: The learner selects a relevant informative text and names a feature or content clue that can answer the task question.

If you are stuck: Offer only two contrasting texts and place the task question beside them while the learner points to the likely source.

E3: Compare images by the job they do

Images in imaginative texts can develop characters, settings or events, while images in informative texts can show, label or explain real information.

Think: Show an illustrated frog adventure and a labelled frog-life-cycle diagram. Describe what each image adds to its text. Connect the image job to the text purpose.

Try: What does each frog image help the reader understand?

A strong answer: Compare the frog story picture with the life-cycle diagram, then explain how each image helps its text communicate.

Check: The learner explains that one image supports an imagined event while the other displays or labels factual information.

If you are stuck: Cover the surrounding words and use simple labels, Story event and Real information, before restoring the whole texts.

Common misconceptions
  • Every text with a picture is imaginative — Read the words and identify whether the picture supports a story event or real information.
  • An informative text cannot be enjoyable — Keep the decision on facts and purpose, because an informative text can still be interesting.
  • One real object makes a text informative — Check whether the whole text tells created events or mainly gives checkable information.
Explain and apply

Check real or imagined

Compare: A frog king invited the moon to tea. Frogs hatch from eggs. Which could be checked in real life?

Answer and teaching guidance

The egg sentence is informative because it can be checked. The frog king event is imaginative because it creates an unreal character and event.

Use more than one clue

Can a picture alone prove whether a whale page is a story or information text?

Answer and teaching guidance

Usually no. Ask for words, labels, facts, characters or author purpose as extra evidence before deciding.

Name the purpose

Which text is mainly made to entertain? Which is mainly made to inform?

Answer and teaching guidance

Imaginative texts often entertain through characters and events. Informative texts teach real-world facts, labels or explanations.

Make both versions

Write or say one created rain event and one checkable rain fact.

Answer and teaching guidance

This makes the difference concrete: a rain cloud singing is imaginative; rain filling a tank is an informative fact if it can be checked.
