AC9EFLY08 · letter formation

Learning focus: I can form most upper- and lower-case letters using the letter shapes I have learnt.

Model it: Worked example: compare three upper-case formation families Worked-model method: start, move, form and compare with the taught model. 1. Watch upper-case T use straight strokes, upper-case O use a continuous curve and upper-case A use slanting strokes with a cross stroke. 2. Form each letter from its named starting point in the school’s taught stroke order. 3. Compare height, direction and recognisable shape, then use the full upper-case reference to choose another letter from each family. Model answer:…

Ask the learner: What is the main idea of letter formation?

Look for: The learner can I can form most upper- and lower-case letters using the letter shapes I have learnt in a fresh example and explain the evidence or reasoning without copying the model.

If they are stuck: If the learner guesses or repeats a rule without evidence, return to the concrete or visual model and ask them to explain what each part shows.
