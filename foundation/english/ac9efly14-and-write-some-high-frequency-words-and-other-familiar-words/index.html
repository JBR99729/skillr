AC9EFLY14 • Foundation English

high-frequency and familiar words

I can read high-frequency and familiar words in meaningful sentences, write them from memory and check every letter in order.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

I can read high-frequency and familiar words in meaningful sentences, write them from memory and check every letter in order.

Learning intention: I can read high-frequency and familiar words in meaningful sentences, write them from memory and check every letter in order.

Success criteria

  • I can recognise taught high-frequency words.
  • I can read a familiar word in context.
  • I can write a taught word from memory.
  • I can check every letter in order.
  • I can use the word meaningfully in a sentence.
Key vocabulary
  • high-frequency word — a word that appears very often in texts
  • familiar word — a word known from everyday life or repeated reading
  • recognise — know something when you see or hear it
  • memory — what the mind keeps and can recall
  • context — the sentence or situation around a word
  • check — compare a response carefully with a model
Model and guided application

Worked example: learn the high-frequency word the

Worked-model method: look, say, cover, write and check every letter.

1. Read the sentence, ‘The dog is on the rug,’ and point to the printed word the.2. Say the whole word, notice its three letters in order and cover it.3. Write the from memory, uncover the model and check the first, middle and final letters.

Model answer: The word the is read as a whole in context and written accurately after every letter is checked.

Worked example: learn a personally familiar word

Worked-model method: look, say, cover, write and check every letter.

1. Choose the learner’s printed name from a small set of classroom name cards.2. Say the name, trace its letters with a finger and notice the upper-case first letter.3. Cover, write the name from memory, then uncover and compare every letter in order.

Model answer: A familiar name becomes easier to read and write when the learner connects its meaning with its complete letter sequence.

Learning activities
  1. Word hunt — Find one target high-frequency word several times in a shared text and read each sentence.
    same word • different sentence places
  2. Look, say, cover, write — Practise one useful word with the four-step routine, then compare every letter.
    accuracy before speed
  3. Familiar labels — Read and copy names or labels that matter in the classroom, then use one in a sentence.
    name card • room label • class topic word
Australian Curriculum elaborations

E1: Read and write high-frequency words in texts

High-frequency words become readily available when learners meet them repeatedly in meaningful shared and independent reading, then practise writing the complete sequence.

Teacher: Find the printed word the in 'The dog is on the rug.' Read it in the sentence and notice all three letters. Cover, write the and compare every letter before rereading the sentence.

Ask: Which whole word appears often here, and how will you check every letter after writing it?

Students: Find the target high-frequency word in a sentence, read it, use look, say, cover and write, then check every printed letter.

Look for: The learner recognises a taught high-frequency word in connected text, writes it from memory and checks its complete letter sequence.

If incorrect: Keep the model visible for the first copy, say the word in a sentence and cover it for only a brief memory attempt.

E2: Read and write personally familiar words

Names of people, characters, places and school contexts become familiar through meaningful repeated use.

Teacher: Select the learner's name or a familiar character name. Read it, trace the complete sequence and notice its opening capital where appropriate. Cover, write and compare each letter in order.

Ask: What makes this word familiar to you, and which letters confirm that it is the right word?

Students: Choose a personally familiar name or label, read the complete word, cover and write it, then compare every letter in order.

Look for: The learner reads a personally familiar word, writes or copies it accurately and verifies the full sequence.

If incorrect: Use a photo or character picture beside the name card, begin with letter tiles and move to writing when the order is secure.

Common misconceptions and quick fixes
  • Only the first letter needs to look right — Track from first letter to last and compare the complete written word with the model.
  • Remembering the outside shape is enough — Name or point to the letters in order so a change inside the word is noticed.
  • A memorised word never needs context — Read the word in a complete sentence and check that its meaning and grammar fit.

  • Why is a learner’s name a familiar word?
