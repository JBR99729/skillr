Comparing Length, Mass, Capacity and Duration

Choose the attribute you are comparing and use a fair direct comparison before saying longer, shorter, heavier, lighter, holds more or takes longer.

Key vocabulary
  • length — how long an object is
  • mass — how heavy an object feels
  • capacity — how much a container can hold
  • duration — how long an event takes

Learning activities
  • Line up a spoon and fork at the same endpoint and compare length.
  • Use a balance or heft two pantry objects to compare mass.
  • Pour the same material between containers to compare capacity.
Australian Curriculum elaborations

E1: Match comparison words to attributes

Objects and events can be compared in different ways. The comparison word must name the attribute being considered: length, mass, capacity or duration.

long / short → lengthheavy / light → massholds more → capacitytakes longer → duration

Teacher: Name what is being compared: length, mass, capacity or duration. Choose words that belong to that attribute. Complete a comparison sentence and give evidence.

Ask: First name the attribute. Then choose a word that compares that attribute.

Look for: Sort long, heavy, holds less and takes longer under length, mass, capacity or duration, then use each in a comparison sentence.

E2: Compare length directly and fairly

A direct length comparison is fair when objects are straight and aligned at the same starting point. The endpoint that extends farther shows the longer object.

|──── spoon|──────── forksame starting point

Teacher: Place the objects beside each other and straighten them. Align one end of each object at the same starting line. Compare the other endpoints and state which is longer or shorter.

Ask: The starts are even. This endpoint goes farther, so this object is longer.

Look for: Line up two pencils at one end, identify the longer pencil and explain how the alignment provides evidence.

E3: Compare duration from the same start

Duration is how long an event lasts. When two events begin together, the event that finishes later has the longer duration.

event A startsevent B starts→later finish = longer duration

Teacher: Choose two observable actions and begin them at the same signal. Watch until the first action finishes, while noting whether the other continues. State which lasted longer or shorter and describe the evidence.

Ask: They started together. This event was still happening after the other stopped, so it lasted longer.

Look for: Start two actions together and explain which has the longer duration using what happened at the finish.

E4: Compare mass by hefting

Mass describes how heavy an object is. Hefting or using a balance provides direct evidence; an object's size or length does not determine its mass.

tin↔ heft ↔marshmallow packetheavier / lighter

Teacher: Predict which object may be heavier, while naming the prediction as a guess. Hold one object in each hand and gently heft them, or place them on a balance. Use the evidence to state which is heavier and which is lighter.

Ask: Size tells us how much space an object takes up. Hefting gives evidence about its mass.

Look for: Heft two safe classroom objects, identify the heavier and lighter object and explain why size alone was not enough.

Common misconceptions and quick fixes
  • Endpoints not aligned — Start both objects at the same point before comparing length.
  • Tall container means more — Test capacity by filling or pouring instead of judging height.
  • Looks heavier — Use hefting or a balance rather than appearance alone.
Quick checks and mastery

Quick checks

  • Which word compares length: heavier or longer?
  • Why must two pencils start at the same endpoint to compare length?
  • How could you check which of two containers holds more?
  • Two activities start together. One finishes later. Which took longer?
