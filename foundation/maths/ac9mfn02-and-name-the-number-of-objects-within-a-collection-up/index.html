What students learn in AC9MFN02

This unit helps students build a clear, usable understanding of Subitising to 5. The goal is not to memorise one answer pattern. Students should be able to explain the idea, recognise it in a new example and apply it in a short practice or worksheet task.

  • Start with the main idea: recognise and name the number of objects within a collection up to 5 using subitising.
  • Use concrete examples, pictures, oral explanation and short written responses before moving to independent practice.
  • recognising how many objects are in a collection or in images on a card with a quick look and saying the associated number without counting playing instructive card games that rely on the recognition of numbers represented in different ways; for example, playing memory games, matching pairs of quantities on dot cards or similar where the arrangement on each is different; using subitising to compare and order collections and to say who has more when sharing items in a game
  • Finish with mixed questions so students must choose the correct strategy rather than copy the last example.

Learning intentions

  • recognise and name the number of objects within a collection up to 5 using subitising
  • recognising how many objects are in a collection or in images on a card with a quick look and saying the associated number without counting
  • playing instructive card games that rely on the recognition of numbers represented in different ways; for example, playing memory games, matching pairs of quantities on dot cards or similar where the arrangement on each is different; using subitising to compare and order collections and to say who has more when sharing items in a game

Success criteria

  • I can show the skill using objects, pictures, actions or numbers.
  • I can use the key vocabulary accurately.
  • I can answer a new example without copying the previous one.
  • I can explain or demonstrate how I know.

Key vocabulary

Recommended teaching sequence

  1. 1

    Recognise one to three objects instantly.

  2. 2

    Recognise familiar dice and five-frame patterns.

  3. 3

    See the same quantity in different arrangements.

  4. 4

    Describe a quantity as smaller parts, such as 3 and 2.

  5. 5

    Compare two small collections without counting every object.

  6. 6

    Apply subitising in games and quick-image tasks.

Hands-on activities

Activity 1

Flash dot cards for two seconds.

Activity 2

Match different dot patterns showing the same total.

Activity 3

Build five in two different ways.

Activity 4

Play a quick-look more-or-fewer sort.

Differentiation

Support

Begin with structured patterns and allow a longer look before gradually shortening display time.

Extension

Ask students to explain the parts they saw and create several patterns for the same total.

Assessment plan

  1. Before teaching: use a few practical prompts to check prior knowledge.
  2. During teaching: select questions from the 56-question Practice bank across multiple response types.
  3. Readiness check: Can the student identify up to five without one-by-one counting and explain how the parts make the whole?
  4. After teaching: administer the separate 24-question Test bank without previewing its answers with students.

Common mistakes to watch for

  • Rushing to a rule before checking the concrete model, drawing or number sentence.
