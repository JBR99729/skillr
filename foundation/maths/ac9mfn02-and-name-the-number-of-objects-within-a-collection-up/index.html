Subitising to 5

See a small collection and know how many there are without counting every object one by one.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

See a small collection and know how many there are without counting every object one by one.

Learning intention: I can see a small collection and know how many there are without counting every object one by one.

Success criteria

  • I can recognise 1–5 quickly.
  • I can see parts within a quantity.
  • I can match equal quantities.
  • I can compare more / fewer / same.
  • I can explain without one-by-one counting.
Key vocabulary
  • subitise — see how many without counting one by one
  • quantity — how many objects there are
  • parts — smaller groups seen inside a whole group
  • arrangement — the way objects are placed

Learning activities
  • Flash a dot card briefly; student says the quantity and how they saw it.
  • Match two different dot arrangements that show the same number.
  • Show two cards and ask which has more, fewer or the same.
Australian Curriculum elaborations

E1: Recognise a small quantity with a quick look

Subitising means recognising how many are in a small collection without counting each object one by one. Structured arrangements help the eyes see smaller parts inside the whole.

+→5
I saw 4 and 1 more

Teacher: Flash the collection briefly, then cover it. Ask for the total before allowing one-by-one counting. Ask which smaller groups the student saw.

Ask: I did not need to count every dot. I saw parts I already knew and combined them.

Look for: Flash 3 dots with 2 underneath. Ask for the total and an explanation such as ‘I saw 3 and 2, so I knew 5’.

E2: Match, compare and order different representations

A quantity stays the same when its objects are rearranged. Once quantities are recognised, they can be matched as equal or ordered from fewer to more.

<<
different arrangements can still show the same total

Teacher: Subitise each card and name its quantity. Match cards that show equal totals in different arrangements. Compare or order the totals and explain the visual evidence.

Ask: The arrangement changed, but no dot was added or removed, so the number stayed the same.

Look for: Match two differently arranged cards showing 5, then order cards for 3, 4 and 5 and explain which has more.

Common misconceptions and quick fixes
  • Counting every dot — Use structured patterns and ask what parts the student sees.
  • Arrangement = new number — Rearrange the same counters and confirm the total stays the same.
  • Names the pattern, not total — Always finish with “How many altogether?”
Quick checks and mastery

Quick checks

  • How many? ● ● / ● ●

Mastery

  • Recognise 1–5 quickly
  • See parts within a quantity
  • Match equal quantities
  • Compare more / fewer / same
  • Explain without one-by-one counting
