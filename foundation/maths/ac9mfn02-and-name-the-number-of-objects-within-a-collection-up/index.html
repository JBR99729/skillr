AC9MFN02 • Foundation Maths

Subitising to 5: recognise a quantity without counting

Recognise and name the number of objects within a collection up to 5 using subitising.

Topic guideWorksheetPracticeTest

What students learn in AC9MFN02

Students learn to recognise very small quantities quickly rather than counting every object one by one. Dot cards, fingers, dice patterns and small collections help children connect a visual quantity with its number name.

  • Look briefly at collections from 1 to 5 and say how many are present.
  • Recognise the same quantity when objects are arranged differently.
  • Compare small collections and explain which has more or fewer.
  • Move between real objects, dot patterns and spoken number names.

AC9MFN02 is the exact Australian Curriculum v9.0 code. Other jurisdictions organise early number learning differently, so the entries below are labelled direct or closest alignment rather than claimed as official equivalences.
