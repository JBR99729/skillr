AC9MFN02 - AC9MFN02: Recognise and name the number of objects within a collection up to 5 using subitising
Example 1

recognising how many objects are in a collection or in images on a card with a quick look and saying the associated number without counting

Example 2

playing instructive card games that rely on the recognition of numbers represented in different ways; for example, playing memory games, matching pairs of quantities on dot cards or similar where the arrangement on each is different; using subitising to compare and order collections and to say who has more when sharing items in a game

Example 3

E1 visual teaching: recognise a quantity with a quick look: Flash for two seconds: ● ● ● ● ● What the eyes can see: [● ● / ● ●] + [●] → 4 + 1 → 5 Teacher model: cover the dots and say, “I did not count every dot. I saw a group of 4 and 1 more. Four and one make 5.” Flash a new arrangement and ask the student to name the total and the parts they noticed. E1 guided check: briefly show ● ● ● with ● ● underneath. Cover it. Ask, “How many? What groups did you see?” A secure response names 5 without recounting and explains “3 and 2”.

Example 4

E2 visual teaching: match, compare and order different arrangements: Same quantity: Card A: ● ● ● ● ● = Card B: ● ● / ● ● ● Compare: Card B: ● ● / ● ● ● &gt; Card C: ● ● / ● ● Conclusion: 5 is one more than 4. Teacher model: say, “A and B look different, but both show 5 because no dot was added or removed. C shows 4, so A and B have more.” Match cards with equal quantities first, then arrange cards from fewer to more. E2 guided check: show differently arranged cards for 3, 4 and 5. Ask the student to match equal quantities, order them and explain which collection has more using the visual evidence.

Review hints

  • Subitising means seeing how many without counting each object one by one.
  • Look for smaller familiar parts: 5 can be seen as 4 and 1, or 3 and 2.
  • Moving the same objects into a new arrangement does not change how many there are.
