Repeating Patterns

A repeating pattern has a smallest unit that repeats again and again in the same order.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

A repeating pattern has a smallest unit that repeats again and again in the same order.

Learning intention: I can a repeating pattern has a smallest unit that repeats again and again in the same order.

Success criteria

  • I can recognise repetition.
  • I can copy a pattern.
  • I can identify smallest unit.
  • I can continue and repair.
  • I can create and explain a pattern.
Key vocabulary
  • pattern — an arrangement that follows a rule
  • repeat — happen again in the same order
  • unit — the smallest part that repeats
  • continue — add the next correct part

Learning activities
  • Copy a clap-stamp pattern, then continue it.
  • Build a bead pattern and circle or separate the repeating unit.
  • Place one wrong item in a pattern and ask students to repair it.
Australian Curriculum elaborations

E1: Copy patterns in many forms

A repeating pattern is made by repeating the same unit in the same order. The unit may be made from objects, shapes, sounds or movements.

red blue greenred blue greenrepeat unit: ABC

Teacher: Experience the whole pattern by looking, listening or moving. Find the smallest unit that repeats in the same order. Copy the complete unit, then repeat it to continue the pattern.

Ask: The unit is the smallest part that repeats. I must repeat every part of it in the same order.

Look for: Continue red–blue–green for two more units and mark the smallest repeating unit.

E2: Find patterns in daily routines

Repeated arrangements and actions occur in familiar routines. Naming the repeated unit helps us predict what comes next and organise a task consistently.

platecupplatecup

Teacher: Notice an arrangement or action that occurs more than once. Say the repeated unit from beginning to end. Use the unit to predict and complete the next part of the routine.

Ask: I know what comes next because the same unit repeats in the same order.

Look for: Describe the repeating unit in a plate–cup table setting and use it to predict the next two items.

E3: Discuss a digitally created pattern

Digital tools can create an image that looks complex, but a mathematical repeating pattern still needs an identifiable unit repeated in the same order.

▲ ● ▲ ●→triangle-circle repeats

Teacher: Inspect the digital image and identify the features that might repeat. Frame the smallest possible unit and compare it with later sections. Confirm the unit repeats exactly, then describe or continue it.

Ask: An image can look patterned without having a repeating unit. I need to show exactly what repeats.

Look for: Mark the repeating unit in ▲ ● ▲ ● ▲ ● and explain how you verified it.

E4: Observe culturally situated patterns

Patterns on Country/Place and in First Nations artworks, performances and material cultures are culturally situated. Mathematical noticing must sit alongside attribution, context and respect for Indigenous Cultural and Intellectual Property.

approved source→observe in context→describe respectfully

Teacher: Choose a community-approved or institutionally authorised source and name the artist, creator, People and context provided. Observe or listen for a repeated element without separating it from the source's explanation. Describe the visible, heard or movement-based repeat; do not copy culturally specific motifs or designs.

Ask: We can notice mathematical repetition while respecting that this work and its knowledge belong in a specific cultural context.

Look for: From the selected authorised source, identify one permitted repeated element and describe it while retaining its attribution and context.

Common misconceptions and quick fixes
  • Repeats only the last item — Identify the whole smallest unit before continuing.
  • Random sequence called a pattern — Check that the same unit repeats in the same order.
  • Copies colours only — Translate the same structure into sounds, movements or shapes.

Quick checks

  • What is the repeating unit in red-blue-green-red-blue-green?
  • Which item is wrong: ■ ○ ■ ○ ○ ○?
  • Create a repeating pattern with a three-item unit.
