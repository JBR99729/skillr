Repeating patterns

Find the repeating unit before continuing a pattern. In red, blue, red, blue, the unit is red-blue; recognising that whole unit helps children copy, extend and create patterns.

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Find the unit in circle, triangle, circle, triangle, circle, triangle

Why it works: The whole two-element unit occurs again. The last shape alone does not describe the rule.

Learn the skill

1. Find the repeating part

A repeating pattern has a part that occurs again in the same order. The repeating part may have two, three or more elements.

Try it · Say the repeating part in clap, clap, tap, clap, clap, tap.

Clap, clap, tap. Keep both claps in the unit.

2. Copy the order exactly

Copying means making the displayed sequence again from its start. Preserve order and the attributes that define the pattern.

Try it · An adult performs stamp, clap, clap, stamp, clap, clap. Perform the same sequence.

Stamp, clap, clap, stamp, clap, clap. An adult checks the actual action order.

3. Continue from the current position

To continue, find where the shown sequence stops within its repeating part. Then add the next elements in order.

Try it · Continue clap, tap, click, clap … with the next four sounds.

Tap, click, clap, tap. The last shown clap already starts the second unit. Perform and check the sounds.

Common mistakes

Not every sequence repeats. One circle, two circles, three circles is growing, rather than the same unit restarting.

Copying the same number of objects is not enough; their order must match.

Alternating based only on the final object fails when the unit has adjacent repeated elements.

10-MINUTE HOME ACTIVITY

Build a repeating pattern

Use two colours of blocks to make red, blue, blue. Repeat that unit three times. Cover the last unit and ask the learner to rebuild it.

Adjust the challenge: Start with two alternating colours. Extend by asking the learner to make the same pattern with sounds.

FAQ

What part repeats?

In red, blue, blue, red, blue, blue, the repeating unit is red, blue, blue.

Learn the idea

Build understanding one step at a time

Learning goal: Find the part that repeats, copy it and continue it. Explore objects, pictures, sounds and actions with the same careful thinking. Open a focus, follow its example, then try the question before checking the answer. An adult can read instructions aloud.

1. Find the repeating part

A repeating pattern has a part that occurs again in the same order. The repeating part may have two, three or more elements.

Worked example: Find the unit in circle, triangle, circle, triangle, circle, triangle.

  1. Look for a chunk that restarts.
  2. Point to circle, triangle in each repeat.
  3. Say “Circle, triangle is the part that repeats.”

Why it works: The whole two-element unit occurs again. The last shape alone does not describe the rule.

Watch for: Not every sequence repeats. One circle, two circles, three circles is growing, rather than the same unit restarting.

Try it: Say the repeating part in clap, clap, tap, clap, clap, tap.

Check the answer

Clap, clap, tap. Keep both claps in the unit.

2. Copy the order exactly

Copying means making the displayed sequence again from its start. Preserve order and the attributes that define the pattern.

Worked example: Copy square, square, circle, square, square, circle.

  1. Start with the first square.
  2. Place a second square, then a circle.
  3. Repeat the same three-element unit and compare item by item.

Why it works: Two adjacent squares are part of the rule. Removing one changes the pattern.

Watch for: Copying the same number of objects is not enough; their order must match.

Try it: An adult performs stamp, clap, clap, stamp, clap, clap. Perform the same sequence.

Check the answer

Stamp, clap, clap, stamp, clap, clap. An adult checks the actual action order.

3. Continue from the current position

To continue, find where the shown sequence stops within its repeating part. Then add the next elements in order.

Worked example: Continue square, square, circle, square, square …

  1. Identify the unit: square, square, circle.
  2. The last two squares begin the next unit. A circle comes next.
  3. After that circle, restart: square, square.

Why it works: The next three elements are circle, square, square. The ending may be only part of a complete unit.

Watch for: Alternating based only on the final object fails when the unit has adjacent repeated elements.

Try it: Continue clap, tap, click, clap … with the next four sounds.

Check the answer

Tap, click, clap, tap. The last shown clap already starts the second unit. Perform and check the sounds.
