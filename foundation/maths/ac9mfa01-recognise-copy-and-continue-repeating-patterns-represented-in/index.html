🎯 Learn the key ideaStart here

Learning intention: A repeating pattern has a smallest unit that repeats again and again in the same order.

Success looks like: Recognise repetition; Copy a pattern; Identify smallest unit; Continue and repair; Create and explain a pattern.

Learning routine: Notice → Copy → Find repeat → Continue → Fix → Create

⚠️ Common mistakes and fixesFix errors
  • Repeats only the last item: Identify the whole smallest unit before continuing.
  • Random sequence called a pattern: Check that the same unit repeats in the same order.
  • Copies colours only: Translate the same structure into sounds, movements or shapes.
✅ Quick checkCheck
  • Continue: ▲ ● ▲ ● ___ ___
  • What is the repeating unit in red-blue-green-red-blue-green?
  • Which item is wrong: ■ ○ ■ ○ ○ ○?
  • Create a repeating pattern with a three-item unit.

🇦🇺 Australian Curriculum coverageE1–E4

Content description: recognise, copy and continue repeating patterns represented in different ways

These are curriculum teaching examples used as a breadth check, not separate mandatory outcomes.

E1

recognising, copying and describing different repeating patterns using materials, shapes, sounds and movements during activities and play; for example, making a bead necklace and describing the pattern they have created, such as, “red, blue, green, red, blue, green, red, blue, green”; copying repeating patterns of drumbeats or dance moves during music activities

Learning connection: A repeating pattern has a smallest unit that repeats again and again in the same order.

E2

recognising repeating patterns used at home and in daily activities to help make tasks easier or to solve problems; for example, setting the table to eat

Learning connection: A repeating pattern has a smallest unit that repeats again and again in the same order.

E3

recognising and discussing repeating patterns in images created using dynamic geometric software or a generative artificial intelligence tool, describing what has been repeated in the pattern

Learning connection: A repeating pattern has a smallest unit that repeats again and again in the same order.

E4

recognising and describing repeating patterns that can be observed on Country/Place and in First Nation Australians artwork, cultural performances and material cultures; for example, shell and seed necklaces, dances and songs

Learning connection: A repeating pattern has a smallest unit that repeats again and again in the same order.
