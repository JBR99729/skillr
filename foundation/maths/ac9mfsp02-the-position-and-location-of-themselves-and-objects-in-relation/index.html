Position and Location

Position words describe where something is in relation to another person, object or place.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Position words describe where something is in relation to another person, object or place.

Learning intention: I can position words describe where something is in relation to another person, object or place.

Success criteria

  • I can use position words.
  • I can name reference object.
  • I can follow instructions.
  • I can give movement instructions.
  • I can describe a precise location.
Key vocabulary
  • position — where something is
  • location — the place where something can be found
  • reference object — the object used to explain where another object is
  • route — a path from one place to another

Learning activities
  • Place a toy from spoken instructions using one position word at a time.
  • Hide an object and describe its location precisely.
  • Create a short obstacle route and have a partner follow the movement instructions.
Australian Curriculum elaborations

E1: Locate an item relative to another item

A position statement describes where one item is in relation to a named reference object. Words such as inside, beside, under and on top of are incomplete without the reference.

● inside □● underneath ━● on top of ▭

Teacher: Identify the item being located. Name the reference object. Join both with a precise position word in a complete sentence.

Ask: The position word tells the relationship, and the reference object tells what the item is positioned against.

Look for: Place a counter on top of a book, then describe its position in a complete sentence with a reference object.

E2: Move, place and describe

Directions can describe a sequence of movements through a familiar space. Completing one instruction at a time preserves the order and leads to the intended finishing position.

start beside chair→ under table →finish inside hoop

Teacher: Identify and describe the starting position. Follow each movement instruction in the stated order. Stop at the finish and describe the final position relative to a named object.

Ask: I will complete the first direction before I act on the second direction.

Look for: Follow a two-step movement instruction and describe the finishing location using a clear reference.

E3: Track a robotic toy

An algorithm is an ordered set of instructions. Movement instructions change an object's location; position statements describe where it is at a checkpoint.

robot beside box→ forward → turn →robot behind chair

Teacher: Describe the robot's starting position relative to a landmark. Execute one instruction at a time without adding an unlisted move. Pause at checkpoints and describe the new position before continuing.

Ask: ‘Move forward’ tells the robot what to do. ‘Behind the chair’ describes where it finishes.

Look for: Move a toy using two instructions and describe its position at the start, midpoint and finish.

E4: Learn position through an instructive game

A specifically sourced First Nations children's instructive game can provide an authentic setting for describing position and movement when its rules and cultural attribution are preserved.

authorised source→play as documented→describe position

Teacher: Select an authorised description of Thapumpan and acknowledge the Wik-Mungkan Peoples of Cape Bedford. Teach and play the game according to that source without inventing or blending rules. At a documented moment, describe a player's movement or position relative to another participant, object or location.

Ask: We are learning this game from a source that acknowledges the Wik-Mungkan Peoples. We will follow the source and describe the positions we actually observe.

Look for: After the approved game, describe one documented movement and resulting position using a precise reference object or person.

Common misconceptions and quick fixes
  • Says “over there” — Name a reference object: beside the chair, under the desk, inside the box.
  • Changes viewpoint silently — Keep the same reference point or explain the viewpoint change.
  • Follows only first step — Repeat a short route in order and check each move.
Quick checks and mastery

Quick checks

  • Where is a ball if it is inside a box?
  • Give one instruction that places a toy under a chair.
  • Which is more precise: “there” or “beside the desk”?
  • Describe a two-step route from a door to a table.

Mastery

  • Use position words
  • Name reference object
  • Follow instructions
  • Give movement instructions
  • Describe a precise location
