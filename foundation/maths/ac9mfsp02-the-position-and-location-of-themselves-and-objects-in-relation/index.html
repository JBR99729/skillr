Describe position and location

Say where you or an object are in relation to something else. Follow, give and check clear position instructions.

Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Describe the pictured counter

Why it works: The reference makes the location understandable to someone else.

Learn the skill

1. Name the object you compare with

Position words tell a relationship. Say both what you are locating and the reference object: “The counter is above the box.”

Try it · Put a block inside a tray. Describe it, naming both objects.

The block is inside the tray. The tray is the reference object.

2. Use and check position instructions

Words such as in, on, under, above, beside, in front of and behind describe different relationships. Act out the instruction and check.

Try it · Move a block from inside a box to beside the box. What changed?

It is now beside the box and no longer inside it. Both descriptions name the same reference.

3. Combine two location clues

Two clues can locate one object more precisely. Check each clue against the same arrangement.

Try it · Place a toy beside a box and behind a chair, with everyone looking from the same side. Explain both clues.

The actual placement must be beside the box and behind the chair from the agreed viewpoint. Move it if either clue fails.

Common mistakes

“It is above” leaves out what it is above. “The box is above the counter” reverses the relationship.

Beside can be on either side. If a particular side matters, say so with a clear viewpoint.

An object can have several relationships at once. “Between the blocks” does not prevent it also being “in front of the toy”.

10-MINUTE HOME ACTIVITY

Guide a toy to a landmark

Put a toy, a cup and a book on a table. Ask the learner to place the toy beside the cup, between the cup and book, and behind the book. Swap roles.

Adjust the challenge: Start with next to and under. Extend by explaining the position from another person's view.

FAQ

Why name a landmark when describing a position?

A landmark tells the listener what to use as a reference, as in beside the cup.

Learn the idea

Build understanding one step at a time

Learning goal: Say where you or an object are in relation to something else. Follow, give and check clear position instructions. Open a focus, follow its example, then try the question before checking the answer. An adult can read instructions aloud.

1. Name the object you compare with

Position words tell a relationship. Say both what you are locating and the reference object: “The counter is above the box.”

Worked example: Describe the pictured counter.

  1. Find the counter.
  2. Name the reference: the box.
  3. Say “The counter is above the box.”

Why it works: The reference makes the location understandable to someone else.

Watch for: “It is above” leaves out what it is above. “The box is above the counter” reverses the relationship.

Try it: Put a block inside a tray. Describe it, naming both objects.

Check the answer

The block is inside the tray. The tray is the reference object.

2. Use and check position instructions

Words such as in, on, under, above, beside, in front of and behind describe different relationships. Act out the instruction and check.

Worked example: Place a toy under a chair.

  1. Identify the toy and chair.
  2. Move the toy into the space below the chair seat.
  3. Say “The toy is under the chair” and check together.

Why it works: Following an instruction connects the word to a real position.

Watch for: Beside can be on either side. If a particular side matters, say so with a clear viewpoint.

Try it: Move a block from inside a box to beside the box. What changed?

Check the answer

It is now beside the box and no longer inside it. Both descriptions name the same reference.

3. Combine two location clues

Two clues can locate one object more precisely. Check each clue against the same arrangement.

Worked example: Place a counter between two blocks and in front of a toy.

  1. Make a clear pair of separated blocks.
  2. Put the counter in the gap between them.
  3. With everyone facing the agreed direction, check it is also in front of the toy.

Why it works: A correct location meets both conditions, not just the first.

Watch for: An object can have several relationships at once. “Between the blocks” does not prevent it also being “in front of the toy”.

Try it: Place a toy beside a box and behind a chair, with everyone looking from the same side. Explain both clues.

Check the answer

The actual placement must be beside the box and behind the chair from the agreed viewpoint. Move it if either clue fails.

4. Keep left and right clear

Left and right depend on the reference person or view. People facing each other have different left sides.

Worked example: Describe the star in the picture from your view.

  1. Look at the picture as the reader.
  2. Find the box as reference.
  3. The star is to the left of the box from this view.

Why it works: Naming the view removes an otherwise unclear direction.

Watch for: Do not assume your left is someone else’s left when you face each other. Stand facing the same way before comparing.

Try it: Stand beside a partner, both facing the same way. Raise your left hands, then place a block to your left.

Check the answer

Check using the agreed body direction. Both left hands point to the same side when you face the same way. The block is on that side; its exact location is practical, not fixed by a text answer.
