AC9MFN01 • Foundation Maths

Numbers to 20

Connect a real quantity, a visual model and a written numeral, then use number order and one more/one less from 0 to 20.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Connect a real quantity, a visual model and a written numeral, then use number order and one more/one less from 0 to 20.

Learning intention: I can connect a real quantity, a visual model and a written numeral, then use number order and one more/one less from 0 to 20.

Success criteria

  • I can build a number.
  • I can match quantity to numeral.
  • I can order numbers.
  • I can find one more / one less.
  • I can explain zero.
Key vocabulary
  • quantity — how many objects there are
  • numeral — a written mark that names a number
  • order — where a number comes when we count
  • zero — the number used when there are no objects

Learning activities
  • Fetch 9 objects and count each as it is placed down.
  • Show 14 and ask for the number before and after.
  • Count 0 → 20, then 20 → 0.
Australian Curriculum elaborations

E1: Collect and match a requested quantity

A number tells how many are in a collection. Accurate counting means pairing one number word with each object; the final number word tells the total.

hear “nine”→↔9

Teacher: Hear or read the requested number. Move one object for each number word. Say the total and match the numeral.

Ask: The objects, the spoken word ‘nine’ and the numeral 9 all name the same amount.

Look for: Collect 9 objects, prove each was counted once and match them to the numeral 9.

E2: Order numbers and find one more or one less

Numbers have a fixed order. Moving one place forward adds one; moving one place backward removes one.

11121314151617
one less ← 14 → one more

Teacher: Build the starting number. Add or remove exactly one object. Locate both numbers on a 0–20 number line.

Ask: One more is the next number because the collection grew by exactly one—not because we guessed the next word.

Look for: Show 14. Find one less and one more, then explain each answer using counters or the number line.

E3: Use ordinal and positional language

Cardinal numbers tell how many. Ordinal words tell position in an ordered line, and position depends on where the line begins.

1st red2nd blue3rd green
red is before blue • blue is between red and green

Teacher: Choose and mark the starting end. Touch each item in order. Describe its place using first, second, third, before, after or between.

Ask: ‘Three toys’ tells how many. ‘The third toy’ tells which position.

Look for: From a marked starting end, identify the second toy and describe it using two position words.

E4: Read and write numerals in familiar places

A numeral is a written symbol for a number. We see numerals in many contexts, where they may show an amount, an order or a label.

door 7bus 12page 20→read • build • write

Teacher: Notice the numeral in context. Say its number name. Build the number when it represents an amount, then trace and write it.

Ask: The numeral 12 keeps its name wherever we see it, even when it is being used as a label.

Look for: Find a familiar numeral, read it, copy it correctly and explain whether it shows an amount, order or label.

E5: Connect quantity, number name and numeral

A collection, a spoken number name and a written numeral can look or sound different while representing the same number.

↔“five”↔5

Teacher: Act or tell a short counting story. Count and say the total. Choose the matching numeral and show the number another way.

Ask: The arrangement changed, but no shells were added or removed, so the number stayed five.

Look for: Show five objects in two arrangements, say ‘five’, select 5 and explain why all representations match.

Common misconceptions and quick fixes
  • Double counting — Move each object once as it is counted.
  • Teen reversal — Rebuild 14 as 10 + 4 before writing it.
  • Zero forgotten — Show an empty collection and label it 0.
Quick checks and mastery

Quick checks

  • Count 8 dots: ● ● ● ● ● ● ● ●
  • Order 16, 5, 11, 2 from smallest to largest.
  • Complete: ___ ← 14 → ___
  • Mia has 9 counters and gets 1 more. How many now?

Mastery

  • Build a number
  • Match quantity to numeral
  • Order numbers
  • Find one more / one less
  • Explain zero
