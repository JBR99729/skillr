What students learn in AC9MFSP01

This unit helps students build a clear, usable understanding of Sort, name and create familiar shapes; recognise and describe familiar.... The goal is not to memorise one answer pattern. Students should be able to explain the idea, recognise it in a new example and apply it in a short practice or worksheet task.

  • Start with the main idea: sort, name and create familiar shapes; recognise and describe familiar shapes within objects in the environment, giving reasons.
  • Use concrete examples, pictures, oral explanation and short written responses before moving to independent practice.
  • sorting a collection of shapes into groups based on different features such as the number of sides, colour or size, and describing how they have been sorted creating a picture using a variety of shapes and a range of materials, including objects to trace around, describing the shapes they have created or used and sharing why they chose each shape in their picture
  • Finish with mixed questions so students must choose the correct strategy rather than copy the last example.

Curriculum coverage and elaborations

Question banks for this unit should draw from the content description and the eligible elaborations below. First Nations-specific notes are kept out of generated question coverage unless they are part of the core concept.

  • Content description: sort, name and create familiar shapes; recognise and describe familiar shapes within objects in the environment, giving reasons
  • E1: sorting a collection of shapes into groups based on different features such as the number of sides, colour or size, and describing how they have been sorted
  • E2: creating a picture using a variety of shapes and a range of materials, including objects to trace around, describing the shapes they have created or used and sharing why they chose each shape in their picture
  • E3: creating familiar shapes using groups of people; for example, holding hands and creating a circle
  • E4: recognising and naming shapes that are (close to) rectangles, squares, triangles and circles in component parts of everyday items; for example, on bicycles, toy vehicles or kitchen pantry items
  • E5: describing and naming shapes within objects that can be observed on Country/Place, recreating and sorting into groups based on their shape

How to use this unit

Read the topic guide, download the teacher slide for instruction, complete the printable worksheet, then use Practice and Test when the unit's checked 8-question bank is available.

Common mistakes to watch for

  • Rushing to a rule before checking the concrete model, drawing or number sentence.
  • Using the correct answer once but not being able to explain why it works.
  • Mixing up similar vocabulary such as more/less, before/after, longer/shorter or equal groups/sharing.
