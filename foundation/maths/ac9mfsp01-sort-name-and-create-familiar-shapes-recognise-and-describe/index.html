Shapes and Shape Sorting

Recognise familiar shapes by their features, even when they are turned, resized or seen inside everyday objects.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Recognise familiar shapes by their features, even when they are turned, resized or seen inside everyday objects.

Learning intention: I can recognise familiar shapes by their features, even when they are turned, resized or seen inside everyday objects.

Success criteria

  • I can name familiar shapes.
  • I can describe sides/corners.
  • I can recognise rotated shapes.
  • I can sort by a rule.
  • I can create and explain shapes.
Key vocabulary
  • shape — the form of an object or outline
  • side — a straight or curved boundary
  • corner — a point where sides meet
  • sort — put things into groups using a rule

Learning activities
  • Run a classroom shape hunt and name shapes inside familiar objects.
  • Sort a mixed collection by a stated feature such as number of sides.
  • Create shapes with sticks or playdough, then make a picture from several shapes.
Australian Curriculum elaborations

E1: Sort shapes and state the rule

Sorting places shapes into groups according to an observable rule. The same collection can be sorted differently when the rule changes.

3 sides
△ △4 sides
□ ▭curved boundary
○

Teacher: Choose one feature that can be observed on every shape. Place every shape according to the same rule. State the rule, check each member and then re-sort using another feature.

Ask: A correct sort needs one rule that explains why every shape belongs in its group.

Look for: Sort five shapes by a shape feature and explain the rule so another person could repeat the sort.

E2: Create and explain a shape picture

Familiar shapes can be selected and combined to represent parts of a picture. Naming their features explains why each shape suits its purpose.

△ roof□ wall▭ door→🏠 picture

Teacher: Choose an object or scene to represent. Select, trace or make shapes for its component parts. Name each shape and justify at least one choice using a feature.

Ask: I can see a house in the whole picture and still name the shapes used to make each part.

Look for: Design a picture from at least three familiar shapes, name them and justify one choice using a feature.

E3: Make shapes with people

A shape can be made at different sizes and with different materials while retaining its defining boundary features, such as straight sides, curves and corners.

peoplejoin and curve○ circlepeoplemake 3 edges△ triangle

Teacher: Name the target shape and its important boundary features. Position people or a rope to create those sides, curves and corners. Inspect the whole boundary and adjust any feature that does not match.

Ask: The group became a different shape because the boundary changed from one curve to three straight sides and three corners.

Look for: Explain and demonstrate how a group can change its circle boundary into a triangle.

E4: Find shapes inside everyday objects

Everyday objects often contain component parts whose boundaries resemble familiar shapes. Shape identity depends on features, not size, colour or orientation.

clock → ○window → □sign → △door → ▭

Teacher: Choose one component part rather than naming the whole object. Trace or point around its boundary. Name the familiar shape and justify it using sides, corners or curves.

Ask: I am naming the shape of this part and giving boundary evidence, not saying the whole object is that shape.

Look for: Identify one familiar shape within an everyday object and justify the name using its boundary features.

E5: Observe and sort shapes on Country and Place

Country/Place contains many observable forms that can be described geometrically. Learning must retain the source context and respect community authority over cultural knowledge and designs.

approved observation→describe geometry→sort by feature

Teacher: Use a locally approved observation or authorised resource and retain its place and community context. Identify a permitted natural or made form and describe its visible geometric features. Represent only the general geometric shape when permitted, then sort it by the stated feature.

Ask: We are describing visible geometry respectfully. We do not copy cultural designs or claim cultural knowledge that has not been shared for this purpose.

Look for: From the approved example, describe one permitted shape feature and explain the geometric group it belongs in.

Common misconceptions and quick fixes
  • Calls a turned square a new shape — Trace the sides and corners; rotation does not change features.
  • Sorts by colour instead of feature — Repeat the sorting rule before placing each item.
  • Names without reasons — Ask “What feature helped you decide?”
Quick checks and mastery

Quick checks

  • Name a shape with 3 straight sides.
  • Is a turned square still a square? Why?
  • Sort circle, triangle, square by number of corners.
  • Name one everyday object that contains a rectangle or circle.

Mastery

  • Name familiar shapes
  • Describe sides/corners
  • Recognise rotated shapes
  • Sort by a rule
  • Create and explain shapes
