AC9MFST01 - AC9MFST01: Collect, sort and compare data represented by objects and images...
Example 1

collecting, and sorting data collected through everyday activities or events; for example, sorting toys into categories, such as “toys that move” and “toys that don’t move” Learning connection: Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Example 2

collecting and deciding how to organise data to answer “Yes/No” questions; for example, “Do more people in our class today have shoes with laces than without?”; explaining that lining up, and matching shoes with and without laces one-to-one will answer the question Learning connection: Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Example 3

creating classroom charts and rosters using stickers to represent data; comparing and interpreting representations Learning connection: Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Example 4

role-playing being a robot that sorts objects into groups based on a set of instructions; for example, imitating a robot designed to pack things away in the classroom or an industrial robot programmed to sort products on an assembly line by colour or shape Learning connection: Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

AC9MFST01 · AC9MFST01: Collect, sort and compare data represented by objects and images...

Learning focus: collect, sort and compare data represented by objects and images in response to given investigative questions that relate to familiar situations

Model it: role-playing being a robot that sorts objects into groups based on a set of instructions; for example, imitating a robot designed to pack things away in the classroom or an industrial robot programmed to sort products on an assembly line by colour or shape Learning connection: Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Ask the learner: Which category has more: ●●●● or ●●?

Look for: The learner can collect, sort and compare data represented by objects and images in response to given investigative questions that relate to familiar situations in a fresh example and explain the evidence or reasoning without copying the model.

If they are stuck: If the learner guesses or repeats a rule without evidence, return to the concrete or visual model and ask them to explain what each part shows.
