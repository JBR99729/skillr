Collecting and Comparing Data

Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Learning intention: I can data helps answer a question when responses are collected, sorted consistently, displayed clearly and compared.

Success criteria

  • I can collect one response each.
  • I can sort consistently.
  • I can represent with objects/images.
  • I can compare most / least / same.
  • I can answer using the display.
Key vocabulary
  • data — information collected to answer a question
  • category — a group made using a sorting rule
  • display — a way to show collected data
  • compare — look for more, fewer or the same

Learning activities
  • Sort classroom toys into two agreed categories and explain the rule.
  • Run a simple class yes/no survey and place one marker per response.
  • Build an object graph and ask which category has most, least or the same.
Australian Curriculum elaborations

E1: Collect and sort data about familiar things

Data are pieces of information collected to answer a question. Categories organise the data so each item can be counted and compared.

favourite toys→building toysother toys→sort again

Teacher: Ask one clear question and collect one response or object for each case. Choose category labels that answer the question and place every item once. Count each category, then subdivide a broad category when more detail is useful.

Ask: The question tells us what information to collect, and the labels tell us how the information is organised.

Look for: Sort a small set of favourite-toy responses into labelled categories and explain how the sort helps answer the question.

E2: Organise data to answer a comparison question

The way data are organised should make the investigative question easy to answer. One-to-one alignment reveals which category has more, fewer or the same number.

laces ● ● ● ●no laces ● ● ●→laces has 1 more

Teacher: Collect one response for each person or object in the investigation. Arrange the two categories in aligned rows or columns. Match entries one-to-one and use the unmatched entries to compare.

Ask: The aligned rows let me compare the data, and the unmatched counter is evidence for ‘one more’.

Look for: Organise two-category class data in aligned rows and justify which category has more, fewer or the same.

E3: Create and interpret a picture chart

A picture chart represents each data value with an agreed picture or sticker. Consistent alignment and a one-picture-to-one-item rule make categories easy to compare.

books ★ ★ ★ ★blocks ★ ★ ★paint ★ ★→books most

Teacher: Label the categories and agree what one picture represents. Add one aligned picture for each response. Count or match the pictures to describe most, fewest, more, fewer or equal.

Ask: I checked the key: one sticker represents one response, so I can compare the numbers of stickers fairly.

Look for: Read a three-category picture chart and support one comparison statement with counts or one-to-one matching.

E4: Investigate data in a story

Stories and illustrations can provide data when the class asks a countable question, defines categories and records only evidence found in the text or image.

story scene→What types?How many?→record and compare

Teacher: Choose a question that can be answered from the story or illustration. Identify and label the categories before counting. Record each observed item once, then compare and answer the question.

Ask: My answer describes the data in these pages; I am not adding animals that I know could live in a garden.

Look for: From a selected story scene, define two or more categories, record the observations and answer a comparison question.

E5: Explore environmental information used to anticipate weather

First Nations seasonal knowledge is specific to Country and community. Long-term observations of connected changes in weather, plants and animals can provide information about seasonal conditions and likely weather events.

authorised local calendar→observe indicators→record relationships

Teacher: Select a community-approved source or a Bureau of Meteorology Indigenous seasonal calendar and retain its named community and Country/Place attribution. Identify one environmental indicator and the weather or seasonal condition connected to it in that source. Represent the published relationship with a simple teacher-prepared picture record, without generalising it to other Countries or communities.

Ask: This knowledge belongs to a specific community and Country. We will describe what the authorised source shares, not turn it into a rule for every place.

Look for: From the selected authorised source, name one environmental indicator and the weather or seasonal condition it is connected with, including the community attribution.

E6: Investigating statistical contexts after reading a story, such…

This elaboration makes collecting and comparing data visible through investigating statistical contexts after reading a story, such as "The Waterhole" by Graeme Base; asking and responding to questions like “What different animals did you see?”, “How many different types of animals were there?” or “Were there more tigers or kangaroos?”.

Teacher: Use this lesson example: Build an object graph and ask which category has most, least or the same. Then connect the evidence explicitly to this elaboration.

Ask: Show one example of investigating statistical contexts after reading a story, such…. What evidence makes it fit?

Look for: The learner gives an example of investigating statistical contexts after reading a story, such… and identifies the feature, action or evidence that makes it fit.

E7: Exploring what and how information from the environment is…

This elaboration makes collecting and comparing data visible through exploring what and how information from the environment is collected and used by First Nations Australians to predict weather events.

Teacher: Use this lesson example: Sort classroom toys into two agreed categories and explain the rule. Then connect the evidence explicitly to this elaboration.

Ask: Show one example of exploring what and how information from the environment is…. What evidence makes it fit?

Look for: The learner gives an example of exploring what and how information from the environment is… and identifies the feature, action or evidence that makes it fit.

Common misconceptions and quick fixes
  • Categories overlap — Use a clear rule so every item has one consistent place.
  • Rows are not aligned — Start rows at the same point for fair visual comparison.
  • Answers from memory — Point to the display and use the data as evidence.
Quick checks and mastery

Quick checks

  • Which category has more: ●●●● or ●●?
  • Why should rows start at the same point?
  • Suggest two categories for sorting classroom toys.
  • What question could this display help answer: cats ●●●, dogs ●●?

Mastery

  • Collect one response each
  • Sort consistently
  • Represent with objects/images
  • Compare most / least / same
  • Answer using the display
