Collect, sort and compare data

Ask a familiar question, collect objects or responses, sort them by a clear rule and use the display to answer the question.

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Ask “Which shape is most common in this bag of blocks?”

Sort each block by the shape marked on it. Count the blocks in each group to find which shape is most common.

Learn the skill

1. Start with a question and collect data

Data are the objects or responses collected to help answer a question. The question tells you what to record.

Try it · Ask “Which colour is most common among these 6 counters?” What must you collect?

Record the colour of each of the six counters once. Use the actual counters; the answer depends on their colours.

2. Sort using one clear rule

A category is a group defined by a rule. Check each item against the chosen rule before placing it.

Try it · Two square blocks have different colours. If sorting by shape, do they belong together?

Yes. Both go in the square category because shape, not colour, is the stated rule.

3. Make a one-picture-for-one-item display

Use one counter or picture for each collected item. Label categories, start rows together and keep spacing equal.

Try it · If a category has no items, how can you show that?

Keep its label and leave its row empty. That category has 0 items; do not add a marker just to fill the row.

Common mistakes

Do not add an invented response or count the same block twice. For a people survey, agree one response per person.

Changing from shape to colour halfway mixes rules. Use categories that account for every item without double counting.

A large picture does not stand for more items. Do not use scaled picture keys in this Foundation display.

10-MINUTE HOME ACTIVITY

Sort, display and compare

Gather five spoons and three forks. Sort them, line them up in two rows from the same starting point, and say which group has more and by how many.

Adjust the challenge: Start with two groups of up to three. Extend by drawing one picture per object and comparing the display.

FAQ

How can we show that two groups are equal?

Pair one object or picture from each group. Equal groups have no leftovers.

Learn the idea

Build understanding one step at a time

Learning goal: Ask a familiar question, collect objects or responses, sort them by a clear rule and use the display to answer the question. Open a focus, follow its example, then try the question before checking the answer. An adult can read instructions aloud.

1. Start with a question and collect data

Data are the objects or responses collected to help answer a question. The question tells you what to record.

Worked example: Ask “Which shape is most common in this bag of blocks?”

  1. For this example, each block has one marked face: round, square or triangular. Agree these three categories.
  2. Take each block out once.
  3. Record or keep each block in its correct category.

Why it works: The data must come from the defined bag. Random decorative pictures would not answer the question.

Watch for: Do not add an invented response or count the same block twice. For a people survey, agree one response per person.

Try it: Ask “Which colour is most common among these 6 counters?” What must you collect?

Check the answer

Record the colour of each of the six counters once. Use the actual counters; the answer depends on their colours.

2. Sort using one clear rule

A category is a group defined by a rule. Check each item against the chosen rule before placing it.

Worked example: Sort a collection by shape, not colour.

  1. Name the shape categories.
  2. Check the marked face of each block and put the block in its matching category.
  3. Check that every block has been placed once.

Why it works: Keeping the same rule makes category totals meaningful. You can re-sort by colour later for a different question.

Watch for: Changing from shape to colour halfway mixes rules. Use categories that account for every item without double counting.

Try it: Two square blocks have different colours. If sorting by shape, do they belong together?

Check the answer

Yes. Both go in the square category because shape, not colour, is the stated rule.

3. Make a one-picture-for-one-item display

Use one counter or picture for each collected item. Label categories, start rows together and keep spacing equal.

Worked example: Display counts of 4 round, 2 square and 4 triangular faces.

  1. Put a label at each row.
  2. Place four, two and four equal-sized markers beside the labels.
  3. Match each marker back to one collected block to check the display.

Why it works: Equal markers and spacing make comparisons clear. Each marker stands for one item, not two or five.

Watch for: A large picture does not stand for more items. Do not use scaled picture keys in this Foundation display.

Try it: If a category has no items, how can you show that?

Check the answer

Keep its label and leave its row empty. That category has 0 items; do not add a marker just to fill the row.

4. Compare categories, including ties

Count or match category amounts. Most and least can have more than one correct category when totals tie.

Worked example: Read the displayed counts: 4, 2 and 4.

  1. Round and triangular each have four.
  2. The square group has two blocks. The round and triangular groups each have four.
  3. Round and triangular tie for most; square has the fewest.

Why it works: The answer follows the amounts. Equal categories remain equal even if a display is rearranged.

Watch for: Do not choose only one category when two tie for most. Do not use a longer row with wider gaps as proof.

Try it: One category has 3 items and another has 3. Which has more?

Check the answer

Neither. They have the same number. Match all three one to one to check.

5. Answer the question using evidence

Return to the question after sorting and comparing. Explain what the collected data show, without making a claim about uncollected items.

Worked example: Answer which shape is most common in the displayed collection.

  1. Read each category’s count.
  2. Identify the tied largest counts: four round and four triangular.
  3. Say “Round and triangular faces are equally most common in this collection.”

Why it works: The conclusion uses the counted evidence and names the collection investigated.

Watch for: Data from one bag do not prove what is most common in every bag. A new collection may give a different result.

Try it: A new bag has 5 square blocks and 1 round block. Which is most common, and how do you know?

Check the answer

Square blocks are most common in this bag: five compared with one round block.
