Learn the idea

Build understanding one step at a time

Learning goal: Make groups with the same number, share one each in rounds, and explain what the answer counts. Open a focus, follow its example, then try the question before checking the answer. An adult can read instructions aloud.

1. Notice groups and the number in each

A group is a collection kept together. Equal groups contain the same number, even when their spacing differs.

Worked example: Read three groups with two counters each.

  1. Point to the three group boundaries.
  2. Count two counters in each group.
  3. Say “Three groups, two in each, six altogether.”

Why it works: Group count and group size answer different questions. Equal means the amounts in each group match.

Watch for: A bigger container does not make a larger amount. Check objects, not container size.

Try it: Make 2 groups with 3 blocks each. Name the groups, number each and total.

Check the answer

2 groups, 3 blocks each, 6 blocks altogether.

2. Share between known recipients

In sharing, you know who receives the objects and work out how many each gets. Deal one to every recipient per round.

Worked example: Share 8 counters equally between 2 mats, using all eight.

  1. Put one counter on each mat.
  2. Repeat until all eight have been allocated.
  3. Check both mats: four counters each, with none left.

Why it works: Each round gives the same amount to both mats. Four rounds use all eight.

Watch for: Equal after one round is not finished if counters remain and the task says to use all of them.

Try it: Share 9 whole blocks among 3 mats equally, using all nine.

Check the answer

3 blocks on each mat. Check equality and that nothing is unallocated.

3. Make groups of a given size

In grouping, you know how many belong in each group and work out how many groups can be made.

Worked example: Put 10 counters into groups of 2.

  1. Make a group of two and move it aside.
  2. Keep making complete groups of two.
  3. Count the five complete groups.

Why it works: Every group contains the requested two. The answer is five groups, not five counters in each.

Watch for: Label the answer unit: groups or objects each. The same total can be used in different sharing and grouping tasks.

Try it: Make groups of 3 from 12 objects, using every object.

Check the answer

4 groups. Each group has 3; together they use all 12.

4. Check equality and leftovers

Check the total, the amount in every group and any unallocated objects. A leftover is different from an unequal share.

Worked example: Repair a share of 6: one mat has 4 and the other has 2.

  1. Count all six to check none are missing.
  2. Move one from the four-mat to the two-mat.
  3. Each now has three, so the share is equal.

Why it works: Moving preserves the total while changing the two allocations.

Watch for: Seven whole blocks cannot all be shared equally between two recipients without splitting a block. Do not quietly discard the leftover.

Try it: Share 7 whole blocks between 2 mats as equally as possible without splitting. Explain what happens.

Check the answer

Three on each mat and one left over. This is not an equal share using all seven. If using every whole block equally is required, it cannot be done with these conditions.

For teachers and parents: Use safe whole objects and clear mats or containers. State whether every object must be used and whether objects may be split. Formal multiplication, division and fraction symbols are unnecessary for these practical models.

Ready to try it independently?

Use 12 objects: share among 3 mats, then rebuild groups of 3. Explain why one answer counts objects each and the other counts groups.

Use fresh objects or examples. Notice what the child can do independently and what needs another model. A correct choice alone may not show the practical action or reasoning.
