Equal Sharing and Grouping

A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Learning intention: I can a fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Success criteria

  • I can make a fair share.
  • I can check equal amounts.
  • I can make equal groups.
  • I can describe groups and group size.
  • I can explain an unfair share.
Key vocabulary
  • equal — the same amount
  • share — give out objects fairly
  • group — a set of objects together
  • group size — how many objects are in each group

Learning activities
  • Deal cards one at a time so every player receives the same number.
  • Make an unfair share, then ask students to fix it.
  • Put 6 objects into 3 equal groups and count each group.
Australian Curriculum elaborations

E1: Role-play a fair share

Equal sharing means every recipient receives the same number. Dealing one object to each recipient in repeated rounds makes a fair share visible.

person A person B person C person D

Teacher: Count the recipients and the whole collection. Deal one object to each recipient in turn, repeating complete rounds. Count each share and compare the amounts.

Ask: A fair share gives the same number to each person. We can prove it by counting every share.

Look for: Share 8 objects among 4 people and prove the share is fair without relying only on how it looks.

E2: Count and share a collection

In an equal-sharing situation, the whole collection is distributed among a known number of groups. The result tells how many are in each group.

→ 3 groups →3 in each

Teacher: Count the whole collection and name the number of groups. Distribute one object to each group until none remain. Subitise or count one group, then confirm that every group is equal.

Ask: Nine is the whole, three is the number of groups, and three in each is the fair share.

Look for: Share 9 beads among 3 people. State the whole, the number of groups and the amount in each group.

E3: Explore sharing through an instructive game

A culturally situated game can provide a meaningful context for noticing equal turns and equal shares when it is taught from an authoritative source and with accurate attribution.

approved source→play as documented→discuss fair sharing

Teacher: Select an authorised description of Yangamini and acknowledge the Tiwi Peoples of Bathurst Island. Teach and play the game exactly as the selected source documents it. Pause at a genuine sharing moment and ask children to show how they know the shares are equal.

Ask: We are learning this game from a source that acknowledges the Tiwi Peoples. We will follow that source and use the sharing we see to discuss fairness.

Look for: After the sourced activity, identify one documented sharing moment and explain how the group checked whether it was equal.

Common misconceptions and quick fixes
  • Shares in chunks — Deal one item to each recipient in turn.
  • Confuses groups with items per group — Ask both: “How many groups?” and “How many in each?”
  • Does not check equality — Count every share at the end and compare.
Quick checks and mastery

Quick checks

  • Share 6 counters equally between 3 people. How many each?
  • Make 2 equal groups from 8 objects. How many in each group?
  • Is 3 counters and 2 counters a fair share? Why?
  • Show another equal grouping for a collection you choose.

Mastery

  • Make a fair share
  • Check equal amounts
  • Make equal groups
  • Describe groups and group size
  • Explain an unfair share
