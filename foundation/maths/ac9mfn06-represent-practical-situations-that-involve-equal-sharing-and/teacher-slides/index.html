Share and group objects equally

Make fair shares and equal groups, then check that every group has the same amount.

Clean one-page examples

AC9MFN06 - AC9MFN06: Represent practical situations that involve equal sharing and grouping with...
Example 1

using materials to role-play equal sharing; for example, sharing pieces of fruit or a bunch of grapes between 4 people and discussing how you would know they have been shared equally; when playing card games where each player is dealt the same number of cards, and counting the number of cards after the deal to ensure they have the same amount Learning connection: A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Example 2

representing situations that involve counting several items; for example, 9 beads or 6 $1 coins, and sharing them equally between 3 people by subitising or counting each group by ones to decide how many beads or coins each person will receive Learning connection: A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Example 3

exploring instructive games of First Nations Australians that involve sharing; for example, playing Yangamini of the Tiwi Peoples of Bathurst Island to investigate and discuss equal sharing Learning connection: A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.

Example 4

Share fairly and check: SHARE 8 BETWEEN 4 A: ● ● B: ● ● C: ● ● D: ● ● Each person gets 2. GROUP 9 INTO 3 ● ● ● | ● ● ● | ● ● ● 3 equal groups of 3. CHECK Count each share or group. If the amounts are different, the share is not equal. Think aloud: Build or point to the model first, explain what each part shows, then state the answer.

Assessment-style questions and review hints 1

Questions

  • Share 6 counters equally between 3 people. How many each?
  • Make 2 equal groups from 8 objects. How many in each group?

Review hints

  • Main idea: A fair share gives each person the same amount, and equal grouping makes groups with the same number of items.
  • Useful routine: Share one each → Check equal → Count each → Group → Explain → Check

Assessment-style questions and review hints 2

Questions

  • Is 3 counters and 2 counters a fair share? Why?
  • Show another equal grouping for a collection you choose.

Review hints

  • equal: the same amount
  • share: give out objects fairly
