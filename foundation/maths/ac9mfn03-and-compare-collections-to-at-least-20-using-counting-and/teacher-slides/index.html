AC9MFN03 - AC9MFN03: Quantify and compare collections to at least 20
Example 1

establishing the language and process of counting, understanding that each object must be counted only once, that the arrangement of objects does not affect how many there are, and that the last number counted answers the question of “How many?”; for example, saying numbers in sequence while playing and performing actions Learning connection: Count every object exactly once, know that the last count tells how many, and compare collections fairly.

Example 2

using counting to compare the size of two or more collections of like items to justify which collection contains more or less items Learning connection: Count every object exactly once, know that the last count tells how many, and compare collections fairly.

Example 3

using counting and one-to-one correspondence to quantify the number of items required for a purpose; for example, when asked to collect enough scissors for each member of their group to have a pair, counting each member and using the total count to know how many to collect Learning connection: Count every object exactly once, know that the last count tells how many, and compare collections fairly.

Example 4

discussing how different cultures may have alternative ways of representing the count; for example, discussing how people of the Asia region use an abacus or Chinese hand gestures Learning connection: Count every object exactly once, know that the last count tells how many, and compare collections fairly.

  • Which has more: 8 counters or 6 counters?
  • Seven counters are spread far apart. Are there still 7? Explain.

Review hints

  • Main idea: Count every object exactly once, know that the last count tells how many, and compare collections fairly.
  • Useful routine: Touch/Move → Count → State total → Match → Compare → Explain
