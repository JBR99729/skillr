Counting and Comparing Collections

Count every object exactly once, know that the last count tells how many, and compare collections fairly.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Count every object exactly once, know that the last count tells how many, and compare collections fairly.

Learning intention: I can count every object exactly once, know that the last count tells how many, and compare collections fairly.

Success criteria

  • I can count each object once.
  • I can use final count as total.
  • I can keep quantity after rearranging.
  • I can compare by count or matching.
  • I can explain more / fewer / same.
Key vocabulary
  • collection — a group of objects
  • total — how many altogether
  • more — a greater number
  • fewer — a smaller number

Learning activities
  • Count a classroom collection by moving each object to a finished mat.
  • Build two rows and match items one-to-one to compare.
  • Ask for enough scissors for a group; count people first, then collect that many.
Australian Curriculum elaborations

E1: Count each object once and know the total

Accurate counting uses one number word for each object. The final number word tells how many are in the whole collection, and rearranging the objects does not change that total.

touch or move→7 altogether
same 7 after rearranging

Teacher: Choose a clear starting object. Touch or move each object once while saying the count sequence. State the total, then rearrange and predict whether it changes.

Ask: The last number I said tells how many are in the whole collection.

Look for: Count 7 counters, spread them apart and explain why the total remains 7.

E2: Compare counted collections fairly

Collections can be compared by counting their totals or matching objects one-to-one. More, fewer and the same describe the relationship between the collections.

A B →A has 2 more

Teacher: Count each collection accurately. Align or pair like objects one-to-one. Name the comparison and explain the unmatched objects.

Ask: I did not judge by how much space the collections used. I counted and matched the objects.

Look for: Compare collections of 8 and 6 using both counting and one-to-one matching.

E3: Work out how many items are needed

One-to-one correspondence helps solve practical problems: when each person needs one item, the number of items must match the number of people.

child ↔ pencilchild ↔ pencilchild ↔ pencilchild ↔ pencil
4 children need 4 pencils

Teacher: Count the people or places needing an item. Collect that total number of items. Pair one item with each recipient and check none are missing or left over.

Ask: The count of people tells me how many items to collect because each person needs exactly one.

Look for: Show how many pencils 4 children need when each child receives one.

E4: Recognise different representations of the same count

People and cultures use different tools and gestures to represent number. The representation can change while the quantity it communicates stays the same.

counters↔5 beads on a counting tool↔5

Teacher: Introduce one accurately sourced representation and its convention. Match it to a familiar collection and numeral. Discuss what is different visually and what number stays the same.

Ask: The way five is shown can change; the quantity five does not.

Look for: Represent 5 with counters and one sourced counting representation, then explain how they match.

E5: Use one-to-one body tallying from an appropriate source

In a taught body-tally system, each next object is paired with the next body point in a fixed sequence. This uses the same one-to-one principle as touching each object while counting.

object 1 ↔ taught point 1object 2 ↔ taught point 2continue in sourced sequence

Teacher: Use a local or authoritative First Nations source for the specific sequence. Pair each object with exactly one taught body point. Stop at the final matched point and state the represented total as taught.

Ask: Each object is matched once to the next point in the sequence, so the tally stays accurate.

Look for: Using the sourced sequence, match 5 objects to 5 taught body points and explain the one-to-one correspondence.

Common misconceptions and quick fixes
  • Double counting — Move counted objects into a finished area.
  • Spread means more — Count the same collection before and after rearranging.
  • Does not state total — After counting, ask “So how many altogether?”
Quick checks and mastery

Quick checks

  • Count: ● ● ● ● ● ● ●
  • Which has more: 8 counters or 6 counters?
  • Seven counters are spread far apart. Are there still 7? Explain.
  • There are 5 children. How many pencils are needed for one each?

Mastery

  • Count each object once
  • Use final count as total
  • Keep quantity after rearranging
  • Compare by count or matching
  • Explain more / fewer / same
