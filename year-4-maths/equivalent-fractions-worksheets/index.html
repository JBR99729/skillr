Parent and teacher guide

Equivalent fractions show the same amount using different-sized parts. Students understand this best when they compare shaded models, fraction strips and number lines before using rules. Begin with familiar pairs such as 1/2 and 2/4, then show how both land at the same point on a number line. A common mistake is thinking larger denominators always mean larger fractions. Use equal wholes and aligned models so the comparison is fair.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
