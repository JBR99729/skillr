Solving and Verifying Linear Equations

Test possible solutions, solve one-variable equations with balance and backtracking strategies, and verify answers by substitution.

PracticeHomeworkTest

Key concepts

Solution

A solution is a value that makes the equation true.

Substitution

Replace x with a proposed value and check whether both sides are equal.

Balance model

Apply the same operation to both sides to preserve equality.

Backtracking

Reverse operations in the opposite order to isolate x.

Worked examples

Check: x=5 in 3x+4=19 → 15+4=19, so x=5 is a solution.

Backtrack: 4x−15=29 → add 15 → 4x=44 → divide by 4 → x=11.

Variables both sides: 8x+12=3x+37 → 5x=25 → x=5.

Brackets: 6(x−2)+4=40 → 6x−8=40 → 6x=48 → x=8.

Important questions

  1. What does it mean for a value to be a solution?
  2. Verify x=6 in 4x+7=31.
  3. Solve 7x−5=23.
  4. Solve 3(x−4)=21.
  5. Explain why the same operation must be applied to both sides.
  6. Solve 8x+12=3x+37.
  7. Solve 6(x−2)+4=40.
  8. Write and solve an equation for “five times a number plus 17 is 62”.
  9. Find and correct an error where only one side of an equation is changed.
  10. Explain why substitution is the strongest final verification step.

Common mistakes

  • Changing only one side of an equation.
  • Forgetting to divide every term when dividing a whole side.
  • Expanding brackets incorrectly.
  • Stopping before the variable is isolated.
  • Checking a transformed equation instead of the original equation.

Curriculum connections

Australian Curriculum: AC9M7A03 focuses on determining whether natural-number values satisfy equations, solving one-variable linear equations using suitable strategies such as balance models and backtracking, and verifying solutions by substitution.
