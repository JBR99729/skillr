Worked example

Learn the skill

1. Undo the addition

Subtract the constant from both sides to isolate the variable term.

Try it · What remains after subtracting 4 from both sides of 3x + 4 = 19?

3x = 15.

2. Undo the multiplication

Divide both sides by the coefficient to isolate the variable.

Try it · Solve 3x = 15.

x = 5.

3. Verify by substitution

Replace the variable in the original equation and compare both sides.

Try it · Does x = 6 solve 2x + 3 = 15?

Yes. 2 × 6 + 3 = 15.

Common mistakes

Changing only one side of an equation. Apply the same operation to both sides to keep the equality true.

FAQ

What value solves 3x + 4 = 19?

5, because 3 × 5 + 4 = 19.

What students learn in AC9M7A03

We are learning to solve one-variable linear equations with natural number solutions and verify the solution by substitution.

In this topic, the one-variable linear equations are deliberately chosen to have natural-number solutions. A solution is the value that makes both sides equal, and every solving line must preserve that equality.

Use inverse operations in reverse order and perform the same operation on both sides. Brackets are handled as a grouped operation before isolating the variable.

Substitution is an independent check: replacing the variable with the proposed solution must produce the same numerical value on both sides.

Success criteria

  • I can solve one-variable linear equations using balanced inverse operations.
  • I can explain why each equation line is equivalent to the previous line.
  • I can verify a natural-number solution by substitution.
Key vocabulary
linear equation
equation where the variable has power one.
equivalent equations
equations with the same solution set.
solution
value making the original equation true.

4 worked numerical & application examples

Follow each example from representation and setup through calculation/reasoning, interpretation and an independent check.

Example 1

Solve 3x+5=26

  1. Subtract 5 from both sides.
  2. Simplify to 3x=21.
  3. Divide both sides by 3.
  4. Substitute the solution into the original equation.

Final answer: x=7

Check: 3(7)+5=26.

Example 2

Solve 4(x−2)=24

  1. Divide both sides by 4.
  2. Simplify to x−2=6.
  3. Add 2 to both sides.
  4. Verify in the original equation.

Final answer: x=8

Check: 4(8−2)=24.

Common misconceptions

Common mistake: Term moved by changing sign without explanation.

Correction: Apply the same inverse operation to both sides.

Common mistake: Distributive brackets ignored.

Correction: 2(x+3)=2x+6.

Common mistake: Division applied to one term only.

Correction: Divide every term or simplify the whole side correctly.
