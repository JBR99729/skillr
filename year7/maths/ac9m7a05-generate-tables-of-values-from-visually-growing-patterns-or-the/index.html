Patterns, Tables, Rules and Cartesian Graphs

Connect growing patterns, tables of values, algebraic rules, function machines and graphs.

PracticeHomeworkTest

Core ideas

Tables → rules

If equal x-steps give a constant change in y, the relationship is linear. In y=mx+b, m is the rate of change and b is the value when x=0.

Function machines

Translate operations in order. “Subtract 4, then triple” is y=3(x−4), not y=3x−4.

Patterns → graphs

Constant first difference gives a straight-line step-number graph. Repeated multiplication gives a different, non-linear growth pattern.

Algorithms

Be explicit about indexing: if term 1=a and each term adds d, then Tₙ=a+(n−1)d.

Worked example

Pattern: 7, 11, 15, 19, …

Difference = 4, so T=4n+b. At n=1, 7=4+b, so b=3. Therefore T=4n+3. The graph is a straight line with slope 4.

Common mistakes

  • Treating every increasing pattern as linear.
  • Forgetting that a constant sequence is also linear with slope 0.
  • Using y=dn+a when a is the first term; usually Tₙ=a+(n−1)d.
  • Confusing slope with intercept.
  • Ignoring brackets in multi-step function machines.
