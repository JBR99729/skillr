Manipulating Formulas with Several Variables

Use formulas, tables and digital tools to vary inputs systematically and explain how each variable affects an output.

PracticeHomeworkTest

Core idea

Substitute

Replace variables with known values and follow the formula accurately.

Vary systematically

Change one input while holding others fixed to isolate its effect.

Use tables

Record input-output pairs so patterns are easier to compare.

Interpret

Explain what coefficients, signs and scale changes mean in context.

Worked examples

V=lwh. If l=8,w=5, then V=40h.

So h=1,2,3 gives V=40,80,120. Holding l and w constant turns a three-variable formula into a simple linear relationship between V and h.

F=3x+2y−4z+15

If only x increases by 2, F increases by 3×2=6. If only z increases by 2, F changes by −4×2=−8.

Cheat sheet

IdeaRemember
SubstitutionReplace each variable with its value before simplifying.
Systematic variationChange one variable at a time when you want to isolate its effect.
Linear sliceIf other variables are fixed, rules like y=3a+2b become y=3a+k.
CoefficientIn a linear rule, it gives the output change for a one-unit input change, with other inputs fixed.
Negative coefficientIncreasing that input decreases the output.
Product modelIn d=st or V=lwh, scale factors multiply.
SensitivityCompare how much output changes when controlled input changes are made.
Important cautionA larger coefficient does not automatically mean “more important” if variables use different units/scales.

Important Questions

  1. For V=lwh, how does V change if only h doubles?
  2. Why do we hold other variables constant in a sensitivity test?
  3. For d=st, what happens if both s and t double?
  4. How do you build a table by varying one variable systematically?
  5. What does a negative coefficient mean in a linear formula?
  6. For y=3a+2b, how much does y change if a rises by 5?
  7. Why is coefficient size not always the same as real-world importance?
  8. How can spreadsheets help test multi-variable formulas?
  9. How do you distinguish an input variable from the dependent output?
  10. What can sensitivity analysis explain, and what can it not prove?

Common mistakes

  • Changing two variables at once when trying to isolate one effect.
  • Ignoring a negative sign in a coefficient.
  • Assuming doubling two factors only doubles a product; scale factors multiply.
  • Calling the largest coefficient the “most important variable” without considering units or scale.
  • Thinking sensitivity analysis proves causation, fairness or model accuracy.
