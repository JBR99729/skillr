AC9M7A02 - Formulating Algebraic Expressions

Open one section at a time

CurriculumStart here

We are learning to formulate algebraic expressions using constants, variables, operations and brackets.

An algebraic expression records a calculation using constants, variables, operations and brackets; unlike an equation, it does not assert that two quantities are equal.

Translate the quantities first, then preserve operation order: “three less than twice n” is 2n−3, while “three times the sum of n and 4” requires 3(n+4).

Expressions model perimeter, grouped costs and number patterns. Verify a translation by substituting a simple value into both the words and the expression and comparing the results.

Success criteria

  • I can translate mathematical language into an algebraic expression.
  • I can use coefficients and brackets to preserve operation order.
  • I can verify an expression by substitution.

    Why: Using the method “Put the coefficient directly before y.” gives 4y.

    Check answer

    Answer: 2(n+6)

    Hint: Use brackets around the whole sum.

    Why: Using the method “Use brackets around the whole sum.” gives 2(n+6).

    Check answer

    Why: Using the method “Write 3p first, then subtract 5.” gives 3p−5.

    Check answer

    Answer: 4m+3

    Hint: Represent the equal groups before the loose amount.

    Why: Using the method “Represent the equal groups before the loose amount.” gives 4m+3.

    Check answer
