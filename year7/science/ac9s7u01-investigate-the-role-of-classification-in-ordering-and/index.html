Biological Classification and Dichotomous Keys

Learn why scientists classify living things, how organisms are organised into nested groups, how scientific names work, and how to use and build dichotomous keys.

Learn the topicTeacher SlidesHomeworkPracticeTest

What you need to know for AC9S7U01

Classification is the process of organising living things into groups using shared characteristics. A useful classification system helps scientists identify organisms, compare them, communicate clearly and organise Earth's biological diversity.

By the end of this topic, you should be able to:

  • compare similarities and differences within and between groups of organisms
  • explain why biological classification is useful
  • describe the main Linnaean classification ranks
  • recognise and write a scientific name using binomial nomenclature
  • follow, create and improve a dichotomous key
  • explain why classification systems can change when new evidence becomes available
  • recognise that First Nations Australian classification systems are diverse, place-based knowledge systems that may organise living things differently from contemporary Western science

1. Why do scientists classify living things?

Earth contains an enormous diversity of organisms. Common names can vary between places and languages, and the same common name may even refer to different organisms. Classification gives scientists a shared system for organising and communicating information.

Classification helps scientists

  • Identify: determine which organism has been observed.
  • Compare: recognise similarities and differences between organisms.
  • Organise: place organisms into groups and smaller groups based on shared characteristics.
  • Communicate: use agreed scientific names so researchers can refer to the same species.

Example: feathers, fur, number of limbs, leaf shape, flowers and body coverings can all provide observable evidence for grouping organisms.

2. Levels of biological classification

The Linnaean system organises organisms into a nested hierarchy. Each step down the hierarchy contains organisms with more characteristics in common.

RankExample: common wombatWhat the rank does
KingdomAnimaliaVery broad group
PhylumChordataGroups animals with major shared body-plan features
ClassMammaliaGroups mammals
OrderDiprotodontiaNarrows the group further
FamilyVombatidaeClosely related genera
GenusVombatusVery closely related species
SpeciesVombatus ursinusThe most specific rank used here

A useful memory order is Kingdom → Phylum → Class → Order → Family → Genus → Species.

Scientific names: binomial nomenclature

A species is commonly given a two-part scientific name: Genus + species. The genus begins with a capital letter, the species name begins with a lowercase letter, and both are normally italicised when typed.

Example: the common wombat is Vombatus ursinus.

The two-part name is more precise than a common name because scientists internationally can use the same scientific name.

3. Groups are based on evidence

Classification begins by comparing characteristics. The most useful characteristics are those that reliably distinguish one group from another.

For example, an animal with feathers can be separated from animals with fur or scales. Within the feathered group, beak shape, feet, habitat and other features may help distinguish smaller groups.

Important: one superficial similarity does not always mean two organisms belong to the same close group. Scientists consider several characteristics and, where appropriate, other evidence.

4. Dichotomous keys

A dichotomous key identifies an organism through a sequence of paired choices. At each step there are only two alternatives. Choose the statement that matches the organism, then follow the direction to the next step or identification.

Worked dichotomous key

StepChoice AChoice B
1Has feathers → KookaburraDoes not have feathers → go to 2
2Has fur → Brushtail possumDoes not have fur → go to 3
3Has 6 legs and an exoskeleton → ButterflyHas 4 legs and scales → Skink

Trace the key

Suppose the unknown organism has 4 legs, scales and no feathers or fur.

  1. Step 1: no feathers → go to 2.
  2. Step 2: no fur → go to 3.
  3. Step 3: 4 legs and scales → Skink.

How to build a good key

  1. List observable characteristics of the organisms.
  2. Choose one characteristic that divides the organisms into two clear groups.
  3. Write two contrasting statements.
  4. Repeat the process within each remaining group.
  5. Make sure each route leads to one identification.
  6. Test the key with every organism and revise ambiguous choices.

Avoid vague choices such as “large/small” unless the size boundary is defined. Prefer observable, mutually exclusive statements.

5. First Nations Australian classification knowledge

Aboriginal and Torres Strait Islander Peoples hold diverse knowledge systems developed through long relationships with Country and Place. Ways of grouping and naming living things are not one single national system; they vary between Nations, language groups and locations.

Classification may draw on characteristics such as appearance, behaviour, habitat, seasonal occurrence, ecological relationships and culturally significant uses or roles. These systems can organise knowledge for purposes that differ from the Linnaean hierarchy.

Compare carefully: contemporary Western biological classification commonly emphasises nested taxonomic groups and evolutionary relationships. First Nations systems may organise knowledge according to locally meaningful relationships with Country, seasons, other organisms and community practices. One system should not be treated as a crude version of the other.

When learning about local knowledge, use appropriate community-approved sources and respect cultural authority, permissions and restrictions around knowledge sharing.

6. Why classification changes over time

Scientific classification can change when better evidence changes our understanding of relationships between organisms.

  • Improved microscopy allowed scientists to observe cells and microscopic structures that could not previously be seen.
  • New observations can show that organisms once grouped together have important differences.
  • As an extension, modern molecular evidence such as DNA comparisons can provide additional evidence about relationships between organisms.

A classification change does not mean earlier scientists were simply careless. Scientific systems are revised when new evidence supports a better explanation or grouping.

Worked examples

Example 1: choosing a useful classification feature

Four animals differ in body covering: feathers, fur, smooth moist skin and dry scales. A useful first split could separate feathers from no feathers because the choices are observable and mutually exclusive.

Example 2: reading a scientific name

In Vombatus ursinus, Vombatus is the genus and ursinus is the species epithet. Together they form the species' binomial scientific name.

Example 3: explaining a classification change

If improved microscopy reveals an important cell structure that separates two groups previously thought to be similar, scientists may revise the classification because the new observation provides additional evidence.

Common misconceptions

  • “Species is the broadest group.” Species is the most specific of the seven ranks listed here; kingdom is the broadest.
  • “A dichotomous key tells you what an organism should look like.” A key uses observed characteristics to identify an organism; it does not change the organism.
  • “Scientific names are just difficult common names.” Scientific naming follows international conventions and reduces ambiguity.
  • “Classification never changes.” Classification can be revised when new evidence changes our understanding.
  • “All First Nations Australians use one classification system.” Knowledge systems are diverse and connected to particular Countries, Peoples and languages.

Apply and transfer

  1. An unknown organism has feathers, wings and a beak. Which observable feature would immediately separate it from mammals in a simple key?
  2. Why is Vombatus ursinus more useful internationally than relying only on the common name “wombat”?
  3. A new microscope reveals that two microorganisms previously placed in one group have very different cell structures. Explain why their classification might be reconsidered.
  4. Create the first two paired statements of a dichotomous key for four local leaves that differ in margin shape and vein pattern.
