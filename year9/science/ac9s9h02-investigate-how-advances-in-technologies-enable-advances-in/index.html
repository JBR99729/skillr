AC9S9H02 • Year 9 Science

Science and Technology Advance Together

New tools create new observations, while scientific understanding enables new technologies and engineering.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

We are learning to explain science and technology advance together using models and evidence.

Success criteria

  • Identify and connect scientific question, technology, new data.
  • Use a model to explain rather than only describe the concept.
  • Apply the central idea to a curriculum example and justify the connection.
  • Evaluate one model limit, misconception or evidence boundary.
Concept boundary and prerequisites

Must teach

  • Technologies extend observation, measurement and analysis.
  • Scientific knowledge informs engineering design.
  • Science–technology relationships are iterative and include limitations.

Prerequisites

  • Read a labelled scientific diagram or data display.
  • Distinguish an observation from an explanation.
  • Use evidence to support a short scientific statement.

Do not overteach

  • Do not describe technological progress as automatic or value-free.
  • Do not claim bigger data alone produces better explanations.
Teaching progression
  1. 1. Identify the limitation
    Use the shared model to foreground scientific question.
    Students: Annotate or explain the link involving scientific question.
  2. 2. Trace the new tool
    Use the shared model to foreground technology.
    Students: Annotate or explain the link involving technology.
  3. 3. Explain the new evidence
    Use the shared model to foreground new data.
    Students: Annotate or explain the link involving new data.
  4. 4. Follow the application
    Use the shared model to foreground new explanation.
    Students: Annotate or explain the link involving new explanation.
Worked examples

Observe → connect → conclude

Particle accelerators enabled controlled collisions and new particle evidence.

Common misconceptions
  • Technology is only applied science.
  • A more advanced instrument removes uncertainty.
