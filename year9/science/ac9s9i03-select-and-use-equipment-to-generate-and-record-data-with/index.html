Choosing equipment and recording precise data

This topic helps students choose suitable equipment, use it safely and record measurements clearly. The aim is not just to collect numbers, but to collect data that is precise, reliable and useful for answering the investigation question.

Start practiceTake testOpen homework

Core understanding

What students need to know

Key idea

Equipment should match the variable being measured and the precision needed.

Key idea

Measurements need units, sensible decimal places and clear headings.

Key idea

Precision is about detail and consistency; accuracy is about closeness to the true value.

Key idea

Good technique reduces errors such as parallax, timing delay and inconsistent reading.

Scientific language and representations

Useful terms and ways to represent the idea

resolution: the smallest change an instrument can show
repeat trials help reveal random variation
record raw data before calculating averages
tables should include variable name, unit and trial number

Worked example

Worked example: choosing equipment

  1. A student needs to measure the temperature change when salt dissolves in water.
  2. A thermometer or temperature probe is more suitable than estimating by touch.
  3. The temperature should be recorded in °C with the same decimal-place rule each time.
  4. The same volume of water and same mass of salt should be used for each trial.
  5. A clear table should record starting temperature, final temperature and temperature change.

Common misconceptions

What to watch for

  • Choosing equipment because it is available rather than because it suits the measurement.
  • Recording numbers without units.
  • Confusing precise-looking decimal numbers with accurate measurements.
  • Changing measuring technique between trials.

Quick check

Try these before moving on

  1. Which equipment would you use to measure 25 mL of water accurately?
  2. Why should repeated measurements be recorded before averaging?
  3. Explain one way parallax error can be reduced.

Support tip

For parents and teachers

Ask students to justify equipment choices using the phrase “This equipment is suitable because…” This builds a link between practical technique and evidence quality.
