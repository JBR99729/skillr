Year 9 Science • AC9S9I05 • Topic guide

Analysing data and drawing evidence-based conclusions

This topic helps students move from “what happened?” to “what does the evidence show?”. Students identify trends, relationships and anomalies, connect different sources of information, and decide how strongly the data supports a conclusion.

Core understanding

What students need to know

Key idea

A trend is a general pattern in data, not just one result.

Key idea

A relationship describes how one variable changes as another variable changes.

Key idea

An anomaly is a result that does not fit the pattern and may need explanation.

Key idea

A conclusion should be supported by evidence and should not overclaim beyond the data.

Scientific language and representations

Useful terms and ways to represent the idea

claim: the answer or conclusion
evidence: specific data that supports the claim
reasoning: scientific explanation linking evidence to the claim
anomaly: data point that does not match the main pattern

Worked example

Worked example: using data in a conclusion

  1. A student tests how temperature affects dissolving time.
  2. The data shows dissolving time decreases as temperature increases.
  3. One trial at 60 °C is unusually slow compared with the pattern.
  4. A strong conclusion mentions the overall trend and the anomaly.
  5. Example: “The data suggests higher temperature decreases dissolving time, although one 60 °C result may need repeating.”

Common misconceptions

What to watch for

  • Writing a conclusion without quoting or describing evidence.
  • Ignoring anomalies because they are inconvenient.
  • Claiming cause and effect when the data only shows an association.
  • Using one data point to describe a whole pattern.

Quick check

Try these before moving on

  1. What is the difference between a result and a trend?
  2. Why should anomalies be considered before drawing a conclusion?
  3. Write one sentence that uses the words “evidence suggests”.

Support tip

For parents and teachers

Use the claim-evidence-reasoning structure. Students should point to specific data, then explain how that data supports their scientific conclusion.
