Conservation and System Efficiency

Energy input equals total output; efficiency compares useful output with total input.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

We are learning to explain conservation and system efficiency using models and evidence.

Success criteria

  • Identify and connect system boundary, input, useful output.
  • Use a model to explain rather than only describe the concept.
  • Apply the central idea to a curriculum example and justify the connection.
  • Evaluate one model limit, misconception or evidence boundary.
Concept boundary and prerequisites

Must teach

  • Energy is conserved across a defined system.
  • Useful and dissipated outputs together equal input.
  • Efficiency is useful output divided by total input, expressed as a percentage.

Prerequisites

  • Read a labelled scientific diagram or data display.
  • Distinguish an observation from an explanation.
  • Use evidence to support a short scientific statement.

Do not overteach

  • Do not confuse energy efficiency with speed or power.
  • Do not omit the system boundary or mix energy and power values.
Teaching progression
  1. 1. Define the system
    Use the shared model to foreground system boundary.
    Students: Annotate or explain the link involving system boundary.
  2. 2. Account for outputs
    Use the shared model to foreground input.
    Students: Annotate or explain the link involving input.
  3. 3. Calculate efficiency
    Use the shared model to foreground useful output.
    Students: Annotate or explain the link involving useful output.
  4. 4. Improve the design
    Use the shared model to foreground dissipated output.
    Students: Annotate or explain the link involving dissipated output.
Worked examples

Observe → connect → conclude

A motor receives 200 J and delivers 140 J of useful motion.

Common misconceptions
  • Inefficient systems destroy energy.
  • Efficiency can exceed 100%.
