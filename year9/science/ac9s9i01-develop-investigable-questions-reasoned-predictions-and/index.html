Year 9 Science • AC9S9I01 • Topic guide

Investigable questions, predictions and hypotheses

This topic builds the planning foundation for practical science. Students learn to turn a broad idea into a testable question, make a reasoned prediction and write a hypothesis that connects variables using science understanding.

Start practiceTake testOpen homework

Core understanding

What students need to know

Key idea

An investigable question can be answered by collecting evidence, not by opinion alone.

Key idea

A prediction states what is expected to happen.

Key idea

A hypothesis explains why the predicted relationship may occur.

Key idea

Clear variables make the investigation easier to plan and evaluate.

Scientific language and representations

Useful terms and ways to represent the idea

independent variable: the factor deliberately changed
dependent variable: the factor measured or observed
controlled variables: factors kept the same for a fair test
hypothesis: a testable explanation linking variables and reasoning

Worked example

Worked example: improving a question

  1. Broad idea: plants and light.
  2. Weak question: Do plants like light?
  3. Better question: How does the number of hours of light each day affect plant height over two weeks?
  4. Prediction: Plants with more light each day will grow taller.
  5. Hypothesis: More light allows more photosynthesis, so plants with more daily light should produce more biomass and grow taller.

Common misconceptions

What to watch for

  • Writing questions that are too vague to test.
  • Writing a prediction without explaining the science behind it.
  • Changing more than one independent variable at once.
  • Confusing the dependent variable with the independent variable.

Quick check

Try these before moving on

  1. Turn “temperature and dissolving” into an investigable question.
  2. Identify the independent and dependent variables in your question.
  3. Write a hypothesis that includes a because statement using science.

Support tip

For parents and teachers

Use the sentence frame: “How does changing ___ affect ___?” Then extend it with a prediction and a because statement.
