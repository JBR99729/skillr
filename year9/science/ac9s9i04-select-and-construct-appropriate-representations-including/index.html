Constructing tables, graphs and models

This topic helps students choose representations that make evidence easier to interpret. Tables organise raw data, graphs show patterns and relationships, and models help explain systems or processes that cannot be observed directly.

Start practiceTake testOpen homework

Core understanding

What students need to know

Key idea

The representation should match the type of data and the question being answered.

Key idea

Tables should make variables, units and repeated trials easy to read.

Key idea

Line graphs are useful for continuous relationships; column graphs compare categories.

Key idea

Models simplify real systems, so they should be explained with strengths and limits.

Scientific language and representations

Useful terms and ways to represent the idea

independent variable commonly goes on the x-axis
dependent variable commonly goes on the y-axis
axis labels need variable names and units
scale should use equal intervals and show the pattern fairly

Worked example

Worked example: choosing a graph

  1. A student measures temperature every minute as water cools.
  2. Time and temperature are both continuous variables.
  3. A line graph is suitable because it shows change over time.
  4. Time goes on the x-axis and temperature on the y-axis.
  5. The graph needs units, a sensible scale and plotted points joined or smoothed carefully.

Common misconceptions

What to watch for

  • Using a graph type because it looks attractive rather than because it suits the data.
  • Leaving units off axes or table headings.
  • Using uneven scale intervals that distort the pattern.
  • Treating a model as a perfect copy of reality.

Quick check

Try these before moving on

  1. Which graph type would suit comparing plant height under three fertilisers?
  2. What should be included in a table heading?
  3. Explain one limitation of a simple particle diagram model.

Support tip

For parents and teachers

Ask students what the representation is meant to show before they draw it. A clear purpose leads to better tables, graphs and models.
