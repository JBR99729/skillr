Real Numbers and Exact Values

Learn how every rational and irrational number fits on one real number line, when a value is exact, and when a decimal is only an approximation.

Learn the topicTeacher SlidesPractice SheetPracticeTest
1. Learn the idea

Learning intention: Classify real numbers, explain the difference between rational and irrational numbers, keep values exact when appropriate, and use approximations deliberately rather than accidentally.

The real-number family

A rational number can be written as a fraction a/b, where a and b are integers and b ≠ 0. Its decimal terminates or repeats. An irrational number cannot be written as such a fraction; its decimal continues forever without a repeating block. Together, rational and irrational numbers make the real numbers.

REAL NUMBERS ℝ
RATIONAL ℚ — fractions; terminating or recurring decimals
INTEGERS ℤ — …, −2, −1, 0, 1, 2, …
NATURAL NUMBERS — 1, 2, 3, …

Examples: 3/5, −4, 0.125, 0.333…

IRRATIONAL — not rational; non-terminating, non-recurring decimals

Examples: √2, √7, π

Key inclusion: every natural number is an integer; every integer is rational because, for example, −4 = −4/1; every rational number is real. Irrational numbers are also real, but they are not rational.

Exact versus approximate

Exact notation represents the value with no rounding error: √2, π, 5π and 25π/4 are exact. Writing √2 ≈ 1.414 or π ≈ 3.142 gives an approximation. The symbol = means equal; ≈ means approximately equal.

Rule: keep exact forms during working whenever possible, then round once at the end if the question requests a decimal accuracy.

2. Worked examples

Example A — classify tricky numbers

Classify 0, √9, √7, 2/11, 0.125 and 0.272727… as rational or irrational.

  1. 0 is rational because 0 = 0/1.
  2. √9 = 3, so it is rational. A square-root symbol does not automatically make a number irrational.
  3. √7 is irrational because 7 is not a perfect square.
  4. 2/11 is already a ratio of integers, so it is rational.
  5. 0.125 = 1/8, so it is rational.
  6. 0.272727… repeats the block 27, so it is rational. In fact it equals 3/11.

Check: rational decimals terminate or repeat; irrational decimals do neither.

Example B — exact and approximate circle values

A circle has diameter 5 units. Find its circumference and area exactly, then approximate the area to 2 decimal places.

  1. Radius r = 5/2.
  2. Circumference C = πd = 5π units exactly.
  3. Area A = πr² = π(5/2)² = 25π/4 square units exactly.
  4. Only now approximate: 25π/4 ≈ 19.63 square units.

The exact answer contains π. Replacing π by a rounded decimal earlier would introduce unnecessary rounding error.

Example C — locate √2 without pretending it equals 1.4

Draw a right triangle with perpendicular sides of length 1. By Pythagoras, its diagonal has length √(1²+1²)=√2. Transfer that diagonal length from 0 onto the number line with an arc. Because 1² < 2 < 2², we know 1 < √2 < 2; more precisely √2 ≈ 1.414.

Example D — inequality on the real number line

Solve 1.2x − 5.4 > 10.8.

  1. Add 5.4: 1.2x > 16.2.
  2. Divide by positive 1.2: x > 13.5.
  3. On a number line use an open point at 13.5 because 13.5 itself is not included, then shade to the right.
3. How to decide quickly

Classification checklist

  1. Simplify first. √25 is 5, so it is rational.
  2. If it is a fraction of integers, it is rational.
  3. If its decimal terminates, it is rational.
  4. If its decimal repeats forever, it is rational.
  5. Square roots of positive non-perfect-square integers are irrational.
  6. Numbers such as π are irrational.

Using a digital tool well

A calculator can help estimate or compare real numbers, but its display is finite. Seeing “1.414213562” on a screen does not prove √2 terminates. Treat the display as an approximation unless the mathematical form itself is exact.

4. Common misconceptions and fixes
  • “Every square root is irrational.” False: √49 = 7 is rational. Simplify before classifying.
  • “π = 3.14.” False: π ≈ 3.14. π is exact; 3.14 is a rounded approximation.
  • “A decimal that goes on forever is irrational.” Not always. 0.333… repeats and equals 1/3, so it is rational.
  • “Integers are not fractions.” Every integer can be written over 1, so every integer is rational.
  • “Calculator digits prove a number terminates.” A calculator display is limited; it may simply have rounded the true value.
  • Rounding at every step. Keep exact forms or extra calculator digits and round once at the requested final accuracy.
5. Support, core and extension

Support: Sort {−3, 1/2, 0.4, √2, √16, π} into rational and irrational groups and give one reason for each.

Core: Classify unfamiliar numbers, order rational and irrational values on a number line, and distinguish exact answers from rounded decimal approximations.

Extend: Decide whether a claim is always, sometimes or never true — for example, “the square root of an integer is irrational” — and prove your decision with examples and counterexamples.

6. Mastery check — 10 important questions

1. Is −8 rational?

Answer: Yes. −8 = −8/1, a ratio of integers.

2. Is √36 irrational because it contains √?

Answer: No. √36 = 6, so it is rational.

3. Is √10 rational or irrational?

Answer: Irrational. 10 is not a perfect square, so √10 cannot be expressed as a ratio of integers.

4. Why is 0.181818… rational?

Answer: Its decimal repeats. In fact 0.181818… = 2/11.

5. Which is exact: 3π or 9.425?

Answer: 3π is exact. 9.425 is a decimal approximation of 3π.

6. What is wrong with π = 3.14?

Answer: 3.14 is only an approximation, so the correct statement is π ≈ 3.14.

7. Between which integers does √20 lie?

Answer: 4 < √20 < 5 because 16 < 20 < 25.

8. Put √2, 1.4 and 3/2 in ascending order.

Answer: 1.4 < √2 < 1.5 because √2 ≈ 1.414.

9. Why keep 25π/4 instead of immediately writing 19.63?

Answer: 25π/4 is exact and carries no rounding error; 19.63 is rounded. Approximate only when required.

10. Can a rational number be a real number?

Answer: Yes. Every rational number is a real number; irrational numbers are the other part of the real-number system.

Exit ticket

Without a calculator, classify √81, √11, −2/7, 0.5050050005… as rational or irrational. Then explain which one is hardest to decide from its written form and what evidence you would need.

7. Revision notes
  • Real numbers = rational numbers + irrational numbers.
  • Natural ⊂ integers ⊂ rational ⊂ real.
  • Rational decimals terminate or repeat; irrational decimals are non-terminating and non-recurring.
  • Simplify expressions before classifying them: √9 = 3 is rational.
  • Use = for equality and ≈ for approximation.
  • Exact forms such as √2 and π preserve value; round only when requested.
  • To bound √n, compare n with nearby perfect squares.
