Relative Frequency and Event Language

Long-run relative frequency estimates probability, while ‘and’ and two meanings of ‘or’ select different outcome sets.

Topic GuideTeacher SlidesHomeworkPracticeTest
What students learn

Long-run relative frequency estimates probability, while ‘and’ and two meanings of ‘or’ select different outcome sets.

Learning intention: Long-run relative frequency estimates probability, while ‘and’ and two meanings of ‘or’ select different outcome sets.

Success criteria

  • Explain use long-run relative frequency using the approved model.
  • Apply code a relative-frequency algorithm to a new case.
  • Verify a conclusion with a second representation, estimate or test case.
Concept boundary and prerequisites

Must teach

  • calculate relative frequencies from given or collected data to estimate probabilities of events involving “and”, inclusive “or” and exclusive “or”

Prerequisites

  • Relevant Year 8 probability representations and vocabulary.

May support informally

  • Digital tools may test, visualise and verify after the mathematical structure is explicit.

Do not overteach

  • Do not introduce later-year formalism that is unnecessary for this content description.

Worked examples

Use long-run relative frequency

Understand that relative frequencies from large data sets or long-run experiments can provide reliable measures of probability and can be used to make predictions of decisions.

Teacher prompt: For use long-run relative frequency, which outcomes belong in the denominator, and why?

Interpret ‘and’ and ‘or’

Use Venn diagrams or two-way tables to estimate frequencies of events involving “and”, “or” questions.

Teacher prompt: For interpret ‘and’ and ‘or’, which outcomes belong in the denominator, and why?

Code a relative-frequency algorithm

Designing, testing and refining an algorithm used to determine relative frequencies from a generated data set, to estimate different probabilities.

Teacher prompt: For code a relative-frequency algorithm, which test case could expose an error in the steps?

Common misconceptions and quick fixes
  • The sample space or dependency changes without being noticed — Rebuild the outcomes and label replacement or conditioning explicitly.
  • The relative frequency and event language model is copied without interpretation — Connect every label in ‘Understand that relative frequencies from large data sets or long-run experiments can provide reliable measures of probability and can be used to make predictions of decisions.’ to its mathematical role.
  • The result is not verified — Use a second representation, boundary case, inverse operation or simulation check.
Support, core and extend

Support: Reduce numerical or representational load while retaining the same decision and explanation.

Core: Connect at least two representations, justify the method and verify independently.

Extend: Test a boundary case, counterexample or model limitation without introducing later-year procedures.
