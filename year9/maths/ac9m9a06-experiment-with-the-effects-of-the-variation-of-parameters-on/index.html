Function transformations and changing parameters

This topic helps students see that graphs are not random shapes: changing a number in an equation changes the graph in predictable ways. Students compare equations, tables and graphs to explain shifts, stretches, reflections and changes in steepness.

Core understanding

What students need to know

Key idea

A parameter is a number in a rule that can be changed to create a related graph.

Key idea

Changing the coefficient of x often changes steepness or rate of change.

Key idea

Adding or subtracting outside the main expression often moves a graph up or down.

Key idea

Using digital tools helps students test patterns quickly, but they still need to explain the mathematics.

Formulas and representations

Useful rules and ways to represent the idea

Linear example: y = mx + c
m controls gradient; c controls the y-intercept
Quadratic example: y = ax² + c
a changes width/reflection; c shifts the graph vertically

Worked example

Worked example: compare y = 2x + 1 and y = 2x + 4

  1. Both graphs have the same gradient, 2, so they are parallel.
  2. The y-intercepts are 1 and 4.
  3. The second graph is 3 units higher than the first at every matching x-value.
  4. Changing +1 to +4 shifts the graph upward by 3 units.

Common misconceptions

What to watch for

  • Thinking every change makes the graph steeper. Some changes only move the graph.
  • Reading a graph visually without checking a table of matching values.
  • Saying “it changed” without naming the exact effect, such as shift, reflection or stretch.

Quick check

Try these before moving on

  1. What happens to y = 3x + 2 if the 2 becomes 7?
  2. How does y = x² compare with y = x² - 5?
  3. Why is a table useful when comparing two related graphs?

Support tip

For parents and teachers

Ask the student to change one number at a time and describe the graph before calculating. This builds a habit of predicting first, then checking with values or a digital graph.
