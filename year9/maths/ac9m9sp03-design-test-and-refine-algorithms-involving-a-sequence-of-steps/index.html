Geometric Algorithms

A reliable construction algorithm uses explicit steps, decisions and test cases grounded in geometric theorems.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

A reliable construction algorithm uses explicit steps, decisions and test cases grounded in geometric theorems.

Learning intention: A reliable construction algorithm uses explicit steps, decisions and test cases grounded in geometric theorems.

Success criteria

  • Explain code a triangle test using the approved model.
  • Apply test and refine a visual-proof algorithm to a new case.
  • Verify a conclusion with a second representation, estimate or test case.
Concept boundary and prerequisites

Must teach

  • design, test and refine algorithms involving a sequence of steps and decisions based on geometric constructions and theorems; discuss and evaluate refinements

Prerequisites

  • Relevant Year 8 space representations and vocabulary.

May support informally

  • Digital tools may test, visualise and verify after the mathematical structure is explicit.

Do not overteach

  • Do not introduce later-year formalism that is unnecessary for this content description.

Worked examples

Code a triangle test

Create an algorithm using pseudocode or flow charts to apply the triangle inequality, or an algorithm to generate Pythagorean triples.

Teacher prompt: For code a triangle test, which labelled relationship justifies the conclusion?

Code an angle construction

Create and testing algorithms designed to construct or bisect angles, using pseudocode or flow charts.

Teacher prompt: For code an angle construction, which labelled relationship justifies the conclusion?

Test and refine a visual-proof algorithm

Develop an algorithm for an animation of a geometric construction, or a visual proof, evaluating the algorithm using test cases.

Teacher prompt: For test and refine a visual-proof algorithm, which test case could expose an error in the steps?

Common misconceptions and quick fixes
  • A diagram is trusted by appearance instead of stated conditions — Mark givens and name the theorem or transformation used.
  • The geometric algorithms model is copied without interpretation — Connect every label in ‘Create an algorithm using pseudocode or flow charts to apply the triangle inequality, or an algorithm to generate Pythagorean triples.’ to its mathematical role.
  • The result is not verified — Use a second representation, boundary case, inverse operation or simulation check.
Support, core and extend

Support: Reduce numerical or representational load while retaining the same decision and explanation.

Core: Connect at least two representations, justify the method and verify independently.

Extend: Test a boundary case, counterexample or model limitation without introducing later-year procedures.

Expected idea: Use the model evidence: Create an algorithm using pseudocode or flow charts to apply the triangle inequality, or an algorithm to generate Pythagorean triples. Then name the deciding relationship or limitation in a complete mathematical sentence.

Students should explain the relationship in their own words, apply it in a new case and verify the result using another representation, estimate or check.
