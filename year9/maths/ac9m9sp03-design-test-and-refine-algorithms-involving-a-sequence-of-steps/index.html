Geometric algorithms and step-by-step reasoning

This topic connects geometry with computational thinking. Students write clear step-by-step methods, test whether the steps work, and refine algorithms when a diagram, construction or calculation does not produce the intended result.

Start practiceTake testOpen homework

Core understanding

What students need to know

Key idea

An algorithm is a clear sequence of steps that can be followed and checked.

Key idea

A good geometric algorithm states inputs, actions, decisions and outputs.

Key idea

Testing means trying the steps on simple, boundary and tricky cases.

Key idea

Refining an algorithm means improving unclear, incomplete or incorrect steps.

Formulas and representations

Useful rules and ways to represent the idea

input → process → output
use precise instructions: draw, measure, compare, classify, repeat
decision step: if condition is true, then do the next action
test case: choose values or diagrams that reveal possible errors

Worked example

Worked example: refine a classification algorithm

  1. Goal: classify a triangle from its side lengths.
  2. First check whether the three lengths can form a triangle.
  3. If all three sides are equal, classify it as equilateral.
  4. If exactly two sides are equal, classify it as isosceles.
  5. Otherwise classify it as scalene.
  6. Test with 5, 5, 10 and refine the algorithm because those lengths do not form a triangle.

Common misconceptions

What to watch for

  • Writing vague steps such as “work it out” instead of precise actions.
  • Forgetting to test special cases, such as equal sides or impossible shapes.
  • Assuming an algorithm works after testing only one easy example.
  • Leaving out the final interpretation or output.

Quick check

Try these before moving on

  1. Write three steps for constructing a perpendicular bisector.
  2. Why should an algorithm be tested on more than one example?
  3. What extra check is needed before classifying side lengths as a triangle?

Support tip

For parents and teachers

Encourage students to swap algorithms with a partner. If another student cannot follow the steps exactly, the algorithm needs clearer language or more detail.
