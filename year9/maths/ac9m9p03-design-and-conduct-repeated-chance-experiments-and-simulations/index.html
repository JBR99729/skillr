Designing repeated chance experiments and simulations

This topic asks students to plan, run and evaluate chance experiments or simulations. A strong response explains the random process, records enough trials, calculates relative frequency and comments on reliability.

Start practiceTake testOpen homework

Core understanding

What students need to know

Key idea

A simulation uses a random process to model a real chance situation.

Key idea

Repeated trials make results more informative than a single trial.

Key idea

A good simulation must match the real situation fairly.

Key idea

Results should be interpreted using relative frequency and compared with theoretical probability where possible.

Formulas and representations

Useful rules and ways to represent the idea

relative frequency = successful trials ÷ total trials
expected count = theoretical probability × number of trials
larger samples usually reduce random variation
simulation design must match the event being modelled

Worked example

Worked example: simulate a basketball free throw

  1. A player usually scores about 70% of free throws. Use random numbers 1–10 to simulate one shot.
  2. Let 1–7 represent a score and 8–10 represent a miss.
  3. Generate 50 random numbers and record how many are 1–7.
  4. If 36 are scores, relative frequency = 36 ÷ 50 = 0.72.
  5. The simulation result, 72%, is close to the expected 70%, but another run could differ.

Common misconceptions

What to watch for

  • Choosing a simulation tool that does not match the probabilities in the real situation.
  • Running too few trials and making a strong conclusion.
  • Changing the rules during the experiment.
  • Reporting results without explaining the sample size or random method.

Quick check

Try these before moving on

  1. Design a simulation for a 25% chance event using numbers 1–100.
  2. Why are 200 trials usually better than 10 trials?
  3. What information should be recorded so another person can repeat your simulation?

Support tip

For parents and teachers

Make students write the simulation rule before collecting data. If the rule is clear, their results and conclusions are much easier to check.
