# Year 2 English full sweep

Scope: AC9E2LA01–AC9E2LA10, AC9E2LE01–AC9E2LE05 and AC9E2LY01–AC9E2LY12.

Authority: Australian Curriculum v9 Year 2 English descriptors from QCAA/ACARA-aligned public material. IXL is used as a teaching and question-design benchmark, not as a source to copy.

IXL review evidence used:

- IXL Australia Year 2 English standards page for all code-to-skill mappings.
- Representative worked-example pages reviewed sequentially in the browser: conjunctions; adjectives; context clues; capitalising titles; actions and dialogue; story analysis; rhyming poem completion; descriptive sentence details; informational passages; writer purpose; ordering story events; opinion reasons; open/closed syllables; vowel digraphs; sight words; prefixes pre-, re-, mis-.
- Codes with no direct IXL Year 2 mapping were covered from the official descriptor: AC9E2LA08, AC9E2LE01, AC9E2LY02, AC9E2LY07 and AC9E2LY08.

Output:

- 27 assessment banks.
- 1,080 questions total.
- Each code has 24 practice questions and 16 test questions.
- 88 adult-review tasks across the year for spoken, written, creative and explanation tasks.
- CSV files generated for every code plus a combined deliverable CSV.
- New quiz routes created for all pending codes and start pages cleaned so local links point only to available activities.

- IXL adaptive private question banks were not copied or bypassed. Only normal visible standards mappings and worked-example/practice page patterns were reviewed.
