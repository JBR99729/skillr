# Year 2 Science release: AC9S2U02, AC9S2U03 and AC9S2H01

Released from the approved CSV on 6 September 2026. The owner specified 24 Practice and 16 Test questions per code through Year 2. This scoped release contains 120 original questions. The CSV beside this note is the exact authored source; production JSON and browser question files retain its prompts, options, correct answers and explanations.

## Curriculum coverage

| Code | Assessed components |
| --- | --- |
| AC9S2U02 | Striking, blowing, scraping/rubbing, plucking and shaking; vibrating sources; loudness and pitch; sound variety; reducing vibrations; sound energy causing another object to vibrate; interpreting supplied observations. |
| AC9S2U03 | Bending, twisting, stretching and breaking; material remaining the same after physical change; comparing responses; shape and amount; changes that are easy or difficult to undo; selecting actions for a purpose. |
| AC9S2H01 | Science informing everyday decisions and problem solving; material, sound, plant, weather and heating applications; sky knowledge for navigation; using repeated observations to predict; uncertainty and updating predictions. |

- Each code has 24 Practice and 16 Test questions with three choices and one correct answer.
- The whole batch has 40 correct answers in each position A, B and C; each Practice bank has eight in each position.
- IDs and normalised prompts are unique. Audio prompts match the written questions; explanations and answer keys match the CSV.
- Eight-question attempts and existing navigation are retained. The three worksheet routes now draw from the same revised Practice banks.
- Existing per-item difficulty labels were removed because the previous labels do not describe these rewritten questions; no adaptive-difficulty equivalence is claimed.
- The required content-review ledger is updated through the repository script. This records content review, not completed IXL benchmarking. The Year 2 Science subject badge remains inactive.
- AC9S2U01 and the six inquiry codes are outside this release. Their existing banks have not been reduced by this change.
