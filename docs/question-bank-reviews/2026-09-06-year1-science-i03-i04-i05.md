## Structure and quality decisions

- 24 Practice + 16 Test per code: 120 questions. Eight recognition, eight application and eight reasoning Practice items. Existing attempt sizes remain unchanged.
- 18 simple SVGs: observation cards, informal length models and one-to-one picture graphs. Labels and alt text supply equivalent evidence. No decorative illustration work.
- Later questions require attention to the same sorting feature, time/place of observation, the changed part of a comparison, or evidence supporting a further question. Formal statistical language and unnecessarily large calculations are removed.
- The existing multiple-choice interface assesses selecting, comparing and correcting records. It does not independently assess making a drawing, collecting real-world observations or dragging items into bins. Practical observation and student-created records remain useful complements.
- New `r3` IDs, cache versions and result/best-score keys isolate previous attempts. Topic guides, classroom views and worksheets are outside this change.
- Canonical authoring: `scripts/year1_science_ixl_review/batch3/`. Build only this batch with its `build.py`, then publish each canonical JSON using `publish_production_question_bank.mjs --reviewed`.
