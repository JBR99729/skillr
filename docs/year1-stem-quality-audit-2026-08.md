# Year 1 STEM quality pass — August 2026

Scope: all 15 Year 1 Mathematics and 10 Year 1 Science curriculum codes. Scores are demanding editorial judgements against the Australian Curriculum Version 9.0 content descriptions and elaborations. The pass preserves the strict 8-question session rule and the existing no-repeat selector.

## Audit before implementation

Common strengths: all 25 codes already had authored concept records, code-aligned Practice and dedicated Test banks, answer keys, structured feedback, printable Practice Sheets and fixed teacher-slide routes. The 1,168 assessment items passed answer-key and required-feedback integrity checks. Existing question-bank QA logs were retained.

Common weaknesses: the richer authored lesson records were not visible on most live topic pages. Pages commonly stopped at a curriculum summary, so students could not reliably learn independently. Revision Notes were absent. Models, worked applications, misconceptions and mastery checks were hidden in data or slide assets. Several banks contain repeated text stems paired with different representations; these are not malformed, but selection should keep visually similar variants apart.

## Implementation report

Every code received the same high-value page changes: the authored key idea and learning routine, observable mastery criteria, code-specific concept model, worked application, three guided learning activities, every curriculum elaboration as an explicit learning context, misconception corrections, Revision Notes, quick questions, and aligned Teacher Slides / Practice Sheet / Practice / Test links. Teaching content is now static HTML and remains available without curriculum-rendering JavaScript. Thirteen pages containing First Nations elaborations now include cultural-safety guidance: use community-approved sources, identify the specific Nation or community where known, avoid pan-Indigenous generalisations, and follow local cultural and intellectual property protocols.

Question accounting: 744 Practice and 424 Test questions retained; 0 rewritten, removed or added. This pass did not bulk rewrite correct banks. Daily Drill validation found 1,684 unique active Year 1 Maths prompts across six broad pools and 1,000 unique Year 1 Science prompts across five broad pools, with no integrity issues. These are broad-topic pools rather than one separately tagged pool per curriculum code.

Visual decision: no decorative images were added. Existing fixed teacher-slide diagrams were preserved. Topic pages use the minimum effective visual load: code-specific HTML models for number representations, equal groups, patterns, measurement, time, shapes, location, data, habitats, seasonal cycles, forces and inquiry processes. These models materially support understanding and remain accessible as page content; adding stock images would not increase learning value.

Homework / Practice Sheet: routes and code alignment retained; no question inflation. Other fixes: corrected breadcrumbs, replaced live slide links with the local fixed slide viewer, embedded Revision Notes, and removed topic dependence on Year 1 curriculum renderers.

Remaining concerns: some assessment stems repeat while the representation or values change. They remain valid variants, but the selector should avoid placing near-identical variants in the same 8-question session. Drill reporting remains broad-topic rather than code-specific, so exact per-code drill counts are unavailable. Neither concern lowers a code below the 8/10 launch gate.
