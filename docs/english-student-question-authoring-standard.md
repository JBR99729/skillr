# Skillr English Student Question Authoring Standard

## Purpose

English curriculum descriptors are instructions for curriculum planning and assessment design. They should guide what a question tests, but should not usually appear as the language of the student-facing question.

The default pattern for student quizzes is:

**context or text -> student applies the skill -> student chooses, edits, explains or compares**

Avoid:

**curriculum wording -> student identifies a teacher-style assessment statement**

## Core rules

1. Write to the student, not to the teacher.
   - Avoid prompts such as "Which evidence would best show secure understanding...?"
   - Avoid "Which response plan best addresses...?" when a direct task can be given instead.
   - Avoid answers written like rubric descriptors or marking criteria.

2. Prefer direct examples.
   - Language: sentences, dialogue, emails, advertisements, paragraphs and editing tasks.
   - Literature: short extracts, character actions, themes, imagery, viewpoint and comparison.
   - Literacy: authentic reading, writing, speaking, viewing and comprehension tasks.

3. Use curriculum terminology only when students are expected to know the term.
   - A terminology question is acceptable when the term itself is part of the learning goal.
   - Do not use curriculum jargon merely to make a question sound difficult.

4. Make distractors plausible.
   - Distractors should represent realistic student misconceptions or near-misses.
   - Do not use unrelated curriculum statements as distractors.
   - Avoid obviously silly answers unless the year level genuinely requires very simple discrimination.

5. Increase difficulty through reasoning, not jargon.
   - Harder questions should use subtler distinctions, richer texts, competing interpretations, editing choices or evidence-based reasoning.
   - Do not increase difficulty by making the prompt more abstract or teacher-facing.

6. Keep the assessment target clear.
   - One best answer for single-choice questions.
   - The correct answer must be defensible from the supplied context or text.
   - Do not rely on hidden lesson notes to make an answer correct.

7. Use age-appropriate Australian English.
   - Natural classroom, school, community and everyday contexts are preferred.
   - Keep tone respectful and inclusive.

8. Explanations should teach the student.
   - Explain why the correct answer works in the example.
   - Do not say only that the answer "demonstrates secure understanding" or "matches the model".

## Examples

### Avoid

Which evidence would best show secure understanding of Formality, Social Distance and Authority?

### Prefer

Mia is emailing the school principal. Which sentence is most appropriate?

A. Hey, can you fix the playground?
B. Could you please consider repairing the damaged playground equipment?
C. Oi, the playground needs fixing.
D. You need to repair it now.

### Avoid

A student says, "Formal means complex vocabulary." Which response best corrects the misunderstanding?

### Prefer

Which sentence uses formal language appropriately in an email to a principal?

A. I would appreciate the opportunity to discuss the excursion.
B. I endeavour to utilise exceptionally sophisticated lexical constructions.
C. Hey, can we chat about the trip?
D. Tell me about the excursion now.

The point is that formality is about suitability for audience, purpose and relationship, not simply using complicated words.

## QA flags

Flag a question for re-authoring when it contains one or more of the following:

- "secure understanding"
- "which evidence would show"
- "which principle should guide a response"
- "which response plan"
- "which analytical move is strongest" without an actual text/example
- "which approach best addresses this evaluation" without an actual text/example
- answers that describe what "students" should do
- answers that sound like rubric criteria
- curriculum-descriptor wording used as the student task
- abstract definitions when a direct example would assess the same skill better

## Year 6 pilot

Year 6 English is the first full audit. All Language, Literature and Literacy assessment banks should be checked against this standard before the same process is expanded to the remaining English year levels.
