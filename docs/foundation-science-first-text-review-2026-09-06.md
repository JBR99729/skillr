# Foundation science text review: features, movement and observing nature

Scope: AC9SFU01, AC9SFU02, AC9SFH01 topic pages and worksheet pages. 6 September 2026. Materials (AC9SFU03) was reviewed earlier and is unchanged. Classroom views, Practice/Test banks and existing images are unchanged.

## IXL evidence
Authenticated Australian IXL Parent-mode tasks inspected:
- https://au.ixl.com/science/year-1/identify-plant-parts — select a named plant part within a complete plant illustration, rather than recognise an isolated label.
- https://au.ixl.com/science/year-1/the-way-things-move — identify a described motion from examples.
- https://au.ixl.com/science/year-1/describe-objects — select an observable description and reject an incorrect shape or material description.

These Australian IXL examples are labelled Year 1. Only overlapping Foundation content was used as a benchmark. The observation task is a partial benchmark for AC9SFH01; it does not cover that code's complete people-and-science context. No full adaptive-sequence equivalence is claimed. All new wording and scenarios are original.

## Changes and value
- Fifteen teaching/check activities: identify external parts in context, compare humans and other animals, regroup with different observable rules, describe actual movement, distinguish observation from possible explanation, and choose useful records.
- Ten generic elaboration expansions replaced with specific teaching examples for movement and observing nature. Existing feature teaching and photos preserved.
- Thirty explained worksheet answers and hints added as static, printable adult guides. The existing student PDF renderer, worksheet appearance and 8 core / 2 enrichment split remain.
- Selected questions now require consistent regrouping, checking a claim against a movement result, or distinguishing directly observed evidence from an inferred cause.
- Corrected the implication that grouping by visible colour is inherently invalid. Clarified that hidden roots can still be external parts and that size alone cannot explain a comparison where material also differs.
