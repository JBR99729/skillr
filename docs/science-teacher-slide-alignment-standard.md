# F–10 Science teacher-slide alignment standard

Teacher slides must summarise the topic page into teachable classroom concepts. They should not duplicate the full topic lesson, and they should not be a single decorative image unless the curriculum code is extremely narrow.

## Role of teacher slides

- Topic page: complete mini lesson and SEO learning resource.
- Teacher slides: concise, visual teaching sequence for classroom display.
- Practice/Test: student application and transfer.

## Minimum deck structure

Foundation–Year 2: 4 slides
1. Main idea
2. Observe / notice
3. Shared example
4. Student practice thought

Years 3–5: 5 slides
1. Main idea
2. Key vocabulary or representation
3. Worked example
4. Common misconception
5. Student practice thought

Year 6: 6 slides
1. Main idea
2. Key model or representation
3. Evidence or cause-effect explanation
4. Worked example
5. Common misconception
6. Student practice thought

Years 7–10: 6–7 slides
1. Main idea and why it matters
2. Core concept map or model
3. Important curriculum/elaboration concepts
4. Worked example or data/model interpretation
5. Misconception / limitation / boundary
6. Transfer or application prompt
7. Student practice thought, where needed

## Required quality checks

- The deck covers the essential ideas taught on the topic page.
- Slides are concise enough to teach from.
- Each deck closes with a student thought, exit question or practice prompt.
- Visuals are relevant: diagrams, symbolic models, process flows, icons or image assets where appropriate.
- First Nations content is included when relevant and written respectfully, acknowledging diversity of Country/Place and avoiding generic claims.
- From Year 6 onward, the slides should increasingly include evidence, mechanism, modelling, limitations and transfer.
- Existing URLs and navigation must remain stable.

## Not required

Interactive drag-and-drop tools are optional and not required for Skillr quality. Practice and Test already handle student interaction. Teacher slides should support classroom teaching, not become a second quiz engine.
