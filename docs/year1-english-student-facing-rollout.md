# Year 1 English student-facing rollout

Scope: AC9E1LA01–AC9E1LA10, AC9E1LE01–AC9E1LE05 and AC9E1LY01–AC9E1LY15.

Each code uses the same Skillr learning model:

1. Topic page explains the child-facing learning goal and curriculum focus.
2. Classroom display uses the same goal, model, worked example, activities, mix-ups and checks.
3. Printable worksheet contains 10 aligned questions, including 2 extension questions.
4. Practice contains 40 three-option MCQs ordered as 10 recognise, 10 explain, 10 discriminate and 10 apply questions.
5. Test remains a separate 16-question source range so assessment examples are not consumed by practice.

The Year 1 student-facing overlay is additive to the existing authored Year 1 English lesson source. It does not replace the Australian Curriculum description; it converts the supplied curriculum and elaboration focus into child-friendly learning goals and practice prompts.
