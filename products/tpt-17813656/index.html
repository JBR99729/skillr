Explore how objects roll, slide, bounce and rest with this illustrated, 136-slide Foundation Science resource aligned to Australian Curriculum v9 code AC9SFU02. Six strands cover observing movement; how shape, size and material affect movement; setting up fair toy tests; and using observations to explain and predict.
