Australian curriculum planning

Australian primary teachers can use this Australian Curriculum v9 (ACARA) Year 2 Mathematics resource for local planning, including NSW teachers using the NSW Curriculum / NSW Mathematics Syllabus (NESA Stage 1) and Victorian teachers using Victorian Curriculum 2.0 Mathematics (VCAA Level 2). Retain the listed AC9 code as the curriculum reference. Check the relevant local syllabus content and achievement standards when selecting activities; this planning guidance does not establish a code-by-code equivalence.
