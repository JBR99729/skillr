About This Year 2 Maths Topic

In this unit, children create different graphical representations of data and compare how effectively each display communicates information.

Children work with:

  • lists;
  • tally charts;
  • picture graphs and pictographs;
  • sticker charts;
  • dot plots;
  • column graphs;
  • bar charts;
  • digital data displays.

They learn that the same dataset can be represented in several ways without changing the underlying information.

Children compare displays by considering:

  • the title;
  • the categories;
  • the labels;
  • the number represented by each symbol, dot or column;
  • the horizontal and vertical arrangement;
  • how easily the display can be read;
  • which features are shared;
  • which features are distinctive.

These activities support Australian Curriculum Version 9.0 content descriptor AC9M2ST02 and its associated elaborations.

The Big Idea for Parents

The same data can be displayed in different ways.

A list, tally chart, picture graph and column graph may look different, but they should show the same category frequencies when they represent the same dataset.

A useful Year 2 data display should:

  • have a clear title;
  • show relevant categories;
  • use accurate frequencies;
  • label categories clearly;
  • use one-to-one correspondence when required;
  • make comparisons easy to see;
  • represent every response once.

Children should not only create graphs. They should also explain what each graph shows and compare the strengths and limitations of different representations.

Teacher Guide for Parents

Teachers usually begin with a small, familiar dataset before helping children transform it into different representations.

At home, follow this sequence: organise the data, select a display, create it accurately, interpret it, compare it and check it.

1. Begin with Organised Data

Before creating a graph, children need to know the categories and the frequency of each category.

For example, a favourite-colour survey may produce:

Colour Number of students
Blue 6
Red 4
Green 3
Yellow 2

Every display created from this dataset should show the same frequencies.

2. Use a Limited List of Choices

A limited list of choices makes the categories clear and manageable.

Suitable Year 2 topics include:

  • favourite colour from four choices;
  • favourite fruit from five choices;
  • preferred playground activity;
  • way of travelling to school;
  • favourite animal from a short list.

Each person should provide one response when the activity is designed as a single-choice survey.

3. Create a Simple List

A list records individual responses or category totals.

A raw response list may show:

  • Blue
  • Red
  • Blue
  • Green
  • Blue

A category list may show:

  • Blue: 3
  • Red: 1
  • Green: 1

Lists are useful for recording data but may make visual comparisons harder when the dataset becomes larger.

4. Create a Tally Chart

A tally chart records each response using tally marks.

The fifth tally crosses the first four, making groups of five easier to count.

Category Tally Total
Blue |||| | 6
Red |||| 4
Green ||| 3

When copying data from a tally chart into another display, children should use the totals rather than recounting carelessly.

5. Create a One-to-One Picture Graph

In a one-to-one picture graph, one picture represents one response.

For example:

1 coloured square = 1 student

If 6 students choose blue, the blue category must contain 6 symbols.

Important Year 2 convention

When the graph uses one-to-one correspondence, children do not need to multiply. They count one symbol for each response.

6. Check Symbol Size and Spacing

Picture graph symbols should be:

  • the same size;
  • spaced consistently;
  • arranged in clear rows or columns;
  • easy to count;
  • matched to the correct category.

Different symbol sizes can make one category appear larger even when the frequency is not greater.

7. Give the Picture Graph a Clear Title

The title should describe the data represented.

Suitable titles include:

  • Our Class Favourite Colours;
  • Ways Students Travel to School;
  • Favourite Playground Activities;
  • Countries of Birth in Our Class.

A title such as “Graph” is too general because it does not explain the subject of the data.

8. Label Every Category

Each picture graph category should have a clear label.

Children should not rely only on colour or picture clues, especially when the graph may be printed in black and white or viewed by someone unfamiliar with the symbols.

9. Create a Sticker Chart

A sticker chart works like a picture graph when each sticker represents one response.

Children can place one sticker above or beside each category for every response collected.

Sticker charts are useful for jointly creating a class display because each learner can add their own response.

10. Create a Dot Plot

A simple Year 2 dot plot places one dot for each response above the relevant category.

Dots should be:

  • the same size;
  • placed directly above the correct category;
  • stacked consistently;
  • counted one at a time.

A dot plot allows the height of each stack to show the relative frequency.

11. Create a Column Graph

A column graph uses vertical columns to show category frequencies.

The categories are commonly placed along the horizontal axis, while numbers are placed on the vertical axis.

Children should ensure:

  • all columns begin at the same baseline;
  • the columns have equal width;
  • the gaps between columns are reasonably consistent;
  • the height of each column matches the frequency;
  • the number scale is evenly spaced;
  • the categories are labelled.

12. Read the Horizontal Axis

The horizontal axis usually displays the data categories in a Year 2 column graph.

For a favourite-colour graph, the horizontal categories may be:

  • blue;
  • red;
  • green;
  • yellow.

13. Read the Vertical Axis

The vertical axis commonly shows the number or frequency.

Children should read the scale carefully rather than assuming every line has the value one.

At this year level, use simple evenly spaced scales that support accurate counting.

14. Create a Simple Bar Chart

A bar chart may use horizontal bars, while a column graph uses vertical columns.

Both representations compare category frequencies using the length or height of rectangular bars.

Children should focus on:

  • the category labels;
  • the number scale;
  • the length of each bar;
  • the most and least common categories.

15. Create Two Displays from the Same Data

Use one dataset to make two different displays.

For example:

  1. Create a picture graph of favourite colours.
  2. Create a column graph using the same totals.
  3. Compare the graphs.

The category frequencies should remain unchanged even though the graphical form is different.

16. Compare Picture Graphs and Column Graphs

A picture graph and column graph may share:

  • the same title;
  • the same categories;
  • the same frequencies;
  • the same most common category;
  • the same least common category.

Their distinctive features may include:

  • pictures versus rectangular columns;
  • counting symbols versus reading a number axis;
  • different visual layouts;
  • different levels of ease when comparing frequencies.

17. Compare Lists, Tallies and Graphs

Each representation has a different purpose.

Display Useful feature
List Shows individual responses or category totals.
Tally chart Makes it easy to record responses as they are collected.
Picture graph Uses visible symbols that can be counted directly.
Column graph Makes category heights easy to compare.
Dot plot Shows one dot for each response in a stack.

18. Discuss Which Display Is Easier to Interpret

There is not always one correct answer. Children should justify their opinion.

For example:

  • A picture graph may be easier because each picture can be counted.
  • A column graph may be easier because the tallest category is immediately visible.
  • A tally chart may be easier when recording data as it is collected.

The explanation should refer to specific features of the display.

19. Identify Common Features

Common features are characteristics shared by two or more displays.

Children may identify:

  • the same dataset;
  • the same categories;
  • the same category totals;
  • the same title or topic;
  • the same most common response;
  • the same least common response.

20. Identify Distinctive Features

Distinctive features are characteristics that make one display different from another.

Examples include:

  • symbols in a picture graph;
  • groups of five in a tally chart;
  • stacked dots in a dot plot;
  • vertical columns and a number axis in a column graph;
  • horizontal bars in a bar chart.

21. Interpret the Most Common Category

The most common category has the greatest frequency.

In different displays, this may appear as:

  • the longest list of symbols;
  • the greatest tally total;
  • the tallest stack of dots;
  • the tallest column;
  • the longest bar.

22. Interpret the Least Common Category

The least common category has the smallest frequency.

More than one category may be least common when categories have equal smallest frequencies.

23. Compare Category Frequencies

Ask children to use comparison language.

For example:

  • more than;
  • fewer than;
  • the same number as;
  • most common;
  • least common;
  • difference between.

Example:

“Blue has 3 more responses than yellow.”

24. Check One-to-One Correspondence

When one symbol represents one response, the number of symbols must equal the category frequency.

Ask children to:

  1. count the original responses;
  2. count the symbols in the graph;
  3. compare the two totals;
  4. correct missing or extra symbols.

25. Check That Every Display Shows the Same Data

Compare category by category.

Category Picture graph Column graph
Blue 6 symbols Column reaches 6
Red 4 symbols Column reaches 4
Green 3 symbols Column reaches 3

If the values do not agree, one of the displays contains an error.

26. Use Country-of-Birth Data Respectfully

Country-of-birth data can be used to create classroom graphs when the activity is appropriate and respectful.

Adults should:

  • explain the purpose clearly;
  • avoid pressuring children to share private information;
  • use inclusive and accurate category labels;
  • allow an appropriate alternative activity;
  • focus on interpreting data rather than making assumptions about individuals.

27. Create a Digital Picture Graph

A familiar drawing, spreadsheet or graphing tool can be used to arrange one symbol for each response.

Children should check:

  • the title;
  • category labels;
  • the number of symbols;
  • consistent symbol size;
  • one-to-one correspondence;
  • whether the graph matches the original data.

28. Use AI Tools Responsibly

A generative artificial intelligence tool may help suggest titles, organise category names or create ideas for symbols.

Children should not assume that an automatically generated graph is correct.

With adult supervision, check:

  • whether the category labels are accurate;
  • whether every frequency matches the dataset;
  • whether one symbol represents one response;
  • whether the title suits the context;
  • whether any category has been omitted;
  • whether private information has been entered.

Digital safety reminder

Children should use digital and AI tools with adult supervision and should not enter personal identifying information into public systems.

29. Choose an Appropriate Graph Title

A suitable title communicates:

  • what was investigated;
  • which group or context the data relates to;
  • what the categories represent.

Compare:

  • Too general: Our Graph
  • More informative: Favourite Colours in Class 2A

30. Review Whether the Categories Are Appropriate

The categories should:

  • match the investigation question;
  • be clear to the reader;
  • avoid unnecessary overlap;
  • include all recorded responses;
  • use respectful and appropriate language.

If the categories are confusing, revise them before creating the final display.

31. Explain What the Graph Shows

A complete interpretation should refer to evidence.

For example:

“Blue was the most popular colour because its column reached 6. Yellow was the least popular because its column reached 2.”

32. Explain Similarities and Differences

Use a comparison structure:

“Both displays show the same four colours and the same frequencies. The picture graph uses one symbol for each response, while the column graph uses column heights and a numbered vertical axis.”

33. Decide Which Display Communicates the Data Best

The preferred display may depend on:

  • the number of categories;
  • the size of the frequencies;
  • the intended audience;
  • whether exact counting is needed;
  • whether quick visual comparison is more important.

Children should justify their choice rather than simply naming a favourite display.

Recommended Teaching Sequence at Home

  1. Organise a small categorical dataset.
  2. Record the data in a list.
  3. Create a tally chart.
  4. Create a one-to-one picture graph.
  5. Add a suitable title and category labels.
  6. Create a sticker chart or dot plot.
  7. Create a column graph.
  8. Check the number scale and column heights.
  9. Create two displays from the same data.
  10. Compare common features.
  11. Compare distinctive features.
  12. Interpret the most and least common categories.
  13. Use digital tools to create a display.
  14. Check that every representation matches the original data.
  15. Explain which display is easiest to interpret and why.

Common Misconceptions and How Parents Can Help

Creating a graph before organising the data

Count each category first and record the totals in a table before building the graph.

Using an unclear graph title

Write a title that states what data was collected and the context of the investigation.

Leaving categories unlabelled

Add a clear written label for every category rather than relying only on colours or pictures.

Using different-sized picture symbols

Keep symbols equal in size because larger pictures can make a category appear more frequent.

Using one picture for several responses without explaining it

For one-to-one graphs, use one symbol for one response. If a different key is introduced later, it must be stated clearly.

Adding an extra symbol for the category label

The picture beside a category name is not automatically a data symbol. Separate labels from response symbols clearly.

Counting the starting line as a value

In a column graph, the baseline usually represents zero. Count the intervals above the baseline.

Starting columns at different heights

All columns should begin at the same baseline so their heights can be compared fairly.

Using uneven number intervals

Keep the number scale evenly spaced and check the value of every interval.

Making columns different widths

Use columns of equal width so the display does not exaggerate one category.

Thinking different graphs show different datasets

Compare category totals to show that two representations can display the same underlying data.

Choosing the tallest-looking picture instead of counting

Count the symbols or read the number scale before deciding which category is most common.

Assuming digital graphs are automatically correct

Compare the digital display with the original frequency table and check every category.

Simple Home Data Display Activities

Activity 1: Favourite Colour Graphs

Survey family members using four colour choices. Create a picture graph and a column graph from the same data.

Compare how the two displays are similar and different.

Focus: AC9M2ST02_E1.

Activity 2: List to Tally Chart

Record a short list of favourite fruits and convert the responses into a tally chart.

Check that the category totals match the original list.

Focus: AC9M2ST02_E2.

Activity 3: One-to-One Picture Graph

Use one small picture, stamp or drawing for every response in a dataset.

Add a clear title and category labels.

Focus: One-to-one correspondence.

Activity 4: Sticker Chart

Ask family members to place one sticker beside their preferred activity.

Count the stickers and identify the most and least popular choices.

Focus: AC9M2ST02_E5.

Activity 5: Dot Plot Challenge

Place one dot above each category for every response.

Compare the height of the dot stacks and write two conclusions.

Focus: Dot plots.

Activity 6: Build a Column Graph

Use graph paper to create a column graph from a completed frequency table.

Check the title, category labels, number scale and column heights.

Focus: Column graph construction.

Activity 7: Graph Detective

Examine two graphs of the same data and identify three shared features and three distinctive features.

Focus: AC9M2ST02_E4.

Activity 8: Which Display Is Easier?

Compare a list, tally chart, picture graph and column graph.

Ask your child to choose the easiest display to interpret and justify the choice.

Focus: Comparing representations.

Activity 9: Digital Picture Graph

With adult supervision, use familiar software to arrange one digital symbol for every response.

Check the graph against the original dataset.

Focus: AC9M2ST02_E3.

Activity 10: Find the Graph Errors

Create or examine a graph with mistakes such as a missing title, unequal columns, incorrect totals or unlabelled categories.

Ask your child to identify and correct each error.

Focus: Checking graph accuracy.

Questions Parents Can Ask

  • What data does this display represent?
  • What is the title of the graph?
  • Are all categories labelled?
  • What does each picture or dot represent?
  • Is this a one-to-one picture graph?
  • How many responses are in this category?
  • Which category is most common?
  • Which category is least common?
  • Are any categories equal?
  • How many more responses are in one category?
  • What does the horizontal axis show?
  • What does the vertical axis show?
  • What is the value of each interval?
  • Do all columns begin at the same baseline?
  • Does this display match the original data?
  • What features do the two displays share?
  • What features are different?
  • Which display is easier to interpret?
  • Why is that display easier?
  • How could the graph be improved?

Supporting Different Learners at Home

Children Who Need More Support

  • begin with two or three categories;
  • use frequencies no greater than ten;
  • use physical objects before drawing symbols;
  • use one picture for one response;
  • provide pre-labelled categories;
  • use graph paper for column alignment;
  • use a vertical scale counting by ones;
  • compare only two displays at a time;
  • colour-code matching categories across displays;
  • allow oral interpretations before written responses.

Children Ready for Extension

  • create three or more displays from one dataset;
  • compare larger category frequencies;
  • create displays using five or six categories;
  • identify misleading graph features;
  • compare horizontal bars with vertical columns;
  • design a graph for a specific audience;
  • write questions that can be answered from a graph;
  • create a digital graph and compare it with a hand-drawn version;
  • justify which display communicates the data most effectively;
  • correct a graph containing several errors.

Quick Parent Check

Use one small dataset to check whether your child understands the main ideas.

  1. Record the data in a tally chart.
  2. Create a one-to-one picture graph.
  3. Add an appropriate title.
  4. Label every category.
  5. Create a column graph using the same data.
  6. Check that both displays show the same frequencies.
  7. Identify the most and least common categories.
  8. State one similarity between the displays.
  9. State one difference between the displays.
  10. Explain which display is easier to interpret and why.

A child shows secure understanding when they can represent the same data accurately in different ways and explain both the shared and distinctive features of the displays.

Quick Exit Ticket

  1. Name two different ways to display the same data.
  2. Explain what one-to-one correspondence means in a picture graph.
  3. State one difference between a picture graph and a column graph.

Home Learning Summary

Graphing skills develop when children create more than one representation of the same data and check that each display communicates the same information accurately.

Use this simple routine:

  1. organise the dataset;
  2. count each category;
  3. choose a suitable display;
  4. add a clear title;
  5. label every category;
  6. represent every response accurately;
  7. create a second display;
  8. compare shared features;
  9. compare distinctive features;
  10. interpret the data;
  11. check both displays against the original dataset.
