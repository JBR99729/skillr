Measure length, capacity and mass

Learning intention: Choose suitable uniform informal units and remeasure with smaller units when needed.

Worked example

Learn the skill

1. Length and height

Align the first unit with the object’s start. Use identical units end-to-end, without gaps or overlaps. Count the unit lengths, not the boundary marks.

Try it · Two ribbons measure 5 and 8 identical blocks. Which is longer?

The ribbon measuring 8 blocks is longer by 3 blocks.

2. Capacity

Capacity is how much a container can hold when full. Fill the same small cup to the same level for every pour, tally the pours and fill the target container. Its current contents are not its capacity.

Try it · A jug holds 6 scoops and a cup holds 3 of the same scoop. Which holds more?

The jug holds 3 scoops more.

3. Mass

Start with an empty level balance. The lower pan holds greater mass; level pans show equal mass. Compare objects with equal-mass units, not just objects of the same apparent size.

Try it · A balance shows a toy has the same mass as 7 identical counters. How would you record it?

Record the mass as 7 counters, giving the number and the informal unit.

Common mistakes

Changing unit size halfway through a measurement. Choose equal units for one measurement. Record both the number and the unit.

10-MINUTE HOME ACTIVITY

Measure three ways

Measure a book with equal blocks, fill a cup with equal scoops, and balance a small object against identical counters on a simple balance. Record the unit with each count.

Adjust the challenge: Start by measuring length only. Extend by predicting how using a smaller unit affects the count.

FAQ

Why use the same scoop to compare cups?

Different scoops hold different amounts. One scoop size makes the counts comparable.

Learn the skill

Small steps, clear examples

Open one focus at a time. Explain the model, try the question and check the reasoning.

1. Length and height

Align the first unit with the object’s start. Use identical units end-to-end, without gaps or overlaps. Count the unit lengths, not the boundary marks.

ObjectSame-sized blocks
Ribbon A7
Ribbon B10

Try it: Which ribbon is longer, and by how much?

Check the answer

Ribbon B is longer by 3 block-units: 10 − 7 = 3.

2. Capacity

Capacity is how much a container can hold when full. Fill the same small cup to the same level for every pour, tally the pours and fill the target container. Its current contents are not its capacity.

Try it: A jug holds 8 full cups. A bottle holds 5 of the same full cups. Which holds more?

Check the answer

The jug holds 3 cups more. A taller-looking bottle need not have the greater capacity.

3. Mass

Start with an empty level balance. The lower pan holds greater mass; level pans show equal mass. Compare objects with equal-mass units, not just objects of the same apparent size.

Try it: A toy balances 6 identical mass-units; a book balances 9. Which has greater mass?

Check the answer

The book has greater mass by 3 of those units. Size alone is not evidence of mass.

4. Fair methods, suitable units and accuracy

Keep the attribute and unit consistent. A pencil needs small length units; a room needs larger practical units. If an end falls between whole units, report the bounds honestly, then remeasure with smaller equal units. Smaller units usually increase the count; they do not make the object larger or guarantee an exact fit.

Try it: A strip ends between 5 and 6 large units. May we call it exactly 6?

Check the answer

No. Say between 5 and 6 large units, or measure again with smaller units.

Try it together
  • Measure two real pencils with identical blocks; align starts and explain your comparison.
  • Supervise a pouring investigation with unbreakable containers: count the same full cup repeatedly until each container is full. Use a tray and do not assume the taller container holds more.
  • Use an empty level balance to compare a small heavy object and a large light object, then measure with equal-mass units. Adult supervision is needed for small parts.

Support: Use real objects, fewer choices and an adult read-aloud. Core: Explain and record the model independently. Extend: Create a new example or repair an error while staying within this skill.

Teaching tips and common mistakes

Ask the learner to explain what each mark, unit or instruction means. Rebuild the model when an answer is correct by guessing. A written answer alone does not establish practical or digital performance.

Curriculum code and learning goal

AC9M2M01: Choose suitable uniform informal units and remeasure with smaller units when needed.

Use appropriate uniform informal units to compare length, capacity and mass; choose smaller units when accuracy requires it.
