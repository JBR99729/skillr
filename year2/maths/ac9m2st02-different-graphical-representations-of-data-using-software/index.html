Create and compare data displays

Learning intention: Create one-to-one displays and explain what stays the same when the representation changes.

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Worked example

Tag and skipping tie at 4 each; climbing has 0.

Learn the skill

1. Create one-to-one picture, sticker and dot displays

Use fresh class-game data: tag 4, ball 2, skipping 4, climbing 0. Add a title and category labels. Use one equal symbol per response; the key is not a response. Keep a labelled zero category and align marks so comparisons are fair.

Try it · A picture stands for one vote. How many pictures show four votes?

Four pictures.

2. Create column and horizontal bar graphs

Use the same counts. Put the category names on one axis and a count scale starting at zero on the other. Use equal intervals of one and equal-width bars. A column graph uses vertical bars; a horizontal bar graph uses bars across. Match each endpoint to its category count.

Try it · A bar has a count of 6. Where should it end on a scale marked in ones?

At the mark labelled 6, starting from zero.

3. Compare, explain, choose and check displays

The dot display and bar display above have the same categories, counts, total and tie. Their marks and arrangement differ. Changing category order must not change which count belongs to each name. Equal totals alone do not prove that two displays match.

Try it · One category has 6 votes and another has 4. How many more does the first have?

Two more votes.

Common mistakes

Starting bars from different positions. Use the same zero line and unit spacing for every bar.

10-MINUTE HOME ACTIVITY

Show the same data two ways

Use counts of 5 cats, 3 dogs and 2 birds. Draw a one-to-one picture display, then draw a bar graph with the same counts. Compare what each shows.

Adjust the challenge: Start with two categories. Extend by making a horizontal bar graph and checking that the comparisons agree.

FAQ

How many more cats than birds are shown?

Three more, because 5 − 2 = 3.

3. Compare, explain, choose and check displays

The dot display and bar display above have the same categories, counts, total and tie. Their marks and arrangement differ. Changing category order must not change which count belongs to each name. Equal totals alone do not prove that two displays match.

Choose a display for a purpose: aligned bars make differences easy to compare; one-to-one pictures can make individual responses visible. With adult support, enter these counts into a graphing tool, select a unit-scale column display, add title/labels and compare every bar with the original table. Correct automatic scales or changed categories when they obscure the intended one-to-one model.

Try it: A second graph shows tag 2 and ball 4, but still totals 10. Is it the same data?

Check the answer

No. The category counts were swapped. Check every category, including zero and tied counts.

Support: Use real objects, fewer choices and an adult read-aloud. Core: Explain and record the model independently. Extend: Create a new example or repair an error while staying within this skill.

Teaching tips and common mistakes
  • Changing counts — Every display must match the original data.
  • No labels — Graphs need category names and counts or scale.
  • Choosing by looks only — Choose the display that answers the question clearly.

Ask the learner to explain what each mark, unit or instruction means. Rebuild the model when an answer is correct by guessing. A written answer alone does not establish practical or digital performance.

Curriculum code and learning goal

The content description and elaborations below show the curriculum ideas taught in this unit. Items marked as teaching context support lesson planning.

  • Content description: create different graphical representations of data using software where appropriate; compare the different representations, identify and describe common and distinctive features in response to questions
  • E1: collecting data from a limited list of choices, creating 2 different graphical representations of the data, discussing and comparing the different representations; for example, asking the class to choose their favourite colour from a given set, then co-creating a picture graph with colours on the horizontal axis and comparing to a column graph with colours on the horizontal axis and numbers on the vertical axis
  • E2: creating different data displays; for example, lists, tally charts, jointly created column graphs and picture graphs to represent a data set; describing the information that each display represents and discussing how easy or hard they are to interpret and why
  • E3: using digital tools, including generative artificial intelligence tools, to create picture graphs to represent data using one-to-one correspondence, deciding on an appropriate title for the graph and considering whether the categories of data are appropriate for the context
  • E4: comparing picture graphs with one-to-one column graphs of the same data, interpreting the data in each and saying how they are the same and how they are different; for example, collecting data on the country of birth of each student and creating different pictographs to represent classroom data
  • E5: using dot plots, sticker charts, picture graphs, bar charts and column graphs to represent data
