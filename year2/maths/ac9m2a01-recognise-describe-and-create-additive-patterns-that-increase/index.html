Growing and shrinking additive patterns

Learning intention: Build a pattern, describe its constant change, find missing elements, and create a rule that someone else can follow.

Learn the skill

Small steps, clear examples

Read, build or draw, then try the question. Open the answer after explaining your thinking.

A term is one element of a pattern. A rule explains the start and what changes each step. Constant means the same amount is added or removed each time.

1. Build a growing visual pattern

Use counters, blocks or drawn marks to show each stage. Count how many are in every stage, then compare neighbouring stages. The objects may change position, but the added amount must stay constant.

The pictured stages have 3, 6 and 9 counters. Each stage keeps the earlier amount and adds 3. Rebuild the same pattern with blocks or drawn squares.

Try it: Draw stages with 2, 4 and 6 dots. Draw the next stage and explain what you added.

Check the answer

The next stage has 8 dots. Add 2 dots each time; each new stage keeps the previous dots and adds two.

2. Continue growing numbers and name the rule

Students should compare neighbouring terms rather than only looking at the numbers themselves. In 5, 8, 11, 14, …, each term is 3 more than the term before it, so the rule is add 3.

In 24, 20, 16, 12, …, each term is 4 less than the term before it, so the rule is subtract 4.

The same rule can be represented in different ways. A shape pattern that gains 2 objects each stage can be recorded as 3, 5, 7, 9, …

Include both the start and the repeated change in a rule. “Add 4” alone does not say whether to begin at 2, 6 or another number. A sequence such as 2, 4, 8, 16 has changing differences, so it is not a constant-step additive pattern.

Try it: Continue 7, 12, 17, __, __. State the start and the change.

Check the answer

22, 27. Start at 7 and add 5 each time. Check every neighbouring difference, not just the first.

3. Follow a shrinking pattern

Work through it: For 42, 37, 32, 27, each term is 5 less. Moving forward subtracts 5; working backwards adds 5. Start and direction both matter.

Try it: Fill the gap: 34, 30, __, 22, 18. What is the rule?

Check the answer

26. Start at 34 and subtract 4 each step. 30 − 4 = 26 and 26 − 4 = 22.

4. Find a missing start, middle or end

Find the change from known neighbouring terms. Use it forwards and backwards, then check the missing term against both neighbours. A blank can appear anywhere, including the first term.

Try it: Complete __, 18, 23, 28, __. Explain how you found the first blank.

Check the answer

13, 18, 23, 28, 33. The known terms increase by 5. Work backwards from 18: 18 − 5 = 13.

5. Connect a table, jumps and a situation

If every toy car has 4 wheels, the totals form a constant additive pattern.

The wheel totals increase by 4. Similar patterns can be found in windows, fence sections, tiles, seats or other repeated features.

Work through it: A display begins with 4 blocks and gains 3 blocks each stage. Record stage 1 → 4 blocks, stage 2 → 7, stage 3 → 10, stage 4 → 13. A number line shows equal +3 jumps between 4, 7, 10 and 13. The stage label increases by 1; the block count increases by 3.

Make the same pattern with a simple digital tool

When using a digital geometry or generative tool, the mathematical goal is still to describe the constant change clearly. Students can specify a starting stage and an instruction such as “add 2 squares to each new stage”, then check whether every stage follows that rule.

Teachers should review generated outputs before classroom use and ask students to verify the mathematics rather than accepting the output automatically.

Try it: A row of chairs grows from 6 chairs to 10, then 14. Record the next two counts and the change.

Check the answer

18 and 22 chairs; add 4 chairs each stage. A drawing, table and equal jumps should show the same counts.

6. Create, explain and check a pattern

Choose a starting amount and a constant increase or decrease. Make at least four terms with objects, shapes or numbers. Give someone your rule and check whether it recreates your pattern. Changing colours alone does not demonstrate constant numerical growth.

Work through it: Error check: 9, 12, 15, 19, 21 claims to add 3. The fourth term should be 18; then 18 + 3 = 21. Check the whole sequence after a repair.

Try it: Create a shrinking pattern starting at 28. Use a step of your choice and write four terms. Explain why your rule works.

Check the answer

One example is 28, 24, 20, 16: subtract 4 each time. Other constant decreases are valid if the four terms follow the stated rule and stay within numbers you can explain.

Teaching tips and common mistakes

Keep the learning focused: Teach a constant increase or decrease. Repeating colour cycles, changing differences and repeated doubling are non-examples unless used explicitly for comparison.

Common mistakes and quick fixes

  • Looking only at the final digit: compare whole terms, not just visible digit patterns.
  • Changing the amount: 3, 5, 8, 10 is not a constant additive pattern because the changes are +2, +3, +2.
  • Giving only “add” or “subtract”: require the amount too, such as “subtract 4 each time.”
  • Guessing a missing term: verify the same rule on both sides of the gap.
  • Disconnecting the model from the numbers: ask what physical part is added or removed at each stage.

Adjust the support

  • Support: build short patterns with counters and mark the added or removed objects in each stage.
  • Core: move between material, picture, table and number-sequence representations.
  • Extension: provide a rule and ask students to create two different visual patterns that follow it, or find a missing term before the starting term.

For First Nations Australian learning contexts, use appropriately authorised local or curriculum resources and follow their guidance. Do not invent cultural stories, rules or meanings. Invite learners to show the relevant pattern, grouping or additive relationship with materials and a number sentence.

Learning check: Choose a fresh example, show a model or useful calculation, and explain why your answer fits. Revisit the matching focus if you cannot yet explain it.

An adult may read directions aloud. Start with objects or drawings, then reduce support as the learner becomes confident.
