AC9M2N01 • Year 2 Maths

Year 2 Numbers to 1000: Read, Represent and Order

Students build number sense to at least 1000 by connecting quantities, place value, numerals, number words, hundreds charts and number lines.

Topic guide Teacher Slides Worksheet Practice Test
What students learn in AC9M2N01

Students learn that a number can be represented in several equivalent ways. For example, 684 can be shown with 6 hundreds, 8 tens and 4 ones; written as 684; written in words; or located between nearby benchmark numbers on a number line.

  • Read and write two- and three-digit numbers, including numbers containing zero.
  • Represent numbers using hundreds, tens and ones, concrete materials, drawings and expanded form.
  • Use hundreds charts and number patterns to locate missing numbers.
  • Locate and estimate numbers on number lines using labelled benchmarks and intervals.
  • Compare and order numbers by considering place value from left to right.
  • Recognise easily confused numerals such as 808, 880, 818 and 881.
The key idea: hundreds, tens and ones

The position of each digit tells its value. In 684, the 6 is worth 600, the 8 is worth 80 and the 4 is worth 4.

684 = 600 + 80 + 4. Students should move between the numeral, materials, expanded form and spoken number without changing the value.

Teaching sequence for numbers to 1000
  1. Build the quantity. Use bundles, blocks or grouped classroom materials to show hundreds, tens and ones.
  2. Connect the representation. Match the model to the numeral, number word and expanded form.
  3. Use number patterns. Fill missing spaces in hundreds-chart sections and explain what changes when moving left, right, up or down.
  4. Locate on number lines. Identify the interval first, then use labelled benchmarks to estimate and locate a number.
  5. Compare and order. Compare hundreds first, then tens, then ones only when needed.
Worked examples

Represent 352

352 = 3 hundreds + 5 tens + 2 ones = 300 + 50 + 2. The same number can also be written as “three hundred and fifty-two”.

Compare 586 and 568

Both numbers have 5 hundreds. Compare the tens next: 8 tens is greater than 6 tens, so 586 > 568.

Order 807, 780 and 870

All three numbers have different hundreds or tens values. From smallest to largest: 780, 807, 870.

Locate 450 on a number line

If 400 and 500 are labelled, 450 belongs halfway between them. Students should first identify what each interval represents before placing the number.

Hundreds charts and missing-number puzzles

Hundreds-chart puzzles develop knowledge of number order rather than simple counting from 1. Ask students to explain the change between adjacent cells. In a standard chart, moving one space right increases the number by 1 and moving one row down increases it by 10.

Give partial chart pieces rather than always displaying a complete chart. This encourages students to use structure to determine missing numbers.

Using number lines accurately

Before locating a number, students should identify the values at the endpoints and determine the size of each interval. A common error is to assume every tick increases by 1.

  • Find two labelled benchmark numbers.
  • Count the equal intervals between them.
  • Work out how much each interval is worth.
  • Count forwards or backwards using that interval size.

Common mistakes to watch for
  • Ignoring zero as a placeholder: in 704, there are 0 tens; the 7 still represents 7 hundreds.
  • Comparing the last digit first: compare hundreds, then tens, then ones.
  • Reading similar numerals too quickly: ask students to state each digit's place in numbers such as 808, 880, 818 and 881.
  • Assuming number-line ticks count by ones: calculate the interval size before locating a number.
  • Matching a model by appearance rather than value: have students count the hundreds, tens and ones explicitly.
Support, core and extension
  • Support: use base-ten materials, place-value mats and partially completed number charts.
  • Core: move between numerals, words, expanded form, models, charts and number lines.
  • Extension: include four-digit examples from the elaborations and number lines with larger or less obvious intervals.
Quick check for understanding
  1. Represent 704 as hundreds, tens and ones.
  2. Write 352 in expanded form.
  3. Which is greater: 639 or 693? Explain using place value.
  4. Order 807, 780 and 870 from smallest to largest.
  5. A number line runs from 300 to 500 with 10 equal intervals. What is each interval worth?
  6. Explain the difference between 808 and 880.
Curriculum coverage and elaborations

Content description: recognise, represent and order numbers to at least 1000 using physical and virtual materials, numerals and number lines.

  • E1: recognise missing numbers on number lines with different scales and intervals.
  • E2: locate pieces within hundreds-chart puzzles using knowledge of natural-number order.
  • E3: read, write, say and order two-, three- and four-digit numbers, including numbers with zeros and similar-looking or similar-sounding numerals.
  • E4: collect and group large quantities of materials into ones, tens and hundreds, then use them to show different representations of two- and three-digit numbers.
How to use this unit

Use the topic guide for planning, present the static Teacher Slides for explicit instruction, then choose the worksheet, supported Practice or independent Test. Return to concrete place-value models whenever a student can read a numeral but cannot explain the value of its digits.
