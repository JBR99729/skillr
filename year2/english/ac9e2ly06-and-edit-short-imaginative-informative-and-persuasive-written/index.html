1. Outcome Overview & Core Concepts

Writers match structure, sentences, vocabulary, punctuation and images to purpose and audience, then edit the draft for meaning and accuracy.

Learning target: create and edit short imaginative, informative and persuasive written and/or multimodal texts for familiar audiences, using text structure appropriate to purpose, simple and compound sentences, noun groups and verb groups, topic-specific vocabulary, simple punctuation and common 2-syllable words

Big idea: Create short imaginative, informative and persuasive texts for familiar audiences

Learning routine: Choose purpose → Plan structure → Draft → Add language features → Edit

3. Common Student Misconceptions

3. Common Student Misconceptions

  • Starting without purpose: Name the text type, purpose and audience first.
  • Editing only spelling: Also revise ideas, order, sentences and vocabulary.
  • Answer without evidence: Point to the word, sentence, image, sound pattern or text feature that supports the answer.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to audience, purpose, vocabulary.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: creating written texts so that readers follow the sequence of ideas or events
  • E2: using vocabulary, including topic-specific vocabulary, appropriate to the purpose
  • E3: using digital tools to create texts
  • E4: using simple and compound sentences correctly and flexibly to express and combine ideas
  • E5: editing by adding, deleting or changing vocabulary to improve a text; for example, replacing an everyday noun with a topic-specific one
  • E6: reviewing sentences for grammatical accuracy; for example, use of pronouns
