Learning goals

1. Outcome Overview & Core Concepts

Legible handwriting uses recognisable letter shapes, consistent direction, appropriate size, spacing and placement on the line. Fluency grows through accurate repeated practice.

Learning target: write words legibly and with growing fluency using unjoined upper-case and lower-case letters

Big idea: Form unjoined upper-case and lower-case letters consistently

Learning routine: Sit and position → Form letters → Space words → Maintain size → Review

4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to meaning, language choices, audience.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

  1. Sort and notice — Sort letters by similar movement patterns and practise one family.
  2. Build or improve — Copy a short sentence, then circle one strength and one improvement goal.
  3. Explain your choice — Use the words legible, formation, spacing to explain what you changed and why.

Common Student Misconceptions

3. Common Student Misconceptions

  • Prioritising speed: Slow down until formation and spacing are secure.
  • Inconsistent size: Use line guides and compare letters with similar height.
  • Answer without evidence: Point to the word, sentence, image, sound pattern or text feature that supports the answer.
Practice Thought & Formative Assessment

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Revision Notes

Revision Notes

  • Remember: Form unjoined upper-case and lower-case letters consistently
  • Use the routine: Sit and position → Form letters → Space words → Maintain size → Review
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
