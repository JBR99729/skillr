AC9E2LA05: Navigate print and screen texts using chapters, tables of contents, indexes, side-bar menus, drop-down menus or links

What students learn

1. Outcome Overview & Core Concepts

Navigation features help readers locate information without reading every page or screen. Different features suit different searches.

Learning target: navigate print and screen texts using chapters, tables of contents, indexes, side-bar menus, drop-down menus or links

Big idea: Use chapters, contents pages, indexes, menus and links efficiently

Learning routine: Decide what you need → Choose navigation feature → Follow location → Check information

2. Subject-Specific Content & Key Examples

2. Subject-Specific Content & Key Examples

Choose the right navigation feature

chapter: read a sectioncontents: find a broad topicindex: find a specific wordmenu or link: move on screen

The best feature depends on whether the search is broad or specific.

Follow print and digital pathways

topic → contents → pagekeyword → index → pagemenu → sectionlink → related information

Check that the destination answers the original question.

Sort and notice

Race to locate three facts using a contents page and an index.

Guided practice

  1. Sort and notice — Race to locate three facts using a contents page and an index.
  2. Build or improve — Draw a simple website map showing a home page, side menu and two links.
  3. Explain your choice — Use the words navigate, index, menu to explain what you changed and why.
3. Common Student Misconceptions

3. Common Student Misconceptions

  • Reading from page one every time: Use navigation features to move directly to likely information.
  • Confusing contents and index: Contents lists sections; an index lists specific terms, usually alphabetically.
  • Answer without evidence: Point to the word, sentence, image, sound pattern or text feature that supports the answer.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to meaning, language choices, audience.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: recognising how numbered chapters, organisation of tables of content and alphabetical order of indexes operate to support access to information
  • E2: exploring how the navigation tools of different websites can be used to locate information
Practice Thought & Formative Assessment

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Revision Notes

Revision Notes

  • Remember: Use chapters, contents pages, indexes, menus and links efficiently
  • Use the routine: Decide what you need → Choose navigation feature → Follow location → Check information
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
