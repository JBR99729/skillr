Guided practice

  1. Sort and notice — Sort responses into opinion only and opinion with a reason.
  2. Build or improve — Improve ‘This book was good’ by adding a reason and one text example.
  3. Explain your choice — Use the words preference, reason, evidence to explain what you changed and why.

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: exploring how language is used to appreciate texts using more precise vocabulary; for example, “I liked how the author described the setting because …”
  • E2: exploring verbs used to express degree of preference; for example, “liked”, “preferred”, “enjoyed”
  • E3: identifying First Nations Australian language words specific to Country/Place that help the reader to be specific when appreciating the setting in a text (teaching context)

Revision Notes

  • Remember: Use opinion language, reasons and evidence when appreciating texts
  • Use the routine: State opinion → Give reason → Point to evidence → Conclude
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.

3. Common Student Misconceptions

  • Only stating a preference: Add because and explain a specific text feature.
  • Reason does not match evidence: Choose an example that proves the reason.
  • Answer without evidence: Point to the word, sentence, image, sound pattern or text feature that supports the answer.

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Quick checks

  • Which word often introduces a reason?
  • Name one text feature you could discuss.
  • Why is evidence useful?
