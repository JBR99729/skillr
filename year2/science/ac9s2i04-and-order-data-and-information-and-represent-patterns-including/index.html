Sort the records. Show the pattern.

Learning intention: Sort and order observations. Use provided tables and visual or physical models to represent patterns faithfully.

WORKED EXAMPLE

More folds does not always mean more pieces

A class counts separate paper pieces after actions in order. Folding does not split the sheet. Tearing can increase the number of pieces. The supplied sequence is 1, 1, 2, 4. Keep the action labels and order with their counts.

Learn the skill

1. Choose a clear sorting rule

Say what each group means. One rule might be “still one piece” versus “more than one piece”. A different sort could use material type.

RecordGroup
Folded sheetOne piece
Sheet torn into fourMore than one piece
Try it · If the rule is number of pieces, should blue colour decide the group?

No. Apply the stated rule consistently.

2. Order for the question

To explain change during an investigation, preserve the real sequence. Sorting the counts from largest to smallest answers a different question.

Action order

Start → fold → tear into two → tear each piece into two.

Try it · Should we rearrange the actions just to make the numbers decrease?

No. Keep the recorded action order when showing what happened over time.

3. Keep the model faithful

In a one-to-one display, one counter represents one piece. Check every row against the source record.

Try it · Did the number of pieces increase when the paper was only folded?

No. The count stayed at one.

Common mistakes

“Every pattern keeps increasing.” Data can stay the same or decrease. Describe the actual record.

“Bigger pictures must mean more objects.” Read the count or key. Picture size alone does not show the number.

10-MINUTE ACTIVITY

Build and check a four-row model

2 minutes: read the paper-action table. 5 minutes: draw one circle for each piece in each row. 3 minutes: compare your display with the table and describe where the count stayed the same.

Adjust the challenge Support: begin with the first two rows. Extend: represent the same data another way and explain why the message should stay unchanged.

Use supplied data and drawings. If using physical counters, choose ones suitable for the child’s age.

Three tricky questions

1. Can one counter mean one piece in one row and two in the next without a new key?

No. That changes the representation and can mislead the reader.

2. A row was not recorded. May we add a likely count as an observation?

No. Mark the observation as missing.

3. Does folding the paper four times mean it must be four separate pieces?

No. Folds and separate pieces are different things to count.

FAQ

What is data?

Recorded observations or information.

Can data be ordered in different ways?

Yes. Choose and label an order that helps answer the question, while keeping values attached to the correct records.

What students learn in AC9S2I04

Data becomes easier to understand when it is sorted into meaningful groups, placed in a useful order and represented in a table, sequence or model.

Learning sequence: Collect → Sort → Order → Represent → Describe pattern

Success looks like

  • Sort with a rule
  • Order data
  • Use tables
  • Use visual models
  • Describe patterns

Curriculum coverage and elaborations

The content description and elaborations below show the curriculum ideas taught in this unit. Items marked as teaching context support lesson planning.

  • Content description: sort and order data and information and represent patterns, including with provided tables and visual or physical models
  • E1: adding labels to a drawing or digital photograph to indicate key features, such as properties of materials that stay the same when changed physically, or to indicate how sound is produced by an instrument
  • E2: ordering images of the changing appearance of the moon to show a monthly cycle
  • E3: using a graphic organiser to sort images of musical instruments and the actions used to produce their sound
  • E4: constructing simple column graphs and picture graphs with guidance to represent class investigations, such as recording objects that produce or do not produce sound
  • E5: completing a table to record the number of ways different materials can be changed physically

Quick questions

  • Why sort data?
  • Give one useful ordering rule.
  • What must stay accurate in a table?
  • How can ordering reveal a pattern?

If an answer is uncertain, return to the model and explain what each part represents before calculating or drawing a conclusion.

Common misconceptions
  • Categories overlap without reason — Use a clear rule so each item has a sensible place.
  • Data left unordered — Choose an order that helps answer the question.
  • Representation changes values — Keep the original observations and counts accurate.
