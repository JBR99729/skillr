Parent and teacher guide

Algebraic expressions introduce students to using letters for numbers. Begin with simple rules in words, then write them using variables. A common mistake is thinking a letter always has one fixed value, rather than representing an unknown or changing value in a rule. Use tables, function machines and substitution examples. Ask students to read an expression aloud, such as 3n as three groups of n. This connects algebra to the number patterns they already know.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
