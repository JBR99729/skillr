Fractions

The numerator counts selected parts; the denominator names equal parts in the whole.

Key ideas

  • unit fractions
  • fraction of collections
  • equivalent representations
  • compare simple fractions
  • number-line placement

Worked example: 2/4 is equivalent to 1/2.

Common trap: Compare fractions using the same whole.

Key words

numerator — number of selected parts
denominator — number of equal parts in a whole
equivalent — same value
unit fraction — numerator 1
whole — complete amount
