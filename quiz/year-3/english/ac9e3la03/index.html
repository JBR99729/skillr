Text Structures Across Subjects

describe how texts across the curriculum use different language features and structures relevant to their purpose

Choose a learning activity. Practice rotates 8 questions from a 24-question bank; Test draws 12 questions from a separate 16-question bank.

Unit focus

  • Students learn to describe how texts across the curriculum use different language features and structures relevant to their purpose. They use the visual model, precise vocabulary and evidence to explain and apply the concept.
  • Use this routine: Notice → Read/View → Discuss → Apply → Explain.
  • Watch for subject determines one fixed structure: Purpose within a subject still matters.
