AC9E3LY08 • Year 3 English

Clear Joined Handwriting

write words using joined letters that are clearly formed and consistent in size

Choose a learning activity. Practice rotates 8 questions from a 24-question bank; Test draws 12 questions from a separate 16-question bank.

Unit focus

  • Students learn to write words using joined letters that are clearly formed and consistent in size. They use the visual model, precise vocabulary and evidence to explain and apply the concept.
  • Use this routine: Notice → Read/View → Discuss → Apply → Explain.
  • Watch for more joins means better handwriting: Legibility and approved joining patterns matter.
