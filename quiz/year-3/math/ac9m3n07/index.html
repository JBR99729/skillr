AC9M3N07 • Year 3 Maths

Number Algorithms and Patterns

follow and create algorithms involving a sequence of steps and decisions to investigate numbers; describe any emerging patterns

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • An algorithm is an ordered set of instructions. Decisions such as even or odd can change the next step, and recording outputs helps reveal patterns.
  • Use this routine: Start value → Follow step → Make decision → Repeat → Record pattern.
  • Watch for changing the order: Algorithms must be followed in the stated sequence.
