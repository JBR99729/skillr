60-second Quick Read

  • Read the minute hand first: count by fives, then count the extra minute marks.
  • Use the hour that has just started. At 3:23, the hour hand is between 3 and 4, so the hour is 3.
  • Common trap: the hour hand moves continuously; it is not fixed on 3 for the whole hour.
