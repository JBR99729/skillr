Choosing Metric Units and Estimating

identify which metric units are used to measure everyday items; use measurements of familiar items and known units to make estimates

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Metric units must match the attribute and size of the item. Familiar benchmarks help make sensible estimates.
  • Use this routine: Identify attribute → Choose unit → Use benchmark → Estimate → Check.
  • Watch for unit does not match attribute: Length, mass and capacity use different units.
