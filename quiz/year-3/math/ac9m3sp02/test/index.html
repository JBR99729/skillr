Maps and Two-Dimensional Representations

Read the quick preparation notes, then start when you are ready.

Quick preparation

  • A map is a two-dimensional representation viewed from above. Symbols, labels, keys and relative position language help locate landmarks and communicate routes.
  • Use this routine: Orient map → Identify landmarks → Use position language → Follow route → Create representation.
  • Watch for drawing side view: Maps usually show familiar spaces from above.
