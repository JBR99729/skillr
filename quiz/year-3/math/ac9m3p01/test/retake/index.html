Before you restart

  • Chance language describes how possible an event is. Certain events must happen, impossible events cannot happen, and likely or unlikely events depend on the situation.
  • Use this routine: List outcomes → Check conditions → Place on chance scale → Explain evidence.
  • Watch for likely means certain: Likely events can still fail to occur.
