Measurement, Shapes, Position and Data

Compare familiar objects directly, name common shapes, describe where objects are, and sort or compare simple categories of data.

Key ideas

  • longer and shorter
  • heavier and lighter
  • common 2D shapes
  • above, below, beside and between
  • sort and compare simple data

Worked example: a triangle has 3 sides; above describes a position.

Common trap: Compare the attribute named in the question, not a different one.

Key words

length — how long something is
mass — how heavy something is
position — where something is
shape — form or outline
data — information collected
How to use this drill: review the short notes when learning, then close them on later attempts and practise from memory. The rotating bank delays a full set repeat for 30 attempts on the same browser.
