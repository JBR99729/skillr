Exponential Growth and Decay

Exponential change repeatedly multiplies by the same factor rather than adding the same amount.

Key ideas

  • growth factor
  • decay factor
  • compound percentage change
  • tables/graphs
  • model interpretation

Formula / rule: new value = initial × factor^n.

Worked example: 5% growth uses factor 1.05 each period.

Common trap: Repeated 5% growth is not the same as adding 5% of the original each time.

Key words

growth factor — multiplier greater than 1
decay factor — multiplier between 0 and 1
exponential — constant multiplicative rate
initial value — starting amount
compound change — repeated percentage change
