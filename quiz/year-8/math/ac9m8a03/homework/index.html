Answer guide · AC9M8A03

Other valid methods and well-supported explanations are welcome.

  1. C = 20 + 8w; at w = 0, the cost is $20.
  2. C = $62. The $12 is a fixed setup charge in this model.
  3. C = 9 + 4h; each hour adds $4.
  4. Equal increases in hours produce equal increases in cost; the fixed charge sets the starting value.
  5. h = 3 hours; both cost $27.
  6. Costs $18, $33, $48. The vertical intercept is the setup cost. Whole poster counts are appropriate inputs.
  7. A costs $35 and B $39, so A is $4 cheaper.
  8. No, not if h means unrounded elapsed hours. The billed hours are 3, so cost is $27; rounding changes the model.
