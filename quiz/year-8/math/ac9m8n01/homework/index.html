Answer guide · AC9M8N01

Other valid methods and well-supported explanations are welcome.

  1. 6² < 45 < 7². √45 ≈ 6.7.
  2. 12π cm ≈ 37.7 cm.
  3. √36 = 6. Since 37 is not a perfect-square integer, √37 is irrational.
  4. π ≈ 3.14. The finite decimal is an approximation, not the exact irrational value.
  5. √50 cm ≈ 7.07 cm.
  6. 3.1² = 9.61 and 3.2² = 10.24, so 3.1 < √10 < 3.2.
  7. 7.84π m² ≈ 24.6 m².
  8. The display has limited digits and shows an approximation. It does not show the infinite non-terminating, non-recurring decimal expansion.
