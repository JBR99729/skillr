Answer guide · AC9M8P03

Other valid methods and well-supported explanations are welcome.

  1. HH, HT, TH, TT; P(HH) = 1/4.
  2. 0.23, or 23%.
  3. No. Random variation makes the observed count fluctuate.
  4. It permits only HH and TT, excluding HT and TH and changing the probabilities.
  5. Generate two separate independent random values with equal H/T chances, then record success only if both are H.
  6. 0.248 is closer to 0.25 than 0.23 is, in these runs.
  7. No. More trials generally stabilise relative frequency, but any particular run can vary.
  8. Run number, total trials, success count, relative frequency and theoretical probability; keep the event definition and simulation rules unchanged.
