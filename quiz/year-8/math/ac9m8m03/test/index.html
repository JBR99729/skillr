Circumference and area of circles

Use the Skillr scratchpad or a notebook to work backwards from area or circumference, check radius versus diameter, and use correct units.

60-second Quick Read

  • Use C = πd when diameter is given, and C = 2πr when radius is given.
  • Use A = πr² for area, so diameter must be halved first.
  • Common trap: Edging a round table asks for circumference, not area.
