Pythagoras theorem

Use the Skillr scratchpad or a notebook to compare side squares, identify triples and calculate coordinate distances carefully.

60-second Quick Read

  • For triangle type, compare c² with a² + b² using the longest side as c.
  • If c² = a² + b² the triangle is right; if c² is smaller it is acute; if c² is larger it is obtuse.
  • Common trap: Distance between points uses the horizontal change and vertical change as the two legs of a right triangle.
