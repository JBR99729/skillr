Exponent laws and zero exponent

Use the Skillr scratchpad or a notebook to check same bases, apply the correct exponent law, and justify why non-zero numbers to the power 0 equal 1.

60-second Quick Read

  • Multiplying powers with the same base means add exponents; dividing means subtract exponents.
  • The zero exponent rule follows from dividing equal powers: aⁿ ÷ aⁿ = a⁰ = 1 for a ≠ 0.
  • Common trap: Do not simplify powers with different bases using the same-base exponent laws.
