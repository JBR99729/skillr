Distinguish a direct judgement from an implied one

Name: __________________________ Date: ______________

Explain your choices using evidence from the example. Give reasons where requested.

Use the first two questions in class and the last two for homework or independent practice.

1. Try the skill

Compare ‘The speech was dishonest’ with ‘The speech polished every crack until nothing looked broken’. Which states its evaluation directly?

2. Try the skill

What evaluation is suggested by describing an explanation as ‘a fog of impressive terminology’?

3. Apply and explain

Rewrite ‘The ending was predictable’ as an indirect evaluation using a metaphor. Explain the implication.

4. Apply and explain

Why should an analysis quote the evocative wording rather than only label it ‘negative’?

Check answers and explanations

Answer guide · AC9E9LA02

  1. ‘Dishonest’ is direct. The second indirectly suggests concealment through the polishing metaphor.
  2. The metaphor suggests obscurity: impressive vocabulary hides rather than clarifies the meaning.
  3. For example, ‘The ending followed tracks visible from the first page’ suggests that the outcome was easy to foresee.
  4. The wording supplies evidence for how the evaluation is created and helps distinguish different shades of criticism.

If help is needed: An allusion's meaning is not fixed by recognition alone. Explain which source association matters and how the surrounding text uses it.
