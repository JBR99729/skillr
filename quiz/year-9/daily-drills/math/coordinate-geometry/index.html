Coordinate Geometry

Coordinates locate points. Gradient measures rate of change; horizontal and vertical changes must be taken in the same direction.

Key ideas

  • gradient
  • midpoint introduction
  • distance on grid
  • line rules
  • parallel lines

Formula / rule: gradient=(y₂−y₁)/(x₂−x₁).

Worked example: from (1,2) to (4,8), gradient = 6/3 = 2.

Common trap: Use matching point order in numerator and denominator.

Key words

gradient — Δy/Δx
midpoint — point halfway between endpoints
intercept — axis crossing
parallel — same direction, no intersection
coordinate — ordered pair
