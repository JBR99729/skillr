Linear Functions and Graphs

A constant first difference corresponds to a linear relationship in equally spaced x-values.

Key ideas

  • tables of values
  • gradient/intercept
  • graph interpretation
  • model contexts
  • solve intersections graphically

Formula / rule: y=mx+b.

Worked example: y=−2x+5 decreases by 2 when x increases by 1.

Common trap: A negative gradient means y decreases as x increases.

Key words

function — rule assigning outputs to inputs
gradient — constant rate of change
intercept — axis crossing
domain — allowed input values
range — resulting output values
