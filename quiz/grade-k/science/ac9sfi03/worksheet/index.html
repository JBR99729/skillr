  1. a simple table. It provides a structure for the observations.

  2. a pattern: the grouped bird pictures share feathers.

    Teaching hint: Point to the observed shared feature.

  3. fish pictures → common animal features; rolling balls → similar movement; wooden objects → similar material use.

    Teaching hint: Connect each record to the comparison it supports.

  4. template. It gives a place to record observations.

  5. Feathers: duck and pigeon. No feathers: dog.

    Teaching hint: Apply the given headings to all three described cards.

  6. The ball and toy car both rolled; the block slid.

    Teaching hint: Use the supplied observations rather than suggesting an unobserved result.

  7. recorded; made is also acceptable.

    Teaching hint: A pattern needs evidence from actual observations.

  8. glass → many window panes; metal → many spoons; wood → many blocks or furniture parts.

    Teaching hint: These are common uses, not claims that every object has that material.
