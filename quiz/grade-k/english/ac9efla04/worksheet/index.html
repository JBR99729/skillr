Core Class Worksheet

Name: ____________________    Date: ____________

Print this page for the whole class. Enrichment is on a separate optional sheet.

1.

Where do we usually start reading an English sentence?

[A] At the left side.[B] At the far right side.[C] In the middle of the last word.
2.

After reaching the end of one line, where do you usually go?

[A] Back to the cover every time.[B] To a random word above.[C] To the start of the next line below.
3.

Which part tells the name of a book?

[A] The table leg.[B] The title.[C] The page corner.
4.

A teacher asks where to start reading a picture book. What should you point to?

[A] The first words on the first reading page.[B] The last word on the last page.[C] Any picture in the middle.
5.

On a simple website, what might a tab help you do?

[A] Sharpen a pencil.[B] Turn a paper page by itself.[C] Move to another section.
6.

Which is a screen navigation clue?

[A] A lunchbox handle.[B] A labelled button.[C] A shoelace.
7.

Words appear under a picture of a koala. What should a reader notice?

[A] The placement shows the words and image belong together.[B] The words must be read backwards.[C] The picture has no connection to the text.
8.

Which action shows good book navigation?

[A] Jump between random pages for every word.[B] Read only the page numbers.[C] Turn pages in order while following the text.
