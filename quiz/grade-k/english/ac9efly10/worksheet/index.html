AC9EFLY10 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. four

Summary: This answer is right because the sentence contains four separate spoken words: The, dog, ran and home; use count spoken parts, blend or change them, then check.

Hint: Repeat The dog ran home slowly and move one counter for each separate meaningful word.

2. Mat.

Summary: To check the answer, count spoken parts, blend or change them, then check.

Hint: Say the speech sounds in order, without adding an extra vowel to consonants.

3. three

Summary: This answer is right because fish has three speech sounds because the ship-cue ending stays together; use count spoken parts, blend or change them, then check.

Hint: Stretch fish and keep the final quiet ship-cue sound together as one sound while counting.

4. The new word is sat.

Summary: This answer is right because replacing only the first sound changes mat to sat; use count spoken parts, blend or change them, then check.

Hint: Hold the middle and final sounds in mat still and replace only the first with the sun-cue sound.

5. Move word counters → segment; join sounds → blend; replace first sound → manipulate.

Summary: This answer is right because each action breaks apart, joins or replaces spoken parts; use count spoken parts, blend or change them, then check.

Hint: Decide whether each oral action breaks apart, joins together or replaces a sound.

6.Core

Use the cue words top, insect and pig to blend a single-syllable word from their beginning sounds.

7.Core

A learner uses three counters for ‘I can hop.’ What does each counter represent?

[A] One printed letter[B] One spoken word[C] One syllable in hop[D] One sentence ending

Tier 3: Extension / Challenge

8.Challenge

Say the spoken word chain pin, tin, tip. Explain which sound position changes at each step.

9.Challenge

Adult: say “The rabbit hops.” Count its words. Then say “shop” and count its speech sounds. Explain what each counter represents.

AC9EFLY10 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. The beginning sounds blend to make tip.

Summary: This answer is right because the top, insect and pig beginnings blend to make tip; use count spoken parts, blend or change them, then check.

Hint: Take only the beginning sounds from top, insect and pig and blend them without saying the cue words.

7. One spoken word.

Summary: This answer is right because each counter stands for one separate word in the sentence; use count spoken parts, blend or change them, then check.

Hint: Touch one counter for I, one for can and one for hop to identify what each represents.

8. Pin to tin changes the first speech sound, while tin to tip changes the final speech sound.

Summary: This answer is right because pin to tin changes the first sound and tin to tip changes the final sound; use count spoken parts, blend or change them, then check.

Hint: Compare pin with tin first and tin with tip second, naming the position that changes each time.

9. The sentence has three words. Shop has three speech sounds; the two letters sh represent one sound. The first task counts words and the second counts sounds within one word.

Summary: To check the answer, count spoken parts, blend or change them, then check.

Hint: Keep both tasks oral; use a fresh set of counters for the second task.
