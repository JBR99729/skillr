Core Class Worksheet

Name: ____________________    Date: ____________

Print this page for the whole class. Enrichment is on a separate optional sheet.

1.

Which item is a text made to communicate a message?

[A] A STOP sign.[B] A plain pebble.[C] An empty patch of grass.
2.

Which is a digital text?

[A] A wooden block.[B] A blank plate.[C] A weather page on a tablet.
3.

Which text would you most likely find on a food packet?

[A] A playground map drawn in sand.[B] A product label.[C] A fairy-tale ending.
4.

Which text helps people know how to wash their hands?

[A] A hand-washing instruction sign.[B] A birthday card.[C] A story about a dragon.
5.

A crossing sign and a picture book are both texts. What is one difference?

[A] Only the book can communicate meaning.[B] Only the sign has a purpose.[C] They present different kinds of messages in different forms.
6.

Which pair are both familiar community texts?

[A] A chair and a spoon.[B] A crossing sign and a shop label.[C] A cloud and a puddle.
7.

A set of picture instructions shows how to make a sandwich. What makes it a text?

[A] The pictures communicate steps in order.[B] The paper is white.[C] The sandwich is food.
8.

Two information texts show the same animal. One uses a photo and one uses a labelled drawing. What can we compare?

[A] Which paper is heavier.[B] Which reader is tallest.[C] How each image presents the information.

Which example shows an oral text?

10.Extension

A school map and a sign both show where to go. What is the same?
