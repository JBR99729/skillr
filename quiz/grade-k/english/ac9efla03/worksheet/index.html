AC9EFLA03 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. A classroom sign that says ‘Wash your hands’

Summary: The sign uses words to communicate an instruction because we name the text form, find its message and explain its purpose.

Hint: Choose the item someone made so another person would understand something.

2. sign

Summary: The visible road text takes the form of a sign because we name the text form, find its message and explain its purpose.

Hint: Think about what we call a text displayed beside a road.

3. picture book → tell a story; food label → name or describe the food; weather page → share today's forecast

Summary: Each form is paired with a job it commonly does because we name the text form, find its message and explain its purpose.

Hint: Ask what a person might use each text to find out or enjoy.

4. Add a label that says ‘Noah’

Summary: The label adds a message about whose lunchbox it is because we name the text form, find its message and explain its purpose.

Hint: Look for the change that communicates information to a reader.

5. For example: Make a sign that says ‘Pack away now’ with a picture of toys going into boxes.

Summary: The spoken message is represented in a printed sign form with the same purpose because we name the text form, find its message and explain its purpose.

Hint: Keep the message, but change how classmates receive it.

AC9EFLA03 • Answer Key

AC9EFLA03 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. notice → text form; Library closed today → message; inform readers → purpose

Summary: The form, message and purpose are identified as different parts of the text because we name the text form, find its message and explain its purpose.

Hint: Ask what kind it is, what it says and why it was made.

7. audience

Summary: Audience names the people a text is intended to reach because we name the text form, find its message and explain its purpose.

Hint: Think of the word for the listeners, viewers or readers.

8. For example: a printed door sign, a spoken announcement and a message on the library screen, all saying the library is closed today.

Summary: One message is carried accurately across three different text forms because we name the text form, find its message and explain its purpose.

Hint: Keep what the audience needs to know the same each time.

9. It is a sign; its message is not to touch; its purpose is to protect the seedlings; its audience is people near the garden.

Summary: The response connects all four text features to evidence in the garden situation because we name the text form, find its message and explain its purpose.

Hint: Answer four questions: What kind, what does it say, why, and for whom?
