AC9EFLA02 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. I prefer pears because they are juicy.

Summary: The sentence names a preferred choice and explains why because we name the choices, state a preference and add a reason with because.

Hint: Look for words that show a personal choice and a reason.

2. because

Summary: Because joins the preference to its reason because we name the choices, state a preference and add a reason with because.

Hint: Use the word that answers why.

3. I like… → something enjoyed; I do not like… → something not enjoyed; I prefer… → a choice liked more

Summary: Each frame clearly signals a like, dislike or preference because we name the choices, state a preference and add a reason with because.

Hint: Say each frame aloud and think about the feeling or choice it introduces.

4. I like the blue cup best.

Summary: The speaker shares a personal choice that another person may not share because we name the choices, state a preference and add a reason with because.

Hint: A preference tells what someone likes, not what everyone can check.

5. For example: I prefer drawing because I like making colourful pictures.

Summary: The response identifies one of the choices and gives a connected reason because we name the choices, state a preference and add a reason with because.

Hint: Say, I prefer, then name your choice and add because with your reason.

AC9EFLA02 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. For example: my socks get wet

Summary: The added words explain the speaker's dislike because we name the choices, state a preference and add a reason with because.

Hint: Tell what happens that makes the speaker not enjoy muddy puddles.

7. I prefer soccer. → You may enjoy a different game from me.; I like quiet music. → You prefer a different sound from me.; I do not like peas yet. → I hear that peas are not your choice yet.

Summary: Each reply listens to the preference without saying the person is wrong because we name the choices, state a preference and add a reason with because.

Hint: Match the topic first, then check that the response is kind.

8. Neither child must be wrong because preferences are personal and both children gave a reason for their choice.

Summary: The explanation recognises that different preferences can both be valid because we name the choices, state a preference and add a reason with because.

Hint: Ask whether a preference must be shared by everyone.

9. For example: You like that fruit; I prefer a different fruit because it tastes better to me.

Summary: The repaired response states a personal preference without judging the other person's choice because we name the choices, state a preference and add a reason with because.

Hint: Name both views kindly and give your own reason.
