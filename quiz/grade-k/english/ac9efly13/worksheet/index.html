Core Class Worksheet

Name: ____________________    Date: ____________

Print this page for the whole class. Enrichment is on a separate optional sheet.

1.

You want to spell ‘map’. Which choice best matches the sounds?

[A] mip[B] map[C] sap
2.

You hear ‘sun’. Which spelling is the best choice?

[A] sin[B] run[C] sun
3.

Which spelling best matches ‘fish’ using known sounds?

[A] fish[B] dish[C] fash
4.

You are unsure how to spell a word. What should you do first?

[A] Choose letters without saying the word.[B] Say it slowly and listen for the sounds you know.[C] Copy a different word.
5.

Which choice is a plausible early spelling of the spoken word ‘bed’?

[A] bid[B] bad[C] bed
6.

You wrote a word and want to check it. What can you do?

[A] Read the letters back using their sounds.[B] Add random capitals.[C] Cover it and never look again.
7.

Which spelling begins with the letter that matches /t/?

[A] mop[B] top[C] pop
8.

Which spelling ends with the letter that matches /n/?

[A] sum[B] sup[C] sun
