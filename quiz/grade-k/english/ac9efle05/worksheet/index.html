AC9EFLE05 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. Tama plants the seed.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; planting begins the connected event sequence.

Hint: Ask what Tama must do before there is a shoot to water.

2. the main events in their story order

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; a retell communicates the important happenings in a sequence listeners can follow.

Hint: Choose what a listener needs to recognise and follow the familiar text.

3. sequence → put events in order; retell → tell the important events again; adapt → change a clear part to make a new version

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; each word is linked to its distinct role in moving from the familiar text to a changed version.

Hint: Match sequence with order first, then decide between tell again and change.

4. Tama still plants and waters, but a tall bean vine grows instead of a yellow flower.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; the version keeps recognisable anchor events and changes one purposeful ending detail.

Hint: Find the version that keeps Tama's planting story but changes one part.

5. the yellow flower opens

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; the final event completes the known beginning-to-ending sequence.

Hint: Recall what appears after Tama cares for the seed.

AC9EFLE05 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. A valid pose shows Tama watering the seed or shoot and can be identified as the middle event.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; the performance represents the correct character action at the correct point in the sequence.

Hint: Use your body to show Tama doing what happens after planting and before the flower opens.

7. The seed is planted, the shoot is watered, then the flower opens.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; the picture sequence follows the story's cause and time order.

Hint: Fix the first and final pictures before placing the watering picture between them.

8. Too many anchors were removed; keep Tama and the planting sequence, then change just one character, setting, event or ending first.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; a recognisable adaptation keeps important parts of the familiar text while changing one clear feature.

Hint: Name two parts to keep and only one part to change.

9. A valid response sequences three main events, changes the ending and identifies retained characters or earlier events.

Summary: Use this method: place the main events in order, retell them, then change one clear part to adapt the text; the response demonstrates an accurate retell before making and explaining a purposeful adaptation.

Hint: Plan First, Next and Finally, then replace only the Finally part and compare both versions.
