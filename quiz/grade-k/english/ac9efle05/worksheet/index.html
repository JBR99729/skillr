AC9EFLE05 — Retell and adapt familiar texts

Core Class Worksheet

Name: ____________________    Date: ____________

Print this page for the whole class. Enrichment is on a separate optional sheet.

1.

To retell a story, what should you do first?

[A] Remember the important events.[B] Invent a completely different story.[C] Start with the last event every time.
2.

Which picture order makes sense for a retell?

[A] Ending → beginning → random event.[B] Middle → unrelated picture → title.[C] Beginning → middle → ending.
3.

Which choice is an adaptation?

[A] Tell an unrelated story about space.[B] Retell the same story but change the forest to a beach.[C] Copy every word exactly.
4.

A child acts out a familiar character and the main events. What are they doing?

[A] Retelling through performance.[B] Writing a shopping list.[C] Reading a road sign.
5.

Which change keeps a familiar story recognisable?

[A] Remove every event and character.[B] Replace it with unrelated facts about weather.[C] Keep the same problem but change the main character from a rabbit to a koala.
6.

You have four story pictures. What helps you retell accurately?

[A] Mix them randomly each time.[B] Put the pictures in the order the events happened.[C] Choose the pictures by colour only.
7.

Which retell includes an important event?

[A] The girl loses the key, searches, then finds it under the rug.[B] The page is blue and square.[C] Keys are made of metal.
8.

You want to adapt a story through drawing. What could you do?

[A] Draw numbers unrelated to the story.[B] Copy the book cover only and stop.[C] Draw the familiar events in a new setting.

9.Extension

A child tells the beginning and ending but misses the main problem. What should be added?

[A] A new title only.[B] The important middle event or problem.[C] A random fact about lunch.
10.Extension

Which statement best explains retell and adapt?

[A] Retell tells the familiar story; adapt changes part of it for a new version.[B] Both mean copy every word exactly.[C] Both mean make an unrelated text.
