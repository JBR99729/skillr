AC9EFLA07 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. Where the puppy hid

Summary: The image adds the location that the words do not name because we name the picture clue, name the word clue and combine both meanings.

Hint: Compare what you can see with the exact words in the sentence.

2. weather

Summary: Both clues contribute to a message about possible rain because we name the picture clue, name the word clue and combine both meanings.

Hint: Name the topic shared by the sentence and the dark clouds.

3. Words: ‘Lina heard a crash.’ → what Lina heard; Picture: a broken flowerpot → what may have made the sound; Words and picture together → an event and its likely source

Summary: The separate clues and their combined message are identified accurately because we name the picture clue, name the word clue and combine both meanings.

Hint: First use each clue alone, then put them together.

4. Visible stages from egg to frog

Summary: The diagram visually shows details and sequence that extend the fact because we name the picture clue, name the word clue and combine both meanings.

Hint: Look at what the labels and changing pictures make visible.

5. For example: The image adds that Niko is waiting in cold, snowy weather.

Summary: The response names a visible setting detail not stated in the words because we name the picture clue, name the word clue and combine both meanings.

Hint: Describe something visible that changes how you understand the waiting.

AC9EFLA07 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. Her name is Priya.

Summary: A name can be supplied by words even when the image does not show it because we name the picture clue, name the word clue and combine both meanings.

Hint: Choose the information a viewer cannot know from appearance alone.

7. story illustration → shows imagined characters or setting; labelled diagram → names parts clearly; photograph → shows a real visible example

Summary: Each image type is connected to a way it can support meaning because we name the picture clue, name the word clue and combine both meanings.

Hint: Think about what each kind of image lets the reader see.

8. For example: Words—‘At last, Zara smiled.’ Image—Zara reaches under the bed and pulls out her missing teddy.

Summary: The words add the character's reaction while the picture clue shows the discovery action and place because we name the picture clue, name the word clue and combine both meanings.

Hint: Let one part tell a feeling and the other show what happened and where.

9. Read the words and compare them with the picture, then name any fact, name, time or idea supplied only by the words.

Summary: The checking process uses both sources before deciding what each contributes because we name the picture clue, name the word clue and combine both meanings.

Hint: Cover the words, notice what is unknown, then reveal and compare them.
