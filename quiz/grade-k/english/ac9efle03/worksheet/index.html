AC9EFLE03 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. Mina

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; Mina is the person who takes part in the literary text.

Hint: Ask who is in the story, not what happens.

2. Mina returns the shell to the beach.

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; returning the shell is something that happens in the text.

Hint: An event answers the question What happens.

3. beginning → Mina finds the shell; middle event → Mina listens to the ocean sound; ending → Mina returns the shell

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; the events are placed according to where they occur from the first event to the final event.

Hint: Find what happens first and what finishes the story before placing the middle.

4. a story poem

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; the poem form carries a character and connected events.

Hint: Look for the choice that can use lines and rhythm while still telling events.

5. wakes, flies, reaches a tree

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; the ordered events form a clear movement from the poem's beginning to its ending.

Hint: Begin with what the sleepy bird must do before it can fly.

AC9EFLE03 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. A frog changes magically into another form.

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; a magical event is a recognisable feature present in the selected fairytale.

Hint: Choose a story feature, not a feature shared by almost every book.

7. events

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; connected events let the poem move from one happening to another.

Hint: Ask what happens to the character across the poem.

8. Finding the key starts the connected action and locking the box completes it, so they mark the beginning and ending.

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; the first and final connected events locate the boundaries of the story.

Hint: Explain what action starts the story problem and what action finishes it.

9. A valid map consistently identifies a literary type, character, connected events, first event and final event from the chosen text.

Summary: Use this method: name the literary text, point to the character or event, then place the beginning and ending; the complete map uses distinct literary features to show how the chosen text works.

Hint: Use the headings Type, Who, What happens, First and Final.
