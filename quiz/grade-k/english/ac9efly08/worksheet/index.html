Core Class Worksheet

Name: ____________________    Date: ____________

1.

Before writing a new letter, what should you look at?

[A] A random number.[B] A clear model showing how the letter is formed.[C] A picture unrelated to the letter.
2.

Why does the starting point of a letter matter?

[A] It changes the sound of every word.[B] It makes the paper bigger.[C] It helps you use the learnt formation consistently.
3.

Which pair shows the same letter in upper- and lower-case?

[A] A / a[B] C / d[C] A / b
4.

Which pair matches correctly?

[A] M / n[B] M / m[C] P / q
5.

What should your pencil grip allow you to do?

[A] Hold the pencil as tightly as possible until your hand hurts.[B] Avoid moving the pencil at all.[C] Control the pencil comfortably enough to form letters.
6.

A letter looks unclear. What is a useful next step?

[A] Compare it with the model and try the taught movement again.[B] Turn the paper over and stop.[C] Add random lines until it looks busy.
7.

Which action helps build letter-formation skill?

[A] Change the letter shape every time.[B] Practise the same taught movement several times.[C] Start from a different place on every attempt.
8.

You are practising lower-case letters. Which choice belongs?

[A] A[B] 7[C] a
