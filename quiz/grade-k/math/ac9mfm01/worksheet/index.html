AC9MFM01 • Answer Key

AC9MFM01 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. longer. It describes a comparison of length.

Summary: longer. It describes a comparison of length. Ask whether you are comparing how long, how heavy, how much it holds or how long it takes.

Hint: Ask whether you are comparing how long, how heavy, how much it holds or how long it takes.

2. longer. A reaches farther when the starting ends are aligned.

Summary: longer. A reaches farther when the starting ends are aligned. Compare the far ends only after lining up the starting ends.

Hint: Compare the far ends only after lining up the starting ends.

3. heavier → mass; holds more → capacity; takes longer → duration.

Summary: heavier → mass; holds more → capacity; takes longer → duration. Say what changes in each comparison.

Hint: Say what changes in each comparison.

4. Line up the same starting point. Then compare the other ends.

Summary: Line up the same starting point. Then compare the other ends. Keep both spoons straight and side by side.

Hint: Keep both spoons straight and side by side.

5. Fill A to the brim, then pour into empty B without spilling. Space left in B means B holds more; overflow means B holds less; exactly full means equal capacity.

Summary: Fill A to the brim, then pour into empty B without spilling. Space left in B means B holds more; overflow means B holds less; exactly full means equal capacity. Start with one full container and one empty container.

Hint: Start with one full container and one empty container.

AC9MFM01 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. longer. B finishes later after the shared start.

Summary: longer. B finishes later after the shared start. Use both the starting and finishing information.

Hint: Use both the starting and finishing information.

7. use a balance → mass; pour between containers → capacity; align endpoints → length.

Summary: use a balance → mass; pour between containers → capacity; align endpoints → length. Choose the method that directly tests the named attribute.

Hint: Choose the method that directly tests the named attribute.

8. The shorter, wider cup holds more: it holds all the tall cup’s full amount and still has space.

Summary: The shorter, wider cup holds more: it holds all the tall cup’s full amount and still has space. Use the pouring result rather than height alone.

Hint: Use the pouring result rather than height alone.

9. Size alone is not enough. Heft the empty box and the book, or put them on a balance to compare their mass.

Summary: Size alone is not enough. Heft the empty box and the book, or put them on a balance to compare their mass. Do not predict the result from appearance; report what the comparison shows.

Hint: Do not predict the result from appearance; report what the comparison shows.
