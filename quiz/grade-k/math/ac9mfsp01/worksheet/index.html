AC9MFSP01 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. triangle. It has three straight sides meeting at three corners.

Summary: triangle. It has three straight sides meeting at three corners. Trace all the way around the boundary.

Hint: Trace all the way around the boundary.

2. 4. A square has four corners.

Summary: 4. A square has four corners. Count each corner once as you trace around it.

Hint: Count each corner once as you trace around it.

3. triangle → 3 straight sides; circle → curved boundary, no corners; square → 4 equal straight sides.

Summary: triangle → 3 straight sides; circle → curved boundary, no corners; square → 4 equal straight sides. Match the listed features; a square also has four square corners.

Hint: Match the listed features; a square also has four square corners.

4. still a square. Turning it does not change its sides or corners.

Summary: still a square. Turning it does not change its sides or corners. Imagine turning the cut-out back without bending it.

Hint: Imagine turning the cut-out back without bending it.

5. For example, a rectangle for the body and circles for the wheels; name and explain both choices.

Summary: For example, a rectangle for the body and circles for the wheels; name and explain both choices. Accept any vehicle drawing using two correctly named familiar shapes.

Hint: Accept any vehicle drawing using two correctly named familiar shapes.

AC9MFSP01 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. 0. Its boundary curves continuously without corners.

Summary: 0. Its boundary curves continuously without corners. Trace the circle and look for a point where straight sides meet.

Hint: Trace the circle and look for a point where straight sides meet.

7. has 3 corners → triangle; has no corners → circle; has 4 corners → square and rectangle.

Summary: has 3 corners → triangle; has no corners → circle; has 4 corners → square and rectangle. Use the stated number-of-corners rule for every shape.

Hint: Use the stated number-of-corners rule for every shape.

8. For example, a lid’s outline is circular with no corners; a book cover is rectangular with four straight sides and four square corners.

Summary: For example, a lid’s outline is circular with no corners; a book cover is rectangular with four straight sides and four square corners. Name the specific part of each object and give a feature as evidence.

Hint: Name the specific part of each object and give a feature as evidence.

9. Both triangles belong in the three-straight-sides group, even if one is blue and one is red.

Summary: Both triangles belong in the three-straight-sides group, even if one is blue and one is red. Apply the stated shape rule; colour matters only when colour is the sorting rule.

Hint: Apply the stated shape rule; colour matters only when colour is the sorting rule.
