AC9MFA01 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. triangle. The repeating unit is triangle, circle.

Summary: triangle. The repeating unit is triangle, circle. Repeat the pair in the same order.

Hint: Repeat the pair in the same order.

2. red. The red-blue pair repeats.

Summary: red. The red-blue pair repeats. Read the whole pattern from the start.

Hint: Read the whole pattern from the start.

3. red blue; clap stamp; A B C are the respective smallest units.

Summary: red blue; clap stamp; A B C are the respective smallest units. Find the shortest unit that repeats to make each shown pattern.

Hint: Find the shortest unit that repeats to make each shown pattern.

4. square circle square circle shows two repeats of the same pair.

Summary: square circle square circle shows two repeats of the same pair. Look for a whole unit shown again in the same order.

Hint: Look for a whole unit shown again in the same order.

5. For example, clap, stamp, clap, stamp; the unit is clap, stamp.

Summary: For example, clap, stamp, clap, stamp; the unit is clap, stamp. Show at least two complete repeats.

Hint: Show at least two complete repeats.

6. B. The unit A, B, C repeats.

Summary: B. The unit A, B, C repeats. Check the place between A and C.

Hint: Check the place between A and C.

7. copy → make the same pattern; continue → add the next correct items; repair → fix the wrong item.

Summary: copy → make the same pattern; continue → add the next correct items; repair → fix the wrong item. Decide what action is being requested.

Hint: Decide what action is being requested.

8. clap, clap, stamp, clap, clap, stamp. The repeated order is unchanged.

Summary: clap, clap, stamp, clap, clap, stamp. The repeated order is unchanged. Replace each red with clap and each blue with stamp.

Hint: Replace each red with clap and each blue with stamp.

9. The fifth item should be red. Then red, blue repeats three times.

Summary: The fifth item should be red. Then red, blue repeats three times. Use the stated red-blue rule to check each position.

Hint: Use the stated red-blue rule to check each position.
