About This Foundation Counting and Comparing Quiz (AC9MFN03)

This interactive Foundation Mathematics quiz helps children quantify and compare collections to at least 20 using counting.

Students practise counting every object once, recognising that the final number counted tells how many objects are in the collection, and comparing collections using language such as more, fewer and the same.

Australian Curriculum Alignment

  • Australian Curriculum Version 9.0: AC9MFN03 — quantify and compare collections to at least 20 using counting and explain or demonstrate reasoning.
  • New South Wales: MAE-RWN-01 — demonstrates an understanding of how whole numbers indicate quantity.
  • New South Wales: MAE-CSQ-01 — reasons about number relations to model addition and subtraction by combining, separating and comparing collections.
  • Victorian Curriculum 2.0: VC2MFN03 — quantify and compare collections to at least 20 using counting and explain or demonstrate reasoning.

International Curriculum Connections

Curriculum structures differ between countries, so the following are the closest equivalent early-number expectations rather than claiming that every curriculum is identical to AC9MFN03.

  • United States — Common Core Kindergarten: K.CC.B.4, K.CC.B.5 and K.CC.C.6. These expectations develop cardinality, counting objects to answer “how many?” and comparing groups as greater than, less than or equal to another group.
  • United Kingdom — EYFS Mathematics: Number and Numerical Patterns Early Learning Goals. Children count, develop understanding of quantities and compare quantities using concepts such as greater than, less than and the same.
  • Canada — Ontario Grade 1 Mathematics: B1.1 and B1.3. Students read and represent whole numbers and compare and order whole numbers in different contexts.
  • New Zealand Curriculum — Mathematics and Statistics, Phase 1 (Years 0–3): Number. Early learners count collections using one-to-one correspondence and recognise when a quantity is greater than, less than or the same as another quantity.
  • India — NCERT Class I Mathematics: Number learning outcomes. Students count objects in collections up to 20 and compare two groups using ideas such as more than, less than and equal.

Skills Practised

  • Counting collections: Counting objects accurately in groups containing up to 20 objects.
  • One-to-one correspondence: Matching one number word to each object so that every item is counted once.
  • Cardinality: Understanding that the final number said when counting tells how many objects are in the collection.
  • Comparing collections: Identifying which collection has more objects, fewer objects or the same number.
  • Arrangement independence: Understanding that moving or spreading objects apart does not change the quantity.
  • Mathematical reasoning: Explaining or demonstrating how a quantity was counted or how two groups were compared.
  • Practical counting: Using counting to work out how many objects are needed for a real-life purpose.

How to Use This Quiz

Each quiz attempt can select a small random set of questions from a larger question bank. This allows children to practise repeatedly without seeing exactly the same quiz each time.

Encourage students to touch, point to or mentally track each object once while counting. When comparing two collections, students should explain how they know which collection has more, fewer or the same number of objects.
