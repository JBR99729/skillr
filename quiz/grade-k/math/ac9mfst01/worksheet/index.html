AC9MFST01 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. Cats. Four counters represent cats and two represent dogs.

Summary: Cats. Four counters represent cats and two represent dogs. Use one counter per response and count each category.

Hint: Use one counter per response and count each category.

2. 1. Pair three apple responses with the three banana responses; one apple response remains.

Summary: 1. Pair three apple responses with the three banana responses; one apple response remains. Match the groups one to one.

Hint: Match the groups one to one.

3. collect → gather responses; sort → put responses into categories; compare → look for more, less or same.

Summary: collect → gather responses; sort → put responses into categories; compare → look for more, less or same. Connect each word to the step it describes.

Hint: Connect each word to the step it describes.

4. So comparison is fair and easy. Equal-sized counters with equal spacing and a shared start make the counts easier to compare.

Summary: So comparison is fair and easy. Equal-sized counters with equal spacing and a shared start make the counts easier to compare. Spacing can change how long a row looks without changing its count.

Hint: Spacing can change how long a row looks without changing its count.

5. For example, toys with wheels and toys with no wheels. Every toy goes in one group.

Summary: For example, toys with wheels and toys with no wheels. Every toy goes in one group. Choose a clear rule that places every toy exactly once.

Hint: Choose a clear rule that places every toy exactly once.

AC9MFST01 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. same. Both groups have five votes.

Summary: same. Both groups have five votes. Equal counts mean neither category has more.

Hint: Equal counts mean neither category has more.

7. 6 vs 3 → first has more; 2 vs 5 → first has fewer; 4 vs 4 → same.

Summary: 6 vs 3 → first has more; 2 vs 5 → first has fewer; 4 vs 4 → same. Compare the first count with the second in each pair.

Hint: Compare the first count with the second in each pair.

8. No. Four counters represent more responses than three, even when the three are spread farther apart.

Summary: No. Four counters represent more responses than three, even when the three are spread farther apart. Count the counters or line them up with equal spacing to check.

Hint: Count the counters or line them up with equal spacing to check.

9. The toy is counted twice, so the display can overstate the total. Apply the rule and remove its extra entry so the toy appears once.

Summary: The toy is counted twice, so the display can overstate the total. Apply the rule and remove its extra entry so the toy appears once. Check that each object has one matching representation.

Hint: Check that each object has one matching representation.
