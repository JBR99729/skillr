Foundation Number Line Practice

This short number line quiz is designed for regular Foundation maths practice. Children work with numbers from 0 to 20 and build confidence with number position, counting and order.

Each attempt uses a small selection of questions so children can practise regularly without completing a long worksheet or test.

Number Line Skills Practised

  • Recognising numbers from 0 to 20.
  • Reading numbers on a number line.
  • Finding missing numbers.
  • Identifying the number before a given number.
  • Identifying the number after a given number.
  • Counting forwards along a number line.
  • Counting backwards along a number line.
  • Finding numbers between two other numbers.
  • Ordering numbers from smallest to largest.
  • Understanding that numbers increase as we move to the right.
  • Understanding that numbers decrease as we move to the left.

How to Use This Quiz for Daily Practice

A short number line activity can be completed at the beginning of a maths lesson, during numeracy rotations, for home practice or as a quick revision activity.

Students can complete one attempt each day, review any mistakes and try another random set when they are ready.

Useful Number Line Ideas for Foundation

Encourage children to say the numbers aloud while moving along a number line. Ask them what number comes before, what comes after, and whether moving left or right makes the number smaller or larger.
