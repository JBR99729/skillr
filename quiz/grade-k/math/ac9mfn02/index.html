About This Foundation Subitising Quiz (AC9MFN02)

Subitising is the ability to instantly recognise the number of objects in a small group without counting them one by one. This interactive quiz supports the Australian Curriculum Version 9.0 Foundation Mathematics content description AC9MFN02.

Australian Curriculum Alignments

  • Australian Curriculum Version 9.0: AC9MFN02 — Foundation Year
  • NSW Syllabus: MAE-RWN-01 — Representing Whole Numbers
  • Victorian Curriculum 2.0: VC2MFN02 — Subitising

Global Curriculum Connections

This activity can also provide useful early-number practice for Kindergarten and early-years learners following other curricula.

  • United States: Common Core Kindergarten counting and cardinality skills.
  • United Kingdom: EYFS and early Key Stage 1 number skills.
  • New Zealand: Early Number and Algebra learning.

Skills Practised

  • Perceptual Subitising: Instantly recognising small quantities using dots, dice faces, counters, stars and familiar visual patterns.
  • Visual Arrays: Recognising quantities arranged as rows, groups, card patterns and simple frames.
  • Conceptual Subitising: Combining smaller groups, such as recognising 3 and 2 as a collection of 5.
  • Comparing Quantities: Recognising which visual collection contains more, fewer or the same number of objects.

How to Use This Quiz

Each attempt gives students a small random selection from the larger question bank. This allows children to repeat the quiz while seeing different questions and visual arrangements.

Encourage students to look at each collection and recognise the quantity before counting objects one by one. Repeated practice can help build faster and more confident number recognition.
