How this practice works

Each practice contains 8 mixed questions. The set is selected to include every curriculum elaboration for this skill and a balance of choosing, typing and arranging tasks.

For mastery: repeat this skill regularly across one week and aim to work through the full question bank over multiple attempts. Repeated practice exposes students to different examples and question formats.

What this practice covers

  • Share objects so everyone gets the same amount.
  • Make equal groups from a collection.
  • Count how many are in each group.
  • Recognise when sharing is equal or not equal.
