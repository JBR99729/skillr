AC9MFN06 Equal Sharing and Grouping

This Foundation Mathematics activity helps children represent practical situations involving equal sharing and grouping. Children practise distributing objects fairly, recognising equal groups and using counting or subitising to determine how many objects are in each group.

The quiz is aligned with Australian Curriculum Version 9.0 Mathematics AC9MFN06 and includes related curriculum references for New South Wales, Victoria and selected international curricula.

Skills Practised

  • Sharing a collection fairly between people.
  • Making groups with the same number of objects.
  • Recognising equal and unequal groups.
  • Giving objects out one at a time when sharing.
  • Counting how many objects each person receives.
  • Counting how many equal groups can be made.
  • Using subitising to recognise small groups.
  • Checking whether a share is fair.
  • Representing practical grouping situations.
  • Developing early understanding of division.

Equal Sharing Example

If 6 strawberries are shared equally between 3 children, each child receives 2 strawberries.

A Foundation child does not need to use a formal division algorithm. They can physically or visually distribute the strawberries one at a time and then count each child's share.

Equal Grouping Example

If there are 8 counters and we make groups of 2, we can make 4 equal groups.

Children can solve this by moving counters into groups and counting the completed groups.

Teacher and Parent Tip

Start with real objects such as counters, blocks, fruit, toy animals or buttons. Ask children to physically make fair shares before expecting them to answer from pictures.

Useful questions include:

  • Does everyone have the same number?
  • Is this a fair share?
  • How do you know the groups are equal?
  • How many does each person get?
  • How many equal groups did you make?
  • Can you share the objects another way?
