AC9MFN06 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. 2 counters each. Three equal shares of two use all six.

Summary: 2 counters each. Three equal shares of two use all six. Deal one counter to each child in turn.

Hint: Deal one counter to each child in turn.

2. 4 in each group. Two groups of four use all eight.

Summary: 4 in each group. Two groups of four use all eight. Check that both groups have the same number.

Hint: Check that both groups have the same number.

3. 6 → 3 groups of 2; 8 → 2 groups of 4; 9 → 3 groups of 3.

Summary: 6 → 3 groups of 2; 8 → 2 groups of 4; 9 → 3 groups of 3. Count the groups and the items in each group.

Hint: Count the groups and the items in each group.

4. No. Three counters and two counters are different amounts.

Summary: No. Three counters and two counters are different amounts. Compare the number in each share.

Hint: Compare the number in each share.

5. Deal one card to each of four players in turn; repeat once. Each gets 2.

Summary: Deal one card to each of four players in turn; repeat once. Each gets 2. Check that all eight cards are used.

Hint: Check that all eight cards are used.

AC9MFN06 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. 3 objects in each group.

Summary: 3 objects in each group. Make three equal groups using all nine objects.

Hint: Make three equal groups using all nine objects.

7. number of groups → how many groups; group size → objects in each group; fair share → everyone gets the same amount.

Summary: number of groups → how many groups; group size → objects in each group; fair share → everyone gets the same amount. Say what each number describes.

Hint: Say what each number describes.

8. Move one counter from the group of 4 to the group of 2. Both then have 3.

Summary: Move one counter from the group of 4 to the group of 2. Both then have 3. Keep the total of six unchanged.

Hint: Keep the total of six unchanged.

9. Three groups of 3 use 9 counters, leaving 1. The groups are equal, but they do not include all 10.

Summary: Three groups of 3 use 9 counters, leaving 1. The groups are equal, but they do not include all 10. Count the grouped counters and the leftover separately.

Hint: Count the grouped counters and the leftover separately.
