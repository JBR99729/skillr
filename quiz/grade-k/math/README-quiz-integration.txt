SkillrHub Foundation Maths question bank

Contains 600 questions: 50 for each main Foundation Mathematics code:
AC9MFN01, AC9MFN02, AC9MFN03, AC9MFN04, AC9MFN05, AC9MFN06,
AC9MFA01, AC9MFM01, AC9MFM02, AC9MFSP01, AC9MFSP02, AC9MFST01.

Each question is tagged with code and elaboration. Set window.exerciseConfig
before loading questions.js. maxQuestions defaults to 5.

IMPORTANT:
- New questions on retake/new page is controlled by script.js/results.html, not questions.js.
- Separate review page is controlled by script.js/results/review page flow, not questions.js.
- PDF button is controlled by worksheet-pdf.js. To guarantee the exact same 5 questions,
  script.js must expose activeQuestions with:
  window.skillrActiveQuestions = activeQuestions;
