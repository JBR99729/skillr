AC9MFSP02 — Topic Practice 1 Answer Key

Teacher copy • this sheet only

1. inside. The ball is in the box.

Summary: inside. The ball is in the box. Use the box as the reference object.

Hint: Use the box as the reference object.

2. under. The toy is directly below the chair seat.

Summary: under. The toy is directly below the chair seat. Name both the position and the chair.

Hint: Name both the position and the chair.

3. inside → in the box; under → below the table; beside → next to the chair.

Summary: inside → in the box; under → below the table; beside → next to the chair. Match each word to its relationship with the named object.

Hint: Match each word to its relationship with the named object.

4. Put it beside the desk. This names a position and a reference object.

Summary: Put it beside the desk. This names a position and a reference object. Look for information that helps someone find the intended place.

Hint: Look for information that helps someone find the intended place.

5. For example, “Put the toy under the chair.”

Summary: For example, “Put the toy under the chair.” Accept an instruction that clearly names the toy, position and chair.

Hint: Accept an instruction that clearly names the toy, position and chair.

AC9MFSP02 — Topic Practice 2 Answer Key

Teacher copy • this sheet only

6. on top of; “on” is also acceptable. The pencil rests on the book’s upper cover.

Summary: on top of; “on” is also acceptable. The pencil rests on the book’s upper cover. Use the location described in the question.

Hint: Use the location described in the question.

7. go forward → move ahead; turn left → change direction left; stop beside the table → finish next to the table.

Summary: go forward → move ahead; turn left → change direction left; stop beside the table → finish next to the table. Use the moving person’s viewpoint for left and forward.

Hint: Use the moving person’s viewpoint for left and forward.

8. Inside tells where the ball is in its box; beside the chair identifies which of the two boxes.

Summary: Inside tells where the ball is in its box; beside the chair identifies which of the two boxes. Use both clues to select the location.

Hint: Use both clues to select the location.

9. “Over there” gives no named reference. “Inside the box beside the chair” identifies the container and where to find it.

Summary: “Over there” gives no named reference. “Inside the box beside the chair” identifies the container and where to find it. Explain how the listener can locate the object without guessing.

Hint: Explain how the listener can locate the object without guessing.
