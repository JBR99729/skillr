Answer guide · AC9S1I05

  1. No. Compare the observations, check the procedure and repeat if useful.
  2. No. The starting push also changed. Release them in the same agreed way.
  3. For example: ‘I predicted the ball would go farther, but the cylinder went farther in this test.’ Keep both statements.
  4. For example, ‘Would a third surface give a different distance?’ Accept a related investigable question.

If help is needed: If different cars are being compared, the car is the thing that changes. Keep the other relevant conditions alike; do not claim the same object must always be used.
