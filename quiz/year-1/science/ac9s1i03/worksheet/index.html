Use the first two questions in class and the last two for homework or independent practice.

1. Try the skill

One result says 5 hand spans and another says 5 paper clips. Are the distances necessarily equal?

2. Try the skill

A leaf has three brown spots. Is ‘three brown spots’ an observation or a prediction?

3. Apply and explain

Observe a fallen leaf. Draw it and label two visible features without guessing what caused them.

4. Apply and explain

Measure a small safe object's length using equal blocks and record the number with the unit.

Check answers and explanations

Answer guide · AC9S1I03

  1. No. The units have different lengths.
  2. An observation, because it describes what was seen.
  3. Accept observable features such as colour, number of spots, edge shape or holes.
  4. Accept a labelled measurement using equal units placed end-to-end; describe any leftover part.

If help is needed: ‘It went far’ is hard to compare with another result. A recorded distance with the same unit gives clearer evidence.
