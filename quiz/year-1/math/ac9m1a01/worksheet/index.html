SkillrHub · AC9M1A01 · Year 1

Connect a growing picture to its number pattern

Name: __________________________ Date: ______________

Show your thinking with objects, drawings or words. An adult may read the instructions aloud.

Use the first two questions in class and the last two for homework or independent practice.

1. Try the skill

Each row of a table is a new stage. Complete the totals: 5, 10, __, 20. Describe the change.

2. Try the skill

A child writes 10, 20, 30, 35 when counting in tens. Correct the last number and explain.

3. Apply and explain

Draw four stages of a pattern that starts with 5 dots and adds 5 dots each time. Label each total.

4. Apply and explain

There are four 10-cent coins. Count their value as each coin is added.

Check answers and explanations

Answer guide · AC9M1A01

  1. 15. Each stage adds five.
  2. 40. The last jump should add ten, not five.
  3. Stages contain 5, 10, 15 and 20 dots; each new stage adds five.
  4. 10c, 20c, 30c, 40c. The total is 40 cents.

If help is needed: A picture of the same pair repeated three times is not three growing stages. Separate the stages and show the total increasing in each one.
