Answer guide · AC9M1ST01

  1. Apple 2 and pear 2; four responses altogether.
  2. Check for a response counted twice or an extra mark. The counts should total six.
  3. Accept three recorded responses in the stated categories, with one response per person.
  4. The responses then describe the same thing and can be compared fairly.

If help is needed: A child who likes two games must still give one response if the question asks for a single favourite. Make that rule clear before collecting data.
