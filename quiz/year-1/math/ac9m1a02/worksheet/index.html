Answer guide · AC9M1A02

  1. red, blue, blue.
  2. It grows by two. No repeating block of these numbers has restarted.
  3. For example, circle-square, circle-square, circle-square, with one circle-square unit circled.
  4. The fifth item should be a star. The two units then match.

If help is needed: Naming only the last action does not identify the unit. Include every part before the pattern starts again.
