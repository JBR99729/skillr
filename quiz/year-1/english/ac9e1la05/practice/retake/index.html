Before you restart

  • Print and screen texts use features such as titles, headings, page numbers, contents, buttons, links and images to help readers navigate and understand.
  • Use this routine: Look at feature → Name it → Say its job → Use it.
  • Watch for names feature but not job: Always say what the feature helps the reader do.
