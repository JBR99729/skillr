AC9E1LY06 • Year 1 English

Create and Edit Short Texts

create and re-read to edit short written and/or multimodal texts to report on a topic, express an opinion or recount a real or imagined event, using grammatically correct simple sentences, some topic-specific vocabulary, sentence boundary punctuation and correct spelling of some one- and two-syllable words

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Writers create short texts to report, express an opinion or recount an event, then re-read to edit simple sentences, topic vocabulary, punctuation and spelling.
  • Use this routine: Plan → Write → Re-read → Edit sentence/punctuation/spelling → Publish.
  • Watch for no re-reading: Read the text aloud to catch missing words.
