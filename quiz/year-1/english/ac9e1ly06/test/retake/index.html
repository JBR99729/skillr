Before you restart

  • Writers create short texts to report, express an opinion or recount an event, then re-read to edit simple sentences, topic vocabulary, punctuation and spelling.
  • Use this routine: Plan → Write → Re-read → Edit sentence/punctuation/spelling → Publish.
  • Watch for no re-reading: Read the text aloud to catch missing words.
