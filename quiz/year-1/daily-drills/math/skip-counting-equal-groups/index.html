Skip Counting and Equal Groups

Skip counting is repeated equal jumps. Equal groups connect repeated addition to early multiplication notation.

Key ideas

  • skip count by 2, 5 and 10
  • recognise equal groups
  • write repeated addition
  • find totals
  • early multiplication notation

Worked example: 4 groups of 2 = 2 + 2 + 2 + 2 = 8.

Common trap: The first factor can describe the number of groups; read the context carefully.

Key words

skip count — count by equal jumps
equal groups — same amount in each group
repeated addition — adding the same amount repeatedly
each — in every group
total — amount altogether
How to use this drill: review the short notes when learning, then close them on later attempts and practise from memory. The rotating bank delays a full set repeat for 30 attempts on the same browser.
