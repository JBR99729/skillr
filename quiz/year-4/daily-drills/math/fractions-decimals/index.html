Fractions and Decimals

Equivalent fractions name the same amount. Decimal place value is another way to represent fractions with denominators 10, 100 and so on.

Key ideas

  • equivalent fractions
  • tenths and hundredths
  • fraction-decimal connections
  • order fractions
  • fraction of quantity

Worked example: 1/2 = 5/10 = 0.5.

Common trap: Equivalent fractions change numerator and denominator by the same scale factor.

Key words

equivalent — same value
numerator — selected parts
denominator — equal parts in whole
decimal — base-ten fraction notation
hundredth — 1/100
