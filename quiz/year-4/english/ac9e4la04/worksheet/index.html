AC9E4LA04 • Homework

Connectives and Topic Cohesion worksheet

Complete eight original reading, writing and editing tasks. An adult checks the actual work; suitable alternative answers are welcome.

Open practice

Eight connected-text tasks

Write in the space below or on separate paper. Use your usual communication support if helpful. Underline or name the words that make each link.

Task 1

“Mina showed Jo a photograph. They framed it.” We mean Jo framed the photograph. Rewrite the text clearly and explain which reference you changed.

Task 2

Write three connected sentences about a classroom collection of buttons. Use “these” before a noun to point back to the buttons and one clear pronoun. Circle both links and explain them.

Task 3

The art room has big tables and a drying rack. A spill has made one table unusable. Write one sentence pair with “in addition” about the room’s features and another with “therefore” about the spill’s result.

Task 4

Write two sentences about rehearsing a play. Use “however” or “nevertheless” to show that a difficulty did not stop progress. Underline the link and explain the contrast.

Task 5

Write four short sections explaining how to prepare a class picture display: choose pictures, arrange pictures, attach labels, invite viewers. Use firstly, then, next and finally. Explain one reason the order helps.

Task 6

A class walk uses the bridge only if an adult confirms it is open. Write this condition in a notice. Then write what the class should do if it is closed, without inventing an unsafe alternative.

Task 7

Write a four-sentence paragraph about a library using shelf, reader, book and librarian. Add one other related topic word. Underline the topic words and explain how they connect.

Task 8

Write a four-sentence plan for making a paper decoration. Include a clear pronoun, a time connective and a condition about getting help. Label each link and explain how the reader uses it.

Examples and adult review guidance

Task 1

Example or expected evidence: Mina showed Jo a photograph. Jo framed it. Naming Jo removes uncertainty about who framed the photograph.

Adult check: Check Jo performs the framing, the photograph stays the object, and the explanation identifies the unclear person reference.

Task 2

Example or expected evidence: Our class collected twenty buttons. These fasteners were round and smooth. We sorted them by colour. “These fasteners” and “them” refer to the buttons.

Adult check: Require three coherent sentences, a demonstrative determiner plus noun, a clear pronoun and correct explanations. Different invented collection details are welcome.

Task 3

Example or expected evidence: The art room has big tables. In addition, it has a drying rack. One table had a spill. Therefore, we used another table.

Adult check: Check addition links the two supplied features and result links the spill with a sensible consequence. Accept a different safe consequence without changing the facts.

Task 4

Example or expected evidence: We forgot some lines at first. Nevertheless, we completed the scene. Forgetting lines did not prevent finishing the scene.

Adult check: Require a believable difficulty, progress despite it and an explanation. Do not demand the same difficulty or wording as the model.

Task 5

Example or expected evidence: Firstly, choose the pictures. Then, arrange them on the board. Next, attach labels beside the pictures. Finally, invite viewers to see the display. Pictures are selected before they are arranged and labelled.

Adult check: Require four section lines, all four actions and connectives, a workable order and an event-based explanation. Usual writing or communication support is allowed.

Task 6

Example or expected evidence: The class may use the bridge only if an adult confirms it is open. If it is closed, the class should stop and ask the adult for a different plan.

Adult check: Check adult confirmation is required, closed means no bridge use, and the alternative follows adult direction. The task is writing, not an instruction to visit a bridge.

Task 7

Example or expected evidence: The librarian placed a book on the shelf. A reader found it there. The reader used the catalogue to find another title. The library helps people find reading material. The words name people, objects and a tool connected with a library.

Adult check: Require all four given words, one sensible additional related word, four connected sentences and a topic explanation. Check references make the intended person or object clear.

Task 8

Example or expected evidence: Choose a sheet of paper. Fold it in half. Next, draw a shape on the folded paper. If you need help, ask an adult. “It” means the sheet; “Next” orders an action; “If” introduces the help condition.

Adult check: Require four connected sentences and all three correctly used and explained links. Accept another suitable paper-decoration plan. No cutting or special materials are required.
