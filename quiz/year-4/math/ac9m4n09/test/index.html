Algorithms that Generate Number Sets

Read the quick preparation notes, then start when you are ready.

SkillrHub quiz practice is built for curriculum-aligned revision with answer feedback and a clear review path.

Quick preparation

  • An algorithm gives precise steps and decisions. Say where to start, what to do, when to write a number and when to stop.
  • Follow only the branch selected by a decision. Test the boundary value to check whether it is included.
  • Use repeated addition or multiplication to generate numbers. A calculator or spreadsheet can help you check the steps and describe patterns.

SkillrHub Test guide

Use this short shuffled test set to check the skill, read feedback and review missed items. Repeat quiz practice to access more of the full question bank over time.

  • Worked example: Start at 3 and write it. Add 4. If the new number is at most 19, write it and repeat the add-and-check steps; otherwise stop. The output is 3, 7, 11, 15, 19. The next value, 23, fails the check and is not written.
  • Common mistake: Check whether the decision happens before or after a number is written. A stop rule changes the output; it is part of the algorithm.
  • Assessment guidance: Have paper and a pencil ready for model or algorithm tasks. An adult checks the completed work against the model answer and marking guidance. Written responses stay pending until checked.
  • Review: Trace each step in order, check both decision branches and describe the pattern. When creating an algorithm, make its start, repeated step and stopping rule clear.
