AC9M4SP02 • Year 4 Maths

Grid References, Directions and Pathways

create and interpret grid reference systems using grid references and directions to locate and describe positions and pathways

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Grid references identify positions consistently. A system must define how letters, numbers or coordinates are read, and pathway instructions must use a fixed orientation and clear sequence.
  • Use this routine: Orient grid → Read horizontal reference → Read vertical reference → Locate cell/point → Follow ordered directions → Verify endpoint.
  • Watch for row and column order switched: State and follow the convention, usually column then row for letter–number cells.
