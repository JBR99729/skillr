AC9M4ST01 • Year 4 Maths

Collecting and Representing Data with Many-to-One Displays

acquire data for categorical and discrete numerical variables to address a question of interest or purpose, using digital tools; represent data using many-to-one pictographs, column graphs and other displays or visualisations; interpret and discuss the information that has been created

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • A data display should preserve the collected values and make the purpose easier to answer. In a many-to-one pictograph, one symbol represents several observations, so partial symbols and keys must be interpreted carefully.
  • Use this routine: Define question → Identify variable → Collect accurately → Organise digitally → Choose display/key/scale → Interpret → Discuss limitations.
  • Watch for key ignored: Multiply symbols by the key value and interpret partial symbols proportionally.
