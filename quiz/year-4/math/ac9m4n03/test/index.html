Equivalent Fractions and Decimal Connections

Read the quick preparation notes, then start when you are ready.

SkillrHub quiz practice is built for curriculum-aligned revision with answer feedback and a clear review path.

Quick preparation

  • Equivalent fractions name the same point or amount even though they use different-sized parts. Multiplying or dividing the numerator and denominator by the same factor preserves value.
  • Use this routine: Identify equal whole → Scale numerator and denominator → Verify model → Connect to tenths/hundredths → Compare.
  • Watch for only numerator changed: Multiply or divide both numerator and denominator by the same non-zero factor.

SkillrHub Test guide

Use this short shuffled test set to check the skill, read feedback and review missed items. Repeat quiz practice to access more of the full question bank over time.

  • Worked example: For the same whole, 3/5 equals 6/10 because each fifth is split into 2 equal parts. Six tenths is written as 0.6. The amount stays the same while the pieces become smaller.
  • Common mistake: Change the numerator and denominator by the same factor. Adding the same number to both does not generally give an equivalent fraction.
  • Assessment guidance: Have paper and a pencil ready for drawing tasks. An adult checks the drawing against the model answer and marking guidance. Written responses stay pending until checked.
  • Review: Check that both representations use the same whole, then use equal partitions to justify the match.
