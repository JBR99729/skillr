Separate information from the writer's judgement

Name: __________________________ Date: ______________

Explain your choices using evidence from the example. Give reasons where requested.

Use the first two questions in class and the last two for homework or independent practice.

1. Try the skill

Replace the evaluative language in ‘The dreadful queue lasted 18 minutes’ with a neutral description.

2. Try the skill

A report includes only praise for a new canteen menu and ignores recorded complaints. How could that create bias?

3. Apply and explain

Write one objective and one subjective sentence about the same fictional park visit.

4. Apply and explain

A headline says ‘Residents finally get a sensible crossing’. Identify two words that convey evaluation and explain them.

Check answers and explanations

Answer guide · AC9E6LA02

  1. The queue lasted 18 minutes.
  2. Selecting only positive views can make support seem more universal than the evidence warrants.
  3. For example, ‘The park had three benches’ and ‘The park was wonderfully peaceful.’ The second expresses a judgement.
  4. ‘Finally’ implies an overdue change; ‘sensible’ expresses approval of the crossing.

If help is needed: Neutral-sounding language is not proof that a claim is true. Check the evidence and also ask what information has been left out.
