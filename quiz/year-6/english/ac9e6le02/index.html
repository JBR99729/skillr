Comparing Literary Texts on Similar Topics or Themes

recognise situations, including financial contexts, that use integers; locate and represent integers on a number line and as coordinates on the Cartesian plane

Choose a learning activity. Worksheet, Practice and Test use the same eight-question unit bank.

60-second Quick Read

  • Students compare central ideas, plot patterns, relationships, setting, viewpoint, imagery and resolution and explain how differences create distinct meanings rather than listing surface features.
  • Example: A shared theme such as belonging is not identical in each text. Context and craft define what belonging means and how it is resolved.
  • Common trap: Shared topic treated as shared message. Analyse how each text develops it.
