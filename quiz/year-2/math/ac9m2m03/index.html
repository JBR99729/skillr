Calendars and Days Between Events

identify the date and determine the number of days between events using calendars

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Calendars show days, weeks and months. Counting days between events means moving carefully across the calendar and explaining the counting method.
  • Use this routine: Find date → Mark events → Count days → Explain.
  • Watch for counting the start day by accident: Decide whether counting begins after the start date.
