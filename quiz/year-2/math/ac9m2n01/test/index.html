Quick preparation

  • Three-digit numbers can be shown with hundreds, tens and ones. Students compare numbers by checking hundreds first, then tens, then ones, and they use number lines to explain where a number belongs.
  • Use this routine: Build → Read → Write → Locate → Order → Explain.
  • Watch for reading zeros incorrectly: In 304, the 0 means there are no tens. The number is three hundred and four, not thirty-four.
