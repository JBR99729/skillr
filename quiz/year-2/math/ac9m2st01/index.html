AC9M2ST01 • Year 2 Maths

Collecting and Organising Data

acquire data for categorical variables through surveys, observation, experiment and using digital tools; sort data into relevant categories and display data using lists and tables

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Data is useful when it answers a clear question. Categorical data is sorted into named groups such as favourite fruit or transport type.
  • Use this routine: Ask question → Collect data → Sort categories → Table → Answer.
  • Watch for unclear question: Use a question everyone can answer the same way.
