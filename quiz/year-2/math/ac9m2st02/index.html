AC9M2ST02 • Year 2 Maths

Graphical Data Displays

create different graphical representations of data using software where appropriate; compare the different representations, identify and describe common and distinctive features in response to questions

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • The same data can be shown in different ways. Students compare displays by checking labels, categories, counts and how easy it is to answer the question.
  • Use this routine: Use data → Choose graph → Compare displays → Answer questions.
  • Watch for changing counts: Every display must match the original data.
