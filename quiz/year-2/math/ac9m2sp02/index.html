AC9M2SP02 • Year 2 Maths

Maps, Positions and Pathways

locate positions in two-dimensional representations of a familiar space; move positions by following directions and pathways

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • A map or grid represents a real space from above. Positions can be described using landmarks, rows, columns and directions.
  • Use this routine: Read map → Find landmark → Locate → Follow path → Check.
  • Watch for vague words: Use beside, between, above or below with a landmark.
