Equal Groups, Arrays, Multiplication and Division

multiply and divide by one-digit numbers using repeated addition, equal grouping, arrays, and partitioning to support a variety of calculation strategies

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Multiplication counts equal groups. Division shares equally or finds groups. Arrays make rows, columns and repeated addition visible.
  • Use this routine: Make groups → Build array → Count → Record → Share.
  • Watch for unequal groups multiplied: Check every group has the same amount.
