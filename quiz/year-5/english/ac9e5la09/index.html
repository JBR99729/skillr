Subjective Language, Certainty and Obligation

use commas to indicate prepositional phrases, and apostrophes where there is multiple possession

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Students analyse how modal verbs, modal adverbs, evaluative vocabulary and sentence stance position claims from tentative to certain and optional to compulsory.
  • Use this routine: Notice → Analyse → Interpret → Apply → Create → Review.
  • Watch for must has one meaning: Context distinguishes obligation and logical certainty.
