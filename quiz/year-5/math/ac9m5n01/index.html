AC9M5N01 • Year 5 Maths

Decimals Beyond Hundredths

interpret, compare and order numbers with more than 2 decimal places, including numbers greater than one, using place value understanding; represent these on a number line

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Students extend place value to thousandths and beyond, align decimal places, use placeholder zeros and locate values between labelled points on a number line.
  • Use this routine: Represent → Reason → Calculate → Interpret → Verify.
  • Watch for more digits means greater value: 3.407 is less than 3.42 because 3.407 < 3.420.
