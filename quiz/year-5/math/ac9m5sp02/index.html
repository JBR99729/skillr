AC9M5SP02 • Year 5 Maths

Transformations of Shapes

construct a grid coordinate system that uses coordinates to locate positions within a space; use coordinates and directional language to describe position and movement

Choose a learning activity. Practice draws from 24 questions, while Test uses a separate 16-question bank.

Unit focus

  • Students perform rigid transformations, describe direction, distance, axis or centre and angle, and explain which properties remain invariant.
  • Use this routine: Represent → Reason → Calculate → Interpret → Verify.
  • Watch for reflection described as rotation: A reflection reverses orientation across a line.
