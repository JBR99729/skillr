AC9M7A06 • Year 7 Maths

Systematic Variation in Multi-variable Formulas

manipulate formulas involving several variables using digital tools, and describe the effect of systematic variation in the values of the variables

Choose a learning activity. Practice rotates 8 questions from a 24-question bank; Test draws 12 questions from a separate 16-question bank.

Unit focus

  • manipulate formulas involving several variables using digital tools, and describe the effect of systematic variation in the values of the variables
  • experimenting with different sets of tables of values from formulas; for example, using volume of a rectangular prism = length × width × height, and…
  • using spreadsheets and the formula function to recognise the effect of changing parameters on the entries in cells
