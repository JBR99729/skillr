AC9M7A01 • Year 7 Maths

Variables, Formulas and Substitution

recognise and use variables to represent everyday formulas algebraically and substitute values into formulas to determine an unknown

Choose a learning activity. Practice rotates 8 questions from a 24-question bank; Test draws 12 questions from a separate 16-question bank.

Unit focus

  • recognise and use variables to represent everyday formulas algebraically and substitute values into formulas to determine an unknown
  • linking variables to attributes and measures being modelled when using formulas, such as the area of a rectangle is equal to the length x width as…
  • interpreting and using formulas obtained from other sources; for example, maximum heart rates and target heart rates for moderate exercise
