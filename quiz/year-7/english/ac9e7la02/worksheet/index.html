Support an evaluation with precise textual evidence

Name: __________________________ Date: ______________

Explain your choices using evidence from the example. Give reasons where requested.

Use the first two questions in class and the last two for homework or independent practice.

1. Try the skill

Which supports an evaluation of suspense more directly: ‘I like mysteries’ or ‘The writer delays revealing who holds the key’? Explain.

2. Try the skill

The same scene is illustrated with the gate in deep shadow. How could this support an evaluation of the mood?

3. Apply and explain

Evaluate this original line using one quoted word as evidence: ‘The paper boat trembled beside the rushing drain.’

4. Apply and explain

Revise ‘The line is effective because it is effective’ into an evidence-based judgement.

Check answers and explanations

Answer guide · AC9E7LA02

  1. The second identifies a structural choice that delays information. The first states a personal preference.
  2. The shadow conceals detail and can make the scene feel uncertain or threatening; an alternative justified reading is acceptable.
  3. For example, ‘trembled’ makes the fragile boat seem vulnerable against the rushing water.
  4. Accept a judgement naming a textual feature and explaining its effect, such as the contrast between the fragile boat and forceful water.

If help is needed: Retelling the events or saying ‘it is good’ does not substantiate an evaluation. Explain how an identified feature creates an effect.
