FOUNDATION MATHS — AC9MFM01
Identify and compare attributes of objects and events, including length, capacity, mass and duration, using direct comparisons and communicating reasoning.

Status: Frozen v1
Note: Adult read-aloud support is expected for Foundation students.
Production note: Use standard Foundation comparison vocabulary: heavier/lighter, longer/shorter, taller/shorter, holds more/less, takes more/less time. Keep comparisons direct and observable; do not introduce rulers, scales, formal units, clocks, or indirect measurement.

PRACTICE QUESTIONS 1–24

PRACTICE 1
Two pencils are placed with their ends lined up.
Pencil 1 sticks out further than Pencil 2.
Which pencil is longer?

A. Pencil 2
B. They are the same
C. Pencil 1

Answer: C
Explanation: When the ends are lined up, the pencil that sticks out further is longer.


PRACTICE 2
Which word tells about length?

A. Heavy
B. Full
C. Long

Answer: C
Explanation: Long is a word used to describe length.


PRACTICE 3
A tall bottle and a short cup are side by side.
Which object is taller?

A. The cup
B. They are the same
C. The bottle

Answer: C
Explanation: The bottle reaches higher, so it is taller.


PRACTICE 4
Two ribbons are lined up at one end.
The red ribbon ends sooner.
Which ribbon is shorter?

A. The blue ribbon
B. Both ribbons
C. The red ribbon

Answer: C
Explanation: The ribbon that ends sooner is shorter.


PRACTICE 5
Which word tells about mass?

A. Heavy
B. Wide
C. Empty

Answer: A
Explanation: Heavy is a word used to describe mass.


PRACTICE 6
You hold a feather in one hand and a rock in the other.
Which is likely heavier?

A. Feather
B. Both are empty
C. Rock

Answer: C
Explanation: A rock usually has more mass than a feather.


PRACTICE 7
A lunchbox feels heavy.
A paper bag feels light.
Which object has more mass?

A. The lunchbox
B. The paper bag
C. Neither object

Answer: A
Explanation: The heavier object has more mass.


PRACTICE 8
Which object is likely lighter?

A. A brick
B. A full bucket
C. A pillow

Answer: C
Explanation: A pillow is usually lighter than a brick or a full bucket.


PRACTICE 9
Which word tells about capacity?

A. Holds more
B. Taller
C. Faster

Answer: A
Explanation: Capacity is about how much a container can hold.


PRACTICE 10
A big jug and a small cup are empty.
Which one can hold more water?

A. The small cup
B. They hold no water forever
C. The big jug

Answer: C
Explanation: A big jug usually has more capacity than a small cup.


PRACTICE 11
One bottle is full.
One bottle is empty.
Which bottle has more water in it now?

A. The empty bottle
B. Both have the same water
C. The full bottle

Answer: C
Explanation: A full bottle has more water than an empty bottle.


PRACTICE 12
Which container is likely to hold less?

A. A cup
B. A bucket
C. A bathtub

Answer: A
Explanation: A cup usually holds less than a bucket or bathtub.


PRACTICE 13
Which word tells about duration?

A. Longer time
B. Heavier
C. Wider

Answer: A
Explanation: Duration is about how long something takes.


PRACTICE 14
Which event usually takes less time?

A. Eating lunch
B. Sleeping all night
C. Washing hands

Answer: C
Explanation: Washing hands usually takes less time than eating lunch or sleeping.


PRACTICE 15
Which event usually takes longer?

A. Putting on one sock
B. Watching a movie
C. Blinking once

Answer: B
Explanation: Watching a movie usually takes a longer time.


PRACTICE 16
Two children start packing away blocks at the same time.
Sam finishes first.
Who took less time?

A. Sam
B. The other child
C. Both took longer

Answer: A
Explanation: The person who finishes first took less time.


PRACTICE 17
Which question is about length?

A. Which stick is longer?
B. Which bag is heavier?
C. Which cup holds more?

Answer: A
Explanation: Longer is used to compare length.


PRACTICE 18
Which question is about mass?

A. Which rope is shorter?
B. Which box is heavier?
C. Which bottle is fuller?

Answer: B
Explanation: Heavier is used to compare mass.


PRACTICE 19
Which question is about capacity?

A. Which cup holds more?
B. Which pencil is longer?
C. Which game takes longer?

Answer: A
Explanation: Holds more is about capacity.


PRACTICE 20
Which question is about duration?

A. Which toy is taller?
B. Which bag is lighter?
C. Which song takes longer?

Answer: C
Explanation: Takes longer is about duration.


PRACTICE 21
Two blocks are placed on a table.
Block A is wider than Block B.
Which block is wider?

A. Block B
B. Block A
C. Both are shorter

Answer: B
Explanation: Wider describes how much space across an object takes.


PRACTICE 22
Why should two straws be lined up at one end before comparing length?

A. So the colours match
B. So the comparison is fair
C. So they become heavier

Answer: B
Explanation: Lining up the ends helps us see which straw is longer.


PRACTICE 23
You compare two bags by holding one in each hand.
One bag pulls down more.
What can you say?

A. It is heavier
B. It is shorter
C. It holds less

Answer: A
Explanation: The bag that pulls down more feels heavier.


PRACTICE 24
A tall glass and a short glass are both filled to the top.
Which glass likely holds more?

A. The short glass
B. The tall glass
C. Neither can hold water

Answer: B
Explanation: The taller glass usually has more capacity if both are similar width.
