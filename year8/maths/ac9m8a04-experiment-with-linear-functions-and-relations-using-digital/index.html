Important questions and answers

1. What is the central idea in Experimenting with Linear Functions?

Answer: Systematic variation reveals what coefficients and constants control in a linear relation.

2. How can you vary one parameter at a time?

Answer: In y=mx+b, changing m changes steepness; changing b shifts the line vertically.

3. What stays invariant when b changes in y=3x+b?

Answer: The gradient remains 3, so all resulting lines are parallel; only the vertical intercept changes.
