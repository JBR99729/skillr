AC9M8A02 • Year 8 Maths • Algebra

Linear Relations, Equations and Inequalities

Tables, graphs and algebra are connected representations of the same linear relationship.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Tables, graphs and algebra are connected representations of the same linear relationship.

Learning intention: Tables, graphs and algebra are connected representations of the same linear relationship.

Success criteria

  • Explain spot constant first differences using the approved model.
  • Apply connect two-sided equations to intersections to a new case.
  • Verify a conclusion with a second representation, estimate or test case.
Concept boundary and prerequisites

Must teach

  • graph linear relations on the Cartesian plane using digital tools where appropriate; solve linear equations and one-variable inequalities using graphical and algebraic techniques; verify solutions by substitution

Prerequisites

  • Relevant Year 7 algebra representations and vocabulary.

May support informally

  • Digital tools may test, visualise and verify after the mathematical structure is explicit.

Do not overteach

  • Do not introduce later-year formalism that is unnecessary for this content description.

Worked examples

Spot constant first differences

Recognise that in a table of values, if the first difference between consecutive values of the dependent variable is constant, then it is a linear relation.

Teacher prompt: For spot constant first differences, which graph feature is direct evidence for the conclusion?

Graph horizontal and vertical boundaries

x = a is a vertical boundary and y = a is horizontal; use a solid line for ≤ or ≥ and shade the solution side.

Teacher prompt: For graph horizontal and vertical boundaries, which graph feature is direct evidence for the conclusion?

Decide whether a relation is linear

Completing a table of values, plotting the resulting points on the Cartesian plane and determining whether the relationship is linear.

Teacher prompt: For decide whether a relation is linear, which graph feature is direct evidence for the conclusion?

Read an equation from a graph

Graph y = ax + b and y = c; the x-coordinate of their intersection solves ax + b = c.

Teacher prompt: For read an equation from a graph, which graph feature is direct evidence for the conclusion?

Solve and check an inequality

Solve ax + b < c using inverse operations when a > 0, then test a value from the solution interval.

Teacher prompt: For solve and check an inequality, which bound or interval is justified by the model?

Connect two-sided equations to intersections

3x+7 = 6x-9, representing these graphically, and verifying solutions by substitution.

Common misconceptions and quick fixes
  • A rule is applied without preserving equivalence or its conditions — Return to the linked table, graph or expanded form and verify by substitution.
  • The linear relations, equations and inequalities model is copied without interpretation — Connect every label in ‘Recognise that in a table of values, if the first difference between consecutive values of the dependent variable is constant, then it is a linear relation.’ to its mathematical role.
  • The result is not verified — Use a second representation, boundary case, inverse operation or simulation check.
Support, core and extend

Support: Reduce numerical or representational load while retaining the same decision and explanation.

Core: Connect at least two representations, justify the method and verify independently.

Extend: Test a boundary case, counterexample or model limitation without introducing later-year procedures.
