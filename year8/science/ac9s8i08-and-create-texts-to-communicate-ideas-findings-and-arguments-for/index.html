AC9S8I08 • Year 8 Science

Communicate Science for a Purpose

Effective scientific texts select accurate content, language and representations for a defined purpose and audience.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

We are learning to explain communicate science for a purpose using models and evidence.

Success criteria

  • Identify and connect purpose, audience, scientific content.
  • Use a model to explain rather than only describe the concept.
  • Apply the central idea to a curriculum example and justify the connection.
  • Evaluate one model limit, misconception or evidence boundary.
Concept boundary and prerequisites

Must teach

  • Content selection matches purpose and audience.
  • Scientific conventions, units and evidence remain accurate.
  • Digital and visual features clarify rather than decorate.

Prerequisites

  • Read a labelled scientific diagram or data display.
  • Distinguish an observation from an explanation.
  • Use evidence to support a short scientific statement.

Do not overteach

  • Do not imply one text form suits every audience.
  • Do not use engagement features that distort scale, uncertainty or causation.
Teaching progression
  1. 1. Set purpose and audience
    Use the shared model to foreground purpose.
    Students: Annotate or explain the link involving purpose.
  2. 2. Select evidence
    Use the shared model to foreground audience.
    Students: Annotate or explain the link involving audience.
  3. 3. Choose the text form
    Use the shared model to foreground scientific content.
    Students: Annotate or explain the link involving scientific content.
  4. 4. Review meaning and accessibility
    Use the shared model to foreground language and structure.
    Students: Annotate or explain the link involving language and structure.
