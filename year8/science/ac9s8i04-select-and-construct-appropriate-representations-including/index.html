AC9S8I04 • Year 8 Science

Choose a Representation That Reveals the Pattern

Tables, graphs, models and mathematical relationships organise information for different scientific purposes.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

We are learning to explain choose a representation that reveals the pattern using models and evidence.

Success criteria

  • Identify and connect data type, table, graph.
  • Use a model to explain rather than only describe the concept.
  • Apply the central idea to a curriculum example and justify the connection.
  • Evaluate one model limit, misconception or evidence boundary.
Concept boundary and prerequisites

Must teach

  • Representation choice depends on data type and question.
  • Conventions make tables and graphs interpretable.
  • Every representation highlights some relationships and hides others.

Prerequisites

  • Read a labelled scientific diagram or data display.
  • Distinguish an observation from an explanation.
  • Use evidence to support a short scientific statement.

Do not overteach

  • Do not use truncated axes without clearly signalling them.
  • Do not turn graphing into decoration detached from analysis.
Teaching progression
  1. 1. Identify the data purpose
    Use the shared model to foreground data type.
    Students: Annotate or explain the link involving data type.
  2. 2. Select a representation
    Use the shared model to foreground table.
    Students: Annotate or explain the link involving table.
  3. 3. Apply conventions
    Use the shared model to foreground graph.
    Students: Annotate or explain the link involving graph.
  4. 4. Evaluate what it reveals
    Use the shared model to foreground model or equation.
    Students: Annotate or explain the link involving model or equation.
Worked examples

Observe → connect → conclude

Distance from a lamp is the independent variable and goes on the horizontal axis.

Australian Curriculum elaborations

E1: Use: data type

using simple formulas in spreadsheets to organise and process collected data

Use simple formulas in spreadsheets to organise and process collected to make the role of data type visible and connect the evidence to the unit’s central explanation.

E2: Use: table

using visual displays of large data sets, such as maps showing the location of volcanoes and earthquakes, charts showing the structure of body systems and graphs showing variable energy production, to identify temporal and spatial relationships

Use visual displays of large data sets to make the role of table visible and connect the evidence to the unit’s central explanation.

E3: Build: graph

constructing graphs using correct conventions such as naming the graph and labelling the axes, using the horizontal axis for the independent variable and the vertical axis for the dependent variable

Use graphs using correct conventions to make the role of graph visible and connect the evidence to the unit’s central explanation.

E4: Build: model or equation

constructing energy flow diagrams to represent energy changes in a system such as a rollercoaster or rocket launch

Use energy flow diagrams to represent energy changes to make the role of model or equation visible and connect the evidence to the unit’s central explanation.

E5: Build: strength and limitation

constructing representations of chemical and physical changes, such as creating a visual model or symbolic representation

Use representations of chemical and physical changes to make the role of strength and limitation visible and connect the evidence to the unit’s central explanation.

E6: Combine: data type

collating data from a number of sources such as different groups in the class who performed the same investigation to create a summary

Use data from a number of sources to make the role of data type visible and connect the evidence to the unit’s central explanation.

E7: Examine: table

examining the strengths and limitations of representations such as physical models, diagrams and virtual simulations and selecting the most appropriate representation to use

Use the strengths and limitations of representations to make the role of table visible and connect the evidence to the unit’s central explanation.

Common misconceptions
  • Any graph type can show the same data.
  • A model is useful only if it is realistic.
