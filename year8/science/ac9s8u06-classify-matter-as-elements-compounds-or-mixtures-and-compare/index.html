Elements, Compounds and Mixtures

Read particle evidence, classify matter and choose the representation that communicates the right information.

Topic GuideTeacher SlidesHomeworkPracticeTest
What you need to know

Classify matter by asking two questions: How many atom types are present? and are different atom types chemically joined in identical particles? An element contains one atom type, a compound contains different atom types chemically combined in fixed ratios, and a mixture contains substances together without becoming one new pure substance.

Success criteria

  • Classify particle models as element, compound or mixture and justify the choice.
  • Explain why O₂ is an element but H₂O is a compound.
  • Use symbols, formulas, percentages and particle models appropriately.
  • Distinguish solutions, suspensions and colloids from evidence.
  • Compare Mendeleev's periodic table with the modern table.
  • Explain how atomic ideas changed as evidence improved.
Particle-model visual guide
Visual rule: count atom types, then check bonding and whether every particle is the same. Do not classify from colour alone.
Matter cheat sheet

Element

One type of atom only. O₂ is still an element.

Compound

Different atom types chemically combined in a fixed ratio. Examples: H₂O, CO₂, NaCl.

Mixture

Two or more substances together. Relative amounts can vary.

Representation

Symbols show element identity; formulas show composition; percentages describe mixture amounts; models show arrangement.

Important notes
  • Two atoms does not mean compound: O₂ has two atoms but only one atom type.
  • Compound ≠ mixture: compounds have fixed composition; mixtures can vary.
  • Formula ≠ exact shape: a molecular formula gives composition, not full 3D geometry.
  • Model colours and sizes are conventions: do not treat them as literal atomic appearance.
  • Modern periodic order uses atomic number: Mendeleev used recurring properties and relative atomic mass to reveal patterns and predict gaps.

How atomic ideas changed: evidence timeline

Ancient Greek ideas

Democritus: proposed that matter could be made of tiny indivisible particles. This was a philosophical idea, not an experimentally tested atomic theory.

→

Dalton · early 1800s

Used experimental patterns in chemical reactions to propose that elements contain characteristic atoms and compounds form in whole-number ratios.

→

Later evidence

Experiments showed atoms have internal structure, so Dalton's solid-sphere model was useful but incomplete.

→

Modern model

Atoms contain smaller particles including protons, neutrons and electrons. Scientific models changed because new evidence became available.

Key idea: science did not simply replace one picture with another. New experimental evidence explained more observations and exposed limitations in earlier models.
Mendeleev vs modern periodic table

Mendeleev

  • Used relative atomic mass and recurring properties.
  • Left gaps for undiscovered elements.
  • Predicted properties of missing elements.
  • Noble gases were not yet known in his earliest table.

Modern table

  • Ordered by atomic number.
  • Groups elements with recurring properties.
  • Includes later discoveries.
High-scoring answer: Mendeleev kept elements with similar properties together even when that required gaps. Later discoveries matching his predictions supported his pattern. The modern table improves the ordering by using atomic number.
Worked examples: Observe → Connect → Conclude

O₂

Observe: each particle contains two oxygen atoms.

Connect: only one atom type is present.

Conclude: O₂ is a molecular element.

H₂O + CO₂

Observe: two different molecular substances are present.

Connect: they coexist rather than forming one identical particle type.

Conclude: the sample is a mixture containing compounds.

Particle model

Observe: every particle contains one red atom bonded to two blue atoms.

Connect: different atom types occur in the same fixed ratio throughout.

Conclude: the sample is a pure compound.

Solve-it: 20 guided self-study questions
How to use this section: attempt each question before opening anything. If stuck, open the Hint only. Then compare with the Model answer. For open research questions, use the hint to identify what evidence to find, then write the answer in your own words and cite the source used.
1. Draw or describe particle models of an element, compound and mixture.
Hint
For each model, count atom types and decide whether unlike atoms are bonded in identical particles.
Model answer
Element: only one atom type, either single atoms or molecules such as O₂. Compound: different atom types bonded in a fixed ratio, such as one red bonded to two blue. Mixture: more than one substance present together, so more than one particle type appears.
2. A sample contains only O₂. Classify and justify.
Hint
Do not count the number of atoms; count the number of atom types.
Model answer
O₂ is an element because every particle contains only oxygen atoms. It is a molecular element, not a compound.
3. A sample contains H₂O and CO₂ molecules together. Classify it.
Hint
Ask whether the sample contains one pure particle type or more than one substance.
Model answer
It is a mixture because two different compounds, H₂O and CO₂, are present together without becoming one new pure substance.
4. Why is NaCl a compound rather than an element?
Hint
Identify how many different atom types are represented by Na and Cl.
Model answer
NaCl is a compound because it contains sodium and chlorine, two different element types, chemically combined in a fixed ratio.
5. Why can saltwater be described as 20% salt and 80% water?
Hint
Compare fixed composition in a compound with variable composition in a mixture.
Model answer
Saltwater is a mixture, so the relative amounts of salt and water can vary. Percentages communicate those variable proportions; one chemical formula would incorrectly imply a fixed ratio.
6. Write the formula for 2 hydrogen atoms and 1 sulfur atom, then classify it.
Hint
Use a subscript 2 for hydrogen and no written 1 for sulfur.
Model answer
H₂S. It is a compound because it contains two different atom types chemically combined.
7. Explain the difference between O and O₂.
Hint
One symbol represents one oxygen atom; the subscript tells you how many oxygen atoms are in a molecule.
Model answer
O represents one oxygen atom. O₂ represents a molecule made of two bonded oxygen atoms. Both represent the element oxygen because only one atom type is present.
8. Write formulas for carbon dioxide, methane and sodium chloride.
Hint
Carbon dioxide has 1 C and 2 O; methane has 1 C and 4 H; sodium chloride is Na and Cl in a 1:1 formula ratio.
Model answer
CO₂, CH₄ and NaCl.
9. Why can a ball-and-stick model be more useful than a formula for shape?
Hint
Compare what a formula tells you with what a 3D representation can show.
Model answer
A formula shows which atom types and how many are present, while a ball-and-stick model can show relative 3D arrangement and bond directions. The model is still simplified and does not show true atom sizes or colours.
10. A particle has three red atoms and one blue atom. Write a possible formula using R and B.
Hint
The subscripts record the number of each atom type.
Model answer
One possible formula is R₃B. It would represent a compound if the red and blue atoms are chemically bonded into identical particles.
11. Give two differences between Mendeleev's and the modern periodic table.
Hint
Compare the organising number and what was known about undiscovered elements.
Model answer
Mendeleev mainly used relative atomic mass together with recurring chemical properties and left gaps. The modern table is ordered by atomic number and includes elements discovered after Mendeleev's time.
12. Why did Mendeleev leave gaps?
Hint
Look for missing positions in a repeating pattern of properties.
Model answer
He left gaps because the property patterns suggested that some elements had not yet been discovered. He predicted that elements with suitable properties would later fill those positions.
13. Compare atomic mass and atomic number as organising ideas.
Hint
Atomic number counts protons. Ask which quantity defines the identity of an element in the modern table.
Model answer
Relative atomic mass compares atomic masses, while atomic number is the number of protons in an atom. The modern periodic table uses atomic number because it uniquely defines each element and gives a consistent order.
14. Why were noble gases missing from Mendeleev's earliest table?
Hint
Think about when those gases were identified and why low reactivity made them difficult to notice.
Model answer
The noble gases had not yet been discovered when Mendeleev produced his earliest table. Their very low reactivity also made them less obvious in ordinary chemical studies.
15. Why might elements in the same group share some properties?
Hint
Use the evidence pattern in the periodic table rather than advanced electron theory: elements in a group repeatedly show similar chemical behaviour.
Model answer
Elements in the same group are placed together because they show recurring similarities in chemical behaviour and compound formation. At this level, the important point is the observed repeating pattern.
16. Classify fog, saltwater, flour in water and milk as mixture types.
Hint
Solution = uniform dissolved mixture; suspension = particles settle; colloid = dispersed particles stay suspended.
Model answer
Fog: colloid; saltwater: solution; flour in water: suspension; milk: colloid.
17. Why is milk a colloid rather than a true solution?
Hint
Ask whether the dispersed particles are truly dissolved at molecular/ionic scale.
Model answer
Milk contains tiny dispersed droplets and particles that remain suspended. They are not all dissolved as individual molecules or ions, so milk is a colloid rather than a true solution.
18. Particles settle after 10 minutes. What mixture type is indicated?
Hint
Settling is the key diagnostic observation.
Model answer
A suspension, because its larger dispersed particles settle on standing.
19. Describe the development from Democritus to Dalton to modern atomic theory.
Hint
Structure the answer as idea → evidence-based model → later evidence showing internal atomic structure.
Model answer
Democritus proposed tiny indivisible particles as a philosophical idea. Dalton later used experimental chemical evidence to build an atomic theory in which elements had characteristic atoms and compounds formed in whole-number ratios. Later experiments showed atoms contain smaller particles, so modern models include internal atomic structure.
20. Why was Dalton's model an improvement but still incomplete?
Hint
State one strength based on evidence and one limitation revealed by later experiments.
Model answer
Dalton improved earlier ideas by linking atoms to experimental patterns in chemical reactions and compound ratios. His model was incomplete because later evidence showed atoms are not indivisible solid spheres and contain internal structure.
Research note: when a question asks for historical evidence, properties of a periodic-table group, or a real material example, students may use a reliable science reference to confirm details. Record the source, extract only the evidence needed, then answer in your own words using evidence → rule/pattern → conclusion.
Common misconceptions

“Two atoms means compound.”

False: O₂ contains one atom type.

“A neat particle diagram must be a compound.”

False: check atom types and bonding.

“Formulas show exact shape.”

False: formulas mainly communicate composition.

“Mixtures have fixed ratios.”

False: mixture proportions can vary.

Australian Curriculum v9.0 elaborations

  • E2: Compare Mendeleev's mass/property arrangement with modern atomic-number ordering and his gap predictions.
  • E3: Translate between symbols, formulas and percentage descriptions and explain why each is useful.
  • E4: Use representations and observable behaviour to distinguish solutions, suspensions and colloids.
  • E5: Compare symbols, formulas, 2D structures and 3D models; identify strengths and limits.
  • E6: Use the evidence timeline to explain how the concept of an element changed from early particle ideas through Dalton to modern atomic theory.
