AC9S8I05 • Year 8 Science

Analyse Patterns Without Ignoring Anomalies

Strong data analysis describes the overall pattern, uses suitable numerical summaries, distinguishes correlation from causation and investigates unusual values before deciding what they mean.

Topic GuideTeacher SlidesHomeworkPracticeTest
Core idea

Inspect the data → describe the pattern or relationship → calculate useful summaries → identify anomalies → investigate explanations → draw a qualified conclusion.

An anomaly is not automatically an error. It may result from measurement problems, changed conditions, an equipment fault or a genuine feature of the system.

E1 — Patterns, relationships and causality

A positive relationship occurs when one variable generally increases as another increases. A negative relationship occurs when one generally decreases. Some relationships are non-linear, such as a reaction rate that rises to an optimum and then falls.

Correlation is not automatically causation

Two variables can change together without one directly causing the other. A causal conclusion is stronger when the independent variable is deliberately changed, relevant variables are controlled and the dependent response is measured consistently.

E2 — Mean, median, mode and outliers
  • Mean: add all values and divide by the number of values.
  • Median: order the data and find the middle value; for an even number, average the two middle values.
  • Mode: the most frequent value.

Extreme outliers can strongly shift the mean, so the median may sometimes better represent a typical value.

Worked example

Data: 2, 3, 3, 4, 25

Mean = 7.4; median = 3. The large value 25 pulls the mean upward, so the median better represents the central cluster.

E3 — Analyse second-hand data with digital tools

Spreadsheets can help sort, graph and inspect larger data sets. Useful tools include:

  • AVERAGE for means
  • MAX/MIN for extreme values
  • conditional formatting to flag thresholds or unusual values
  • line graphs for time-series trends

Digital tools help find patterns, but students still need to judge whether an unusual value is meaningful and check supporting evidence such as weather, maintenance or equipment logs.

E4 — Battery output and chemical potential energy

Battery data can show a gradual decline in output over repeated recharge cycles. Small fluctuations may sit around the overall trend. A sudden departure from the trend may indicate temperature effects, incomplete charging, degradation changes or measurement error.

A trendline summarises the overall direction; it does not delete anomalies or guarantee exact future values.

E5 — Chemical reaction temperature data

Changing reactant proportions can produce linear, non-linear or plateauing temperature responses. A plateau may indicate a limiting reactant or another limiting condition. An unusually low or high trial should be checked for heat loss, incomplete mixing, contamination or measurement problems before being removed.

How to investigate an anomaly
  1. Check whether the value was recorded or entered correctly.
  2. Check instrument or equipment logs.
  3. Compare with repeated trials.
  4. Check environmental or experimental conditions.
  5. Use independent evidence where available.
  6. Repeat the measurement if appropriate.
  7. Keep, annotate or exclude the value only with a justified reason.
Common mistakes
  • Assuming every correlation proves causation.
  • Deleting any value that does not fit the trend.
  • Using the mean automatically when extreme outliers are present.
  • Describing a non-linear trend as “no relationship”.
  • Calling several consecutive related values a single random outlier.
  • Using a trendline as if it predicts every future value exactly.
  • Ignoring external evidence that may explain an anomaly.
Assessment strategy

For AC9S8I05, work through this sequence:

  1. Pattern: What does most of the data do?
  2. Relationship: Positive, negative, linear, non-linear or no clear relationship?
  3. Summary: Which numerical measure helps describe the data?
  4. Anomaly: Which values depart from the pattern?
  5. Explanation: What evidence could explain them?
  6. Conclusion: What does the evidence support without overclaiming?
