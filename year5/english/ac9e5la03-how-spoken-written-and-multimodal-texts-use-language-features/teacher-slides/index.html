Year 5 English · AC9E5LA03

Purpose → structure → stages → features

Help students explain not just what a text contains, but how its organisation helps it achieve its purpose.

Learning intention

We are learning to identify the main purpose of a text, recognise its dominant structure and explain how stages, language and multimodal features guide the audience.

  • I can separate topic from purpose.
  • I can identify sequence, compare–contrast, cause–effect and problem–solution.
  • I can name characteristic stages in common text types.
  • I can explain how a feature supports the organisation and purpose.
Board 1: topic is not purpose

Write SHARKS in the centre. Ask students to imagine:

Inform

A factual page on habitat and diet.

Persuade

A campaign asking people to protect shark habitat.

Entertain

A suspenseful story about a diver.

Same topic, different purposes. Purpose describes what the text is mainly designed to achieve.

Board 2: four structures

Sequence

first → next → finally

Events, stages or steps.

Compare–contrast

both ↔ unlike

Similarities and differences.

Cause–effect

because → therefore

Reasons and results.

Problem–solution

issue → response

A difficulty and ways to address it.

Rule: choose the dominant relationship across the whole text, not the first signal word you notice.

Board 3: whole-text thinking

Example: a passage compares two animals in parallel columns. It includes one sentence saying what happened “later”. Ask: Does one time word make the text a sequence?

No. If most information is organised as similarities and differences, compare–contrast is the stronger whole-text label.

Board 4: stages and phases

Narrative

orientation → complication → resolution

Persuasive

position → reasons/evidence → response → conclusion

Information report

introduction/classification → grouped sections → summary

Procedure

goal → materials → ordered steps → check

Ask students what job each stage performs for the reader, listener or viewer.

Board 5: language and visual features
  • first/next/finally make sequence visible
  • both/unlike/however support comparison
  • because/therefore/as a result support cause–effect
  • headings group information
  • parallel columns can support comparison
  • arrows + ordered images can show a process visually
  • characters, setting and dialogue help organise imaginative texts
Quick checks
  1. “Both planets are rocky; however, one is much hotter.” Structure? Compare–contrast.
  2. “Heavy rain saturated the slope, therefore it collapsed.” Structure? Cause–effect.
  3. A notice says “Please wear sunscreen.” Purpose? Persuade.
  4. A biography moves childhood → study → discovery. Structure? Sequence.
  5. A page describes litter, then clean-up options. Structure? Problem–solution.
Misconceptions to correct
  • “The topic tells me the purpose.”
  • “One signal word decides the structure.”
  • “Every text with an order is sequence.”
  • “Two subjects automatically mean compare–contrast.”
  • “Images and layout are only decoration.”
Exit ticket

Give students a short unfamiliar text. Ask them to write three sentences:

  1. The main purpose is ___ because ___.
  2. The dominant structure is ___ because most ideas are organised ___.
  3. One feature that helps the audience is ___ because ___.
