What students learn in AC9E5LY09

Build and spell new words from knowledge of known words, base words, prefixes and suffixes, word origins, letter patterns and spelling generalisations.

Core idea: Word building is systematic: identify a base or root, add meaningful affixes, apply spelling changes, and check that the finished word fits the sentence.

Success looks like

  • use the code’s metalanguage accurately
  • select specific evidence from the text, word or draft
  • explain rather than merely label
  • apply the routine in an unseen context

Concept model and worked thinking

Reliable routine

base/root → affix → meaning → spelling rule → context check

Word building is systematic: identify a base or root, add meaningful affixes, apply spelling changes, and check that the finished word fits the sentence.

Research-informed progression

Direct IXL evidence: IXL directly supports prefixes, suffixes, Greek and Latin roots, plural and tense families.

Coverage boundary: IXL evidence is strong for discrete word-building tasks; extended explanation of word history and generalisations is a curriculum-level synthesis.

Common misconceptions
  • attaching an affix to the wrong base — stop, return to the evidence and use the routine before deciding.
  • using the right meaning with the wrong spelling — stop, return to the evidence and use the routine before deciding.
  • assuming every word that looks similar shares a root — stop, return to the evidence and use the routine before deciding.
  • forgetting a spelling change when adding a suffix — stop, return to the evidence and use the routine before deciding.
Guided learning activities

1. Notice and name

Use a short model from happy → unhappy and identify the exact clue that matters.

2. Explain and compare

Compare a strong and weak response. Require evidence plus a reason, not a label alone.

3. Transfer and revise

Apply the same routine to magic → magician, then revise one choice after feedback.

Revision Notes

Exam routine: base/root → affix → meaning → spelling rule → context check

  • What exact clue supports the answer?
  • Which term names the feature or strategy precisely?
  • What effect, meaning or grammatical change follows?
  • Which tempting answer is plausible but unsupported?
  • Would the reasoning still work in an unseen context?
Support, core and extend
  • Support: provide a short model, highlighted evidence and a sentence stem.
  • Core: use an unseen example and require evidence plus explanation.
  • Extend: compare alternatives, evaluate effectiveness, or revise a created response.
