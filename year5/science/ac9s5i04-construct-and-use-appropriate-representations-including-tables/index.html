YEAR 5 SCIENCE · AC9S5I04

Represent data without changing its meaning

Learning intention: Choose tables, graphs and models that organise evidence clearly and reveal patterns while preserving values, units and limitations.

One dataset, different useful views

The same upright card stays 10 cm from the screen. Only the torch-to-card distance changes. The supplied numbers are invented model records, not measurements from the illustration or an actual class. The graph shows Run 1 only: at torch distances 10, 20 and 30 cm, shadow heights are 20, 15 and 13 cm. The table preserves all three runs. Learn the skill

1. Organise complete records in a table

Use clear headings and units. Keep the changed variable and measured outcome distinct. Preserve all valid records, including values that differ from the others.

Read the row and column

At torch-to-card distance 20 cm, Run 2 shadow height is 14 cm. The 20 cm is an input distance; the 14 cm is a measured outcome in the model record.

Try it · May we copy the Run 1 graph value into every run in the table?

No. The runs differ. A representation must preserve the actual supplied values, not replace them with a preferred example.

2. Choose and label a useful graph

For this numeric-distance relationship, put torch-to-card distance on the horizontal axis and shadow height on the vertical axis. Use equal intervals and make clear which runs are plotted.

Check the supplied graph

The graph plots Run 1: (10,20), (20,15), (30,13), with both quantities in centimetres. Read labels before interpreting the descending line.

Try it · Does the line supply an actual measurement at 25 cm?

No. It links measured-position records to reveal a pattern. A value between them would be an estimate or prediction, not a recorded result.

3. Explain a pattern and a model’s limits

Describe how the measured quantity changes with the changed variable. A path model can help explain the pattern, while a graph displays supplied data. They answer different questions.

A bounded pattern

In Run 1, shadow height decreases as torch-to-card distance increases from 10 to 30 cm in this setup. The graph does not describe every possible torch or screen arrangement.

Try it · Does a descending line mean that time passed from left to right?

No. The horizontal axis is torch-to-card distance, not time. Interpret the named quantities.

Common mistakes

“Any downward graph means the object moved downward.” Read the axes. Here the graph compares distances with shadow heights.

“Models show every real-world detail.” Models select useful relationships and leave other details out.

10-MINUTE ACTIVITY

Cross-check a graph and table

2 minutes: identify both graph axes and units. 4 minutes: locate the three Run 1 pairs in the table and graph. 2 minutes: describe the trend with its tested range. 2 minutes: name something the line does not establish.

Adjust the challenge Support: highlight Run 1 before plotting. Extend: explain a clear way to display repeat variation without erasing the original records.

Use the supplied invented dataset. If using a spreadsheet, check copied values, labels, scales and which series is displayed.

Three tricky questions

1. Why is Run 2 at 20 cm equal to 14 cm, while the graph shows 15 cm?

The graph is explicitly Run 1 only. The table shows separate runs; different values are not automatically a copying error.

2. Could a graph with no units communicate this comparison adequately?

It would be incomplete. Readers need to know which quantities and units the numbers represent.

3. Is a ray diagram a replacement for the recorded results table?

No. It can explain a light-path mechanism but does not retain every supplied trial record.

FAQ

Are line graphs always the right choice?

No. Choose a representation for the variables and purpose. Categories may suit columns; a numeric relationship can suit plotted points or a line.

Why keep a table as well?

A table preserves exact records and run identities that may be harder to retrieve from a simplified graph.

What students learn in AC9S5I04

Students choose representations by variable type and question, calculate or organise data transparently and interpret patterns while distinguishing what a model or graph shows from what it cannot establish.

A representation is appropriate when it preserves the evidence and makes the relevant relationship easier to inspect.

Use labels, units and consistent scales. Calculated values such as means should be traceable to raw data.

Graphs reveal relationships but do not alone prove cause. Link conclusions to the method and scope.

Curriculum coverage and elaborations

Content description: construct and use appropriate representations, including tables, graphs and visual or physical models, to organise and process data and information and describe patterns, trends and relationships.

  • E1: using annotated digital photography or field sketches to describe structural features of plants or animals
  • E2: constructing a column graph to illustrate the relationship between predation and an animal feature such as colour as indicated by a simulation, and using values to represent the outcomes of repeated simulations
  • E3: modelling landscapes using materials such as sand, gravel, soil and rocks to show effects of erosion by water
  • E4: constructing labelled ray diagrams to represent observations and compare how light interacts with different objects
  • E5: using maps to identify patterns in erosion site locations or aerial photographs to show effects of erosion over time

Common misconceptions
  • Graph type chosen by habit — Match it to variables and question.
  • Calculated value has no method — Show how data were processed.
  • Axes omit units — Readers need quantity and scale.
  • Pattern described as universal law — Limit to evidence and conditions.
