Learn the skill

Four focused steps

Learning goal: Construct numbered axes, locate exact intersections and describe a route from a stated start.

Study a worked example, explain the reasoning and try its short check before moving on.

1. Construct the coordinate system

Draw two perpendicular number lines meeting at zero. Number equal intervals on the lines, not the spaces. The shared zero is the origin.

Make a grid from 0 to 6 on each axis.

  1. Draw a horizontal axis and a vertical axis with a shared zero.
  2. Mark each unit the same distance apart along its axis, then extend the grid lines.
  3. A cell reference names an area; a coordinate pair names an exact intersection.

Watch for this: Letter/number cell references and ordered coordinates are different locating systems.

Try it: Where is the origin?

Check the answer

At the shared zero: (0, 0).

2. Read and plot the horizontal value first

Write an ordered pair in brackets with a comma. Move along the horizontal axis first, then vertically.

Plot P(2, 4) and Q(4, 2).

  1. P is two units right and four up from the origin.
  2. Q is four right and two up.
  3. The points differ even though they use the same two numbers.

Watch for this: (5, 0) lies on the horizontal axis; (0, 3) lies on the vertical axis.

Try it: Which labelled point is two units up and four units right?

Check the answer

Q(4, 2), because horizontal is written first.

3. Describe a route from its current position

Name the start, grid units and direction. Each instruction acts on the latest point.

Start at (2, 1), move three units right, then two up.

  1. Three right changes the horizontal coordinate to 5: (5, 1).
  2. Two up changes the vertical coordinate to 3: (5, 3).
  3. To return, reverse the order and directions: two down, then three left.

Watch for this: Count spaces between lines, not the number of lines crossed including the start.

Try it: Start at (5, 4), move two left and three down. Where do you finish?

Check the answer

(3, 1).

4. Communicate and check a drawing

List vertices in the order they should be joined. A partner needs the same axes, scale and join instructions to reproduce the shape.

Re-create A(1, 1), B(4, 1), C(4, 3), D(1, 3), joining A–B–C–D–A.

  1. Plot each exact intersection and label it.
  2. Join in the stated order to form a rectangle three units wide and two high.
  3. Compare with a partner’s drawing and use the coordinates to locate any disagreement.

Watch for this: A correct list without joining instructions may not determine the intended picture.

Try it: How would moving every vertex one unit up change this rectangle?

Check the answer

Its vertical coordinates all increase by one; its width and height remain the same.

Vocabulary and teaching help

Before this lesson: Read equal number-line intervals and distinguish horizontal from vertical.

Help a learner get started

Open one focus at a time. Read the worked steps together, ask the learner to explain what each quantity means, then let them try the short check before opening its answer. Use paper, objects or a drawing when that makes the idea clearer.

Keep the challenge meaningful: A practical construction, investigation or digital activity needs the learner’s actual work. A correct spoken answer alone does not demonstrate that practical skill.
