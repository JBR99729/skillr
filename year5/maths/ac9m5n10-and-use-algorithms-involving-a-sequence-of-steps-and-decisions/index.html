Learn the skill

Four focused steps

Learning goal: Write clear steps and decisions, test them with digital tools and explain the patterns you find.

Study a worked example, explain the reasoning and try its short check before moving on.

1. Make the decision rule explicit

An algorithm states the input, ordered steps, decisions, output and when to stop. A flowchart shows which branch to follow.

Test whether 126 is divisible by 6.

  1. Add its digits: 1 + 2 + 6 = 9, a multiple of 3.
  2. Its last digit is even, so it is divisible by both 2 and 3.
  3. Output “divisible by 6”. If either test fails, output “not divisible by 6”, then stop.

Watch for this: For this rule the tests are joined by AND, not OR.

Try it: Use the algorithm for 123.

Check the answer

Not divisible by 6: its digit sum is divisible by 3 but it is odd.

2. Create a systematic factor search

For a positive input number, test possible divisors in order. If division leaves no remainder, record the divisor and its partner.

Design a search for the factors of 20.

  1. Start a candidate at 1; divide 20 by it. Record 1 and 20.
  2. Increase the candidate by 1 and repeat up to 20, recording exact divisors only.
  3. Remove duplicate entries or store each factor once: 1, 2, 4, 5, 10, 20.

Watch for this: The process needs a stopping rule. A correct factor guess is not a complete algorithm.

Another worked model

Create a factor-testing algorithm

1Inputnatural number n
2Set divisord = 1
3DecisionDoes n ÷ d give a whole number?
4RecordIf yes, record d
5Repeatincrease d until d × d > n
6Outputall paired factors

Stopping at the square root avoids retesting reversed factor pairs, but every recorded factor below the root must be paired with n ÷ d.

Try it: What should the algorithm output for input 9?

Check the answer

1, 3 and 9, with 3 recorded once.

3. Generate multiples in a spreadsheet

Keep the chosen number in one cell and multiply it by a changing whole-number index. Use fill down to repeat the rule.

Make a multiples-of-8 column.

  1. Enter 8 in B1. Put 1, 2, 3, 4 … in A2, A3, A4, A5 …
  2. In B2 enter =$B$1*A2 and fill down. The dollar signs fix B1 while the A-row changes.
  3. The first results are 8, 16, 24, 32 … Change B1 to 6 and check that the whole column updates.

Watch for this: Reading a supplied column is useful practice; actually creating and changing the spreadsheet is part of this investigation.

Try it: What is the fifth positive multiple when B1 contains 6?

Check the answer

30. Check by creating the column and reading its fifth result.

4. Compare common values and test a pattern

A common multiple appears in every list; the least positive one is the LCM. A common factor divides every input; the largest is the HCF.

Compare 6 and 9.

  1. Multiples of 6: 6, 12, 18 …; multiples of 9: 9, 18 …; LCM = 18.
  2. Factors of 6: 1, 2, 3, 6; of 9: 1, 3, 9; HCF = 3.
  3. For 3, 4 and 5, the HCF is 1 and the LCM is 60. Extend the spreadsheet far enough to see it.

Watch for this: A short list can miss the first common multiple; no overlap yet does not mean none exists.

Vocabulary and teaching help

Before this lesson: Understand factors, multiples, exact division and multiplication facts.

Useful vocabulary

algorithm
finite ordered instructions for a task
decision branch
different next steps determined by a condition
debugging
finding and correcting an error or ambiguity

Help a learner get started

Open one focus at a time. Read the worked steps together, ask the learner to explain what each quantity means, then let them try the short check before opening its answer. Use paper, objects or a drawing when that makes the idea clearer.

Common errors and quick fixes

  • One decision branch missing — Define what happens for both yes and no outcomes.
  • Loop never stops — Include a clear stopping condition.
  • Pattern from small sample claimed as proof — Test more cases and use reasoning.
  • Digital result hides procedure — Trace at least one input manually.

Keep the challenge meaningful: A practical construction, investigation or digital activity needs the learner’s actual work. A correct spoken answer alone does not demonstrate that practical skill.
