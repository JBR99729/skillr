Common mistakes

Including blank responses as a rating. Check the original responses and report any missing answers separately.

10-MINUTE HOME ACTIVITY

Check and display survey data

Ask each person to rate an activity as easy, medium or hard. Check that each person gave one valid response, then display the counts in a spreadsheet column graph.

Adjust the challenge: Start with a tally table. Extend by comparing this ordered scale with unordered favourite colours.

FAQ

Why order the labels easy, medium, hard?

The categories have a meaningful order, so arranging them that way makes the graph easier to read.

Learn the skill

Four focused steps

Learning goal: Choose a variable, check the records and use tables or graphs to explain the distribution.

Study a worked example, explain the reasoning and try its short check before moving on.

1. Identify what kind of data is needed

A variable is the feature recorded. Nominal categories have no natural order; ordinal categories do; discrete numerical data counts things.

Classify a travel survey.

  1. Travel mode (walk, bus, car) is nominal categorical.
  2. Satisfaction (poor, fair, good) is ordinal categorical. Ratings 1–5 can label ordered categories too.
  3. Number of journeys is discrete numerical: it counts whole journeys.

Watch for this: Number labels do not automatically turn a rating category into a measured quantity.

Try it: Is the number of pets nominal categorical or discrete numerical?

Check the answer

Discrete numerical; it counts pets.

2. Collect and validate the records

Use consistent categories and one record per intended observation. Check missing values, impossible counts and accidental duplicate entries.

Validate a spreadsheet column for number of pets.

  1. Accept nonnegative whole numbers such as 0, 1 and 2.
  2. Check an entry of −2 or 1.5 against the original response instead of silently using it.
  3. Keep the column in a number format; use an agreed category for missing responses rather than treating them as zero.

Watch for this: Two people may genuinely give the same answer; equal values are not automatically duplicate records.

Try it: A blank response is entered as zero pets. Why check it?

Check the answer

Blank means not recorded; zero states that the person has no pets.

3. Create a frequency table and suitable graph

Frequency counts how often a value occurs. A column graph displays category or count frequencies with a consistent scale.

Display these illustrative pet-count records: 0, 1, 1, 2, 2, 2, 3, 4.

  1. Tally the values: 0→1, 1→2, 2→3, 3→1, 4→1. Frequencies total 8.
  2. Enter values in spreadsheet column A and frequencies in B; select both columns and insert a column chart.
  3. Label the axes “Number of pets” and “Number of respondents”; use a zero-based frequency scale.

Watch for this: Do not graph the list positions as though they were the pet values.

Try it: What height should the bar for two pets have?

Check the answer

3 respondents.

4. Describe mode and shape in context

The mode is the value or category with the highest frequency. For ordered numerical data, discuss where results cluster, spread and have gaps. Nominal category order cannot support a numerical shape claim.

Describe these illustrative pet counts: 0, 1, 1, 2, 2, 2, 3, 4.

  1. Two pets is the mode, occurring three times. Four is the largest count but not the mode.
  2. Most responses are one or two pets; counts run from zero to four, with fewer at the high end.
  3. In 1, 1, 2, 3, 3 there are two modes: 1 and 3.

Watch for this: The highest frequency is a count; the mode is the value or category having that frequency.

Try it: For 0, 1, 1, 2, 4, 4, name all modes.

Check the answer

1 and 4; each occurs twice.

Vocabulary and teaching help

Before this lesson: Read a tally, a labelled scale and a simple column graph.

Help a learner get started

Open one focus at a time. Read the worked steps together, ask the learner to explain what each quantity means, then let them try the short check before opening its answer. Use paper, objects or a drawing when that makes the idea clearer.

Keep the challenge meaningful: A practical construction, investigation or digital activity needs the learner’s actual work. A correct spoken answer alone does not demonstrate that practical skill.
