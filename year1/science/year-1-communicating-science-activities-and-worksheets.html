Year 1 Communicating Science Activities and Worksheets

Help students communicate observations, findings and ideas using everyday and scientific vocabulary. These engaging activities include creating habitat models, representing seasonal changes, using role-play to explain forces and exploring First Nations ways of sharing observations.

About This Year 1 Science Inquiry Topic

Communicating is an essential part of scientific inquiry. Students learn that scientists communicate ideas using drawings, labels, diagrams, models, photographs, writing, oral presentations and scientific vocabulary.

In Year 1, students describe observations and findings using both everyday language and appropriate scientific terms. They create simple texts, models and visual representations to communicate their ideas clearly.

Students also learn that First Nations Australians have long shared scientific observations through stories, artwork, symbols and cultural knowledge. These experiences help students recognise that science can be communicated in many different ways.

Australian Curriculum Alignment

AC9S1I06

AC9S1I06_E3

Represent seasonal changes of plants using sequential drawings, calendars or digital photographs.

AC9S1I06_E5

Represent push and pull forces using role-play, arrows, labels or time-lapse drawings while describing observations using everyday and scientific vocabulary.

AC9S1I06_E6

Role-play or recount how people use patterns to make predictions in work and everyday life.

Learning Intentions

Students will learn to:

  • communicate scientific observations clearly;
  • use everyday and scientific vocabulary appropriately;
  • create labelled diagrams and simple scientific texts;
  • represent ideas using drawings, photographs and models;
  • communicate habitat features using recycled materials;
  • describe seasonal changes using sequences;
  • represent forces using arrows and labels;
  • share observations respectfully using different communication methods;
  • explain findings using evidence;
  • present ideas confidently to others.

Student Success Criteria

I can use science words correctly.

I can create a labelled diagram.

I can explain my model.

I can communicate my findings clearly.

I can compare everyday and scientific words.

I can use drawings or photographs to show changes.

I can share my ideas respectfully.

Year 1 Communicating Science Activities

Activity 1: Everyday Words vs Science Words

Students examine classroom objects and describe them using everyday language before replacing suitable words with scientific vocabulary.

Curriculum connection: AC9S1I06_E1

Activity 2: Science Vocabulary Matching

Students match everyday words with scientific words using picture cards before writing simple observation sentences.

Curriculum connection: AC9S1I06_E1

Activity 3: First Nations Ways of Sharing Knowledge

Students explore age-appropriate examples of how First Nations Australians represent observations through stories, artwork and symbols.

Curriculum connection: AC9S1I06_E2

Activity 4: Build a Habitat Model

Students create a model showing where a plant or animal lives using recycled materials, clay or classroom objects and explain the features.

Curriculum connection: AC9S1I06_E3

Activity 5: Seasonal Plant Life Cycle

Students create a sequence of drawings or photographs showing seasonal changes in a familiar plant.

Curriculum connection: AC9S1I06_E4

Activity 6: Push and Pull Poster

Students use arrows, labels and simple sentences to explain push and pull forces in everyday situations.

Curriculum connection: AC9S1I06_E5

Activity 7: Force Role-Play

Students act out pushes and pulls while classmates identify the force using scientific vocabulary.

Curriculum connection: AC9S1I06_E5

Activity 8: People Who Use Patterns

Students discuss occupations such as gardeners, farmers, weather forecasters and builders who use patterns to make predictions.

Curriculum connection: AC9S1I06_E6

Activity 9: Science Presentation

Students present one investigation to the class using drawings, photographs, labelled diagrams or a model.

Curriculum connection: AC9S1I06

Activity 10: Create a Science Poster

Students combine scientific vocabulary, drawings, labels and findings to produce an informative science poster.

Curriculum connection: AC9S1I06

Differentiation

Support

  • provide picture vocabulary cards;
  • offer sentence starters;
  • allow oral explanations instead of written responses;
  • use labelled diagrams with missing words;
  • provide partially completed habitat models;
  • pair students for presentations;
  • use visual communication before written communication.

Extension

  • write longer science explanations;
  • include more scientific vocabulary;
  • compare different communication methods;
  • design a labelled scientific poster independently;
  • create digital presentations;
  • explain why one communication method is more effective;
  • teach scientific vocabulary to another class.

Assessment Ideas

Observe whether the student can:

  • communicate observations clearly;
  • use appropriate scientific vocabulary;
  • produce labelled diagrams;
  • create simple science models;
  • explain findings using drawings or writing;
  • use arrows and labels correctly;
  • communicate seasonal changes accurately;
  • describe habitats using appropriate vocabulary;
  • present ideas confidently;
  • select an appropriate communication method.

Quick Exit Ticket

  1. Write one science observation.
  2. Use one scientific vocabulary word.
  3. Draw one labelled diagram to explain your idea.

Home Learning Ideas

  • draw and label a favourite plant or animal;
  • create a simple habitat model using recycled materials;
  • take photographs showing seasonal changes in the garden;
  • use arrows to show pushes and pulls during play;
  • practise using one new science word each day;
  • compare everyday words with scientific vocabulary at home;
  • explain an observation to a family member using a labelled drawing;
  • find patterns in weather, plants or daily routines and discuss predictions.

Encourage students to explain their observations using drawings, photographs, models and simple scientific vocabulary rather than focusing only on written work.
