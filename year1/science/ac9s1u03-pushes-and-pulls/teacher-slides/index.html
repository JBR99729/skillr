Example 1

Worked example Question: What happens if you push the same toy car harder on the same floor? It will usually move farther because the push is stronger while the object and surface stay the same.

Example 2

Force arrows Draw arrows to show the direction of pushes and pulls on classroom objects. Model: push → box

Example 3

Gentle vs strong Compare a gentle push and a strong push on the same toy car. Model: same car • same surface • different strength

Example 4

Change shape Use soft material to test how pushing, squeezing or pulling can change shape. Model: clay: round → flat

Important questionsWith answers

Key idea: A push or pull can change how an object moves or changes shape. The effect depends on the force direction and strength.

Remember

  • Identify pushes
  • Identify pulls
  • Describe strength
  • Show direction
  • Predict motion or shape

Quick questions

  • Is opening a drawer usually a push or pull?
  • How can you show force direction?
  • What might a strong push do to a toy car?
  • Name one force that changes shape.

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.

Assessment and reviewReady for practice
  • Forgetting direction — Use an arrow to show where the force acts.
  • Only saying move — Forces can also change shape, not only position.
  • Unfair comparison — Keep the object and surface the same when comparing strength.

Use the Practice Sheet for written or hands-on work, Practice for supported feedback, and Test when the student is ready to demonstrate independent mastery.
