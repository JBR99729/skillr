AC9S1U03 • Year 1 Science

Pushes and Pulls

A push or pull can change how an object moves or changes shape. The effect depends on the force direction and strength.

Topic GuideClassroom ViewPractice SheetPracticeTest
What students learn

A push or pull can change how an object moves or changes shape. The effect depends on the force direction and strength.

Learning routine: Name force → Show direction → Compare strength → Predict effect → Test

Success looks like

  • Identify pushes
  • Identify pulls
  • Describe strength
  • Show direction
  • Predict motion or shape
Concept model and worked application

Force has direction and strength

push →← pullgentlestrong

A stronger push may move an object farther. A different direction can change where it goes.

Worked example

Question: What happens if you push the same toy car harder on the same floor? It will usually move farther because the push is stronger while the object and surface stay the same.

Predict motion or shape before testing

push ballpull drawersquash claystretch band

Say the force, direction, strength and predicted effect.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Guided learning activities

Force arrows

Draw arrows to show the direction of pushes and pulls on classroom objects.

Model: push → box

Gentle vs strong

Compare a gentle push and a strong push on the same toy car.

Model: same car • same surface • different strength

Change shape

Use soft material to test how pushing, squeezing or pulling can change shape.

Model: clay: round → flat

Common misconceptions and traps
  • Forgetting direction — Use an arrow to show where the force acts.
  • Only saying move — Forces can also change shape, not only position.
  • Unfair comparison — Keep the object and surface the same when comparing strength.
Revision Notes

Quick questions

  • Is opening a drawer usually a push or pull?
  • How can you show force direction?
  • What might a strong push do to a toy car?
  • Name one force that changes shape.
