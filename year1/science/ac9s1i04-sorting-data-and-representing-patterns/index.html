Sorting Data and Representing Patterns

Data and information become clearer when they are sorted, ordered and represented in tables, displays or physical models.

What students learn

Data and information become clearer when they are sorted, ordered and represented in tables, displays or physical models.

Learning routine: Collect → Sort → Order → Represent → Describe pattern

Success looks like

  • Sort data
  • Order information
  • Use tables
  • Use physical models
  • Describe patterns
Concept model and worked application

A table can reveal a pattern

objectrollsslidesspins

Sorting observations helps students see which objects behave in similar ways.

Worked example

Data: ball rolls, block slides, tube rolls. Sorted pattern: round objects rolled more easily; flat-faced objects were more likely to slide.

Choose a representation that shows the pattern

Use the display to say what pattern you noticed.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Guided learning activities

Sort the evidence

Sort object cards by how they moved: roll, slide, spin or bounce.

Model: roll | slide | spin

Order by measurement

Order informal measurements from shortest to longest.

Model: 3 blocks, 5 blocks, 8 blocks

Represent pattern

Use a provided table to show which season activities belong to.

Model: season / activity

Common misconceptions and traps
  • Sorting without a rule — State the sorting rule before placing items.
  • Display but no pattern statement — After representing, say what the display shows.
  • Mixing categories — Use one sorting feature at a time.
