YEAR 1 SCIENCE · AC9S1I04

Sort the evidence. Show the pattern.

Sort and order observations. Use provided tables and visual or physical models to show patterns accurately.

Learning intention: Sort and order observations. Use provided tables and visual or physical models to show patterns accurately.

WORKED EXAMPLE

More flowers, then the same number

A class records open flowers on the same plant at the same time on three days. The supplied counts are 2, 4 and 4. Keep the dates in order: the count increases, then stays the same.

Learn the skill

1. Choose a sorting rule

Group records by a named feature. Keep the rule consistent and explain uncertain cases.

RecordGroup: rain observed?
Rain fallingYes
Clear sky, no rain seenNo
Try it · If you sort leaves by shape, should colour decide the group?

No. Use the chosen shape rule. You can sort by colour in a separate sort.

2. Order and label the data

Use date order for changes over time. Match each value to its correct label.

Correct date orderCounts
Day 1 → Day 2 → Day 32 → 4 → 4
Try it · Should you reorder the days to make the numbers go 2, 4, 4, 6?

No. Preserve the real dates and counts. Do not invent a fourth record.

3. Build a faithful model

In a one-to-one display, one counter represents one observation. Use the same meaning throughout.

DayOne counter = one flower
1● ●
2● ● ● ●
3● ● ● ●
Try it · What happened between days 2 and 3?

The count stayed the same at 4. It did not increase.

Common mistakes

“A pattern must keep increasing.” The count may decrease or stay the same. Report what the records show.

“We may add counters to make the picture look full.” Every counter must match the chosen key and recorded data.

10-MINUTE ACTIVITY

Build a three-day display

2 minutes: read the 2, 4, 4 flower records. 5 minutes: make three labelled rows with large counters or drawn circles. 3 minutes: describe the change and check each row against the table.

Adjust the challenge Support: use one-to-one drawn circles. Extend: represent the same records another way and check that the message stays the same.

Choose counters suitable for the child's age; drawings work just as well.

Three tricky questions

1. Two rows have four counters each. Did the number increase?

No. It stayed the same.

2. Can one counter mean one flower in one row and two flowers in another?

Not in this one-to-one display. Keep the key consistent.

3. Does a bigger drawing of a flower mean more flowers?

No. Count or read the key; picture size alone does not show number.

FAQ

What is data?

Recorded observations or information.

Must every pattern repeat?

No. A pattern can show change or sameness across ordered records.

Additional explanations and guided checks for AC9S1I04.

1. Sort with a clear rule

For a leaf sort by edge type, use smooth-edge and jagged-edge groups. Colour does not decide this rule.

Try it: Where does a brown smooth-edged leaf belong?

See answer and explanation

Smooth edge. Use the stated observed feature.

2. Order records appropriately

Put dated records in time order. Sorting by size answers a different question. Use the same units for size comparisons.

Try it: Which comes first: a record from Tuesday or Monday in the same week?

See answer and explanation

Monday. Keep the dates and object identity clear.

3. Complete a provided table

Read each row and column label before entering observations. Record zero only when no items were observed, not when data are missing.

Try it: A table has counts but no group names. What is missing?

See answer and explanation

Labels explaining what each count represents.

4. Make a visual or physical model

If one counter represents one butterfly, four butterflies need four counters. Label the group and state the key.

Try it: Does a bigger counter represent two butterflies?

See answer and explanation

No. The stated key is one counter for one butterfly.

5. Show change or sameness

Compare dated records of the same plant: four leaves then six leaves shows two more. Other records may show no change.

Try it: Must every dataset contain a clear repeating pattern?

See answer and explanation

No. Describe only the change, sameness or pattern supported by the records.

6. Explain the pattern honestly

Monday wet, Tuesday dry, Wednesday wet, Thursday dry shows alternation in those records. It does not guarantee Friday's weather.

Try it: May you change a wet record to dry to make a neater pattern?

See answer and explanation

No. Preserve the observations even if the pattern changes.

Common mistakes and quick fixes
  • Sorting without a rule — State the sorting rule before placing items.
  • Display but no pattern statement — After representing, say what the display shows.
  • Mixing categories — Use one sorting feature at a time.
