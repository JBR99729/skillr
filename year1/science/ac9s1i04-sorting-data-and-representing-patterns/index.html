Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Sort with a clear rule

For a leaf sort by edge type, use smooth-edge and jagged-edge groups. Colour does not decide this rule.

Try it: Where does a brown smooth-edged leaf belong?

See answer and explanation

Smooth edge. Use the stated observed feature.

2. Order records appropriately

Put dated records in time order. Sorting by size answers a different question. Use the same units for size comparisons.

Try it: Which comes first: a record from Tuesday or Monday in the same week?

See answer and explanation

Monday. Keep the dates and object identity clear.

3. Complete a provided table

Read each row and column label before entering observations. Record zero only when no items were observed, not when data are missing.

Try it: A table has counts but no group names. What is missing?

See answer and explanation

Labels explaining what each count represents.

4. Make a visual or physical model

If one counter represents one butterfly, four butterflies need four counters. Label the group and state the key.

Try it: Does a bigger counter represent two butterflies?

See answer and explanation

No. The stated key is one counter for one butterfly.

5. Show change or sameness

Compare dated records of the same plant: four leaves then six leaves shows two more. Other records may show no change.

Try it: Must every dataset contain a clear repeating pattern?

See answer and explanation

No. Describe only the change, sameness or pattern supported by the records.

6. Explain the pattern honestly

Monday wet, Tuesday dry, Wednesday wet, Thursday dry shows alternation in those records. It does not guarantee Friday's weather.

Try it: May you change a wet record to dry to make a neater pattern?

See answer and explanation

No. Preserve the observations even if the pattern changes.

Try a worked example together

Keep counts matched to their labels

Work through the example

  1. This supplied record shows flower counts: two, four and four on three days.
  2. Keep each day beside its count. Put the days in order before describing the change.
  3. The count increased from Day 1 to Day 2, then stayed the same from Day 2 to Day 3.

Watch for this: These symbols represent recorded counts. They do not explain why the flowers changed.

Try it together

Does this record show that the count increased every day? Explain.

Answer and teaching guidance

No. Days 2 and 3 both have four. Describe the whole record, including where it stays the same.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Sorting without a rule — State the sorting rule before placing items.
  • Display but no pattern statement — After representing, say what the display shows.
  • Mixing categories — Use one sorting feature at a time.
