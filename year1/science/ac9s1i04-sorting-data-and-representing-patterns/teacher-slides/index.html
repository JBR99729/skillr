AC9S1I04 - Sorting Data and Representing Patterns
Example 1

Worked example Data: ball rolls, block slides, tube rolls. Sorted pattern: round objects rolled more easily; flat-faced objects were more likely to slide.

Example 2

Sort the evidence Sort object cards by how they moved: roll, slide, spin or bounce. Model: roll | slide | spin

Example 3

Order by measurement Order informal measurements from shortest to longest. Model: 3 blocks, 5 blocks, 8 blocks

Example 4

Represent pattern Use a provided table to show which season activities belong to. Model: season / activity

Quick questions

  • What does it mean to sort data?
  • Name one way to represent information.
  • Why should a sorting rule be clear?
  • What pattern could a table show?

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.

Assessment and reviewReady for practice
  • Sorting without a rule — State the sorting rule before placing items.
  • Display but no pattern statement — After representing, say what the display shows.
  • Mixing categories — Use one sorting feature at a time.
