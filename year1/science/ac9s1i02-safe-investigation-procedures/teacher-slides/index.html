AC9S1I02 - Safe Investigation Procedures
Example 1

Worked example Question: Which object rolls farther? Safe procedure: use the same ramp, roll one object at a time, stand back, measure the distance, then record the result.

Example 2

Safety sort Sort investigation actions into safe and unsafe choices. Model: walk with equipment / run with equipment

Example 3

Step builder Put mixed investigation steps into a sensible order. Model: ask → safety → test → observe

Example 4

Prediction check Decide whether a procedure actually tests the prediction. Model: Does this step answer the question?

Concept modelTeach from the board

A safe procedure is a set of clear steps

1 ask2 check safety3 test4 observe5 pack away

Safe steps help everyone test the same question without guessing or rushing.

Worked example

Question: Which object rolls farther? Safe procedure: use the same ramp, roll one object at a time, stand back, measure the distance, then record the result.

Connect the step to the prediction

predictionprocedureobservation

If the procedure does not test the prediction, change the steps before starting.

Remember

  • Suggest safe steps
  • Follow procedures
  • Test predictions
  • Use equipment carefully
  • Work in order

Quick questions

  • Name one safe investigation rule.
  • Why should steps be in order?
  • What should you do before touching equipment?
  • How do procedures help test predictions?

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.

Assessment and reviewReady for practice
  • Starting before safety — Read or suggest safety steps before touching equipment.
  • Steps out of order — Put the procedure in sequence before testing.
  • Procedure does not test prediction — Match each step to the question being investigated.

Use the Practice Sheet for written or hands-on work, Practice for supported feedback, and Test when the student is ready to demonstrate independent mastery.
