Show and compare data

Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories. Use this free guide to learn the idea, then practise on paper with the matching worksheet pack.

Learn the skill

1. Make a one-to-one display

Use one equal-size symbol for each response. Four apples need four symbols, not one larger symbol.

Try it · How many symbols show two banana choices?

Two when the key says one symbol means one choice.

2. Align and label the display

Give each category a label and start its row at the same baseline. Equal spaces make counts easier to compare.

Try it · Does making a symbol larger add another response?

No. Count symbols according to the key, rather than comparing their size.

3. Compare frequencies

Frequency means how many. Apples 4 is two more than bananas 2; pears 0 is the fewest in this survey.

Try it · How many more apple than banana choices are there?

Two. Compare the counts: 4 − 2 = 2.

Common mistakes

Comparing rows that start in different places. Align the first picture in each row and use equal spacing. Count the pictures to confirm your comparison.

10-MINUTE HOME ACTIVITY

Make a picture display

Use counts of 4 apples, 2 pears and 3 bananas. Draw one picture for each fruit, label the rows and start them at the same line. Say which row has most and by how many.

Adjust the challenge: Start with two rows. Extend by changing one count and explaining how the comparison changes.

FAQ

What does each picture stand for?

In this display, one picture stands for one piece of fruit.

Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Start with collected counts

Use the actual counts, including zero categories. Suppose a survey records apples 4, bananas 2 and pears 0.

Try it: How many choices were recorded altogether?

See answer and explanation

Six. Keep the pear category even though its count is zero.

2. Make a one-to-one display

Use one equal-size symbol for each response. Four apples need four symbols, not one larger symbol.

Try it: How many symbols show two banana choices?

See answer and explanation

Two when the key says one symbol means one choice.

3. Align and label the display

Give each category a label and start its row at the same baseline. Equal spaces make counts easier to compare.

Try it: Does making a symbol larger add another response?

See answer and explanation

No. Count symbols according to the key, rather than comparing their size.

4. Compare frequencies

Frequency means how many. Apples 4 is two more than bananas 2; pears 0 is the fewest in this survey.

Try it: How many more apple than banana choices are there?

See answer and explanation

Two. Compare the counts: 4 − 2 = 2.

5. Say only what the data show

“More surveyed children chose apples than bananas” is supported. It does not tell us why they chose them or everyone's preference.

Try it: Does this small survey prove all children prefer apples?

See answer and explanation

No. It describes this collected group and these choices only.

Try a worked example together

Compare counts using the picture key

Work through the example

  1. The key says one circle represents one child.
  2. Count four walking responses and two cycling responses. Their first two circles line up.
  3. Walking has two more responses. There are six children altogether.

Watch for this: A bigger picture does not mean more children when each picture represents one.

Try it together

If another child cycles, what changes in the display?

Answer and teaching guidance

Add one circle to cycling. There are then three cyclists and seven children altogether.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Symbols worth different amounts — In a one-to-one display, every symbol must mean one response.
  • Comparing by picture size — Compare by frequency, not by how big a drawing looks.
  • Claim without evidence — Use the data display to support the finding.
