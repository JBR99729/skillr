Representing and Comparing Data

Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

Step 1 · Learn the idea

Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

Learning routine: Use collected data → Make display → Count frequencies → Compare → Discuss

Success looks like

  • Make one-to-one displays
  • Count frequencies
  • Compare categories
  • Discuss findings
  • Use evidence

Step 2 · Learn by example

Build a display

Use counters to show data with one counter per response.

Model: one counter = one vote

Compare categories

Find which category has the most, least or same number.

Model: most / least / equal

Discuss finding

Say one finding using evidence from the display.

Model: Dog has 3 more than cat.

Australian Curriculum elaborations

These curriculum examples extend the central model into varied contexts. They are learning contexts, not extra definitions to memorise.

E1

creating a pictograph with objects or drawings; discussing the possible categories for the pictograph, arranging the objects or drawings into the categories, then reflecting on the chosen categories and deciding whether they were helpful

Learning connection: CREATING a pictograph with objects or drawings. Connect the example back to this key idea: Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

E2

translating data from a list or pictorial display into a tally chart to make counting easier; describing what the tally chart is showing, by referring to the categories; using skip counting by fives to compare the numbers within each category and explaining how the tally chart answers the question

Learning connection: translating data from a list or pictorial display into a tally chart to make counting easier. Connect the example back to this key idea: Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

E3

recognising that when there is no data for a particular category you may choose whether or not to include it in your data display, and use a zero or blank for that category depending on the purpose of the data collection or presentation; for example, creating a birthday calendar for the class and discussing that there are no students born in May and therefore there are no names listed

Learning connection: RECOGNISING that when there is no data for a particular category you may choose whether or not to include it in your data display, and use a zero or blank for that category depending on the purpose of the data collection or presentation. Connect the example back to this key idea: Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

E4

representing data with objects and drawings where one object or drawing represents one data value; describing the displays and explaining patterns that have been created using counting strategies to determine the frequency of responses

Learning connection: REPRESENTING data with objects and drawings where one object or drawing represents one data value. E5

discussing what data frequency means in terms of the total count for a particular category and relating the highest frequency to being the most popular category in the collected data

E6

exploring First Nations Australian children’s instructive games; for example, Kolap from Mer Island in the Torres Strait region, recording the outcomes, representing and discussing the results

Learning connection: EXPLORING First Nations Australian children’s instructive games. Connect the example back to this key idea: Collected data can be represented with one-to-one displays where each mark or symbol stands for one response. Frequencies help compare categories.

Cultural safety: Use a community-approved source, name the specific Nation or community where the source does, and avoid presenting diverse First Nations knowledges as one generic tradition. Follow local cultural and intellectual property protocols before inviting community participation.

Avoid this trap
  • Symbols worth different amounts — In a one-to-one display, every symbol must mean one response.
  • Comparing by picture size — Compare by frequency, not by how big a drawing looks.
  • Claim without evidence — Use the data display to support the finding.

Quick questions
