Measuring Length with Informal Units

Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

Learning routine: Choose unit → Start at end → No gaps → No overlaps → Count units

Success looks like

  • Use informal units
  • Keep units uniform
  • No gaps/overlaps
  • Measure end-to-end
  • Compare using same unit

Australian Curriculum elaborations

These curriculum examples extend the central model into varied contexts. They are learning contexts, not extra definitions to memorise.

E1

using 2 different units; for example, pop sticks and pencils, to measure the length of an object such as a desk, and explaining why the number of units used may be different

Learning connection: USING 2 different units. Connect the example back to this key idea: Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

E2

comparing the length of 2 objects such as a desk and a bookshelf by laying multiple copies of a unit and counting to say which is longer and how much longer; explaining why they shouldn’t have gaps or overlaps between the units as this will change the length of the unit

Learning connection: COMPARING the length of 2 objects such as a desk and a bookshelf by laying multiple copies of a unit and counting to say which is longer and how much longer. Connect the example back to this key idea: Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

E3

measuring the distance between 2 locations using footsteps, comparing the results and explaining why there may be different results; for example, referring to the different length of footsteps as using different units

Learning connection: measuring the distance between 2 locations using footsteps, comparing the results and explaining why there may be different results. Connect the example back to this key idea: Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

E4

measuring and comparing the length of objects using blocks; for example, comparing the height of 2 toys by stacking blocks one on top of the other and counting how many it takes to reach the height of each object to decide which is taller

Learning connection: measuring and comparing the length of objects using blocks. Connect the example back to this key idea: Length can be measured with informal units, but the units must be the same size and placed end-to-end without gaps or overlaps.

Common misconceptions and traps
  • Gaps between units — Units must touch end-to-end.
  • Overlapping units — Do not cover the same length twice.
  • Different-sized units — Use uniform units so the count is meaningful.
Revision Notes

Remember
