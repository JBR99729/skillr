Measuring Length with Informal Units

Measure length with equal-sized units placed end-to-end, without gaps or overlaps. If a pencil is six identical blocks long, those six blocks describe its length in that chosen unit.

Blocks touch end to end without gaps or overlaps.

Learn the skill

1. Choose equal units

Use units of the same size, such as identical cubes. A count of mixed-size blocks is not a reliable length measurement.

Try it · Why should all six measuring cubes match?

Each must represent the same amount of length.

2. Start at an endpoint

Place the first unit at one end and continue to the other. Six equal cubes covering a strip exactly show six cubes of length.

Try it · Does starting beyond the pencil's end measure it correctly?

No. Align the first unit with the endpoint and measure again.

3. Avoid gaps and overlaps

Place units end-to-end. Gaps leave some length unmeasured; overlaps cover part of the length twice.

Try it · Fix a row of units with spaces between them.

Slide equal units together from the endpoint, then recount the full row.

Common mistakes

Leaving gaps between units. Start at the endpoint and place equal units end to end with no gaps or overlaps.

10-MINUTE HOME ACTIVITY

Measure with paper clips

Put equal-size paper clips end to end along a pencil. Start at one end and count the clips. Measure a second pencil using the same clips and compare.

Adjust the challenge: Start with an object that matches a whole number of units. Extend by measuring the same object with longer units.

FAQ

Why do shorter units give a bigger count?

More short units fit along the same length.

4. Compare using the same unit

A ribbon covering eight cubes is longer than one covering six of the same cubes. The difference is two cubes.

Try it: One pencil measures seven cubes and another five matching cubes. Compare.

See answer and explanation

The first is two cubes longer. Both measurements use the same-size unit.

5. Explain different counts

The same ribbon may measure eight short blocks or four long blocks. Longer units need fewer repetitions. Different footsteps can also give different counts.

Try it: Must one of those ribbon measurements be wrong?

See answer and explanation

No. Check unit size and placement before comparing counts.

Try a worked example together

Measure with equal units and no gaps

Work through the example

  1. Start the first block at the beginning of the strip.
  2. Place five equal-sized blocks end to end. They reach the other end with no gaps or overlaps.
  3. The strip is five blocks long. Record both the number and the unit.

Watch for this: The blocks must be the same size. A count of mixed-sized units is not a clear length.

Try it together

Why would gaps between the blocks make this measurement unreliable?

Answer and teaching guidance

Some of the strip would not be covered by blocks. Put the equal blocks together and measure again.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Gaps between units — Units must touch end-to-end.
  • Overlapping units — Do not cover the same length twice.
  • Different-sized units — Use uniform units so the count is meaningful.
