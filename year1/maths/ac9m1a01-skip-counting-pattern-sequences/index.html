Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Find the skip

Compare neighbouring numbers. In 5, 10, 15, 20, each step adds five. The start and the change both matter.

Try it: Continue 10, 20, 30, __, __.

See answer and explanation

40, 50. Add ten at every step.

2. Build growing stages

Build separate stages: two blocks, four blocks, six blocks. Each new stage has one more pair, so the totals grow by two.

Try it: How many blocks belong in the next stage?

See answer and explanation

Eight. Show four pairs, rather than repeating a picture of just two blocks.

3. Fill a missing step

Use the same change on both sides of a gap. In 5, 10, __, 20, the missing number is 15.

Try it: Fill 20, __, 40, 50.

See answer and explanation

30. The change is ten throughout.

4. Notice patterns in the digits

Counting in fives from zero ends in 0 or 5: 0, 5, 10, 15, 20. Check the whole sequence, not only a digit.

Try it: Will 23 occur in this count by fives?

See answer and explanation

No. In this sequence, the ones digit is always 0 or 5.

5. Create and explain a sequence

Choose a start and a skip. Start at four and add two: 4, 6, 8, 10. Use objects or numbers to show the same rule.

Try it: Create four stages that add five each time, starting at five.

See answer and explanation

5, 10, 15, 20. Each stage contains five more objects than the previous one.

Try a worked example together

Follow an equal counting step

Work through the example

  1. Start at zero and move two spaces each time.
  2. The landing numbers are 0, 2, 4, 6, 8 and 10.
  3. Each new number is two more. Use the step to find a missing number or continue the sequence.

Watch for this: A counting sequence can start at a number other than zero.

Try it together

Continue 3, 5, 7, __, __. Explain the step.

Answer and teaching guidance

9 and 11. The sequence starts at 3 and adds two each time.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Guessing the next number — Compare neighbouring terms to find the skip.
  • Changing the rule halfway — Keep the same skip unless the pattern says otherwise.
  • Counting objects not groups — For skip counting, count equal jumps or equal groups.
