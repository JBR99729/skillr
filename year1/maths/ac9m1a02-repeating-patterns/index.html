Repeating Patterns

A repeating pattern is made from a unit that repeats again and again. The unit is the smallest part that repeats.

What students learn

A repeating pattern is made from a unit that repeats again and again. The unit is the smallest part that repeats.

Learning routine: Look → Find unit → Continue → Create → Explain

Success looks like

  • Find repeating unit
  • Continue patterns
  • Create patterns
  • Use shapes/numbers/symbols
  • Explain rule

Guided learning activities

Find the unit

Circle the smallest repeating unit in a pattern.

Model: A B A B A B

Continue the pattern

Use the unit to add the next three terms.

Model: red yellow red yellow

Create and explain

Create a repeating pattern and name the unit.

Model: clap stomp clap stomp

Common misconceptions and traps
  • Choosing too much as the unit — Find the smallest part that repeats.
  • Continuing by colour only — Check shape, symbol, number or object as well.
  • Changing the unit — Keep the same repeating unit all the way through.
