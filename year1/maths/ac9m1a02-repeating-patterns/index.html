Repeating Patterns

Identify the complete repeating unit, then copy, continue and create a pattern. In circle, circle, square, circle, circle, square, the three-shape unit repeats as a group.

Learn the skill

1. Find the smallest repeating unit

In red, red, blue, red, red, blue, the smallest unit is red, red, blue. The whole unit starts again.

Try it · What repeats in clap, clap, tap, clap, clap, tap?

Clap, clap, tap. Include all three actions.

2. Continue from the correct place

In circle, square, square, circle, square, square, circle, the next item is square. Continue the unit rather than restarting early.

Try it · Give the next two items after that circle.

Square, square. The unit is circle, square, square.

3. Show the same pattern another way

Clap, stamp, clap, stamp can be recorded as C S C S. Different symbols can show the same repeating structure.

Try it · Replace red, blue, blue with letters.

A B B, repeated. Each symbol keeps its place in the unit.

Common mistakes

Restarting the pattern in the wrong place. Mark the repeating unit. After red, red, blue, red, the next item is red, followed by blue.

10-MINUTE HOME ACTIVITY

Turn a pattern into sounds

Build red, red, blue three times. Say the shortest part that repeats. Change red to a clap and blue to a tap, then perform the pattern.

Adjust the challenge: Start with red, blue. Extend by removing one item from the middle and asking what belongs there.

FAQ

Is red, red, blue the same pattern as clap, clap, tap?

Yes. Both repeat a unit with two of one kind followed by one of another.

4. Look for repeating digits

Across 20–29, the ones digits go 0 to 9. They repeat across 30–39 while the tens digit changes.

30. The ones digit restarts at zero and the tens digit increases.

5. Create and check a pattern

Repeat triangle, circle, circle three times. Check that every unit follows the same order. Growing numbers are a different kind of pattern.

Find the smallest repeating unit

Work through the example

  1. Read the shapes in order: triangle, circle, square.
  2. The same three shapes appear again in the same order. This is the repeating unit.
  3. After each square, the unit starts again with a triangle.

Watch for this: A repeating pattern repeats its unit; it does not keep adding a larger number.

Try it together

Copy the pattern. Add the next three shapes and circle one smallest repeating unit.

Answer and teaching guidance

Triangle, circle, square. One unit contains those three shapes in that order.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Choosing too much as the unit — Find the smallest part that repeats.
  • Continuing by colour only — Check shape, symbol, number or object as well.
  • Changing the unit — Keep the same repeating unit all the way through.
