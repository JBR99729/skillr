Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Ask a category question

A categorical question gathers groups, such as “Which fruit do you choose: apple or banana?” A measurement question asks a different kind of data.

Try it: Is “How long is your pencil?” a category choice question?

See answer and explanation

No. It asks for a length. Name the categories before collecting choices.

2. Collect each response once

For a one-choice survey, ask everyone the same question and record one response each. Count actual responses, not guesses.

Try it: Five children answer. How many responses should a one-choice record contain?

See answer and explanation

Five. Check that nobody was missed or counted twice.

3. Use labels and lists

A list or table needs category names so each mark has a meaning. Keep the collection rule unchanged.

Try it: Why is a row of marks without a name hard to use?

See answer and explanation

You cannot tell which category the marks represent.

4. Record with tally marks or symbols

One mark records one response. Tally marks can be grouped in fives; each full group still represents five responses.

Try it: What do one group of five tallies and two extra tallies represent?

See answer and explanation

Seven responses. Count each mark once.

5. Check the record

Compare the record with the original responses. Zero is a valid count; a missing entry is not automatically zero.

Try it: A child has no response recorded. May you count that as “banana”?

See answer and explanation

No. Ask or record that the response is missing; do not invent a choice.

Try a worked example together

Give each response one place

Work through the example

  1. Five children each choose one fruit. Their answers are apple, pear, apple, apple, pear.
  2. Make one record for each answer in its fruit row.
  3. There are three apple responses and two pear responses. The total is five, matching the number of children.

Watch for this: If the question asks for one favourite, agree that each person gives one answer.

Try it together

Record these four answers: pear, apple, pear, pear.

Answer and teaching guidance

Apple: 1; pear: 3. Four responses altogether.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Unclear categories — Make categories that answer the question.
  • Counting a response twice — Record each data item once.
  • Mixing category and number — The category is the group name; the frequency is how many.

An adult can read instructions, model the idea and accept oral, pointed or drawn explanations. For reading, writing, speaking and practical tasks, observe the child doing the skill.
