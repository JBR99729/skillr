Concept modelTeach from the board

Categories must match the question

Question: favourite fruitCategories: apple, banana, orangeRecord: tally marks

Every response should fit one category or a planned other category.

Record each answer once

apple |||banana ||orange ||||

Organised recording makes it easier to count later.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

These curriculum examples extend the central model into varied contexts. They are learning contexts, not extra definitions to memorise.

E1

discussing methods of collecting data to answer a question, such as “What types of rubbish are found in the playground?”, sharing ideas and trying out some of the suggested methods; reviewing the data collected and explaining how they might change the way they collect data next time

Learning connection: DISCUSSING methods of collecting data to answer a question, such as “What types of rubbish are found in the playground?”, sharing ideas and trying out some of the suggested methods. Connect the example back to this key idea: Categorical data sorts answers into named groups. Data can be recorded with objects, drawings, lists, tally marks, symbols or digital tools.

E2

collecting and recording information on a topic of interest using lists; for example, “how many people follow a particular football team” or “what colour eyes each person has”; examining the data, to generate some questions that it could answer, then rearranging the data or collecting different data to answer the question

Learning connection: COLLECTING and recording information on a topic of interest using lists. Connect the example back to this key idea: Categorical data sorts answers into named groups. Data can be recorded with objects, drawings, lists, tally marks, symbols or digital tools.

Learning connection: CREATING a tally to record data while observing events such as the year level of students using the bike shed. Connect the example back to this key idea: Categorical data sorts answers into named groups. Data can be recorded with objects, drawings, lists, tally marks, symbols or digital tools.

using star charts with stickers or emojis to represent class data; for example, using emojis on a personal feeling chart to represent how they are feeling each day or using emojis to represent activities on the class calendar

E6

exploring ways of representing, sharing and communicating data through stories and symbols used by First Nations Australians

Cultural safety: Use a community-approved source, name the specific Nation or community where the source does, and avoid presenting diverse First Nations knowledges as one generic tradition. Follow local cultural and intellectual property protocols before inviting community participation.

Remember

  • Ask categorical questions
  • Choose categories
  • Collect data
  • Record with tallies/symbols
  • Count responses

Quick questions

  • What is a categorical question?
  • Give three categories for favourite pet.
  • Why use tally marks?
  • What does frequency mean?

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.

Assessment and reviewReady for practice
  • Unclear categories — Make categories that answer the question.
  • Counting a response twice — Record each data item once.
  • Mixing category and number — The category is the group name; the frequency is how many.

Use the Practice Sheet for written or hands-on work, Practice for supported feedback, and Test when the student is ready to demonstrate independent mastery.
