Familiar Shapes and Objects

Shapes and objects can be compared and classified using observable features such as sides, corners, faces, curves and flat surfaces.

Topic GuideClassroom ViewPractice SheetPracticeTest
What students learn

Shapes and objects can be compared and classified using observable features such as sides, corners, faces, curves and flat surfaces.

Learning routine: Make → Name features → Compare → Classify → Explain

Success looks like

  • Make shapes
  • Compare features
  • Classify shapes
  • Recognise objects
  • Explain similarities/differences
Concept model and worked application

Classify by features, not by colour

triangle: 3 sidesrectangle: 4 sidescircle: curved edgecube: flat faces

Use shape features to explain your group.

Find shapes in the environment

window → rectangleclock → circlebox → prism/cube

Real objects may look like familiar shapes but also have 3D features.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Guided learning activities

Shape build

Make a shape with sticks or paper and name its features.

Model: 3 sticks → triangle

Feature sort

Sort shapes by sides, corners, curves or faces.

Model: curved / not curved

Environment hunt

Find familiar shapes in the room and explain the match.

Model: door → rectangle

Common misconceptions and traps
  • Sorting by colour only — Use mathematical features such as sides, corners, faces or curves.
  • Mixing 2D and 3D language — A square is flat; a cube is a solid object.
  • Naming without evidence — Say the feature that proves the name or group.
