Quick questions

  • How many sides does a triangle have?
  • Name a classroom rectangle.
  • What feature helps classify a circle?
  • How are a square and cube different?

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.

Assessment and reviewReady for practice
  • Sorting by colour only — Use mathematical features such as sides, corners, faces or curves.
  • Mixing 2D and 3D language — A square is flat; a cube is a solid object.
  • Naming without evidence — Say the feature that proves the name or group.
