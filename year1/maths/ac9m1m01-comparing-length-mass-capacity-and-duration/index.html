Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Choose the attribute

Length asks longer or shorter; mass asks heavier or lighter; capacity asks how much fits; duration asks how long an event lasts.

Try it: Which attribute answers “Which bag is heavier?”

See answer and explanation

Mass. Its size alone does not tell you its mass.

2. Compare lengths fairly

Align two pencils at one end. The farther endpoint shows the longer pencil. A marked string can transfer a length when objects cannot be moved.

Try it: How could you compare two fixed shelves?

See answer and explanation

Mark one shelf's length on string, then compare the same string with the other shelf from aligned starts.

3. Compare and order mass

A balance's lower side holds the heavier object. Compare pairs to order three objects; looking larger is not enough evidence.

Try it: A stone's side moves down compared with a pine cone. Which is heavier?

See answer and explanation

The stone. The balance gives evidence about mass.

4. Compare capacity

Fill containers with the same small cup. A container holding five cupfuls has greater capacity than one holding three.

Try it: Could a taller container hold less than a shorter one?

See answer and explanation

Yes. Height alone does not decide capacity; compare what each holds.

5. Compare duration

Start two adult-prepared timers together. The one finishing later has the longer duration. Compare the same event or clear start and finish.

Try it: Timer A empties before B when started together. Which lasts longer?

See answer and explanation

B. It finishes later. Starting first would not prove a longer duration.

Try a worked example together

Compare the same feature

Work through the example

  1. The two strips begin at the same line.
  2. Strip B reaches farther along the line, so it is longer than strip A.
  3. This picture compares length. It does not tell which strip is heavier or holds more.

Watch for this: Longer does not automatically mean heavier. Choose the feature you are comparing.

Try it together

Place two ribbons at the same starting point. Which is shorter? Explain how you know.

Answer and teaching guidance

The shorter ribbon ends nearer the shared starting point. Judge length, not colour or width.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Wrong attribute — Check whether the question asks length, mass, capacity or duration.
  • Unfair comparison — Line up ends or use the same container/tool.
  • Only saying bigger — Use precise words such as longer, heavier, holds more or takes longer.
