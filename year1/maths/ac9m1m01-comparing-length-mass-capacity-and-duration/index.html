Comparing Length, Mass, Capacity and Duration

What students learn

Objects and events can be compared by length, mass, capacity or duration. The attribute must match the question.

Learning routine: Choose attribute → Compare fairly → Order → Explain

Success looks like

  • Choose attribute
  • Compare directly
  • Compare indirectly
  • Order objects/events
  • Communicate reasoning
Concept model and worked application

Choose the measurement attribute first

length = longer/shortermass = heavier/lightercapacity = holds moreduration = takes longer

Use the correct comparison words for the attribute.

Compare directly when possible, indirectly when needed

side by sidebalance scalesame cupsame timer

A fair comparison uses the same start, tool or unit.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Common misconceptions and traps
  • Wrong attribute — Check whether the question asks length, mass, capacity or duration.
  • Unfair comparison — Line up ends or use the same container/tool.
  • Only saying bigger — Use precise words such as longer, heavier, holds more or takes longer.
