Learn numbers to 120

Read the explanation, try the example together, then use the worksheets to build independence.

What this skill covers

Numbers to 120 can be represented with objects, numerals, number lines and charts. The same number can be shown in different ways.

Learning routine: Build → Say → Write → Locate → Order

Success looks like

  • Represent numbers to 120
  • Read numerals
  • Use tens and ones
  • Locate on number lines/charts
  • Order and compare
Understand tens, ones and number order

Show the same number in more than one way

Use the representation to explain how you know the number and where it belongs.

Use place and order to compare numbers

5885105

Compare the largest place first: hundreds, then tens, then ones. On a number line, numbers farther right are greater.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Compare the whole number

Connect a numeral to its groups and position, including numbers past 100.

Worked example

Which is greater: 97 or 103?

Place values
NumberHundredsTensOnes
97097
103103
  1. Build 97 with 9 tens and 7 ones. Build 103 with 1 hundred, no tens and 3 ones.
  2. One hundred is already more than 97. Comparing only the final digits would miss the hundred.
  3. On a number line, 97 comes before 100 and 103 comes after it. So 103 is greater.

Watch for this mistake: Looking at the ones digit first can give the wrong comparison. Compare the complete quantities; start with the largest place.

Try it, then explain

  1. Order 89, 108 and 98 from least to greatest.

    Hint

    Build or sketch the tens and hundreds first.

    Answer and explanation

    89, 98, 108. The two numbers below 100 come first; 8 tens is less than 9 tens.

  2. A number line shows 109, 110, __, 112. What is missing?

    Hint

    Each step adds one.

    Answer and explanation

    111. One more than 110 is 111.

Try a worked example together

See where numbers belong

Work through the example

  1. Each space on this line adds one. Read across: 98, 99, 100, 101.
  2. Crossing 99 does not restart the count. One more than 99 is 100.
  3. 103 is three steps after 100, so it is greater than 99.

Watch for this: Count the spaces between marks, not only the labelled marks.

Try it together

What number is one step before 102? What number is one step after it?

Answer and teaching guidance

101 and 103. Each step changes the number by one.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Explore the six learning focuses

Learning journey

Six learning focuses in this topic

Use these six focuses to organise teaching and practice. Move at the learner’s pace.

  1. 1

    Read and write numbers

    Recognise, read and write numbers to 120 in numerals and connect them with spoken number names.

  2. 2

    Count collections in tens

    Organise objects into groups of ten to count efficiently and see the structure of larger numbers.

  3. 3

    One more and one less

    Find neighbouring numbers and explain how a number changes when one is added or removed.

  4. 4

    Crossing 99 to 100

    Understand what happens to the digits and place-value structure when counting through 99 to 100 and beyond.

  5. 5

    Use the 120 chart

    Use a number chart to locate, compare and reason about patterns in numbers.

  6. 6

    Before, after and order

    Identify which numbers come before or after and place numbers in ascending or descending order.

How to use this roadmap: learn the idea, study examples, explain your thinking, then practise and check mastery.

Hands-on activities to build confidence

Build and write

Build a two-digit number with tens and ones, then write the numeral.

Model: 47 = 4 tens + 7 ones

Number-line locate

Place 36, 63 and 103 on a simple number line or hundred chart.

Model: 0 — 20 — 40 — 60 — 80 — 100 — 120

Order check

Order four number cards from smallest to largest and explain how you decided.

Model: 29, 92, 39, 109

When a learner gets stuck
  • Reversing digits — Say the tens first: 64 is six tens and four ones, not 46.
  • Counting chart rows incorrectly — Check the tens row before reading the ones.
  • Thinking more digits always means close numbers — 105 is greater than 99 even though it starts again after 100.
Review the skill before the test

Key idea: Numbers to 120 can be represented with objects, numerals, number lines and charts. The same number can be shown in different ways.

Remember

  • Represent numbers to 120
  • Read numerals
  • Use tens and ones
  • Locate on number lines/charts
  • Order and compare

Quick questions

  • Show 74 in two different ways.
  • Which is greater: 68 or 86? Explain.
  • Where would 115 sit on a 0–120 number line?
  • Order 42, 24, 102 and 72.

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.
