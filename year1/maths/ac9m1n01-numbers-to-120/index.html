Numbers to 120

Numbers to 120 can be represented with objects, numerals, number lines and charts. The same number can be shown in different ways.

What students learn

Numbers to 120 can be represented with objects, numerals, number lines and charts. The same number can be shown in different ways.

Learning routine: Build → Say → Write → Locate → Order

Success looks like

  • Represent numbers to 120
  • Read numerals
  • Use tens and ones
  • Locate on number lines/charts
  • Order and compare
Concept model and worked application

Show the same number in more than one way

Use the representation to explain how you know the number and where it belongs.

Use place and order to compare numbers

5885105

Read the tens first, then ones. On a number line, numbers farther right are greater.

Explain your thinking: Say what each part of the model represents, then explain why the answer or conclusion follows.

Guided learning activities

Build and write

Build a two-digit number with tens and ones, then write the numeral.

Model: 47 = 4 tens + 7 ones

Number-line locate

Place 36, 63 and 103 on a simple number line or hundred chart.

Model: 0 — 20 — 40 — 60 — 80 — 100 — 120

Order check

Order four number cards from smallest to largest and explain how you decided.

Model: 29, 92, 39, 109

Common misconceptions and traps
  • Reversing digits — Say the tens first: 64 is six tens and four ones, not 46.
  • Counting chart rows incorrectly — Check the tens row before reading the ones.
  • Thinking more digits always means close numbers — 105 is greater than 99 even though it starts again after 100.

Quick questions

  • Show 74 in two different ways.
  • Which is greater: 68 or 86? Explain.
  • Where would 115 sit on a 0–120 number line?
  • Order 42, 24, 102 and 72.

Return to the concept model if an answer is uncertain. Use the model to explain, not just to guess.
