Learn the skill

Small steps, clear examples

Open the focus you need for today’s worksheet. Read, try and explain before moving on.

1. Make equal groups

Group a collection into pairs, fives or tens. Every full group must contain the same number before you skip count.

Try it: Can you count groups of 5, 5 and 3 as three fives?

See answer and explanation

No. The last group is not a full five.

2. Match one count to one group

For four groups of five, point once per group: 5, 10, 15, 20. The total is 20 objects, not four objects.

Try it: Count six full groups of five.

See answer and explanation

5, 10, 15, 20, 25, 30: 30 objects.

3. Include the leftovers

Seven groups of ten and four loose counters make 74. Count the groups to 70, then count 71, 72, 73, 74.

Try it: What is eight tens and three loose counters?

See answer and explanation

83. Include all three leftovers once.

4. Count beyond 100

Ten groups of ten make 100. Keep counting the remaining groups: eleven tens are 110 and twelve tens are 120.

Try it: Count eleven groups of ten and six loose blocks.

See answer and explanation

116 blocks. Count to 110, then six more.

5. Check another way

Regrouping changes the layout, not how many objects there are. Two groups of ten and three singles still make 23.

Try it: Show 23 using groups of five.

See answer and explanation

Four full groups of five and three singles. 20 + 3 = 23.

Try a worked example together

Count equal groups without missing any

Work through the example

  1. There are four groups. Each group has five counters.
  2. Count the groups of five: 5, 10, 15, 20.
  3. There are twenty counters altogether. Counting each counter gives the same total.

Watch for this: Check that every group has the same number before skip-counting.

Try it together

Make three groups of five counters. Count the groups, then check each counter.

Answer and teaching guidance

5, 10, 15: fifteen counters in three equal groups.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Common mistakes and quick fixes
  • Unequal groups — Make every group the same size before skip counting.
  • Counting the groups instead of objects — Four groups of 5 is 20 objects, not 4 objects.
  • Losing the leftover — Count equal groups first, then add any leftover objects.
