What students learn in AC9E1LY15

This unit helps students build a clear, usable understanding of Recognise and know how to use grammatical morphemes to create word families. The goal is not to memorise one answer pattern. Students should be able to explain the idea, recognise it in a new example and apply it in a short practice or worksheet task.

  • Start with the main idea: recognise and know how to use grammatical morphemes to create word families.
  • Use concrete examples, pictures, oral explanation and short written responses before moving to independent practice.
  • building word families from common morphemes; for example, “play”, “plays”, “playing”, “played”, “playground” using morphemes to read words; for example, by recognising the base word in words such as “walk-ed”
  • Finish with a mixed activity so students must choose the correct strategy rather than copy the last example.

Common mistakes to watch for
  • Answering from memory without using clues from the text, sentence or image.
  • Knowing the idea orally but not transferring it into reading, writing or speaking.
  • Missing punctuation, word order or vocabulary clues that change meaning.
