AC9E1LY15: Recognise and know how to use grammatical morphemes to create word families

What students learn

1. Outcome Overview & Core Concepts

Grammatical morphemes such as -s, -ed and -ing can be added to base words to make related words in a word family.

Learning target: recognise and know how to use grammatical morphemes to create word families

Big idea: Use meaningful word parts to build word families

Learning routine: Find base word → Add morpheme → Read new word → Explain meaning

2. Subject-Specific Content & Key Examples

2. Subject-Specific Content & Key Examples

Base word plus meaningful ending

playplaysplayedplayingplayer

Worked example

Question: What happens when -ed is added to jump? It becomes jumped, which shows the action happened before now.

Explain how the ending changes meaning

base word-s-ed-ingword family

Word family build

Start with a base word and add endings.

Guided practice

  1. Word family build — Start with a base word and add endings.
    jump → jumps/jumped/jumping
  2. Meaning match — Match an ending to its meaning.
    -ed → happened before
  3. Sentence test — Use two words from the same family in sentences.
    I play. I played.
3. Common Student Misconceptions

3. Common Student Misconceptions

  • Ending has no meaning: Explain what the morpheme changes.
  • Base word lost: Find the base word first.
  • Word family as rhymes: Word families here are about shared meaning parts.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to morpheme.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: building word families from common morphemes; for example, “play”, “plays”, “playing”, “played”, “playground”
  • E2: using morphemes to read words; for example, by recognising the base word in words such as “walk-ed”
