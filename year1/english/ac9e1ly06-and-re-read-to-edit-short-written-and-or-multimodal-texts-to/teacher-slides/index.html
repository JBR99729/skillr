1. Outcome Overview & Core Concepts

Writers create short texts to report, express an opinion or recount an event, then re-read to edit simple sentences, topic vocabulary, punctuation and spelling.

Learning target: create and re-read to edit short written and/or multimodal texts to report on a topic, express an opinion or recount a real or imagined event, using grammatically correct simple sentences, some topic-specific vocabulary, sentence boundary punctuation and correct spelling of some one- and two-syllable words

Big idea: Create and edit short texts with clear sentences and topic words

Learning routine: Plan → Write → Re-read → Edit sentence/punctuation/spelling → Publish

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: applying emerging knowledge of text structure and grammar when creating text
  • E2: using learning area vocabulary when creating text
  • E3: creating digital images and composing a story or information sequence on screen using images and captions
  • E4: adding or deleting words on a page or screen to improve meaning; for example, adding an adjective to add meaning to a noun
  • E5: beginning to use dictionaries and resources to check and correct spelling
  • E6: identifying words that might not be spelt correctly

3. Common Student Misconceptions

  • No re-reading: Read the text aloud to catch missing words.
  • Editing everything at once: Check sentence, punctuation and spelling separately.
  • Topic vocabulary missing: Add one precise word from the topic.

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.
