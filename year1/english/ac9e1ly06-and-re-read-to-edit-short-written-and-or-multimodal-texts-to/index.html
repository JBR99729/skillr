Create and Edit Short Texts

I can create, reread and edit a short text so its sentences, vocabulary, punctuation and spelling make sense.

What this skill means

Learning goal: I can create, reread and edit a short text so its sentences, vocabulary, punctuation and spelling make sense.

  • Use an appropriate text structure and correct simple sentences when creating a text.
  • Use learning-area vocabulary where it helps meaning.
  • Sequence images and captions in a digital story or information text.
  • Add, remove or change words to improve meaning.
  • Use dictionaries and other resources to check spelling.
  • Notice words that may need a spelling check.

Steps to use

Plan → Write → Re-read → Edit sentence/punctuation/spelling → Publish

Worked example

Question: Fix “my dog run fast” → “My dog runs fast.” It needs a capital, correct verb and full stop.

Edit one thing at a time

Does it make sense?capital?end mark?spelling pattern?topic word?
Try these
  1. Sentence audit — Check one sentence for capital, verb and end mark.
    The frog jumps.
  2. Topic-word insert — Add one precise topic word to a report sentence.
    habitat / shelter
  3. Edit with a partner — Read aloud and fix one spelling or punctuation error.
    my cat sleeps → My cat sleeps.
Common mix-ups
  • No re-reading — Read the text aloud to catch missing words.
  • Editing everything at once — Check sentence, punctuation and spelling separately.
  • Topic vocabulary missing — Add one precise word from the topic.
Check your understanding

Quick checks

  • Why re-read your writing?
  • Fix: sam went home
  • What is a topic word?
  • Name one thing to check when editing.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: applying emerging knowledge of text structure and grammar when creating text
  • E2: using learning area vocabulary when creating text
  • E3: creating digital images and composing a story or information sequence on screen using images and captions
  • E4: adding or deleting words on a page or screen to improve meaning; for example, adding an adjective to add meaning to a noun
  • E5: beginning to use dictionaries and resources to check and correct spelling
  • E6: identifying words that might not be spelt correctly
