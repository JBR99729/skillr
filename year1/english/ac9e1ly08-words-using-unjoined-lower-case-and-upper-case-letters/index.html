Write Words with Upper- and Lower-Case Letters

I can form clear unjoined lower-case and upper-case letters when I write words.

What this skill means

Learning goal: I can form clear unjoined lower-case and upper-case letters when I write words.

  • Write words using clear, unjoined lower-case and upper-case letters.
  • Use a functional pencil grip or grasp that supports controlled writing.

Steps to use

Start point → Form letter → Space word → Re-read

See it, then try it

Letter shape and word spacing matter

Catcattall lettersshort lettersspaces

Worked example

Question: Is “dogcat” two readable words? No. It needs a space: “dog cat”.

Check formation and spacing

start in right placecorrect directionletters sit on linespace between words
Try these
  1. Letter family practice — Write letters with similar movements together.
    c o a d
  2. Word spacing check — Rewrite two words with a clear finger space.
    red ball
  3. Readable word test — Read your word back to a partner.
    Can they read it?
Common mix-ups
  • Joined words — Use clear spaces between words.
  • Capital inside word — Use capitals only where needed.
  • Letter reversal — Practise start point and direction.
Check your understanding

Quick checks

  • Write Cat and cat.
  • Where should spaces go?
  • Why re-read handwriting?
  • Name one letter that starts like c.

I am ready when I can
