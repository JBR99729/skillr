1. Outcome Overview & Core Concepts

Different texts have features that hint at their purpose, such as entertaining, informing, instructing or persuading.

Learning target: discuss different texts and identify some features that indicate their purposes

Big idea: Use text features as clues to purpose

Learning routine: Look at text → Notice feature → Infer purpose → Explain

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: discussing a range of texts encountered in school and in the community, and identifying their purpose
  • E2: recognising that types of texts with similar purposes usually have predictable structures

Revision Notes

  • Remember: Use text features as clues to purpose
  • Use the routine: Look at text → Notice feature → Infer purpose → Explain
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
Assessment and reviewReady for practice

3. Common Student Misconceptions

  • Guessing from topic: Use features as evidence.
  • One feature only: Check more than one clue if possible.
  • Purpose word missing: Name the purpose clearly.

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Quick checks

  • What feature suggests a recipe?
  • What purpose might a story have?
  • How can a poster persuade?
  • Use a feature as evidence.
