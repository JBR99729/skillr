Creating Characters, Settings and Events

I can explain how words and images create characters, settings and events in literature.

Topic GuideClassroom ViewPrintable Worksheet40-question PracticeTest
What this skill means

Learning goal: I can explain how words and images create characters, settings and events in literature.

  • Discuss how animal characters can show human qualities.
  • Notice how First Nations Australian authors and illustrators create characters, settings and events.
  • Use story events to explain what a character is like.

Steps to use

Notice words → Notice images → Name character/setting/event → Explain effect

See it, then try it

Words and images build story meaning

character words: bravesetting words: dark forestimage clue: tiny houseevent clue: running feet

Worked example

Question: A story says “the timid mouse” and shows the mouse hiding. Both words and image build the character as shy or scared.

Use evidence from words and picture choices

charactersettingeventevidence
Try these
  1. Character evidence — Use words and a neutral picture card to describe a character.
    brave / worried / curious
  2. Setting map — Name the setting clues in words and image layout.
    forest / beach / classroom
  3. Event freeze-frame — Act a story event and choose words that match it.
    The boat rocked.
Common mix-ups
  • Opinion without evidence — Point to words or image clues.
  • Only one mode — Use both language and image where available.
  • Mixing event and setting — Setting is where/when; event is what happens.
Check your understanding

Quick checks

  • What is a character?
  • Name one image clue for setting.
  • How can words show a character?
  • What is an event?

I am ready when I can

  • I can discuss how animal characters can show human qualities.
  • I can notice how First Nations Australian authors and illustrators create characters, settings and events.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: discussing how animal characters reflect human characteristics; for example, the creation of animal characters and their human qualities in fables by wide-ranging world authors
  • E2: discussing how characters, settings and events are described or depicted in literature by First Nations Australian authors and illustrators (teaching context)
  • E3: discussing the events associated with Australian animal characters and what is learnt about their characters in picture books from wide-ranging Australian authors
