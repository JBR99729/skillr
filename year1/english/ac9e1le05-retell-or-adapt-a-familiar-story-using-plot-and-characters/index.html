What students learn

1. Outcome Overview & Core Concepts

A retell keeps the important plot and characters. An adaptation changes a part while still using a familiar story structure.

Learning target: orally retell or adapt a familiar story using plot and characters, language features including vocabulary, and structure of a familiar text, through role-play, writing, drawing or digital tools

Big idea: Retell or adapt a story using plot, characters and structure

Learning routine: Remember story → Keep main parts → Change/adapt one part → Retell clearly

  3. Role-play retell — Act the main events in order.
    first / next / finally
3. Common Student Misconceptions

3. Common Student Misconceptions

  • Random changes: Keep enough familiar structure for the story to make sense.
  • Missing ending: A retell needs a clear ending.
  • Changes all parts at once: Change one or two parts deliberately.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to language, vocabulary, visual.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: writing character descriptions
  • E2: imitating a characteristic piece of speech or dialogue, or the attitudes or expressions of favourite characters in texts
  • E3: retelling key events in stories using oral language, visual arts, digital tools or performance
Practice Thought & Formative Assessment

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Quick checks

  • What can be changed in an adaptation?
  • Name one story character.

Revision Notes

Revision Notes

  • Remember: Retell or adapt a story using plot, characters and structure
  • Use the routine: Remember story → Keep main parts → Change/adapt one part → Retell clearly
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
