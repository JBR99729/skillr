AC9E1LA03: Explore how texts are organised according to their purpose, such as to recount, narrate, express opinion, inform, report and explain

explore how texts are organised according to their purpose, such as to recount, narrate, express opinion, inform, report and explain

Topic guideWorksheetPracticeTest
What students learn

1. Outcome Overview & Core Concepts

Texts are organised differently because they do different jobs, such as recounting, narrating, informing, reporting, explaining or giving an opinion.

Learning target: explore how texts are organised according to their purpose, such as to recount, narrate, express opinion, inform, report and explain

Big idea: See how text structure changes when the purpose changes

Learning routine: Identify purpose → Notice structure → Find key features → Explain

2. Subject-Specific Content & Key Examples

2. Subject-Specific Content & Key Examples

Purpose controls the shape of the text

recount: first/next/finallynarrative: character/problem/endinginform: facts/headingsopinion: I think/because

Worked example

Question: A text has facts, labels and a heading. Its purpose is probably to inform, because it gives information.

Use clues to name the purpose

What is it trying to do?What features prove it?How is it organised?

Purpose detective

Look at three short text examples and name the purpose.

Guided practice

  1. Purpose detective — Look at three short text examples and name the purpose.
    recount / story / information
  2. Structure sort — Match text features to purpose.
    heading → information text
  3. Change the purpose — Turn one event into a recount sentence and an opinion sentence.
    We went to the park. / I liked the park because...
3. Common Student Misconceptions

3. Common Student Misconceptions

  • Topic = purpose: Ask what the text is doing, not only what it is about.
  • One structure for all texts: Match structure to purpose.
  • No evidence: Point to a heading, time word, fact or opinion word.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to purpose.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: discussing and comparing the purposes and organisation of familiar texts
  • E2: becoming familiar with the typical stages of types of texts; for example, recount and procedure
  • E3: recognising that the structure of a text may include words and pictures; for example, an informative text may include words, illustrations and diagrams
Practice Thought & Formative Assessment

Practice Thought & Formative Assessment

Use a fresh, code-aligned example. The student should show the exact word, sound, sentence, image feature, audience clue or text evidence that supports the answer.

Quick checks

  • What purpose uses first, next, finally?
  • What purpose gives facts?
  • Name one feature of an opinion text.
  • How is a story organised?

Mastery evidence

  • Identify purpose
  • Notice structure
  • Use feature evidence
  • Compare text types
Revision Notes

Revision Notes

  • Remember: See how text structure changes when the purpose changes
  • Use the routine: Identify purpose → Notice structure → Find key features → Explain
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
