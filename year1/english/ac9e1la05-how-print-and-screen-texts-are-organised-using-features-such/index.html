Print and Screen Text Features

I can use print and screen features to find my way through a text.

Topic GuideClassroom ViewPrintable Worksheet40-question PracticeTest
What this skill means

Learning goal: I can use print and screen features to find my way through a text.

  • Compare the layout of print and digital texts.
  • Use titles, headings, page numbers, contents, buttons, links and images to find information.

Steps to use

Look at feature → Name it → Say its job → Use it

See it, then try it

Every feature has a job

title: names the textheading: names a sectionpage number: finds a pagebutton/link: moves on screen

Worked example

Question: Where would you look to find Chapter 3 quickly? The table of contents, because it lists parts and page numbers.

Use the feature that solves the problem

find a section → headingfind a page → page numbermove online → button/link
Try these
  1. Feature hunt — Find and label five features in a book or screen text.
    title / heading / link
  2. Feature job match — Match each feature to its job.
    page number → find a page
  3. Navigation challenge — Use a contents page or button to reach a target section.
    Go to Animals
Common mix-ups
  • Names feature but not job — Always say what the feature helps the reader do.
  • Confuses title and heading — Title names the whole text; heading names a part.
  • Ignores screen features — Buttons, links and swipes also organise texts.
Check your understanding

Quick checks

  • What does a page number help you do?
  • What is a heading for?
  • Name one screen-text feature.
  • Which feature names the whole text?

I am ready when I can

  • I can compare the layout of print and digital texts.
  • I can use titles, headings, page numbers, contents, buttons, links and images to find information.

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: comparing the layout of print and digital texts; for example, the layout of print and images in an information book and the layout of information in an online text
