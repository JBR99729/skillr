Key concept

Learning goal: I can use print and screen features to find my way through a text.

  • Compare the layout of print and digital texts.
  • Use titles, headings, page numbers, contents, buttons, links and images to find information.

Steps to use

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: comparing the layout of print and digital texts; for example, the layout of print and images in an information book and the layout of information in an online text
Common misconceptions
  • Names feature but not job — Always say what the feature helps the reader do.
  • Confuses title and heading — Title names the whole text; heading names a part.
  • Ignores screen features — Buttons, links and swipes also organise texts.
Try these
  1. Feature hunt — Find and label five features in a book or screen text.
    title / heading / link
  2. Feature job match — Match each feature to its job.
    page number → find a page
  3. Navigation challenge — Use a contents page or button to reach a target section.

Explain and apply

Feature has a job

Find a title, heading, page number, contents page, link or button. What does it help the reader do?

Answer and teaching guidance

Each print or screen feature should be tied to a job: name, locate, move, hear, open or organise information.

Use the contents page

Where would you look to find a section quickly in a book?

Answer and teaching guidance

The table of contents helps because it lists sections and page numbers.

Navigate a screen

A page has a Home link, Next button and speaker icon. Which feature moves forward?

Answer and teaching guidance

The Next button moves forward. The speaker icon usually plays audio and the Home link returns to the main page.

Compare book and screen

How is turning a printed page like tapping Next on a screen?

Answer and teaching guidance

Both actions move the reader to the next part of the text, even though one uses a physical page and the other uses a digital control.
