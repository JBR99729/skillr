YEAR 1 ENGLISH

Find your way through books and screens AC9E1LA05

Learning intention: I can use text features to locate information and explain the route I chose.

An adult can read and model the examples. Use a short turn or return to a section later.

More examples ↓Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Contents points to a section

Model book: title “Our school garden”. Contents: Tools — page 2; Watering — page 4; Growing — page 6. To find watering information, read its contents entry, turn to page 4 and check the heading. A contents entry tells where a section starts; it does not contain all its information.

Learn the skill

1. Use titles, headings and page numbers

The title names the whole text. A heading names a section. Contents entries and page numbers work together to guide you to that section.

Title: Our school garden. Contents: Tools 2; Watering 4; Growing 6.

Try it · Where does Growing start, and what should you check on arrival?

Page 6. Check its page number and Growing heading. Do not stop after reading the contents entry if you need the actual section information.

2. Follow the stated screen controls

Read a button or link’s label and the rules of that particular screen. Menus, scrolling and swipe directions can work differently across texts.

Model screen rules: Menu opens a list containing Tools, Watering and Growing. Selecting a section opens it. Next opens the next page; swiping left does the same on this model.

Try it · How would you open Watering from the section list?

Open Menu, then choose Watering. Next or a swipe might move one page, but the named section link is the supplied direct route. These rules belong to this model.

3. Compare routes and available actions

A print and screen feature may do a similar job through different actions. Images and labels help readers identify information. A verbal command works only when the device supports it and it is enabled.

Model screen: Watering tips is a link; Read aloud plays the text; Back returns to the previous screen. Enabled voice control also accepts “Go back”.

Try it · Which feature lets you hear the text? Give two stated ways to return.

Read aloud lets you hear it. Back or the enabled “Go back” command returns to the previous screen. These printed rules explain a model; actual device use must be observed separately.

Common mistakes

“Contents gives all the topic information.” It directs you to a section.

“Every screen uses the same swipe direction.” Read and learn that screen’s stated rules.

“Every device obeys a spoken command.” Check support and whether voice control is enabled.

10-MINUTE ACTIVITY

Find one topic two ways

An adult supplies a real information book and a safe familiar digital text. Choose one section to find using their actual headings, contents or controls. Explain the route and compare the actions used.

Adjust the challenge Starter: one target and two labelled choices. Core: follow a contents entry or named menu link and check the section. Stretch: compare two valid routes to the same information and explain which fits the task.

An adult can read labels and supervise actual device use without choosing the route. A paper button or written route answer does not show that the learner has navigated a device.

Three tricky questions

1. Can a digital book also have page numbers and contents?

Yes. Print and screen features can overlap. Compare their actual jobs.

2. Is an image always decoration?

No. A labelled picture can connect an object’s appearance with its name, as the retained watering-can example shows.

3. Should you press Next repeatedly if a direct section link is available?

Either may work under the model rules, but a named section link can be a more direct route. Check the destination.

FAQ

Must children use a particular brand of device?

No. Use available supervised resources and teach their actual controls.

What does successful navigation show?

The learner reaches the requested information and can explain which feature helped. Note any labels read or steps supplied by an adult.

More teaching examples and curriculum coverage

Useful words and learning goals

Useful words: A title names the whole text. A heading names a section. Contents lists sections and where they start. A link can take you to another page or section.

1. Titles and headings

Use the title to find the topic. Use a heading to find a part of the text.

Example

Book title: “Our school garden”. Section headings: “Tools”, “Watering”, “Growing”.

Try it: Which heading would help you find how the beds are watered?

See answer and explanation

Watering. The title names the whole book; the heading names the relevant part.

2. Page numbers and contents

Find the section in the contents, then turn to its starting page and check the heading.

Example

Contents: Tools — 2; Watering — 4; Growing — 6.

Try it: Where does the Growing section start? How could you check you reached it?

See answer and explanation

Page 6; check the page number and Growing heading. A contents entry points to information rather than giving all the information itself.

3. Images and layout

Look at where words, pictures and labels are placed. Use them together.

Example

The worksheet has a page headed “Garden Jobs”, with a section called “Watering”. Placing this picture beside the label “watering can” connects the words with the object.

Try it: How does placing “watering can” beside this picture help the reader?

See answer and explanation

It connects the object’s name with its appearance. A watering can fits the Watering section because it is used to give plants water. It is not just decoration.

4. Buttons, menus and swipes

Read a control’s label and learn what it does on that screen. Swipe or scroll actions depend on the app or text.

Example

Model screen rules: Menu opens a list of sections. Next opens the next page. On this model, swiping left also opens the next page.

Try it: You want to choose Tools from the section list. Which control would you use first?

See answer and explanation

Menu, then Tools. The stated model rules make the answer clear. Other screens may work differently; do not teach a universal swipe direction.

5. Links, icons and spoken commands

A link or icon has a job. A spoken command can work when a device supports it and the setting is enabled.

Example

Model rules: “Watering tips” opens those tips. A speaker button reads the page aloud. With voice control enabled, “Go back” returns to the previous screen.

Try it: You want to hear the page, then return to the previous screen. Describe a route.

See answer and explanation

Use the speaker button to hear it; use the enabled Go back voice command to return. A visible Back button could be another supported route. Discuss paper models separately from actual device use.

6. Compare books and screens

Compare the information and the route, rather than saying one format is always better.

Example

In a book, contents says Watering starts on page 4. On the model screen, a Watering menu link opens the same section.

Try it: Name one similar job and one different action.

See answer and explanation

Both routes locate the Watering section. Turning to page 4 is a print action; selecting the named menu link is a screen action. Some digital books also have page numbers and contents.

Try a worked example together

Follow a contents entry to a page

Work through the example

  1. The contents gives the name of each section and its starting page.
  2. To find nests, read “Nests — page 4”, then turn to page 4.
  3. A heading names that section. On a screen, a link or button can take you to a section.

Watch for this: A contents page helps you find information; it is not the whole information itself.

Try it together

The contents says “Food — page 6”. Where would you look for the food section?

Answer and teaching guidance

Page 6. Check its heading when you arrive.

An adult can read the directions, model the idea and accept an oral, pointed or drawn explanation where appropriate. For reading, spelling, handwriting or speaking tasks, observe the child doing the stated skill.

Check learning and offer support

Watch for this: Define the rules of each model screen. Swipes, buttons, menus, icons and verbal commands can vary. Never assume a spoken command works on every device. A paper navigation answer shows understanding of the model; observe actual use separately if you want evidence of device navigation.

Check: Use the contents model to find Watering. Explain how you would reach the same section on the model screen.

See answer and explanation

Turn to page 4 and check its heading in print; open Menu and choose Watering on the screen. Ask why the chosen feature helps. Accept another route only when the screen rules support it.

Help: Use a familiar book and one simple model screen. Offer a single target section and two labelled controls. An adult can read the labels without choosing the route.

Next challenge: Give two possible routes to the same section. Compare the steps and explain which you would choose for that task.

Contents and screen rules for this check

Print contents: Tools — page 2; Watering — page 4; Growing — page 6. Check each destination’s heading. Model screen: Menu opens the section list; selecting Watering opens that section. The target is Watering: turn to page 4 in print; select Menu then Watering on the model screen. A paper response explains the model, not actual device use.
