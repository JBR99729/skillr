What students learn

1. Outcome Overview & Core Concepts

Written language uses capital letters and punctuation to show sentence boundaries, questions, exclamations and familiar proper nouns.

Learning target: understand that written language uses punctuation such as full stops, question marks and exclamation marks, and uses capital letters for familiar proper nouns

Big idea: Use sentence end marks and capital letters for proper nouns

Learning routine: Read sentence → Check start/name → Choose end mark → Re-read

2. Subject-Specific Content & Key Examples

2. Subject-Specific Content & Key Examples

End marks show how the sentence works

statement.question?exclamation!Mia / Australia / Monday

Worked example

Question: Fix “where is tom” → “Where is Tom?” because it asks a question and Tom is a name.

Use the job of the sentence

telling → .asking → ?strong feeling → !name → capital

End mark sort

Sort sentences by punctuation needed.

Guided practice

  1. End mark sort — Sort sentences by punctuation needed.
    Where are you / I am here / Wow
  2. Name hunt — Find proper nouns that need capitals.
    Sam / Friday / Canberra
  3. Fix the sentence — Rewrite a sentence with capitals and punctuation.
    mia ran home
3. Common Student Misconceptions

3. Common Student Misconceptions

  • Question with full stop: If it asks, use a question mark.
  • Capital for every word: Use capitals for sentence starts and proper nouns.
  • Exclamation everywhere: Use exclamation marks for strong feeling or emphasis.
4. 4-Step Instructional Sequence

4. 4-Step Instructional Sequence

Step 1: Explicit Teaching & Modelling

Name the target in child-friendly language and demonstrate one concrete example connected to language, sentence, punctuation.

Step 2: Guided Analysis

Compare or practise a second example together. Students point to, say or show the clue.

Step 3: Collaborative / Independent Practice

Create or analyse one example together, then use a fresh familiar example independently.

Step 4: Formative Assessment

Use a one-minute check with a new example; require observable evidence rather than a guess.

Curriculum Coverage & Elaborations

Curriculum Coverage & Elaborations

The content description is the required target. The elaborations below are taught as examples and contexts, not as disconnected checklist wording.

  • E1: using intonation and pauses in response to punctuation, when reading
  • E2: identifying different sentence boundary punctuation, when reading
  • E3: writing different types of sentences; for example, statements and questions, and discussing appropriate punctuation
  • E4: identifying and using capital letters to name places and holidays

Practice Thought & Formative Assessment

Mastery evidence

Revision Notes

Revision Notes

  • Remember: Use sentence end marks and capital letters for proper nouns
  • Use the routine: Read sentence → Check start/name → Choose end mark → Re-read
  • Before answering: point to the clue in the spoken words, written sentence, image, page layout or text purpose.
  • Self-check: change the example slightly and see whether the same reasoning still works.
