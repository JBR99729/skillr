Parent and teacher guide

Number recognition grows when children connect numerals, number words and real quantities. Start with small groups of objects, then match each group to a numeral. Students should touch or move each object as they count so one number word matches one item. A common mistake is reciting numbers without checking the amount. Keep practice visual and short: count, match, circle, trace and compare. Once students can identify numerals confidently, ask them to explain how they know a group shows that number.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
