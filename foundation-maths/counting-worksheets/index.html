Parent and teacher guide

Counting is more than saying number words in order. Foundation students need to match one number word to one object, understand that the last number tells how many, and compare small groups. Use physical objects first, then pictures, then numerals. A common mistake is touching the same object twice or skipping an object while counting. Slow counting with pointing, moving objects into a counted group and checking the total helps build accuracy.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
