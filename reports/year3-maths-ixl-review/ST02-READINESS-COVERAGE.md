# AC9M3ST02 readiness and coverage map

Official ACARA v9 descriptor: “create and compare different graphical representations of data sets including using software where appropriate; interpret the data in terms of the context”. Source: official ACARA v9 workbook, Learning areas sheet.

Assessable components: create different graph types; compare representations of the same data; use software where appropriate; interpret results in context.

Direct IXL observations (signed-in Year 3 pages, 7 September 2026):

- [Interpret bar graphs](https://au.ixl.com/maths/year-3/interpret-bar-graphs): live greatest-category question; example located the shortest bar to identify the fewest.
- [Create bar graphs](https://au.ixl.com/maths/year-3/create-bar-graphs): live and example transferred a table value to a missing bar on a labelled 0–10 scale.
- [Interpret picture graphs](https://au.ixl.com/maths/year-3/interpret-picture-graphs): live and example counted symbols using a key of one item per symbol.
- [Create picture graphs](https://au.ixl.com/maths/year-3/create-picture-graphs): live tally-to-pictograph completion; example table-to-pictograph transfer using a one-to-one key.

Observed depth: direct reading, least/greatest, table-to-graph transfer, keys and missing elements. Higher adaptive stages were not completed and are not claimed. Software selection and comparison of representational strengths were not observed on these IXL pages.

Existing gap: 24 practice + 16 test, three-option legacy bank; insufficient practice count and limited comparison/software depth. Planned original 48/16 coverage: graph construction and correction; contextual interpretation; bar/picture/table comparison; appropriate software actions and checks. **READY FOR DRAFTING.**
