## AC9M4SP01

Official descriptor: represent and approximate composite shapes and objects in the environment, using combinations of familiar shapes and objects

Boundary: Must cover both 2D combinations and 3D approximations. Shape recognition is prerequisite; exact volume/surface-area calculations and formal nets are not this code’s target.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4SP01_E1 | Identify constituent shapes and physically recreate a composite arrangement; assess a construction and explanation, not just shape naming. |
| AC9M4SP01_E2 | Build or plan a cube model of an everyday 3D object, and explain which real features are approximated. Avoid turning this into a volume-formula lesson. |
| AC9M4SP01_E3 | Draw an original animal or environmental object from familiar shapes, explaining fit and simplification. |
| AC9M4SP01_E4 | Design an original logo from familiar shapes using available graphics tools; do not copy protected branding. Explain the component choices. |

## AC9M4SP02

Official descriptor: create and interpret grid reference systems using grid references and directions to locate and describe positions and pathways

Boundary: Grid references designate labelled cells, with the map convention explicit. Do not silently substitute Cartesian coordinate points, negative coordinates or algebraic transformations.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4SP02_E1 | Read a labelled map and write an unambiguous route with grid references and directions. State label order and whether references denote cells. |
| AC9M4SP02_E2 | Locate and enter actual data in spreadsheet cells; explicit column-letter and row-number convention. A paper analogue supports but does not replace the digital activity. |
| AC9M4SP02_E3 | Compare the same busy scene with and without a grid; explain how reference cells improve communication. |
| AC9M4SP02_E4 | Copy an image cell by cell onto a larger grid and preserve its shape; do not require formal scale factors or coordinate transformation rules. |
| AC9M4SP02_E5 | Plan and follow a robot route, distinguish turn from movement, and state initial facing direction when relative turns matter. |

## AC9M4SP03

Official descriptor: recognise line and rotational symmetry of shapes and create symmetrical patterns and pictures, using dynamic geometric software where appropriate

Boundary: Teach line and rotational symmetry and construction, using trace/fold/turn evidence. Avoid formal transformation matrices, coordinate rules or proof; degrees may support familiar quarter/half turns but are not required formalism.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4SP03_E1 | Trace a shape and test whether a turn smaller than a full turn gives an exact match. Distinguish rotational symmetry from merely being able to rotate. |
| AC9M4SP03_E2 | Create and inspect line/rotationally symmetrical patterns with dynamic geometry or a supervised AI output; verify the geometry rather than assuming the tool is correct. |
| AC9M4SP03_E3 | Inspect respectfully sourced textile/art motifs and describe actual observed line/rotational symmetry. Do not invent cultural meaning. |
| AC9M4SP03_E4 | Observe patterns in nature on Country/Place; acknowledge approximate natural symmetry and local context without inventing First Nations knowledge. |

## AC9M4ST01

Official descriptor: acquire data for categorical and discrete numerical variables to address a question of interest or purpose, using digital tools; represent data using many-to-one pictographs, column graphs and other displays or visualisations; interpret and discuss the information that has been created

Boundary: Categorical and discrete numerical variables, many-to-one pictographs, column graphs, acquisition and interpretation. No continuous-data histogram, mean formula or inferential statistics as core.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4ST01_E1 | Use digital tools to inspect and discuss many-to-one graphs; identify key, scale, labels and totals. |
| AC9M4ST01_E2 | Convert pictograph symbols using the key, including meaningful half symbols where the unit count is whole; explain why counting icons alone fails. |
| AC9M4ST01_E3 | Collect science observation data and graph/interpret it in its experiment context. |
| AC9M4ST01_E4 | Co-create a safe school poll and inspect poll/word-cloud outputs, including how AI tools may present collected data; check accuracy and preserve privacy. |
| AC9M4ST01_E5 | Collect categorical and discrete numerical data using practical observations or trials; tally, enter a digital table and create/compare a column graph. |
| AC9M4ST01_E6 | Use attributed real secondary fire-burn data to explore useful displays for caring for Country/Place; do not call invented values real Ranger data. Illustrative data must be explicitly labelled and the authentic-source investigation retained. |

## AC9M4ST02

Official descriptor: analyse the effectiveness of different displays or visualisations in illustrating and comparing data distributions, then discuss the shape of distributions and the variation in the data

Boundary: Effectiveness of displays, distribution shape and variation are central; reading totals alone is insufficient. Everyday descriptors are sufficient; no standard deviation or formal distribution theory.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4ST02_E1 | Pose answerable questions from a display and justify responses using labels/scale. |
| AC9M4ST02_E2 | Interpret media-style many-to-one symbols and part symbols; identify misleading pictorial scaling and state what the key means. |
| AC9M4ST02_E3 | Compare diagrams/tables/graphs of the same data and explain usefulness for a purpose; describe peaks, clusters, gaps, spread and variation in everyday language. |
| AC9M4ST02_E4 | Explain at an age-appropriate level that AI developers examine and display data to detect patterns, gaps or unusual values; no AI modelling/statistical theory required. |

## AC9M4ST03

Official descriptor: conduct statistical investigations, collecting data through survey responses and other methods; record and display data using digital tools; interpret the data and communicate the results

Boundary: A complete investigation with actual data collection/digital recording and communication is needed. MCQ planning decisions cannot replace the practical investigation. No causation claim from a small survey.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4ST03_E1 | Complete a survey cycle: question, fair collection, spreadsheet recording, suitable display, interpretation and communication to classmates. |
| AC9M4ST03_E2 | Retrieve a suitable small dataset from a named online source, record provenance and interpret the question it can address. Prepared invented data is not evidence of actual online retrieval. |
| AC9M4ST03_E3 | Plan relevant questions and measurements for a real context (for example sugar content and cereal shelf position); distinguish what data can show from unsupported causal claims. |

## AC9M4P01

Official descriptor: describe possible everyday events and the possible outcomes of chance experiments and order outcomes or events based on their likelihood of occurring; identify independent or dependent events

Boundary: Qualitative likelihood ordering, outcomes and dependence/independence. Use fair-device assumptions and transparent bag models; numerical probability formulae and conditional notation are beyond the core boundary.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4P01_E1 | Order familiar events by likelihood and explain contextual differences; avoid absolute ordering of unspecified everyday events. |
| AC9M4P01_E2 | Explain that independent fair-coin tosses do not remember a run of heads; tails is not due. |
| AC9M4P01_E3 | Compare red-selection likelihood across the three official bag structures using proportions/models, not red count alone; do not require formal probability fractions. |
| AC9M4P01_E4 | Explain dependence in everyday plans such as weather-dependent outdoor activities. |
| AC9M4P01_E5 | Identify incompatible outcomes in the same stated situation; distinguish cannot occur together from independent. |
| AC9M4P01_E6 | Describe how occurrence changes or does not change another chance; clearly state replacement when drawing objects. |
| AC9M4P01_E7 | Discuss likelihood-based early-warning decisions without suggesting AI predictions are certainty. |
| AC9M4P01_E8 | Predict likely next words and refine possibilities after a letter is revealed; the added information changes available evidence. |

## AC9M4P02

Official descriptor: conduct repeated chance experiments to observe relationships between outcomes; identify and describe the variation in results

Boundary: Actual repeated chance trials and observed variation, with simple recording and comparison. Results fluctuate; do not promise exact equal counts, claim a short run proves fairness, or introduce formal convergence/probability formulae.

| Elaboration | Required coverage / evidence |
| --- | --- |
| AC9M4P02_E1 | Play and investigate a specified game with explicit rules; record whether player order/strategy matters. Do not assume every game is a pure chance experiment. |
| AC9M4P02_E2 | Conduct repeated trials with different physical/virtual random generators; record and compare variation. Briefly discuss that AI training can use randomness without overclaiming how every tool works. |
| AC9M4P02_E3 | Run and record two-coin trials; distinguish HH, HT, TH, TT and grouped outcomes so one head/one tail is not treated as a single equally likely ordered outcome. |
| AC9M4P02_E4 | Shuffle and repeatedly draw/classify cards, recording outcomes and variation; state replacement/reshuffling procedure and define picture/numbered/ace conventions. |
