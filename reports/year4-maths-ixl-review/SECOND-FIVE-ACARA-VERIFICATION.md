The spreadsheet elaboration needs explicit starting data and a clear distinction between filling a series of inputs and copying a constant. Authored examples should state the actual cells and values, then check the formula's changing row references. Algorithm models must show genuine branch routing, output timing and a stopping condition when a finite output is requested.
