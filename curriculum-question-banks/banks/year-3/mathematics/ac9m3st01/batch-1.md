# AC9M3ST01 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** Categorical data uses names or groups; discrete numerical data uses countable numbers.
- **Worked example:** Favourite fruit is categorical; number of siblings is discrete numerical.
- **Common trap:** A survey question must match the data needed.
- **Visual model:** Use arrays, number lines, clocks, maps, measuring tools, graph cards or manipulatives that match the question. Online tasks must include tap and keyboard alternatives to drag-and-drop.
