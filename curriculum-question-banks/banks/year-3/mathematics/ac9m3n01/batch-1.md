# AC9M3N01 — Pass 1 question bank

## 60-second Quick Read

- **Place-value rule:** A digit is worth different amounts depending on its place. Read large numbers in groups of three digits: thousands, then ones. In Australia, write a space between groups, for example `42 305`.
- **Worked example:** `58 407` means 5 ten-thousands, 8 thousands, 4 hundreds, 0 tens and 7 ones. It is read as **fifty-eight thousand, four hundred and seven**.
- **Compare carefully:** Compare the leftmost place first. `63 190` is greater than `62 999` because 63 thousands is greater than 62 thousands.
- **Common trap:** A zero still holds its place. In `70 506`, there are no thousands or tens; do not read it as seven thousand and fifty-six.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Read a numeral

**Type:** Short response

**Question:** Write `46 208` in words.

**Marking key:** **forty-six thousand, two hundred and eight**. Accept “forty six” without a hyphen. 1 mark.

**Coverage:** reads a five-digit numeral using correct place-value language.

### P02 — Write a numeral

**Type:** Short response

**Question:** Write this number using digits and a space between each group of three digits: **ninety-three thousand, sixty-five**.

**Marking key:** `93 065`. Award 1 mark only if the zero is included in the hundreds place.

**Coverage:** writes a named number beyond 10 000 using Australian spacing convention.

## Tier 2 — Core skill practice

### P03 — Partition by place value

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match each part of `71 304` to its value: digit 7, digit 1, digit 3, digit 4; values 70 000, 1 000, 300, 4.

**Marking key:** 7 → 70 000; 1 → 1 000; 3 → 300; 4 → 4. 4 marks, one per correct match.

**Coverage:** identifies the value of digits in a five-digit number.

### P04 — Rename a number

**Type:** Short response

**Question:** Mia says `34 560` is 3 ten-thousands, 4 thousands, 5 hundreds and 6 tens. What part is missing, and how many are there?

**Marking key:** **ones; 0 ones**. 1 mark for both the place and value.

**Coverage:** represents a number by decomposing it into place-value parts, including zero.

## Tier 3 — Guided application

### P05 — One more across a boundary

**Type:** Short response

**Question:** What is one more than `19 999`? Explain which place values change.

**Marking key:** `20 000`. Explanation: 9 ones become 0 ones, 9 tens become 0 tens, 9 hundreds become 0 hundreds and 9 thousands become 0 thousands; the ten-thousands changes from 1 to 2. Award 1 mark for the number and 1 mark for a correct place-value explanation.

**Coverage:** predicts one more across several place-value boundaries.

### P06 — Order numbers

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Put these numbers in order from smallest to largest: `50 406`, `50 046`, `49 999`, `50 460`.

**Marking key:** `49 999`, `50 046`, `50 406`, `50 460`. 2 marks: 1 for the first two in order and 1 for the complete correct sequence.

**Coverage:** orders close natural numbers by comparing digits from the highest place.

## Tier 4 — Problem solving and reasoning

### P07 — Find the hidden digit

**Type:** Short response

**Question:** The number `6□ 482` is greater than `65 000` but less than `67 000`. What digit belongs in the box? Explain.

**Marking key:** `6`. The thousands digit must be 6, making the number `66 482`; this is between 65 000 and 67 000. 2 marks: digit and explanation.

**Coverage:** uses place-value inequalities to determine an unknown digit.

### P08 — Explain an ordering decision

**Type:** Extended response

**Question:** A library recorded these numbers of pages read in a month: 82 715, 82 571 and 81 999. Which is the greatest? Write a comparison that proves your answer.

**Marking key:** **82 715** is greatest. It has 82 thousands, like 82 571, but 7 hundreds is greater than 5 hundreds; both are greater than 81 999 because 82 thousands is greater than 81 thousands. 3 marks: correct number, valid comparison with 82 571, and valid comparison with 81 999.

**Coverage:** justifies the ordering of five-digit numbers using place-value evidence.

## Exam questions

## Section A — Core knowledge

### E01 — Read a six-digit numeral

**Type:** Short response

**Question:** Write `305 018` in words.

**Marking key:** **three hundred and five thousand and eighteen**. Accept the equivalent conventional wording “three hundred and five thousand, eighteen”. 1 mark.

**Coverage:** reads a six-digit numeral with zero placeholders.

### E02 — Build a number from parts

**Type:** Short response

**Question:** What numeral is made from 4 hundred-thousands, 2 ten-thousands, 0 thousands, 9 hundreds, 3 tens and 6 ones?

**Marking key:** `420 936`. 1 mark.

**Coverage:** combines named place-value parts into a six-digit numeral.

### E03 — Locate a digit value

**Type:** Short response

**Question:** In `148 276`, what is the value of the digit 8?

**Marking key:** `8 000`. 1 mark.

**Coverage:** identifies the value of a digit in the thousands place.

## Section B — Application and problem solving

### E04 — Choose a possible number

**Type:** Extended response

**Question:** Write a five-digit number that has 4 in the ten-thousands place, 0 in the hundreds place and is greater than `45 000`. Explain why your number fits all three clues.

**Marking key:** Answers vary; for example, `46 035`. Must have 4 ten-thousands, 0 hundreds and be greater than 45 000. 3 marks: valid numeral, all place-value requirements shown, and correct comparison explanation.

**Coverage:** constructs a number meeting multiple place-value constraints.

### E05 — Compare two close numbers

**Type:** Short response

**Question:** Insert `<`, `>` or `=`: `109 090 ___ 109 900`. Then state the first place value that decides the comparison.

**Marking key:** `109 090 < 109 900`; the **hundreds** place decides it (0 hundreds is less than 9 hundreds). 2 marks.

**Coverage:** compares six-digit numbers and identifies the deciding place.

### E06 — Count forward across 100 000

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Starting at `99 998`, write the next three whole numbers in order.

**Marking key:** `99 999`, `100 000`, `100 001`. 2 marks: 1 for the first number and 1 for all three in correct order.

**Coverage:** counts forward across the transition to 100 000.

## Section C — Extended response and analysis

### E07 — Analyse a mistake

**Type:** Extended response

**Question:** Noah wrote `70 509` as “seven thousand, five hundred and nine”. Explain Noah’s error and write the number correctly in words.

**Marking key:** Noah treated the 7 as thousands instead of ten-thousands and missed the zero thousands place. Correct wording: **seventy thousand, five hundred and nine**. 3 marks: identifies the incorrect place, identifies the zero/scale issue, and writes the correct name.

**Coverage:** analyses a place-value misconception involving zero and ten-thousands.

### E08 — Create and justify an order

**Type:** Extended response

**Question:** Use the digits 2, 0, 5, 7 and 9 once each to make the greatest and the smallest possible five-digit numbers. Then explain why the smallest number cannot begin with 0.

**Marking key:** Greatest `97 520`; smallest `20 579`. A five-digit number cannot start with 0 because then it would only have four digits. 3 marks: greatest, smallest, explanation.

**Coverage:** creates extreme five-digit numbers from digits and explains the zero constraint.
