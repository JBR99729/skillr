# AC9M3SP02 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** A map is a top-view representation. Use symbols, labels, directions and grid references to locate places.
- **Worked example:** On a grid, B3 means column B and row 3 when that convention is given.
- **Common trap:** Always check the map key and direction arrow before deciding left, right, north or south.
- **Visual model:** Use arrays, number lines, clocks, maps, measuring tools, graph cards or manipulatives that match the question. Online tasks must include tap and keyboard alternatives to drag-and-drop.
