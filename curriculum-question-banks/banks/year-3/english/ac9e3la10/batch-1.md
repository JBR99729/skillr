# AC9E3LA10 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises technical vocabulary in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match word to context

**Type:** Matching

**Question:** Match word to subject: evaporate, estimate, caption, habitat. Subjects: science, maths, English, science living things.

**Marking key:** Evaporate -> science; estimate -> maths; caption -> English; habitat -> science living things.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose meaning in context

**Type:** Multiple choice

**Question:** In science, "conduct" can mean carry heat. In music, it can mean lead a group. Which meaning fits "metal can conduct heat"?

**Marking key:** Carry heat.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Use a technical word

**Type:** Short response

**Question:** Write one sentence using the science word "temperature" accurately.

**Marking key:** A sentence showing temperature as how hot or cold something is.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - General or technical

**Type:** Sorting

**Question:** Sort: thing, mineral, stuff, centimetre.

**Marking key:** Technical: mineral, centimetre. General: thing, stuff.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Replace vague vocabulary

**Type:** Editing

**Question:** Replace "stuff" in "The stuff changed when heated" with a more precise word.

**Marking key:** For example, material, wax, chocolate or substance.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Context changes meaning

**Type:** Short response

**Question:** Explain two meanings of "scale" in different school subjects.

**Marking key:** For example, map scale and weighing scale, or music scale.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Vocabulary helps precision

**Type:** Extended response

**Question:** Why is "millilitres" more precise than "a bit" in an investigation report?

**Marking key:** It gives a measurable amount so others can understand or repeat the investigation.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose best word

**Type:** Multiple choice

**Question:** Which word best completes: "A ___ shows what each symbol on a map means": legend, paragraph, fraction.

**Marking key:** legend.

**Coverage:** Assesses the code through an applied Year 3 English task.
