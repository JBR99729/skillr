# AC9E3LY03 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises audience and purpose in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match text to purpose

**Type:** Matching

**Question:** Match: story, advertisement, report, invitation to entertain, persuade, inform, invite.

**Marking key:** Story -> entertain; advertisement -> persuade; report -> inform; invitation -> invite.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Find audience clue

**Type:** Multiple choice

**Question:** A text says "Parents and carers are invited to..." Who is the audience?

**Marking key:** Parents and carers.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Purpose from language

**Type:** Short response

**Question:** A text says "You should buy this because..." What is its likely purpose?

**Marking key:** To persuade.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Feature clues

**Type:** Sorting

**Question:** Sort: price, character dialogue, facts table, date/time into persuasive, imaginative, informative or invitation clues.

**Marking key:** Price -> persuasive; dialogue -> imaginative; facts table -> informative; date/time -> invitation.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Select persuasive words

**Type:** Hotspot / selection

**Question:** Select persuasive words: amazing, because, turtle, yesterday, best.

**Marking key:** amazing, because, best.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Explain purpose using evidence

**Type:** Extended response

**Question:** A poster has a big photo of a clean beach and the words "Join our clean-up". Explain audience and purpose.

**Marking key:** Audience is people who can join; purpose is to persuade/invite them to clean up.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Choose title for purpose

**Type:** Multiple choice

**Question:** Which title best suits an informative text: "Why Dogs Are the Best"; "How Frogs Grow"; or "The Magic Door"?

**Marking key:** "How Frogs Grow."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Image clue

**Type:** Short response

**Question:** How can a picture help you identify the purpose of a text?

**Marking key:** It can show product, event, information, mood or intended audience.

**Coverage:** Assesses the code through an applied Year 3 English task.
