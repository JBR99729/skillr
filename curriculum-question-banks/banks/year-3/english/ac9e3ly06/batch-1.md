# AC9E3LY06 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises creating written and multimodal texts in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Plan-create-edit-publish

**Type:** Sequencing

**Question:** Order: draft, plan, edit, publish.

**Marking key:** Plan; draft/create; edit; publish.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose text form

**Type:** Short response

**Question:** What form would suit telling people how to care for a class pet: story, instructions or joke book?

**Marking key:** Instructions.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Improve punctuation

**Type:** Editing

**Question:** Fix: "bring a hat water bottle and lunch"

**Marking key:** "Bring a hat, water bottle and lunch."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Choose visual feature

**Type:** Multiple choice

**Question:** Which visual feature helps a procedure: random cartoon, numbered diagram, or blurry background?

**Marking key:** Numbered diagram.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Audience sentence

**Type:** Short response

**Question:** Write one clear sentence for Year 2 students about crossing the road safely.

**Marking key:** A simple audience-appropriate safety sentence.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Match text part

**Type:** Matching

**Question:** Match title, introduction, image, conclusion to job.

**Marking key:** Title names topic; intro opens; image supports meaning; conclusion closes.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Edit for purpose

**Type:** Extended response

**Question:** A persuasive poster has no reason, no audience and tiny text. Suggest two improvements.

**Marking key:** Add clear reason/evidence, address audience, improve readable layout.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Publish check

**Type:** Short response

**Question:** Name two things to check before publishing a class information page.

**Marking key:** Spelling, punctuation, facts, layout, images, audience.

**Coverage:** Assesses the code through an applied Year 3 English task.
