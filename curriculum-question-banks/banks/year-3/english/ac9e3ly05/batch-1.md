# AC9E3LY05 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises comprehension strategies in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Literal or inferred

**Type:** Multiple choice

**Question:** Text: "Lena packed sunscreen and a towel." What can you infer?

**Marking key:** She may be going swimming or to the beach/pool.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Ask a question

**Type:** Short response

**Question:** Before viewing a video called "How Bees Make Honey", write one question you could listen for.

**Marking key:** A relevant question about bees/honey.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match strategy

**Type:** Matching

**Question:** Match predict, visualise, summarise, infer to: guess using clues, make a picture in your mind, tell main points, read between lines.

**Marking key:** Predict -> guess; visualise -> picture; summarise -> main points; infer -> read between lines.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Fact or inference

**Type:** Sorting

**Question:** Sort: "The boy carried an umbrella"; "It might rain"; "The sign says Closed"; "The shop is not open".

**Marking key:** Facts: umbrella, sign says Closed. Inferences: might rain, shop not open.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Summarise viewing

**Type:** Short response

**Question:** A clip shows seeds sprouting, growing leaves, then flowering. Write a one-sentence summary.

**Marking key:** A sentence about stages of plant growth.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Evaluate a message

**Type:** Extended response

**Question:** A poster says "This snack is the best" but gives no reasons. How could you evaluate it?

**Marking key:** Look for evidence, reasons, source and compare with other information.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Select evidence

**Type:** Hotspot / selection

**Question:** Text: "The path was slippery." Clues: wet leaves, bright sun, dry shoes, muddy puddle. Select two evidence clues.

**Marking key:** wet leaves and muddy puddle.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Connect to knowledge

**Type:** Short response

**Question:** How does knowing that smoke can be dangerous help you understand a bushfire warning text?

**Marking key:** It helps explain why people must leave or stay away.

**Coverage:** Assesses the code through an applied Year 3 English task.
