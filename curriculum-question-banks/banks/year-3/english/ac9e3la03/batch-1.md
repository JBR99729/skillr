# AC9E3LA03 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises curriculum text features in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match subject and feature

**Type:** Matching

**Question:** Match each text to its likely feature: science report, recipe, history timeline, maths solution. Features: steps, labelled diagram, dates in order, working out.

**Marking key:** Science report -> labelled diagram; recipe -> steps; history timeline -> dates in order; maths solution -> working out.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose the best structure

**Type:** Multiple choice

**Question:** Which structure best suits instructions for planting seeds: problem-solution, step-by-step, or opinion paragraph?

**Marking key:** Step-by-step.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Name a science feature

**Type:** Short response

**Question:** Name one language or structure feature often used in a science explanation.

**Marking key:** For example, technical vocabulary, labelled diagram, cause/effect language or headings.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Sort feature by purpose

**Type:** Sorting

**Question:** Sort these as helpful for explaining or persuading: evidence table, strong opinion, labelled diagram, reason to agree.

**Marking key:** Explaining: evidence table, labelled diagram. Persuading: strong opinion, reason to agree.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Improve a procedure heading

**Type:** Editing

**Question:** Change the heading "Stuff" in a seed-growing procedure to a clearer heading.

**Marking key:** For example, "Materials" or "What You Need".

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Find the purpose clue

**Type:** Short response

**Question:** In a text with headings "Aim", "Materials" and "Method", what is the likely purpose?

**Marking key:** To explain or guide an investigation/procedure.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain feature choice

**Type:** Extended response

**Question:** Why would a maths page use numbered steps and working-out boxes?

**Marking key:** They help readers follow the method and check each part of the solution.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose navigation words

**Type:** Short response

**Question:** Write two words that help readers move through an information page.

**Marking key:** For example, first, next, finally, contents, page, heading.

**Coverage:** Assesses the code through an applied Year 3 English task.
