# AC9E3LA04 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises paragraphs in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose the paragraph topic

**Type:** Multiple choice

**Question:** A paragraph says: "Bees collect nectar. They carry pollen between flowers. This helps plants make seeds." What is the paragraph mostly about?

**Marking key:** How bees help plants.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Order paragraph stages

**Type:** Sequencing

**Question:** Order these parts for an information paragraph: detail, topic sentence, explaining sentence, closing sentence.

**Marking key:** Topic sentence; detail; explaining sentence; closing sentence.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Split unrelated ideas

**Type:** Editing

**Question:** This paragraph has two topics: "Turtles lay eggs on beaches. My favourite sport is soccer." What should the writer do?

**Marking key:** Start a new paragraph or remove the unrelated soccer sentence.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Write a topic sentence

**Type:** Short response

**Question:** Write a topic sentence for a paragraph about keeping lunch rubbish out of the playground.

**Marking key:** Any clear sentence introducing that topic.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Group related sentences

**Type:** Sorting

**Question:** Group these ideas into two paragraphs: koalas eat leaves; soccer uses a round ball; joeys stay in pouches; goals score points.

**Marking key:** Animal paragraph: koalas, joeys. Soccer paragraph: ball, goals.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Find the odd sentence

**Type:** Multiple choice

**Question:** Which sentence does not belong in a paragraph about rainforests: "Tall trees make shade"; "Many insects live there"; "My bike has a bell"?

**Marking key:** "My bike has a bell."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain paragraph breaks

**Type:** Extended response

**Question:** Why should a new paragraph begin when a story changes from the beach to the classroom?

**Marking key:** The setting/topic changes, so a paragraph break helps readers follow the shift.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Improve flow

**Type:** Editing

**Question:** Add a linking word to join these ideas: "The seeds need water. ___, they need sunlight."

**Marking key:** For example, Also, Next, Finally.

**Coverage:** Assesses the code through an applied Year 3 English task.
