# AC9E3LA05 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises layout and navigation in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match layout feature to job

**Type:** Matching

**Question:** Match feature to job: heading, caption, menu, bold word. Jobs: names section, explains picture, navigates page, highlights key word.

**Marking key:** Heading -> names section; caption -> explains picture; menu -> navigates page; bold word -> highlights key word.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose the fastest navigation

**Type:** Multiple choice

**Question:** You need the weather page on a website. Which helps most: menu, paragraph, or decorative border?

**Marking key:** Menu.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Use a caption

**Type:** Short response

**Question:** Write a useful caption for a photo of students measuring plant growth.

**Marking key:** A caption that explains the photo, such as "Students measure the plant height each day."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Find the link words

**Type:** Hotspot / selection

**Visual:** Use the text/table/cards shown in the question.

**Question:** Select the navigation words: Home | Red foxes live in dens | Next page | The cubs play.

**Marking key:** Home and Next page.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Improve a button label

**Type:** Editing

**Question:** Change the button label "Click here" to a clearer label for a spelling practice page.

**Marking key:** For example, "Start Spelling Practice."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Explain a contents page

**Type:** Short response

**Question:** What does a contents page help a reader do?

**Marking key:** Find sections or page numbers quickly.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Choose layout for instructions

**Type:** Extended response

**Question:** A page teaches how to make a kite. Name two layout features that would help and explain why.

**Marking key:** For example, numbered steps, materials list, diagrams, headings.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Purpose of a sidebar

**Type:** Multiple choice

**Question:** A small box says "Remember: wear gloves." What is its purpose?

**Marking key:** To highlight an important reminder/safety note.

**Coverage:** Assesses the code through an applied Year 3 English task.
