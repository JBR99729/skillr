# AC9E3LE02 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises personal connections in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Make a text-to-self connection

**Type:** Short response

**Question:** A character feels nervous before a performance. Write one personal connection a reader might make.

**Marking key:** A relevant connection to feeling nervous before an event.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose useful preference

**Type:** Multiple choice

**Question:** Which preference gives a reason: "I like it"; "I like it because the mystery made me predict"; or "Book good"?

**Marking key:** "I like it because the mystery made me predict."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Share preference

**Type:** Extended response

**Question:** Choose a character from a familiar story and explain whether you would like to be their friend.

**Marking key:** A preference supported by character evidence.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Connection or summary

**Type:** Sorting

**Question:** Sort: "This reminds me of moving house"; "The girl moved house"; "I also have a younger brother"; "The story has three chapters".

**Marking key:** Connections: reminds me, also have. Summaries: girl moved house, three chapters.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Connect to event

**Type:** Short response

**Question:** A story family loses power during a storm. What experience or knowledge could help a reader understand this event?

**Marking key:** A relevant experience/knowledge of storms, blackouts or being prepared.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Improve weak response

**Type:** Editing

**Question:** Improve: "I liked the dog." Add a reason connected to the story.

**Marking key:** For example, "I liked the dog because it warned the family about danger."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Personal response with evidence

**Type:** Multiple choice

**Question:** Which response uses evidence: "I hate it"; "I felt worried when the bridge cracked"; "It was a book"?

**Marking key:** "I felt worried when the bridge cracked."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Different readers

**Type:** Extended response

**Question:** Explain why two readers might prefer different characters in the same story.

**Marking key:** Readers bring different experiences, values and interests.

**Coverage:** Assesses the code through an applied Year 3 English task.
