# AC9E3LY01 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises same purpose, different audience in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Audience choice

**Type:** Multiple choice

**Question:** Which greeting best suits a letter to the principal: Hey mate, Dear Principal, Yo!

**Marking key:** Dear Principal.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Match audience to text feature

**Type:** Matching

**Question:** Match younger students, parents, council, classmates to: simple steps, clear notice, formal request, friendly examples.

**Marking key:** Younger students -> simple steps; parents -> notice; council -> formal request; classmates -> friendly examples.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Same purpose different wording

**Type:** Short response

**Question:** Write one sentence asking a friend to recycle, then one asking visitors at assembly.

**Marking key:** Friend version informal; assembly version more formal/polite.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Audience clues

**Type:** Sorting

**Question:** Sort: slang, technical term, school logo, emoji into formal notice or friend chat.

**Marking key:** Formal notice: technical term, school logo. Friend chat: slang, emoji.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Change for younger readers

**Type:** Editing

**Question:** Rewrite "Dispose of waste responsibly" for Year 1 students.

**Marking key:** For example, "Put your rubbish in the bin."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Explain audience difference

**Type:** Extended response

**Question:** Why might two posters both ask people to save water but use different words and pictures?

**Marking key:** They may target different audiences, ages or situations.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Purpose remains same

**Type:** Multiple choice

**Question:** A teacher email and class poster both explain excursion rules. What is the same?

**Marking key:** The purpose: to explain/inform rules.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose image for audience

**Type:** Short response

**Question:** What image would help younger children understand a handwashing poster?

**Marking key:** A clear image/steps of washing hands.

**Coverage:** Assesses the code through an applied Year 3 English task.
