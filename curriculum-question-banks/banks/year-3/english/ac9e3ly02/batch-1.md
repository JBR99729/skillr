# AC9E3LY02 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises discussion skills in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Best discussion move

**Type:** Multiple choice

**Question:** Which helps a discussion: interrupting, building on an idea, or changing the topic?

**Marking key:** Building on an idea.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Ask a follow-up

**Type:** Short response

**Question:** Write a follow-up question after someone says, "Our graph shows more students chose soccer."

**Marking key:** A relevant question, such as "How many chose soccer?"

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Helpful or unhelpful

**Type:** Sorting

**Question:** Sort: eye contact, laughing at mistakes, adding evidence, ignoring a speaker.

**Marking key:** Helpful: eye contact, adding evidence. Unhelpful: laughing, ignoring.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Improve a response

**Type:** Editing

**Question:** Improve: "No, wrong." Make it respectful and useful.

**Marking key:** For example, "I see it differently because..."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Match talk role

**Type:** Matching

**Question:** Match chairperson, speaker, listener, reporter to their job.

**Marking key:** Chairperson manages turns; speaker shares; listener pays attention; reporter summarises.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Summarise an idea

**Type:** Short response

**Question:** A partner says, "We need shade because plants wilt." Write a short summary.

**Marking key:** For example, "You think shade will protect the plants."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Solve a group problem

**Type:** Extended response

**Question:** One student does all the talking. Explain two fair ways to improve the discussion.

**Marking key:** Use turn-taking, invite quieter students, assign roles or set time limits.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Evidence in talk

**Type:** Multiple choice

**Question:** Which contribution includes evidence: "I agree"; "I agree because 12 people voted yes"; or "Cool"?

**Marking key:** "I agree because 12 people voted yes."

**Coverage:** Assesses the code through an applied Year 3 English task.
