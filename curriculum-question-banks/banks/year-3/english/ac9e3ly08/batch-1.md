# AC9E3LY08 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises joined handwriting in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose readable handwriting

**Type:** Multiple choice

**Question:** Which feature matters most: letters clearly formed and consistent size, random slopes, or words touching every line?

**Marking key:** Letters clearly formed and consistent size.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Spacing check

**Type:** Short response

**Question:** Why do writers leave spaces between words?

**Marking key:** So readers can tell where each word starts and ends.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Fix letter size advice

**Type:** Editing

**Question:** A student writes some letters huge and some tiny. Give one improvement goal.

**Marking key:** Keep letters more consistent in size.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Readable or hard to read

**Type:** Sorting

**Question:** Sort: even spacing, unclear joins, clear ascenders, crowded words.

**Marking key:** Readable: even spacing, clear ascenders. Hard: unclear joins, crowded words.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Joined letter pair

**Type:** Short response

**Question:** Name one pair of letters that can be joined clearly in handwriting.

**Marking key:** Any plausible joined pair, such as in, th, er.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Publishing handwriting

**Type:** Multiple choice

**Question:** Before displaying handwriting, what should a student check: neat formation, fastest scribble, or secret code?

**Marking key:** Neat formation.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain consistency

**Type:** Extended response

**Question:** Explain how consistent letter size helps a reader.

**Marking key:** It makes words easier to recognise and follow.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Rewrite instruction

**Type:** Short response

**Question:** Write a short reminder for neat joined handwriting.

**Marking key:** A reminder about clear letters, spacing, size or joins.

**Coverage:** Assesses the code through an applied Year 3 English task.
