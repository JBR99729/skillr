# AC9E3LE03 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises author language and illustrations in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Setting mood

**Type:** Multiple choice

**Question:** Which words best create a spooky setting: bright and busy, silent and shadowy, warm and friendly?

**Marking key:** Silent and shadowy.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Character through illustration

**Type:** Short response

**Question:** An illustration shows a character with crossed arms and a frown. What might it suggest?

**Marking key:** The character may be angry, upset or unwilling.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match description to effect

**Type:** Matching

**Question:** Match: sparkling river, cracked path, tiny whisper, heavy boots. Effects: beauty, danger, quietness, weight/noise.

**Marking key:** Sparkling -> beauty; cracked -> danger; tiny whisper -> quietness; heavy boots -> weight/noise.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Improve setting language

**Type:** Editing

**Question:** Replace "nice forest" with a more vivid phrase.

**Marking key:** For example, "a cool forest filled with tall ferns."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Select character clue

**Type:** Hotspot / selection

**Question:** Text: "Ravi stepped back." Picture clues: wide eyes, open lunchbox, blue sky, green grass. Which clue extends Ravi's feeling?

**Marking key:** Wide eyes.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Explain combined effect

**Type:** Extended response

**Question:** How can words and illustrations work together to make a storm scene feel dangerous?

**Marking key:** Words can describe sound/action; images can show dark clouds, bent trees or worried faces.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Event changes setting

**Type:** Short response

**Question:** A quiet classroom becomes noisy after a surprise announcement. Name one word the author could use to show the change.

**Marking key:** For example, burst, buzzed, erupted, chatter.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose image support

**Type:** Multiple choice

**Question:** Which illustration best supports "the path disappeared": a clear signpost, thick fog over a track, or a neat map?

**Marking key:** Thick fog over a track.

**Coverage:** Assesses the code through an applied Year 3 English task.
