# AC9E3LA02 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises evaluation language in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose the stronger opinion

**Type:** Multiple choice

**Question:** Which sentence is strongest: "The game might be fair"; "The game is definitely fair"; or "The game could be fair"?

**Marking key:** "The game is definitely fair" is strongest.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Sort forceful and gentle language

**Type:** Sorting

**Question:** Sort these words into gentle or forceful: might, must, could, absolutely.

**Marking key:** Gentle: might, could. Forceful: must, absolutely.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Make it less forceful

**Type:** Editing

**Question:** Rewrite "Everyone must agree that the ending is terrible" so it sounds less forceful.

**Marking key:** A suitable softer version, such as "Some readers might think the ending is disappointing."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Add feeling language

**Type:** Short response

**Question:** Add one emotion word to improve this sentence: "I felt ___ when the lost dog came home."

**Marking key:** Any sensible emotion word, such as relieved, excited or happy.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Modal verb meaning

**Type:** Multiple choice

**Question:** In "We should recycle the paper", what does should show: possibility, advice or past time?

**Marking key:** Advice.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Make the recommendation stronger

**Type:** Editing

**Question:** Change "Students could bring a hat" to give stronger advice for a hot day.

**Marking key:** For example, "Students should bring a hat" or "Students must bring a hat."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain the change

**Type:** Extended response

**Question:** Explain how changing "might" to "must" changes the meaning of a school rule.

**Marking key:** "Must" makes the rule compulsory; "might" only suggests possibility.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose a fair review word

**Type:** Short response

**Question:** A book has exciting parts but a confusing ending. Write one balanced review sentence.

**Marking key:** A balanced sentence that includes both ideas.

**Coverage:** Assesses the code through an applied Year 3 English task.
