# AC9E3LY09 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises phoneme-grapheme knowledge in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose grapheme

**Type:** Multiple choice

**Question:** Which letters can represent the /ai/ sound in rain: ai, sh or oo?

**Marking key:** ai.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Segment sounds

**Type:** Short response

**Question:** How many phonemes are in ship: /sh/ /i/ /p/?

**Marking key:** 3 phonemes.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match sound spelling

**Type:** Matching

**Question:** Match sound to word: /ee/ in tree, /igh/ in night, /oa/ in boat, /ch/ in chair.

**Marking key:** tree -> ee; night -> igh; boat -> oa; chair -> ch.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Long a spellings

**Type:** Sorting

**Question:** Sort words with long /a/: rain, cake, cat, play.

**Marking key:** rain, cake, play.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Blend word parts

**Type:** Short response

**Question:** Blend: s-t-r-ee-t.

**Marking key:** street.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Choose decoded word

**Type:** Multiple choice

**Question:** Which word has three syllables: banana, cat, train?

**Marking key:** banana.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain decoding strategy

**Type:** Extended response

**Question:** What can you do when a long word is hard to read?

**Marking key:** Break into syllables/morphemes, blend sounds, check meaning.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Find less common pattern

**Type:** Short response

**Question:** In "phone", which letters make the /f/ sound?

**Marking key:** ph.

**Coverage:** Assesses the code through an applied Year 3 English task.
