# AC9E3LY12 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises high-frequency words and homophones in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose homophone

**Type:** Multiple choice

**Question:** Choose the correct word: "Their/There/They're books are on the desk."

**Marking key:** Their.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Fix high-frequency word

**Type:** Editing

**Question:** Correct: "I sed we could go."

**Marking key:** "I said we could go."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match homophone meaning

**Type:** Matching

**Question:** Match to, two, too to: number 2, also, direction.

**Marking key:** two -> number 2; too -> also; to -> direction.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Use there

**Type:** Short response

**Question:** Write a sentence using "there" to show place.

**Marking key:** A sentence using there as place.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Homophone or not

**Type:** Sorting

**Question:** Sort: hear/here, blue/blew, cat/cut, sun/son.

**Marking key:** Homophones: hear/here, blue/blew, sun/son. Not: cat/cut.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Choose correct word

**Type:** Editing

**Question:** Fix: "They're dog is friendly."

**Marking key:** "Their dog is friendly."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain checking

**Type:** Extended response

**Question:** How can reading the whole sentence help you choose a homophone?

**Marking key:** Meaning/context tells which spelling is needed.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose correct sentence

**Type:** Multiple choice

**Question:** Which is correct: "I went too school"; "I went to school"; "I went two school"?

**Marking key:** "I went to school."

**Coverage:** Assesses the code through an applied Year 3 English task.
