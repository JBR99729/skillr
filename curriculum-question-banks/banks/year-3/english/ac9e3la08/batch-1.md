# AC9E3LA08 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises tense in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Sort tense

**Type:** Sorting

**Question:** Sort these verbs as past, present or future: jumped, jumps, will jump, is jumping.

**Marking key:** Past: jumped. Present: jumps, is jumping. Future: will jump.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Fix tense consistency

**Type:** Editing

**Question:** Fix the tense: "Yesterday we walk to the creek and found tadpoles."

**Marking key:** "Yesterday we walked to the creek and found tadpoles."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Choose future tense

**Type:** Multiple choice

**Question:** Which sentence is future tense: "I planted seeds"; "I plant seeds"; "I will plant seeds"?

**Marking key:** "I will plant seeds."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Change to past tense

**Type:** Short response

**Question:** Change "The class observes the clouds" to past tense.

**Marking key:** "The class observed the clouds."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Match time words to tense

**Type:** Matching

**Question:** Match yesterday, today and tomorrow to past, present and future.

**Marking key:** Yesterday -> past; today -> present; tomorrow -> future.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Choose the correct verb

**Type:** Editing

**Question:** Choose: "Last week the team choose/chose a leader."

**Marking key:** chose.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain tense clue

**Type:** Extended response

**Question:** Explain how "will" changes the time in "The bird will return".

**Marking key:** It shows the action has not happened yet; it is future.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Write three tenses

**Type:** Short response

**Question:** Write past, present and future forms of "play" in short sentences.

**Marking key:** Played, plays/is playing, will play in suitable sentences.

**Coverage:** Assesses the code through an applied Year 3 English task.
