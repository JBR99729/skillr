# AC9E3LE05 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises creating imaginative texts in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Plan a simple plot

**Type:** Sequencing

**Question:** Order: problem appears, introduce character and setting, character tries a solution, ending shows result.

**Marking key:** Introduce character/setting; problem; solution attempt; ending.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Create a character detail

**Type:** Short response

**Question:** Write one detail that makes a character more interesting than "a boy".

**Marking key:** A specific trait, goal, habit or description.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Improve a boring opening

**Type:** Editing

**Question:** Improve: "There was a cave." Add setting detail.

**Marking key:** Any vivid cave opening with sensory detail.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Choose a story problem

**Type:** Multiple choice

**Question:** Which creates the clearest story problem: "Everything was normal"; "The map blew into the river"; or "The bag was blue"?

**Marking key:** "The map blew into the river."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Borrow a structure

**Type:** Short response

**Question:** A story you read has a lost object and a helpful friend. Write a new idea using that structure, not the same characters.

**Marking key:** A new story idea with lost object/helper structure.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Edit for reader interest

**Type:** Extended response

**Question:** Explain two changes you would make to improve a draft story with no setting detail and no clear ending.

**Marking key:** Add setting details and a clear/resolved ending, with explanation.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Match feature to purpose

**Type:** Matching

**Question:** Match dialogue, setting detail, problem, ending to: shows speech, helps imagine place, creates tension, resolves story.

**Marking key:** Dialogue -> speech; setting -> place; problem -> tension; ending -> resolves.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Write dialogue

**Type:** Short response

**Question:** Write one line of dialogue a character might say after finding a mysterious key.

**Marking key:** A suitable dialogue line.

**Coverage:** Assesses the code through an applied Year 3 English task.
