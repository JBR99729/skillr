# AC9E3LE04 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises literary devices in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Find onomatopoeia

**Type:** Multiple choice

**Question:** Which word is onomatopoeia: splash, beautiful, slowly?

**Marking key:** splash.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Rhythm effect

**Type:** Short response

**Question:** Why might a poem use repeated beats?

**Marking key:** To create rhythm, movement, emphasis or make it enjoyable to hear.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match sound word

**Type:** Matching

**Question:** Match buzz, crash, whisper and pop to bee, thunder, secret voice and balloon.

**Marking key:** buzz -> bee; crash -> thunder; whisper -> secret voice; pop -> balloon.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Add sound

**Type:** Editing

**Question:** Add one onomatopoeia word to: "The rain ___ on the tin roof."

**Marking key:** For example, pattered, drummed, splashed.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Reader reaction

**Type:** Short response

**Question:** How does "crack!" make a branch breaking more exciting than "broke"?

**Marking key:** It imitates the sound and makes the moment feel sudden.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Device or ordinary description

**Type:** Sorting

**Question:** Sort: bang, silky leaves, tick-tock, the green door.

**Marking key:** Sound devices: bang, tick-tock. Descriptions: silky leaves, green door.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain device choice

**Type:** Extended response

**Question:** A poet writes "clip-clop, clip-clop" in a horse poem. Explain the effect.

**Marking key:** It imitates hoof sounds and creates rhythm/movement.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose best sound for mood

**Type:** Multiple choice

**Question:** Which sound word suits a quiet night: boom, hush or clang?

**Marking key:** hush.

**Coverage:** Assesses the code through an applied Year 3 English task.
