# AC9E3LY11 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises spelling patterns in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose spelling

**Type:** Multiple choice

**Question:** Which spelling is correct: becos, because, becawse?

**Marking key:** because.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Less common pattern

**Type:** Short response

**Question:** Which letters make /n/ in "knee"?

**Marking key:** kn.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match pattern to word

**Type:** Matching

**Question:** Match wr, gn, ph, eigh to write, gnome, phone, eight.

**Marking key:** wr -> write; gn -> gnome; ph -> phone; eigh -> eight.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Pattern groups

**Type:** Sorting

**Question:** Sort: light, phone, night, graph.

**Marking key:** igh: light, night. ph: phone, graph.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Fix spelling

**Type:** Editing

**Question:** Correct the spelling: "The nife is sharp."

**Marking key:** "The knife is sharp."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Spell from sounds

**Type:** Short response

**Question:** Spell the word with sounds /f/ /o/ /n/ that uses ph.

**Marking key:** phone.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Choose a spelling strategy

**Type:** Extended response

**Question:** How could you learn to spell "through"?

**Marking key:** Use chunking, look-say-cover-write-check, known pattern, word wall or memory cue.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose silent-letter word

**Type:** Multiple choice

**Question:** Which word has a silent letter: map, knee, sun?

**Marking key:** knee.

**Coverage:** Assesses the code through an applied Year 3 English task.
