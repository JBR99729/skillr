# AC9E3LE01 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises characters, events and settings in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match story part

**Type:** Matching

**Question:** Match: character, event, setting, context. Examples: old forest, flood, brave child, another country.

**Marking key:** Character -> brave child; event -> flood; setting -> old forest; context -> another country.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Compare settings

**Type:** Short response

**Question:** How might a beach setting change a story compared with a snowy mountain setting?

**Marking key:** A sensible comparison of weather, activities, danger or mood.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Choose cultural clue

**Type:** Multiple choice

**Question:** Which detail gives context: "the character wore a school hat"; "the story happens during a local festival"; or "the page is blue"?

**Marking key:** The story happens during a local festival.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Character evidence

**Type:** Short response

**Question:** A character shares food with a stranger. What trait might this show?

**Marking key:** Kind, generous or caring, with evidence.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Sort event or setting

**Type:** Sorting

**Question:** Sort: cave, storm arrives, city street, family moves house.

**Marking key:** Settings: cave, city street. Events: storm arrives, family moves house.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Discuss context

**Type:** Extended response

**Question:** Explain how knowing a story is set long ago might change how you understand the characters' choices.

**Marking key:** It may explain different transport, rules, jobs, clothing or beliefs.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Connect event and character

**Type:** Short response

**Question:** A character gets lost in the bush. Name one decision the character might need to make.

**Marking key:** Any relevant decision, such as stay still, look for a track, call for help.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Compare two characters

**Type:** Extended response

**Question:** Two stories have helpers: one helps quietly, one wants praise. Compare the characters using evidence.

**Marking key:** A comparison that uses both behaviours as evidence.

**Coverage:** Assesses the code through an applied Year 3 English task.
