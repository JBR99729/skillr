# AC9E3LY04 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises reading fluency and self-correction in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Choose self-correction

**Type:** Multiple choice

**Question:** A sentence reads "The horse galloped across the paddock." If you read "garden" instead of "paddock", what should you do?

**Marking key:** Reread and check the letters and meaning.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Use context

**Type:** Short response

**Question:** In "The chef stirred the soup with a ladle", what clue helps you understand ladle?

**Marking key:** Chef, soup and stirred suggest it is a kitchen tool/spoon.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match strategy to problem

**Type:** Matching

**Question:** Match: sound it out, reread, use meaning, check grammar to unknown word, lost meaning, odd word, sentence sounds wrong.

**Marking key:** Sound it out -> unknown word; reread -> lost meaning; use meaning -> odd word; check grammar -> sentence sounds wrong.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Fix misread sentence

**Type:** Editing

**Question:** The text says "The boat drifted slowly." A reader says "The boat drove slowly." Which word should they check?

**Marking key:** drifted.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Blend syllables

**Type:** Short response

**Question:** Read by parts: in-vest-i-gate. What is the word?

**Marking key:** investigate.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Choose fluent reading

**Type:** Multiple choice

**Question:** Which is most fluent: word-by-word with no expression, smooth reading in phrases, or guessing every second word?

**Marking key:** Smooth reading in phrases.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain rereading

**Type:** Extended response

**Question:** Why can rereading help when a sentence does not make sense?

**Marking key:** It lets the reader check words, grammar and meaning.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Use grammar

**Type:** Short response

**Question:** Which word fits: "The birds ___ loudly" - sings or sing?

**Marking key:** sing.

**Coverage:** Assesses the code through an applied Year 3 English task.
