# AC9E3LA06 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises clauses and agreement in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Find the complete clause

**Type:** Multiple choice

**Question:** Which is a clause: "the noisy birds"; "The birds sing"; or "under the tree"?

**Marking key:** "The birds sing."

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Fix subject-verb agreement

**Type:** Editing

**Question:** Fix the sentence: "The dogs runs across the oval."

**Marking key:** "The dogs run across the oval."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match subject to verb

**Type:** Matching

**Question:** Match subjects to verbs: The child / The children / My friend / The birds. Verbs: plays, play, laughs, fly.

**Marking key:** The child plays; The children play; My friend laughs; The birds fly.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Add a verb

**Type:** Short response

**Question:** Complete the clause: "The red kite ___ above the park."

**Marking key:** A suitable verb, such as flies or floated depending tense.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Clause or phrase

**Type:** Sorting

**Question:** Sort: "after lunch"; "Mum cooked"; "the small shell"; "Rain fell".

**Marking key:** Clauses: Mum cooked; Rain fell. Phrases: after lunch; the small shell.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Make the clause agree

**Type:** Editing

**Question:** Choose the correct verb: "The box of pencils is/are on the desk."

**Marking key:** is.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain agreement

**Type:** Extended response

**Question:** Explain why "The team are winning" may sound different from "The teams are winning".

**Marking key:** "Team" is singular in this Year 3 sentence; "teams" is plural.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Write a clause

**Type:** Short response

**Question:** Write one clause about a scientist observing rocks.

**Marking key:** A sentence/clause with subject and verb, such as "The scientist observes rocks."

**Coverage:** Assesses the code through an applied Year 3 English task.
