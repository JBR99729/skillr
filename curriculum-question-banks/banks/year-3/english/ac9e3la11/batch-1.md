# AC9E3LA11 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises apostrophes in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Contraction meaning

**Type:** Multiple choice

**Question:** What does "didn't" mean: did not, did it, or do not?

**Marking key:** did not.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Add contraction apostrophe

**Type:** Editing

**Question:** Rewrite "do not" as a contraction.

**Marking key:** don't.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Singular possession

**Type:** Short response

**Question:** Rewrite to show one girl owns the hat: "the hat of the girl".

**Marking key:** the girl's hat.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Plural possession

**Type:** Short response

**Question:** Rewrite to show many students own the projects: "the projects of the students".

**Marking key:** the students' projects.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Contraction or possession

**Type:** Sorting

**Question:** Sort: can't, teacher's desk, they're, dogs' bowls.

**Marking key:** Contractions: can't, they're. Possession: teacher's desk, dogs' bowls.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Fix the apostrophe

**Type:** Editing

**Question:** Fix: "The cats toy is under the sofa" for one cat.

**Marking key:** "The cat's toy is under the sofa."

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain apostrophe difference

**Type:** Extended response

**Question:** Explain the difference between "the dog's lead" and "the dogs' leads".

**Marking key:** One dog owns a lead; more than one dog owns leads.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose correct sentence

**Type:** Multiple choice

**Question:** Which is correct: "Its raining"; "It's raining"; "Its' raining"?

**Marking key:** "It's raining."

**Coverage:** Assesses the code through an applied Year 3 English task.
