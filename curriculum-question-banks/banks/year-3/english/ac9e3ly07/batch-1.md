# AC9E3LY07 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises oral presentations in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Presentation structure

**Type:** Sequencing

**Question:** Order: greeting/topic, main points, conclusion, audience question time.

**Marking key:** Greeting/topic; main points; conclusion; questions.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Clear opening

**Type:** Short response

**Question:** Write an opening sentence for a short talk about saving water at school.

**Marking key:** A clear topic-opening sentence.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Best speaking behaviour

**Type:** Multiple choice

**Question:** Which helps an audience: mumbling, clear voice, facing away?

**Marking key:** Clear voice.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Verbal or non-verbal

**Type:** Sorting

**Question:** Sort: eye contact, pace, volume, gesture.

**Marking key:** Verbal/vocal: pace, volume. Non-verbal: eye contact, gesture.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Improve slide text

**Type:** Editing

**Question:** A slide has a full paragraph in tiny print. Suggest one improvement.

**Marking key:** Use fewer key words, larger text or supportive image.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Rehearsal goal

**Type:** Short response

**Question:** Name one thing to practise before presenting.

**Marking key:** Voice, pace, timing, order, eye contact or using notes.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Use multimodal support

**Type:** Extended response

**Question:** Explain how one image or prop could help a talk about rocks.

**Marking key:** It gives visual evidence and helps the audience understand the object/features.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Conclusion purpose

**Type:** Multiple choice

**Question:** What should a conclusion do: introduce a new unrelated topic, finish the main idea, or hide the message?

**Marking key:** Finish the main idea.

**Coverage:** Assesses the code through an applied Year 3 English task.
