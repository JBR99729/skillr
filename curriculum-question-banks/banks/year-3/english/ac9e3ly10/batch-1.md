# AC9E3LY10 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises base words and affixes in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Match prefix meaning

**Type:** Matching

**Question:** Match un-, re-, pre-, mis- to not, again, before, wrongly.

**Marking key:** un -> not; re -> again; pre -> before; mis -> wrongly.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Find base word

**Type:** Short response

**Question:** What is the base word in "replaying"?

**Marking key:** play.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Suffix meaning

**Type:** Multiple choice

**Question:** Which word means full of hope: hopeless, hopeful or hoping?

**Marking key:** hopeful.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Add suffix

**Type:** Editing

**Question:** Add -ed to "hop" correctly.

**Marking key:** hopped.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Prefix or suffix

**Type:** Sorting

**Question:** Sort: unhappy, teacher, replay, careful.

**Marking key:** Prefixes: unhappy, replay. Suffixes: teacher, careful.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Change meaning

**Type:** Short response

**Question:** How does un- change the word "kind"?

**Marking key:** It means not kind.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain spelling change

**Type:** Extended response

**Question:** Why does "make" become "making" without the e?

**Marking key:** Usually drop final e before adding -ing.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose word family

**Type:** Multiple choice

**Question:** Which belongs with sign: signal, design, sandwich?

**Marking key:** signal or design; both share sign meaning/spelling connection if accepted with explanation.

**Coverage:** Assesses the code through an applied Year 3 English task.
