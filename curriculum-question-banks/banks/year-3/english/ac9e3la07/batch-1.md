# AC9E3LA07 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises verb processes in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Sort verbs by process

**Type:** Sorting

**Question:** Sort verbs into doing, feeling, thinking or saying: climb, wonder, whisper, love.

**Marking key:** Doing: climb; thinking: wonder; saying: whisper; feeling: love.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Choose a saying verb

**Type:** Multiple choice

**Question:** Which is a saying verb: replied, carried or believed?

**Marking key:** replied.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Replace a weak verb

**Type:** Editing

**Question:** Replace "went" with a stronger doing verb: "The athlete went across the track."

**Marking key:** For example, sprinted, jogged or raced.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Find the thinking verb

**Type:** Short response

**Question:** In "Ari wondered why the moon looked bigger", which verb shows thinking?

**Marking key:** wondered.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Match verb to evidence

**Type:** Matching

**Question:** Match: felt, measured, asked, knew. Labels: feeling, doing, saying, thinking.

**Marking key:** felt -> feeling; measured -> doing; asked -> saying; knew -> thinking.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Add a relating verb

**Type:** Short response

**Question:** Complete: "The shells ___ smooth and shiny."

**Marking key:** are, were, seem or another suitable relating verb.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Explain verb choice

**Type:** Extended response

**Question:** Why is "whispered" more precise than "said" in a secret scene?

**Marking key:** It shows the manner/quiet voice and helps the reader imagine the scene.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose the best verb

**Type:** Editing

**Question:** Choose the best verb: "The puppy smelled/snored the hidden biscuit under the chair."

**Marking key:** smelled.

**Coverage:** Assesses the code through an applied Year 3 English task.
