# AC9E3LA09 - Pass 1 question bank

## 60-second Quick Read

- **Key idea:** This unit practises images extending meaning in real reading, writing, speaking and viewing situations.
- **Use evidence:** Check the exact words, image clues, audience and purpose before choosing an answer.
- **Explain your choice:** A strong Year 3 answer usually gives the answer plus a short reason from the text.
- **Common trap:** Do not guess from one word only; reread the whole sentence or visual context.

## Practice questions

## Tier 1 - Knowledge and terms

### P01 - Use picture evidence

**Type:** Multiple choice

**Question:** A story page says "The camp was quiet." The picture shows dark clouds and a broken tent. What extra meaning does the image add?

**Marking key:** It suggests trouble or worry at the camp.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P02 - Caption inference

**Type:** Short response

**Question:** A photo shows a child holding a trophy while classmates clap. What can you infer that the words "The race ended" do not say?

**Marking key:** The child likely won or did well and others are celebrating.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 2 - Core skill practice

### P03 - Match image feature to meaning

**Type:** Matching

**Question:** Match: close-up face, dark colours, map, arrows. Meanings: emotion, mood, place, movement.

**Marking key:** Face -> emotion; dark colours -> mood; map -> place; arrows -> movement.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P04 - Add image detail to text

**Type:** Editing

**Question:** Add one sentence that uses a picture of muddy shoes beside a door to extend a story.

**Marking key:** Any sentence using the muddy-shoe clue.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 3 - Guided application

### P05 - Select the clue

**Type:** Hotspot / selection

**Question:** Text: "Mina smiled." Picture clues: clenched fists, bright eyes, torn homework, sunny window. Select the clue that best supports happiness.

**Marking key:** Bright eyes.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P06 - Explain a diagram

**Type:** Short response

**Question:** How can a labelled diagram extend an information text about a frog life cycle?

**Marking key:** It shows stages/parts visually that the words may not fully explain.

**Coverage:** Assesses the code through an applied Year 3 English task.

## Tier 4 - Problem solving and reasoning

### P07 - Image changes reaction

**Type:** Extended response

**Question:** Explain how a picture of a lonely character sitting apart can change how readers feel about a cheerful sentence.

**Marking key:** It can create contrast and suggest the character may not truly feel cheerful.

**Coverage:** Assesses the code through an applied Year 3 English task.

### P08 - Choose image for purpose

**Type:** Multiple choice

**Question:** Which image best supports a safety poster about crossing roads: a decorative rainbow, a child using a crossing, or a lunch box?

**Marking key:** A child using a crossing.

**Coverage:** Assesses the code through an applied Year 3 English task.
