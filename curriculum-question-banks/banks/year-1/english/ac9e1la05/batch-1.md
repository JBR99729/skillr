# AC9E1LA05 — Pass 1 question bank

## 60-second Quick Read

- **Rule:** Text features help readers find, predict and move through information. Print often uses contents, headings and page numbers; screens also use buttons, links, swipes or voice controls.
- **Worked example:** A contents entry ‘Habitats — page 6’ tells the reader to turn to page 6; a labelled Home button returns to the main screen.
- **Reading strategy:** Use the title for the overall topic, headings for sections, page numbers for location and images/labels for extra meaning.
- **Visual interaction:** Use mock pages and safe non-clicking screen cards with keyboard-focus labels and paper navigation choices.
- **Common trap:** An image can support meaning, but it does not replace reading labels, headings or link text.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Use a page number

**Type:** Short response

**Question:** A contents page says ‘Weather — page 8’. Where should the reader turn?

**Marking key:** Page 8 (1 mark).

**Coverage:** Using a contents entry and page number.

### P02 — Match features and jobs

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match title, heading and Home button to names whole text, names section and returns to main screen.

**Marking key:** Title ↔ whole text; heading ↔ section; Home ↔ main screen (1 mark each).

**Coverage:** Connecting organisational features with functions.

## Tier 2 — Core skill practice

### P03 — Navigate a mock book

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Using the provided contents page, demonstrate how to find ‘Animal homes’ and state the page number used.

**Marking key:** Finds correct contents entry and turns/selects the matching page (2 marks).

**Coverage:** Using print navigation features.

### P04 — Choose a screen control

**Type:** Short response

**Question:** A reader wants the next page of a digital story. Name one suitable labelled control or gesture.

**Marking key:** Next button, right arrow, swipe as instructed or suitable voice command (1 mark).

**Coverage:** Recognising screen navigation methods.

## Tier 3 — Guided application

### P05 — Order print navigation

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: scan contents; open book; find topic title; turn to listed page.

**Marking key:** Open book → scan contents → find topic → turn to listed page (2 marks).

**Coverage:** Sequencing navigation in a print information text.

### P06 — Draw a useful page

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw an information page with title, heading, page number and labelled image.

**Marking key:** Includes all four features placed so their roles are clear (3 marks).

**Coverage:** Representing print-text organisation.

## Tier 4 — Problem solving and reasoning

### P07 — Explain heading value

**Type:** Short response

**Question:** Why is the heading ‘What frogs eat’ more useful than the heading ‘Things’?

**Marking key:** It names the section topic precisely, helping readers predict and locate information (2 marks).

**Coverage:** Evaluating informative heading wording.

### P08 — Compare print and screen

**Type:** Extended response

**Question:** State one feature shared by print and screen texts and one feature mainly used for screen navigation.

**Marking key:** Shared example title/image/heading; screen example button/link/swipe/voice command (2 marks).

**Coverage:** Comparing organisational features across modes.

## Exam questions

## Section A — Core knowledge

### E01 — Follow a link label

**Type:** Short response

**Question:** A safe mock screen has links ‘Food’, ‘Habitat’ and ‘Games’. Which link best finds where an animal lives?

**Marking key:** Habitat (1 mark).

**Coverage:** Selecting a descriptive navigation link.

### E02 — Match print and digital tools

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match contents page, underlined descriptive link and back arrow to locate print section, open linked screen and return to previous screen.

**Marking key:** Each feature matches its navigation function (1 mark each).

**Coverage:** Interpreting multimodal navigation controls.

### E03 — Sequence voice navigation

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: say approved command; hear/read response; open accessible reading app; check correct page appears.

**Marking key:** Open app → say command → hear/read response → check page (2 marks).

**Coverage:** Sequencing a verbal navigation interaction.

## Section B — Application and problem solving

### E04 — Find a missing feature

**Type:** Short response

**Question:** A five-page booklet has no page numbers, but its contents lists page numbers. Explain the problem and fix.

**Marking key:** Reader cannot match entries to pages; add clear page numbers consistently (2 marks).

**Coverage:** Diagnosing inconsistency in text organisation.

### E05 — Demonstrate two routes

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** On a mock screen, show one way to reach the glossary using a menu and another using a descriptive link.

**Marking key:** Completes two valid labelled routes without relying on icon appearance alone (3 marks).

**Coverage:** Using alternative screen navigation paths.

### E06 — Draw accessible controls

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw Back, Home and Next controls with words and simple arrows. Explain why words help.

**Marking key:** Three correctly labelled controls; words clarify icon meaning for readers/users (3 marks).

**Coverage:** Designing clear multimodal navigation.

## Section C — Extended response and analysis

### E07 — Correct an unclear link

**Type:** Extended response

**Question:** A link says ‘Click here’. Rewrite it for a page about insect life cycles and explain the improvement.

**Marking key:** Example ‘Read about insect life cycles’; descriptive text predicts destination and supports navigation/accessibility (3 marks).

**Coverage:** Revising vague link text.

### E08 — Plan a hybrid text

**Type:** Extended response

**Question:** Plan a four-section animal guide that works in print and on screen. Include titles/headings, page or screen location features, images and two navigation methods.

**Marking key:** Logical sections and named features for both modes, with clear image roles and two usable navigation methods (5 marks).

**Coverage:** Applying organisational features across print and digital texts.
