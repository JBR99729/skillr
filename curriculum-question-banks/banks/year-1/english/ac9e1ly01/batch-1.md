# AC9E1LY01 — Pass 1 question bank

## 60-second Quick Read

- **Rule:** A text is made for a purpose such as to entertain, inform, instruct, invite or persuade. Its words, layout and images give clues to that purpose.
- **Worked example:** ‘Plant the seed. Add water. Place it near light’ uses command verbs and ordered steps, showing an instructional purpose.
- **Purpose clues:** Stories have characters and events; reports group facts; instructions use steps; invitations give event details; persuasive texts state a desired choice and reasons.
- **Visual interaction:** Use original mock text cards with title, layout and image descriptions for spoken, tap, keyboard and paper sorting.
- **Common trap:** A text may be enjoyable and informative, but identify the main job its features are designed to do.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Identify instruction purpose

**Type:** Short response

**Question:** A card says ‘Cut on the line. Fold the paper. Tape the sides.’ What is its purpose?

**Marking key:** To instruct/show how to make something (1 mark).

**Coverage:** Using command steps to identify purpose.

### P02 — Match features and purposes

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match character/problem, labelled facts and date-time-place to entertain, inform and invite.

**Marking key:** Story features ↔ entertain; labelled facts ↔ inform; event details ↔ invite (1 mark each).

**Coverage:** Connecting text features with purposes.

## Tier 2 — Core skill practice

### P03 — Discuss a warning sign

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Explain how the words ‘Wet floor—walk slowly’ and a slipping-person image support the text's purpose.

**Marking key:** Words give safe action; image quickly shows hazard; both warn/instruct (3 marks).

**Coverage:** Discussing multimodal clues to purpose.

### P04 — Find a persuasive feature

**Type:** Short response

**Question:** ‘Choose the reusable bottle because it can be filled again.’ Name one feature showing persuasion.

**Marking key:** It recommends a choice and gives a supporting reason (2 marks).

**Coverage:** Recognising viewpoint-and-reason structure.

## Tier 3 — Guided application

### P05 — Order an invitation

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: event name; greeting; date/time/place; friendly closing.

**Marking key:** Greeting/event name → event details → closing; accepts event name before greeting if clear (2 marks).

**Coverage:** Sequencing features of an invitation.

### P06 — Draw a report feature

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw a small information page about ants with a title, fact heading and labelled image.

**Marking key:** All three features present and suited to informing readers (3 marks).

**Coverage:** Representing features of an informative text.

## Tier 4 — Problem solving and reasoning

### P07 — Compare two purposes

**Type:** Short response

**Question:** A recipe and a food advertisement both show soup. Explain one feature that reveals each main purpose.

**Marking key:** Recipe uses ingredients/steps to instruct; advertisement uses praise/reasons/call to choose to persuade (3 marks).

**Coverage:** Comparing purposes of texts on one topic.

### P08 — Choose evidence for purpose

**Type:** Extended response

**Question:** A text has numbered steps, command verbs and a materials list. State the likely purpose and cite two clues.

**Marking key:** Instructional purpose with any two named features as evidence (3 marks).

**Coverage:** Justifying purpose from multiple features.

## Exam questions

## Section A — Core knowledge

### E01 — Recognise an imaginative text

**Type:** Short response

**Question:** A talking moon helps a lost cloud return home. What main purpose and feature are likely?

**Marking key:** To entertain/tell an imaginative story; impossible/fantastical characters and plot events (2 marks).

**Coverage:** Identifying imaginative purpose from content features.

### E02 — Match text openings

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match ‘Once a tiny boat…’, ‘Koalas are mammals…’ and ‘Please join us…’ to story, report and invitation.

**Marking key:** Each opening matched correctly (1 mark each).

**Coverage:** Using opening language as a purpose clue.

### E03 — Sequence a how-to text

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: finish/result; title; materials; numbered actions.

**Marking key:** Title → materials → numbered actions → result (2 marks).

**Coverage:** Organising text features for instruction.

## Section B — Application and problem solving

### E04 — Explain a missing detail

**Type:** Short response

**Question:** An invitation says ‘Come to my party!’ but gives no date or place. Why does it not yet meet its purpose?

**Marking key:** Readers cannot know when/where to attend; date/time/place must be added (2 marks).

**Coverage:** Evaluating whether features fulfil text purpose.

### E05 — Demonstrate alternate reading

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Read a weather report sentence and a weather warning sentence with suitable voice. Explain how purpose changes delivery.

**Marking key:** Report sounds clear/neutral; warning is urgent/emphatic, with accurate purpose explanation (3 marks).

**Coverage:** Adapting oral delivery to text purpose.

### E06 — Draw two layouts

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw a story page and a procedure page. Label two layout differences.

**Marking key:** Story layout supports narrative/image; procedure uses title/steps/numbers or materials, with two contrasts labelled (4 marks).

**Coverage:** Comparing layout features across purposes.

## Section C — Extended response and analysis

### E07 — Correct a feature mismatch

**Type:** Extended response

**Question:** A fire-safety instruction page hides its action in a long fantasy story with no heading. Suggest two changes.

**Marking key:** Adds clear safety heading and direct ordered actions/visual labels; any two purpose-suited changes (3 marks).

**Coverage:** Revising features to make purpose clear.

### E08 — Analyse a mixed text

**Type:** Extended response

**Question:** A zoo page has a map, animal facts, a ticket button and ‘Visit today!’ Explain two purposes and the features serving each, then identify the likely overall purpose.

**Marking key:** Inform/navigate via map/facts; persuade/action via visit/button; overall choice justified from emphasis (6 marks).

**Coverage:** Discussing multiple purposes within one multimodal text.
