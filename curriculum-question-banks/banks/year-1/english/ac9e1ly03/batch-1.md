# AC9E1LY03 — Pass 1 question bank

## 60-second Quick Read

- **Rule:** Imaginative texts create characters and events; informative texts explain or report facts; persuasive texts try to influence a choice. All can use words, images, titles and topic vocabulary.
- **Worked example:** On the topic of bees: a bee adventure is imaginative, a labelled life-cycle page is informative, and ‘Plant bee-friendly flowers’ with reasons is persuasive.
- **Comparison strategy:** Name a shared feature, then compare purpose, organisation, language and evidence.
- **Visual interaction:** Use original same-topic text cards and compare hoops/tables with tap, keyboard and paper alternatives.
- **Common trap:** Persuasive texts may include facts, but those facts are selected to support a viewpoint or action.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Identify an informative text

**Type:** Short response

**Question:** A page gives labelled facts about a turtle's body and habitat. Which text type is it mainly?

**Marking key:** Informative (1 mark).

**Coverage:** Recognising informative purpose and features.

### P02 — Match types and features

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match imaginative, informative and persuasive to character/plot, facts/headings and viewpoint/reasons.

**Marking key:** Each type matched correctly (1 mark each).

**Coverage:** Connecting text categories with typical features.

## Tier 2 — Core skill practice

### P03 — Sort same-topic cards

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Sort three short cards about rain into story event, weather facts and ‘carry an umbrella’ recommendation.

**Marking key:** Story ↔ imaginative; facts ↔ informative; recommendation/reason ↔ persuasive (3 marks).

**Coverage:** Classifying texts on a shared topic.

### P04 — State a similarity

**Type:** Short response

**Question:** Give one feature an imaginative and informative picture book might both use.

**Marking key:** Any valid shared feature such as title, images, words, pages, headings in some cases or topic vocabulary (1 mark).

**Coverage:** Recognising similarities across text types.

## Tier 3 — Guided application

### P05 — Order comparison thinking

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: identify purpose; notice shared topic/features; cite one difference; name each type.

**Marking key:** Name/identify types and purpose → note similarity → cite difference (2 marks; first steps may swap).

**Coverage:** Sequencing text comparison.

### P06 — Draw three covers

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw cover ideas for an imaginative, informative and persuasive text about water. Label one clue on each.

**Marking key:** Three distinct purpose clues: story character/event, factual heading/diagram and recommended action/reason (4 marks).

**Coverage:** Representing differences among text types.

## Tier 4 — Problem solving and reasoning

### P07 — Explain factual persuasion

**Type:** Short response

**Question:** A poster says ‘Refill your bottle to reduce waste’ and gives a waste fact. Why is it persuasive rather than only informative?

**Marking key:** It calls for a behaviour/choice and uses the fact as a reason (2 marks).

**Coverage:** Distinguishing persuasion that includes facts.

### P08 — Compare openings

**Type:** Extended response

**Question:** Write one imaginative and one informative opening about a storm. Explain the language difference.

**Marking key:** Imaginative opening creates character/event/mood; informative opening states topic/fact, with contrast explained (3 marks).

**Coverage:** Comparing language according to purpose.

## Exam questions

## Section A — Core knowledge

### E01 — Recognise persuasive wording

**Type:** Short response

**Question:** Which words show persuasion in ‘Choose the shaded path because it is cooler’?

**Marking key:** ‘Choose’ states desired action and ‘because it is cooler’ gives a reason (2 marks).

**Coverage:** Identifying persuasive language features.

### E02 — Match shared and unique features

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match title/images to shared, plot to mainly imaginative and recommendation to persuasive.

**Marking key:** All three matched correctly (1 mark each).

**Coverage:** Separating shared from type-specific features.

### E03 — Sequence a type decision

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: read whole text; notice purpose clues; decide main purpose; name type and evidence.

**Marking key:** Read → notice clues → decide purpose → name type/evidence (2 marks).

**Coverage:** Using evidence to classify text type.

## Section B — Application and problem solving

### E04 — Compare image use

**Type:** Short response

**Question:** How might a frog image differ in a story and a factual report?

**Marking key:** Story image develops character/event/mood; report image shows accurate features/labels (2 marks).

**Coverage:** Comparing multimodal features across text types.

### E05 — Demonstrate three voices

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Say one sentence about a playground as a storyteller, fact reporter and persuader.

**Marking key:** Three clearly different sentences suited to narrative, factual and opinion/action purposes (3 marks).

**Coverage:** Adapting oral language to text type.

### E06 — Draw a comparison table

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Create a table comparing purpose, one word clue and one image clue for all three text types.

**Marking key:** Nine suitable entries organised accurately (4 marks).

**Coverage:** Structuring a multi-feature comparison.

## Section C — Extended response and analysis

### E07 — Correct a type label

**Type:** Extended response

**Question:** A text says ‘You should adopt this pet because it is gentle’ and is labelled informative. Explain and correct.

**Marking key:** It is persuasive because it recommends action and supports it with a reason, though it may contain information (3 marks).

**Coverage:** Evaluating classification from language evidence.

### E08 — Analyse a blended page

**Type:** Extended response

**Question:** A museum page tells a short fictional dinosaur story, labels real fossil facts and asks readers to visit. Identify all three text types/purposes and one feature of each.

**Marking key:** Imaginative story/entertain; informative fossil facts/inform; persuasive invitation/call to visit, each with evidence (6 marks).

**Coverage:** Analysing multiple text types within a multimodal page.
