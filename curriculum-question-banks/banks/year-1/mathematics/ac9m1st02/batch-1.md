# AC9M1ST02 — Pass 1 question bank

## 60-second Quick Read

- **Key idea:** In a one-to-one display, each picture, object or mark represents exactly one response.
- **Method:** Label categories, place one symbol per response, align symbols so counts are easy, then compare frequencies.
- **Worked example:** If dog has 4 paw symbols and cat has 2, dog has 2 more responses because 4 − 2 = 2.
- **Visual model:** Use aligned object graphs and picture graphs with a clear key stating one symbol = one response.
- **Common trap:** Count symbols, not their size; every category must use the same one-to-one rule.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Read one-to-one symbols

**Type:** Short response

**Question:** A display has 5 apple pictures in the apple row. If one picture means one vote, how many votes are there?

**Marking key:** 5 votes (1 mark).

**Coverage:** Reading a one-to-one frequency.

### P02 — Match comparisons

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match cat 3/dog 6, red 4/blue 4 and bus 2/walk 5 to dog has 3 more, equal, and walk has 3 more.

**Marking key:** Cat/dog ↔ dog 3 more; red/blue ↔ equal; bus/walk ↔ walk 3 more (1 mark each).

**Coverage:** Comparing frequencies in one-to-one displays.

## Tier 2 — Core skill practice

### P03 — Build an object graph

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Use counters to show juice choices: orange 4, apple 2, water 5. Align one counter per vote.

**Marking key:** Correct labelled rows/columns with 4, 2 and 5 counters, one per response (3 marks).

**Coverage:** Constructing a one-to-one data display.

### P04 — Find most and least

**Type:** Short response

**Question:** A picture graph shows soccer 7, swimming 3 and cycling 5. Name the most and least frequent choices.

**Marking key:** Soccer most; swimming least (2 marks).

**Coverage:** Identifying extremes in categorical frequencies.

## Tier 3 — Guided application

### P05 — Order display steps

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: compare rows; label categories; place one symbol per response; check symbol total.

**Marking key:** Label → place symbols → check total → compare (2 marks).

**Coverage:** Sequencing construction and interpretation of a display.

### P06 — Draw a one-to-one graph

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw a display for pets: none 2, dog 4, cat 3. Include a key.

**Marking key:** Accurate labelled categories, 2/4/3 symbols, key one symbol = one response (4 marks).

**Coverage:** Representing collected data visually.

## Tier 4 — Problem solving and reasoning

### P07 — Calculate a difference

**Type:** Short response

**Question:** There are 8 sun symbols and 5 cloud symbols. How many more sunny days are shown?

**Marking key:** 3 more sunny days; 8 − 5 = 3 (2 marks).

**Coverage:** Comparing category frequencies by difference.

### P08 — Discuss what data supports

**Type:** Extended response

**Question:** A class graph shows blue 9 and green 6. Write one supported finding and one claim the graph cannot prove.

**Marking key:** Supported: blue has 3 more votes; unsupported example: everyone outside the class prefers blue (3 marks).

**Coverage:** Distinguishing evidence-based findings from overclaims.

## Exam questions

## Section A — Core knowledge

### E01 — Read a digital chart

**Type:** Short response

**Question:** A digital one-to-one chart lists library visits: Monday 4, Tuesday 6, Wednesday 6. State the highest frequency and any tie.

**Marking key:** Highest is 6; Tuesday and Wednesday tie (2 marks).

**Coverage:** Interpreting frequencies and ties.

### E02 — Match displays to totals

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match rows with 2, 5 and 7 symbols to frequencies two, five and seven.

**Marking key:** Each row matches its symbol count (1 mark each).

**Coverage:** Connecting displayed symbols with numeric frequency.

### E03 — Sequence categories by frequency

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order book choices from least to greatest: adventure 6, humour 3, animals 5.

**Marking key:** Humour 3, animals 5, adventure 6 (2 marks).

**Coverage:** Ordering categories using frequencies.

## Section B — Application and problem solving

### E04 — Compare combined responses

**Type:** Short response

**Question:** A display has 4 train, 3 bus and 2 walk choices. How many responses altogether, and how many more train than walk?

**Marking key:** 9 total; train has 2 more than walk (3 marks).

**Coverage:** Finding totals and differences from a display.

### E05 — Demonstrate a corrected graph

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** A graph row has overlapping tokens that hide one vote. Rebuild it so every token can be counted.

**Marking key:** Places one visible token per response in an aligned row and preserves the original total (2 marks).

**Coverage:** Improving readability without changing data.

### E06 — Draw from a tally table

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Tallies show mango 3, pear 1 and berry 4. Draw a one-to-one picture graph with a clear key.

**Marking key:** Correct 3/1/4 symbols, category labels and one-symbol-equals-one key (4 marks).

**Coverage:** Converting tally data to a one-to-one display.

## Section C — Extended response and analysis

### E07 — Audit a misleading key

**Type:** Extended response

**Question:** One row uses each star as one vote, but another uses each star as two votes without saying so. Explain why the comparison is unfair and fix it.

**Marking key:** Rows use inconsistent meanings; choose one shared key and redraw/recalculate all categories (3 marks).

**Coverage:** Evaluating consistency of a display key.

### E08 — Write a findings report

**Type:** Extended response

**Question:** For playground choices—slide 8, swings 5, climbing 5—state the total, most popular choice, tie and two valid comparisons.

**Marking key:** Total 18; slide most; swings/climbing tie; two accurate comparisons such as slide 3 more than either (5 marks).

**Coverage:** Summarising several evidence-based findings.
