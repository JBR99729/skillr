# AC9M1M02 — Pass 1 question bank

## 60-second Quick Read

- **Key idea:** A length measurement counts equal-sized units covering a distance from one end to the other.
- **Method:** Choose identical units, begin at the object's end, place units end-to-end with no gaps or overlaps, then count.
- **Worked example:** Six equal cubes fit along a pencil with no gaps, so the pencil is 6 cubes long.
- **Visual model:** Use cubes, paperclips or hand spans shown along a baseline; online units snap end-to-end with keyboard placement.
- **Common trap:** A mixed row of large and small units does not give a fair single-unit measurement.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — State a measured length

**Type:** Short response

**Question:** Eight equal tiles fit end-to-end along a book. What is the book's length in tiles?

**Marking key:** 8 tiles (1 mark).

**Coverage:** Reading a length in uniform informal units.

### P02 — Match errors and fixes

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match gap, overlap and mixed unit sizes to: move units together, separate units, and use one unit size.

**Marking key:** Gap ↔ move together; overlap ↔ separate; mixed sizes ↔ use one size (1 mark each).

**Coverage:** Recognising and correcting measurement errors.

## Tier 2 — Core skill practice

### P03 — Measure with cubes

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Measure the provided strip using equal cubes placed end-to-end and report the count.

**Marking key:** Uses identical cubes from one end with no gaps/overlaps and reports the correct count (3 marks).

**Coverage:** Demonstrating accurate informal-unit measurement.

### P04 — Explain different counts

**Type:** Short response

**Question:** The same desk is 9 hand spans for a child and 6 for an adult. Explain why.

**Marking key:** Adult hand spans are larger, so fewer cover the same length; the desk did not change (2 marks).

**Coverage:** Explaining how unit size affects the count.

## Tier 3 — Guided application

### P05 — Order the measuring steps

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: count the units; choose equal units; place them with no gaps from the start; state the unit name.

**Marking key:** Choose equal units → place from start with no gaps → count → state unit name (2 marks).

**Coverage:** Sequencing an accurate measuring process.

### P06 — Draw a fair measurement

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw five equal paperclips end-to-end along a line. Mark the start and finish.

**Marking key:** Five uniform units touch end-to-end and align with both endpoints (2 marks).

**Coverage:** Representing a valid informal measurement.

## Tier 4 — Problem solving and reasoning

### P07 — Find the measuring mistake

**Type:** Short response

**Question:** A student says a ribbon is 7 cubes long, but the first cube starts 2 cm before the ribbon. Explain and fix the error.

**Marking key:** Units must start at the ribbon endpoint; realign and recount (2 marks).

**Coverage:** Identifying endpoint misalignment.

### P08 — Choose the better unit

**Type:** Extended response

**Question:** Would identical popsticks or mixed classroom objects better measure a long shelf? Choose and justify.

**Marking key:** Identical popsticks; they are uniform and can repeat end-to-end, giving a comparable count (3 marks).

**Coverage:** Selecting a practical uniform informal unit.

## Exam questions

## Section A — Core knowledge

### E01 — Read a fresh unit row

**Type:** Short response

**Question:** A crayon is covered by 4 equal blocks with no gaps. Write the measurement correctly with a number and unit.

**Marking key:** 4 blocks (1 mark).

**Coverage:** Reporting a measurement with its informal unit.

### E02 — Match setups to validity

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match these setups to fair or unfair: identical tiles touching; paperclips with gaps; large and small blocks mixed.

**Marking key:** Identical touching tiles ↔ fair; gaps ↔ unfair; mixed sizes ↔ unfair (1 mark each).

**Coverage:** Judging measurement setups.

### E03 — Sequence a remeasurement

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** A row overlaps. Order the repair: remove the row; align first unit; place equal units touching; recount.

**Marking key:** Remove row → align first unit → place equal touching units → recount (2 marks).

**Coverage:** Correcting overlap through a complete remeasurement.

## Section B — Application and problem solving

### E04 — Compare using one unit

**Type:** Short response

**Question:** A marker is 5 cubes long and a glue stick is 7 cubes long using the same cubes. Which is longer and by how many units?

**Marking key:** Glue stick; 2 cubes longer (2 marks).

**Coverage:** Comparing measurements made with a common unit.

### E05 — Demonstrate two unit choices

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Measure one object with equal cubes and then equal paperclips. Report both counts and explain why they may differ.

**Marking key:** Both methods are accurate; counts and units are reported; differing unit sizes explain different counts (3 marks).

**Coverage:** Comparing measurements made with different informal units.

### E06 — Draw and diagnose

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw an unfair six-unit measurement containing one gap, then redraw it fairly.

**Marking key:** First drawing visibly has a gap; corrected row begins at the endpoint with six equal touching units (3 marks).

**Coverage:** Representing and repairing a measurement error.

## Section C — Extended response and analysis

### E07 — Evaluate two answers

**Type:** Extended response

**Question:** Zac reports a mat is 10 units long but does not name the unit. Priya reports 14 equal blocks. Explain which answer is more useful and what Zac must add.

**Marking key:** Priya's answer identifies the unit; Zac must name and describe a uniform unit and valid placement (3 marks).

**Coverage:** Evaluating completeness of measurement reports.

### E08 — Plan a fair class comparison

**Type:** Extended response

**Question:** Two groups will measure different tables. Write rules that let their results be compared fairly without rulers.

**Marking key:** Use the same-sized informal unit, align at endpoints, place end-to-end without gaps/overlaps, count and record unit name (4 marks).

**Coverage:** Planning consistent informal measurement across groups.
