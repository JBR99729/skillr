# AC9S1I04 — Pass 1 question bank

## 60-second Quick Read

- **Concept answer:** Sorting groups data by a clear rule; ordering arranges it along a scale or sequence. Tables and models make patterns easier to see.
- **Key vocabulary:** A category is a named group. A pattern is a repeated or regular feature; a model represents something so it can be examined.
- **Observable example:** Leaf lengths 3, 5, 4 and 5 cubes can be ordered 3, 4, 5, 5, revealing that 5 occurs most often.
- **Visual model:** Use labelled sorting hoops, movable rows, provided tables and physical block models with text and paper alternatives.
- **Common misconception:** A pattern must come from the data; arranging objects to look pretty does not prove a scientific pattern.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Name a sorting rule

**Type:** Short response

**Question:** Red, blue and green counters are grouped by colour. State the sorting rule.

**Marking key:** Colour (1 mark).

**Coverage:** Identifying the rule used to categorise data.

### P02 — Match representations

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match table, ordered line and physical model to rows/columns, least-to-greatest sequence and objects showing data.

**Marking key:** Each representation matches its defining format (1 mark each).

**Coverage:** Recognising common data representations.

## Tier 2 — Core skill practice

### P03 — Sort material samples

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Sort teacher-approved cards into flexible and rigid using the recorded bend observations.

**Marking key:** Uses evidence to place every card once and explains the rule (3 marks).

**Coverage:** Sorting observations by a material property.

### P04 — Order measurements

**Type:** Short response

**Question:** Order plant heights 6, 3, 8 and 5 cubes from shortest to tallest.

**Marking key:** 3, 5, 6, 8 cubes (1 mark).

**Coverage:** Ordering informal measurement data.

## Tier 3 — Guided application

### P05 — Sequence a table process

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order: enter each observation; read headings; check every item appears once; look for a pattern.

**Marking key:** Read headings → enter observations → check completeness → look for pattern (2 marks).

**Coverage:** Sequencing data organisation and analysis.

### P06 — Draw a physical model

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Draw towers representing 2, 4 and 6 rainy-day observations for three months. Label each tower.

**Marking key:** Accurate tower heights and three clear labels (3 marks).

**Coverage:** Representing frequency data with a physical-style model.

## Tier 4 — Problem solving and reasoning

### P07 — Describe a growing pattern

**Type:** Short response

**Question:** A model has towers 2, 4, 6 and 8 blocks high. Describe the pattern without inventing a cause.

**Marking key:** Tower height increases by 2 blocks each step; no unsupported cause stated (2 marks).

**Coverage:** Identifying a numerical pattern in a model.

### P08 — Choose a useful organisation

**Type:** Extended response

**Question:** For ten animal observations, choose sorting by body covering or ordering by observed length. Explain which answers a question about similarity.

**Marking key:** Sorting by body covering best shows similarity categories; reasoning connects organisation to the question (3 marks).

**Coverage:** Selecting data organisation for a purpose.

## Exam questions

## Section A — Core knowledge

### E01 — Read a provided table

**Type:** Short response

**Question:** A table records paper absorbs 5 drops, cloth 9 and plastic 0. Order materials from least to most absorbed.

**Marking key:** Plastic 0, paper 5, cloth 9 (2 marks).

**Coverage:** Ordering data from a table.

### E02 — Match categories and entries

**Type:** Matching

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students draw lines between matching entries.

**Question:** Match floats, sinks and unsure to cork/button, coin/stone and untested object.

**Marking key:** Cork/button ↔ floats; coin/stone ↔ sinks; untested ↔ unsure, based on supplied observations (1 mark each).

**Coverage:** Placing information into evidence-based categories.

### E03 — Sequence life-stage cards

**Type:** Sequencing

**Delivery:** Online, provide movable cards with drag, tap-to-place and keyboard controls. On paper, students number or rewrite the cards in order.

**Question:** Order seed, sprout, flowering plant and seed-producing plant.

**Marking key:** Seed → sprout → flowering plant → seed-producing plant (2 marks).

**Coverage:** Ordering information in a biological sequence.

## Section B — Application and problem solving

### E04 — Complete a pattern table

**Type:** Short response

**Question:** Trial numbers 1,2,3,4 have distances 2,4,6,__ blocks. Complete the shown pattern and state it.

**Marking key:** 8 blocks; increases by 2 each trial (2 marks).

**Coverage:** Extending a simple data pattern.

### E05 — Demonstrate a two-way sort

**Type:** Demonstration

**Delivery:** Provide the named classroom materials or an equivalent labelled visual. Accept a teacher-observed demonstration or a written description.

**Question:** Sort cards first into living/non-living, then sort living cards into plant/animal. Explain both rules.

**Marking key:** All cards placed appropriately and both hierarchical rules stated (3 marks).

**Coverage:** Using nested categories in a physical model.

### E06 — Draw a labelled table

**Type:** Drawing response

**Delivery:** Online, provide a simple drawing or selectable-diagram tool with a keyboard-labelled alternative. On paper, students draw and label.

**Question:** Create a table for object, observed surface and roll/slide result for ball, block and tube.

**Marking key:** Clear headings and plausible supplied/observed entries for all three objects (3 marks).

**Coverage:** Representing linked observations in a table.

## Section C — Extended response and analysis

### E07 — Correct an unsupported pattern

**Type:** Extended response

**Question:** A child sees two red objects float and says all red objects float. Explain why colour is not yet supported as the cause.

**Marking key:** Only two cases and other properties differ; test more objects while comparing relevant material/shape evidence (3 marks).

**Coverage:** Evaluating a claimed relationship from limited data.

### E08 — Analyse two representations

**Type:** Extended response

**Question:** A table and block model both show daily bird counts 3,5,5,7. Describe the pattern, identify the repeated value and explain one advantage of each representation.

**Marking key:** Overall increase with 5 repeated; table gives exact values, model makes comparisons/pattern visible (5 marks).

**Coverage:** Comparing representations and interpreting patterns.
