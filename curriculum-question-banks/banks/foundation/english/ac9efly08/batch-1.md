# AC9EFLY08 — Pass 1 question bank

Handwriting is assessed using the letter formations taught by the learner’s
school. Variations between approved Australian handwriting styles are accepted.

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Matching letter cases

**Type:** Matching

**Delivery:** Show **A, g, M, t** and the choices **a, G, m, T**.

**Question:** Match each letter with the same letter in the other case.

**Marking key:** A–a, g–G, M–m, t–T. Award 1 mark each; 4 marks total.

**Coverage:** Recognising upper- and lower-case forms of the same grapheme.

### P02 — Choosing lower-case letters

**Type:** Multiple choice

**Delivery:** Show the options clearly.

**Question:** Which group contains only lower-case letters?

A. A, m, s

B. a, m, s

C. a, M, S

D. A, M, S

**Correct answer:** B — All three are lower-case forms.

**Coverage:** Distinguishing case visually.

## Tier 2 — Core skill practice

### P03 — Forming a lower-case sequence

**Type:** Demonstration

**Delivery:** Provide handwriting lines and the model **c a d** in the school’s taught style.

**Question:** Copy each lower-case letter twice, using the taught starting place and movement.

**Marking key:** Award 1 mark for each letter type recognisably and consistently formed according to the taught model; 3 marks total. Do not require identical size.

**Coverage:** Applying learned movements to three lower-case formations.

### P04 — Forming upper-case initials

**Type:** Demonstration

**Delivery:** Say, “Write the first letter for the names Ben, Kim and Rosa.” Provide the lower-case words only if needed.

**Question:** Write the three upper-case initials in order.

**Marking key:** B, K, R, each recognisable and using taught formation. Award 1 mark each; 3 marks total.

**Coverage:** Producing upper-case letter forms for name initials.

## Tier 3 — Guided application

### P05 — Copying a name with mixed case

**Type:** Demonstration

**Delivery:** Show the model **Mina** on handwriting lines.

**Question:** Copy the name, keeping the capital first letter and lower-case remaining letters clear.

**Marking key:** 1 mark for recognisable capital M, 1 mark for recognisable lower-case i/n/a, and 1 mark for consistent left-to-right placement and separation; 3 marks total.

**Coverage:** Coordinating upper- and lower-case formation within a familiar word.

### P06 — Repairing confusing case

**Type:** Short response

**Delivery:** Show **cAT** as a model error.

**Question:** Rewrite the word using lower-case letters throughout.

**Marking key:** **cat**, with recognisable c, a, t. Award 1 mark for correct case choice and 1 mark for legible formation; 2 marks total.

**Coverage:** Revising inappropriate case while forming a word.

## Tier 4 — Problem solving and reasoning

### P07 — Checking letter identity

**Type:** Extended response

**Delivery:** Show a child-written word intended as **bed**, but the first letter lacks the upright stem and looks like **o**. Do not present a real child’s work or name.

**Question:** Which letter needs clearer formation? Rewrite the word and explain what feature makes the first letter recognisable.

**Marking key:** Identifies b (1 mark), rewrites legible **bed** (1 mark), and explains a relevant taught feature such as stem plus rounded part/orientation (1 mark); 3 marks total.

**Coverage:** Analysing formation features that distinguish letter identity.

### P08 — Writing for another reader

**Type:** Extended response

**Delivery:** Provide the sentence model **A red hen.** and handwriting space.

**Question:** Copy the sentence so another person can read it easily. Then circle one letter you formed carefully and explain what you checked.

**Marking key:** 1 mark for recognisable upper-case A, 1 mark for mostly recognisable lower-case letters, 1 mark for left-to-right word order and spacing, and 1 mark for a relevant self-check such as starting point, direction, size, shape or orientation; 4 marks total.

**Coverage:** Applying and reflecting on legible letter formation in connected writing.

## Exam questions

## Section A — Core knowledge

### E01 — Matching an upper-case form

**Type:** Multiple choice

**Delivery:** Show the target **h** and options.

**Question:** Which is the upper-case form of **h**?

A. K

B. N

C. H

D. R

**Correct answer:** C — H and h represent the same letter.

**Coverage:** Identifying a case pair.

### E02 — Producing a named letter

**Type:** Demonstration

**Delivery:** Say, “Write lower-case f.” Do not show a model unless required by an approved adjustment.

**Question:** A label needs the lower-case letter **g**. Write **g** carefully and check that its parts sit in the correct handwriting zones.

**Marking key:** A recognisable lower-case f with taught formation. Award 1 mark.

**Coverage:** Retrieving and producing a learned lower-case formation.

### E03 — Producing an upper-case letter

**Type:** Demonstration

**Delivery:** Say, “Write upper-case D.”

**Question:** The name **Riley** begins with a capital. Form one clear upper-case **R** in the space provided.

**Marking key:** A recognisable upper-case D with taught formation. Award 1 mark.

**Coverage:** Retrieving and producing a learned upper-case formation.

## Section B — Application and problem solving

### E04 — Writing a label

**Type:** Demonstration

**Delivery:** Show a picture of a sun and say the word slowly.

**Question:** Write the lower-case label **sun**.

**Marking key:** 1 mark for s, 1 mark for u and 1 mark for n, each recognisable and in correct order; 3 marks total.

**Coverage:** Applying lower-case formations in an independently written CVC label.

### E05 — Writing two names

**Type:** Demonstration

**Delivery:** Say and show the names **Leo** and **Amir** in plain print for copying.

**Question:** Copy both names, using the correct case pattern.

**Marking key:** 1 mark per correctly formed capital initial, 1 mark per name for mostly recognisable lower-case sequence, and 1 mark for clear separation between names; 5 marks total.

**Coverage:** Sustaining mixed-case formation across familiar proper names.

### E06 — Correcting a case pattern

**Type:** Short response

**Delivery:** Show the sentence **mY dog can run.**

**Question:** Rewrite only the first word with the case pattern needed at the sentence beginning.

**Marking key:** **My** with recognisable upper-case M and lower-case y. Award 1 mark for case and 1 mark for formation; 2 marks total.

**Coverage:** Applying sentence-initial case through handwriting.

## Section C — Extended response and analysis

### E07 — Finding and repairing unclear letters

**Type:** Extended response

**Delivery:** Show this teacher-made sample in the school style with deliberate ambiguities: **The lid is red.** Make the l in **lid** look like an undotted i and the r in **red** look like v.

**Question:** Identify the two unclear letters, rewrite both words and explain one formation feature for each repair.

**Marking key:** 1 mark each for identifying l and r, 1 mark each for legibly rewriting **lid** and **red**, and 1 mark each for explaining a taught distinguishing feature; 6 marks total.

**Coverage:** Diagnosing and explaining formation-based legibility problems.

### E08 — Independent mixed-case handwriting sample

**Type:** Extended response

**Delivery:** Dictate: “Kim has a pet.” Repeat naturally, not letter by letter.

**Question:** Write the sentence, then compare it with your taught letter models and improve one letter if needed.

**Marking key:** 1 mark for capital K, 1 mark for recognisable lower-case letters, 1 mark for left-to-right order and word spacing, 1 mark for readable overall formation, 1 mark for identifying a letter to check, and 1 mark for a plausible correction/explanation; 6 marks total. Spelling/punctuation are noted but not the primary formation marks.

**Coverage:** Producing and self-reviewing upper- and lower-case formations in connected writing.
