# AC9SFI03 — Pass 1 question bank

## Practice questions

## Tier 1 — Knowledge and terms

### P01 — Putting observations in a table

**Type:** Matching

**Delivery:** Provide a two-column template labelled **Has wings** and **No wings**, plus images of a butterfly, dog, magpie and snail.

**Question:** Place each image in the correct column using only the visible feature.

**Marking key:** Has wings: butterfly, magpie; no wings: dog, snail. Award 1 mark per correctly completed column; 2 marks total.

**Coverage:** Representing a simple animal-feature sort in a provided table.

### P02 — Reading a dot record

**Type:** Multiple choice

**Delivery:** Show a template with **Birds: ••••** and **Butterflies: ••**.

**Question:** What pattern does the record show?

A. No birds were observed.

B. Both were observed the same number of times.

C. More birds than butterflies were observed.

D. Butterflies were the largest animals.

**Correct answer:** C — Four bird dots are more than two butterfly dots; size was not recorded.

**Coverage:** Identifying a quantity pattern in a simple representation.

## Tier 2 — Core skill practice

### P03 — Linking objects to materials

**Type:** Matching

**Delivery:** Give a template with material headings **wood, metal, plastic** and images of a wooden ruler, metal key, plastic bottle and metal spoon.

**Question:** Place each object under its observed material and describe the pattern in the metal group.

**Marking key:** Ruler → wood; key and spoon → metal; bottle → plastic (2 marks); states that 2 objects are metal/the metal group has more than one object (1 mark). 3 marks total.

**Coverage:** Representing material observations and verbalising a group pattern.

### P04 — Completing a movement organiser

**Type:** Short response

**Delivery:** Show a template: **Ball—rolls**, **Toy car—rolls**, **Block—slides**, **Tube—?**. State that the tube was observed moving on its curved side.

**Question:** Complete the final cell and state the repeated movement pattern.

**Correct answer:** Tube → **rolls**; the ball, toy car and tube all roll, while the block slides.

**Coverage:** Completing a representation and identifying a repeated movement outcome.

## Tier 3 — Guided application

### P05 — Common bird features

**Type:** Short response

**Delivery:** Provide a picture table of a sparrow, duck and emu with columns **feathers, beak, wings, can fly**. All have ticks for feathers, beak and wings; only sparrow and duck have ticks for can fly.

**Question:** Which features form a pattern shared by all three birds? Which feature is not shared by all?

**Marking key:** Shared: feathers, beak and wings (2 marks); not shared: can fly (1 mark). 3 marks total.

**Coverage:** Identifying common and variable features from a guided data display.

### P06 — Pattern in object use

**Type:** Multiple choice

**Delivery:** Show a chart: metal—spoon, key, saucepan; fabric—shirt, towel, curtain; glass—window, jar, cup.

**Question:** Which statement describes a pattern in the chart without claiming that it is always true?

A. Metal objects are all the same shape.

B. Every fabric object in the world is a towel.

C. Glass can never be used for containers.

D. In this chart, the fabric objects can bend or fold.

**Correct answer:** D — It describes the displayed fabric examples and avoids an unsupported universal claim.

**Coverage:** Describing a material-use pattern with appropriate limits.

## Tier 4 — Problem solving and reasoning

### P07 — Fixing a misleading picture graph

**Type:** Extended response

**Delivery:** Say: “A class saw 3 lizards and 5 birds. Their template shows three equal lizard pictures but uses two large bird pictures, each secretly meant to stand for different numbers.”

**Question:** Explain why the graph is hard to read. Redesign it using one clear symbol rule and state the pattern the corrected display shows.

**Marking key:** Identifies inconsistent/unexplained symbol values or sizes (1 mark); chooses a clear rule such as 1 picture/dot = 1 animal (1 mark); represents lizards = 3 and birds = 5 accurately (2 marks); states more birds than lizards were observed (1 mark). 5 marks total.

**Coverage:** Evaluating and repairing a representation so a pattern is trustworthy.

### P08 — Finding a pattern across two features

**Type:** Extended response

**Delivery:** Provide a table: marble—round—rolls; ball—round—rolls; cube—flat faces—slides; block—flat faces—slides.

**Question:** Describe the shape-and-movement pattern, add one object you predict could fit either row pattern and explain where it belongs.

**Marking key:** States that the round objects roll and flat-faced objects slide in this set (2 marks); gives a plausible new object such as wheel/orange for round-rolls or book/eraser for flat-slides (1 mark); explains the placement using shape and expected movement (1 mark); limits the claim to the shown/test conditions rather than saying it must always happen (1 mark). 5 marks total.

**Coverage:** Connecting two represented variables and extending a pattern cautiously.

## Exam questions

## Section A — Core knowledge

### E01 — Choosing a template heading

**Type:** Multiple choice

**Delivery:** Show images already sorted into Group 1: cat, rabbit; Group 2: snake, fish.

**Question:** Which pair of headings best matches the visible body-covering pattern?

A. Fur / no fur

B. Fast / slow

C. Friendly / unfriendly

D. Likes people / avoids people

**Correct answer:** A — Fur can be observed in the first group and is absent in the second; the other traits are not shown.

**Coverage:** Inferring appropriate labels for a feature-based representation.

### E02 — Reading a tally table

**Type:** Short response

**Delivery:** Show: smooth stones = `||||` (4); rough stones = `||||| |` (6), with conventional grouped tallies explained.

**Question:** How many stones are in each group, and what comparison pattern is shown?

**Marking key:** Smooth = 4 (1 mark); rough = 6 (1 mark); 2 more rough than smooth/more rough stones observed (1 mark). 3 marks total.

**Coverage:** Interpreting counts and comparison from a provided tally representation.

### E03 — Adding an observation to a table

**Type:** Short response

**Delivery:** Show columns **Transparent** and **Not transparent** with glass under the first and wood under the second. Present a clear plastic sheet.

**Question:** Add the plastic sheet to the correct column and state the observation that supports your choice.

**Correct answer:** Transparent; objects/light can be seen through the clear plastic sheet.

**Coverage:** Entering a new material observation into an existing template.

## Section B — Application and problem solving

### E04 — Finding the common fish features

**Type:** Multiple choice

**Delivery:** Show a table for goldfish, clownfish and tuna. Each has fins and scales; colours and sizes differ.

**Question:** Which statement reports the strongest shared pattern?

A. All three are the same colour.

B. All three have fins and scales.

C. All three are the same size.

D. None has a body covering.

**Correct answer:** B — Those are the features recorded for every fish.

**Coverage:** Selecting a pattern that is supported across all rows.

### E05 — Completing a prediction–observation organiser

**Type:** Short response

**Delivery:** Show: “Object: rubber ball. Observation: bounced 6 times.” Provide empty boxes for a drawing and number.

**Question:** Represent the observation in both empty boxes so another person can understand the result.

**Marking key:** Draws the ball with 6 bounce marks/arcs or a labelled bounce image (1 mark); records the numeral 6 with a label such as “bounces” (1 mark); representations agree (1 mark). 3 marks total.

**Coverage:** Recording one observation in complementary visual and numerical forms.

### E06 — Detecting a pattern with one exception

**Type:** Short response

**Delivery:** Read a table: toy wheel—rolls; tennis ball—rolls; tin can on side—rolls; box—slides.

**Question:** Describe the main pattern and identify the item that does not follow it.

**Marking key:** States that 3 of the 4 objects roll (1 mark); identifies box as the exception and that it slides (1 mark); may link the pattern to curved versus flat contact surfaces for an additional mark. 3 marks total.

**Coverage:** Identifying a majority pattern and an exception in represented observations.

## Section C — Extended response and analysis

### E07 — Building a display from raw observations

**Type:** Extended response

**Delivery:** Read the schoolyard observations: 2 animals with 6 legs, 3 animals with 8 legs, 1 animal with no visible legs. Provide a blank three-column template.

**Question:** Label and complete the template, choose a clear symbol or numeral system and describe two patterns or comparisons that it reveals.

**Marking key:** Labels columns 6 legs, 8 legs, no visible legs (1 mark); represents 2, 3 and 1 accurately with a consistent key (3 marks); gives 2 valid comparisons, such as 8-leg group largest, no-leg group smallest or 1 more in 8-leg than 6-leg (2 marks); includes a clear title/key (1 mark). 7 marks total.

**Coverage:** Converting raw categorical counts into a readable display and extracting patterns.

### E08 — Comparing two representations

**Type:** Extended response

**Delivery:** Say: “Template A lists each leaf with its length. Template B sorts the same leaves only by colour. The question is ‘Do longer leaves tend to be dark or light?’”

**Question:** Explain why neither template alone fully answers the question. Design one combined template and describe the pattern it would allow the class to check.

**Marking key:** Explains A lacks colour and B lacks length (2 marks); designs rows for leaves with both length and colour columns, or length groups crossed with colour (2 marks); explains it allows comparison of length with dark/light colour (1 mark); avoids predicting a pattern not yet supported by data (1 mark). 6 marks total.

**Coverage:** Evaluating representation fitness and combining variables to enable pattern finding.
