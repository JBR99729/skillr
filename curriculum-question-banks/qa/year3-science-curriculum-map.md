# Year 3 Science quality-bank curriculum map

This map records the manual curriculum design and review for the 24-question Practice and separate 16-question Test bank for every current Year 3 Science code. Each row represents eight question families expressed across five contexts: the first three contexts are Practice and the last two are Test.

| Code | Curriculum intent | Question-family coverage | Misconceptions explicitly tested | Visual approach | Practice / Test context distinction |
|---|---|---|---|---|---|
| AC9S3U01 | Compare living and non-living characteristics; compare plant and animal life cycles | classify from evidence; reject movement-only classification; order stages; identify biological change; classify pairs; compare shared stages; request sufficient evidence; compare cycles | movement proves life; appearance proves life; plant and animal cycles are identical; only animals have young stages | comparison cards and ordered life-cycle flows | Practice uses garden, pond and seed-study organisms; Test uses bushwalk and habitat-display organisms |
| AC9S3U02 | Compare observable properties of soils, rocks and minerals and link Earth resources to uses | observe properties; fair drainage comparison; property-to-use; rock–mineral relation; mineral identification; soil composition; evidence-limited drainage conclusion; particle-size comparison | all soils are the same; names or preferences establish a property; every material suits every use; soil is a pure substance | property tables, material cards and rock–mineral relationship flows | Practice uses soil, rock and drainage stations; Test uses garden-bed and materials-workshop decisions |
| AC9S3U03 | Identify heat sources and explain temperature change through heat-energy transfer | transfer direction; interpret paired temperatures; identify source; choose thermometer; plan fair insulation test; distinguish heat and temperature; predict approach to equilibrium; predict both objects' changes | cold flows; heat and temperature are identical; cooler object changes without warmer object changing; labels are evidence | warm-to-cool arrows, temperature tables, instrument cards and simple change graphs | Practice uses water, spoon and sunny-window studies; Test uses lunchbox and cooling investigations |
| AC9S3U04 | Compare solid/liquid properties and connect melting/freezing to adding/removing heat | identify liquid; identify solid; melting; freezing; reversibility; conservation of matter; evidence of melting; compare melting conditions | liquids have no volume; matter disappears; cutting is melting; every change is reversible | state comparisons, solid–liquid flows, cycles and condition tables | Practice uses ice, chocolate and wax; Test uses butter and frozen-juice state changes |
| AC9S3H01 | Examine how data support scientific explanations | identify data; make supported claim; select relevant evidence; explain reasoning; build claim–evidence explanation; distinguish opinion; handle variation; state cautious conclusion | opinion is evidence; one result proves a universal rule; different repeat should be deleted; reasoning replaces data | source-data tables, simple graphs and claim–evidence–reasoning flows | Practice uses plant, cooling and drying data; Test uses soil and melting evidence |
| AC9S3H02 | Use scientific explanations to meet needs and solve problems | define need; connect science to design; set measurable criterion; test and improve; compare multiple criteria; choose evidence; respond to failed criterion; explain trade-offs | colour or name proves success; first design is final; one criterion is enough; failed test should be hidden | need-to-solution flows, criteria tables and iterative design cycles | Practice uses lunch, water and shade needs; Test uses garden and drink-temperature solutions |
| AC9S3I01 | Pose testable questions about patterns and make evidence-based predictions | form testable question; identify measurable prediction; use observation as evidence; identify changed factor; identify outcome; repair subjective question; respond honestly to mismatch; use if–then–because | “best” is measurable; prediction must come true; preference supports prediction; unexpected data should be changed | observation-to-question flows, variable cards and prediction frames | Practice uses seedling, ice and drying observations; Test uses soil and shadow patterns |
| AC9S3I02 | Plan and conduct fair, safe investigations with scaffolds | identify changed factor; measured outcome; controls; safety control; repeats; select complete fair plan; monitor safety; respond to unusual trial | changing several factors is fair; repeats allow deleting results; safety is checked only after an event; guessing is measurement | fair-test planning tables, safety cards and procedure flows | Practice tests towel, seedling and ice conditions; Test tests soil drainage and shade materials |
| AC9S3I03 | Follow procedures and make formal measurements using scaled and digital tools | select instrument; record value/unit; explain unit; distinguish qualitative/quantitative; read scale correctly; interpret intervals; use consistent procedure; choose digital table | unit is optional; qualitative means inaccurate; side-on scale reading is acceptable; same method guarantees identical results | instrument matches, scale diagrams, observation comparisons and labelled tables | Practice measures length, temperature and volume; Test measures mass and time |
| AC9S3I04 | Construct and use tables, column graphs and models to show patterns and relationships | select table; select graph; identify maximum; check source fidelity; use consistent scale; state pattern; identify model limitation; correct mismatch | graphs may differ from source; equal-height columns can represent unequal values; models include all reality; dramatic scales are acceptable | exact-value tables, proportional columns, scales and relationship flows | Practice represents plant, soil and temperature data; Test represents melting and shadow data |
| AC9S3I05 | Compare findings, judge fairness, identify further questions and draw conclusions | compare groups/methods; identify fairness; cautious conclusion; explain variation; evidence-based conclusion; further question; diagnose two-variable flaw; value repeats | different result means someone is wrong; multiple changes prove multiple causes; repeats guarantee prediction; conclusions are universal | group-result tables, fairness cards and question–evidence–conclusion flows | Practice evaluates melting, plants and drainage; Test evaluates cooling and drying studies |
| AC9S3I06 | Communicate findings for purpose and audience with scientific vocabulary and digital tools | establish purpose; state precise finding; select data visual; choose vocabulary; adapt for audience; identify method; write conclusion; final accuracy check | decoration substitutes for evidence; vague wording is scientific; audience adaptation means removing findings; equipment list is a conclusion | report layouts, labelled-data cards, audience comparisons and communication flows | Practice creates class, teacher and younger-student texts; Test creates family-video and garden-team digital communications |
