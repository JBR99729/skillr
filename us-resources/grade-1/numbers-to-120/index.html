Count and write numbers to 120

Start at the number you’re given and count forward by ones. Then practice reading and writing numerals and using them to show how many objects you counted.

1. Count on by ones

Start at 98. Each step adds one. After 99 comes 100, then 101. You don’t have to start at 1, and the count doesn’t restart at 100.

98, 99, 100, 101

Try it: Start at 117. Say and write the next three numbers.

Check the counting answer

118, 119, 120. The number after 119 is 120.

2. Read and write the numeral

A numeral is how we write a number using digits. Say “thirty-two,” then write 32. The order matters: 23 is twenty-three, a different number.

Try it: Write the numeral for “forty-six,” then read it back.

Check the numeral answer

46. If you wrote 64, read it aloud: that’s sixty-four, not forty-six.

3. Count objects and record how many

Set out six counters. Touch each counter once as you say one number. The last number you say is “six,” so write 6. That number tells you how many are in the whole group.

Try it: Put 5 counters in one row and 4 in the next. Count all of them by ones, then write the total. Keep counting when you move to the next row.

Check the counters answer

Write 9. End the first row at 5, then say 6, 7, 8, 9 as you touch the counters in the second row.

Teaching tip and next steps

Ask the learner to show you how they know. If they lose their place, use a number chart to track each step or have them move each counter as they count. You can read number names aloud so spelling doesn’t get in the way of the math.
