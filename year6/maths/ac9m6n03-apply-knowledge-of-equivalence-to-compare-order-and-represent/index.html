Comparing fractions on a number line

Compare halves, thirds, quarters and related fractions and justify their order

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Compare 3/4 and 3/8

With the same numerator and whole, a larger denominator gives smaller parts.

Learn the skill

1. Use one whole

Compare fractions on the same interval from 0 to 1.

Try it · Where does one half go?

Halfway between 0 and 1.

2. Rename equivalent fractions

Divide each original part into the same number of smaller parts. The amount stays the same.

Try it · How many sixths equal one third?

Two sixths.

3. Compare positions

A point further right on the number line represents a greater fraction.

Try it · Which comes first from 0, one third or one half?

One third. It is two sixths, while one half is three sixths.

Common mistakes

Comparing only the denominators. Rename both fractions in equal-sized parts of the same whole, then compare how many parts each has.

10-MINUTE HOME ACTIVITY

Place fractions on one line

Draw a number line from 0 to 1 and divide it into 12 equal intervals. Mark one half, two thirds and three quarters and explain their order.

Adjust the challenge: Start by marking one half. Extend by adding five sixths.

FAQ

Which is greater, two thirds or three quarters?

Three quarters. It is nine twelfths, while two thirds is eight twelfths.

Key concept

Compare 2/3, 3/4 and 5/6

Use the visual model first. Ask students to identify the quantities, structure or conditions before calculating or explaining.

2/3 = 8/12
3/4 = 9/12
5/6 = 10/12

A common denominator creates equal-sized parts, so numerators can be compared meaningfully. Equivalent forms occupy the same point.

Curriculum elaborations explicitly taught

AC9M6N03: apply knowledge of equivalence to compare, order and represent common fractions including halves, thirds and quarters on the same number line and justify their order

  • E1: applying factors and multiples to fraction denominators, such as halves with quarters, eighths and twelfths, and thirds with sixths, ninths and twelfths to determine equivalent representations of fractions in order to make comparisons
  • E2: representing fractions on the same number line, paying attention to relative position, and using this to explain relationships between denominators
  • E3: explaining equivalence and order between fractions using number lines, drawings and models
  • E4: comparing and ordering fractions by placing cards on a string line across the room and referring to benchmark fractions to justify their position; for example, \frac58 is greater than \frac12 can be written as \frac58>\frac12, because half of 8 is 4; \frac16 is less than \frac14, because 6 > 4 and can be written \frac16 < \frac14

Use the central and application models above to connect each elaboration to the same underlying concept.

Common misconceptions
Larger denominator means larger valueFor the same numerator, more parts means smaller parts.
Different wholes comparedFractions must refer to equal-sized wholes.
Improper fraction placed below oneCompare numerator with denominator first.
Number-line intervals drawn unequallyEqual numerical steps require equal spacing.

  • Show 3/4 = 9/12.
  • Locate 5/4.
  • Compare 7/8 and 5/6.
  • Use 1/2 as a benchmark.
