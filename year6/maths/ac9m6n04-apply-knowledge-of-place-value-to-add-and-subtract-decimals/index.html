Add and subtract decimals

Use place value to calculate with decimals and estimate to check your answer.

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Line up decimal place values

Align place values. A trailing zero can make an empty decimal place visible.

Learn the skill

1. Align place values

Write tenths under tenths and hundredths under hundredths.

Try it · How can you rewrite 4.7 in hundredths notation?

4.70.

2. Subtract with regrouping

Regroup one tenth as ten hundredths when needed.

Try it · What is 3.50 − 1.26?

2.24.

3. Estimate to check

Round the numbers to check the approximate size of the result.

Try it · Is 5.9 + 3.1 closer to 9 or 90?

9. Both numbers are close to 6 and 3 respectively.

Common mistakes

Lining up the last digits of numbers with different decimal lengths. Line up decimal points so each place is in the correct column.

10-MINUTE HOME ACTIVITY

Add a shopping list

Estimate $4.75 + $2.60, then add the exact prices and find the change from $10.

Adjust the challenge: Use a place-value chart first. Extend by adding a third item.

FAQ

What is the exact change?

$2.65, because the total is $7.35.

Learning goals

Learning goal

Students align place values, rename when regrouping, choose mental or written strategies and compare exact results with purposeful estimates.

Key concept

Calculate 18.375 + 6.84 by aligning place values

Use the visual model first. Ask students to identify the quantities, structure or conditions before calculating or explaining.

Write 6.84 as 6.840 to align equal place values. Placeholder zeros clarify structure without changing value.

Curriculum elaborations explicitly taught

AC9M6N04: apply knowledge of place value to add and subtract decimals, using digital tools where appropriate; use estimation and rounding to check the reasonableness of answers

  • E1: applying estimation strategies to addition and subtraction of decimals to at least thousandths before calculating answers or when a situation requires just an estimation
  • E2: applying whole-number strategies; for example, using basic facts, place value, partitioning and the inverse relationship between addition and subtraction, and properties of operations to develop meaningful mental strategies for addition and subtraction of decimal numbers to at least hundredths
  • E3: working additively with linear measurements expressed as decimals up to 2 and 3 decimal places; for example, calculating how far off the world record the athletes were at the last Olympic games in the women’s long jump or shot-put and comparing school records to the Olympic records
  • E4: deciding to use a calculator as a calculation strategy for solving additive problems involving decimals that vary in their number of decimal places beyond hundredths; for example, 1.0 - 0.0035 or 2.345 + 1.4999

Use the central and application models above to connect each elaboration to the same underlying concept.

Common misconceptions
Decimal points not alignedAlign place values, not final digits.
Zeros added to the left or inside incorrectlyOnly trailing placeholder zeros preserve a decimal’s value.
Estimate omittedUse it to detect misplaced decimal points.
Calculator result accepted without contextCheck operation, input and magnitude.
