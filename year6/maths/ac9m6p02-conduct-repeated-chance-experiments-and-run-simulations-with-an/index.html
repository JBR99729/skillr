Repeated trials and simulations

Compare observed results with expectations as the number of trials grows.

Practice on app ↗Help with gaps ↓10-minute activity ↓

WORKED EXAMPLE

Compare expected and observed results

Expected frequency is a long-run prediction, not a guaranteed count.

Learn the skill

1. Set an expectation

Use the chance model to predict a proportion.

Try it · What fraction of fair coin tosses do you expect to be heads?

About one half.

2. Calculate observed proportions

Divide the outcome count by the total number of trials.

Try it · What proportion is 12 heads out of 20 tosses?

0.6, or 60%.

3. Compare trial sizes

Larger runs typically vary less in proportion, although a single run can still differ from the expected result.

Try it · Does a longer run guarantee a closer result every time?

No. Random variation still occurs.

Common mistakes

Comparing only the number of heads across different trial totals. Compare the proportion of heads so the trial totals are taken into account.

10-MINUTE HOME ACTIVITY

Compare two simulation sizes

Use a digital coin simulator. Record the fraction of heads after 20 tosses and after 200 tosses, then compare both with one half.

Adjust the challenge: Start with a tally table. Extend by repeating both simulations and comparing variation.

FAQ

Must 200 tosses produce exactly 100 heads?

No. One half is the expected proportion and observed results vary.

Learning goals

Learning goal

Students calculate expected frequency, conduct physical and digital trials, compare relative frequencies across sample sizes and discuss why results vary while often becoming more stable.

Success criteria

  • I can represent or identify the concept.
  • I can explain the underlying relationship.
  • I can select an appropriate strategy or feature.
  • I can apply it in a new context.
  • I can justify and verify the response.
