# Skillr Project Rules

- Do not touch Daily Drills unless explicitly requested.
- Do not touch question banks unless the task is question-bank work.
- Do not redesign existing UI unless requested.
- Use small branches.
- Show changed files before commit.
- Do not merge unfinished features.
- Prefer shared code over editing many pages.
- Practice is for learning with feedback.
- Test is for mastery.
- 75% or higher means proficient.
- Certificates only show where certificateOnPass is enabled.
- Dashboard progress is local and must support backup/export and restore/import.
- Before merging, run: npx playwright test.
