Parent and teacher guide

Decimals are easiest when students connect them to place value and fractions. Tenths, hundredths and thousandths extend the same base-ten system students already use with whole numbers. Start with place value charts and number lines so learners can see that 0.4 is four tenths and 0.40 is the same value with an extra zero. A common mistake is comparing decimals as if they are whole numbers. Align decimal places and use zeros as placeholders.

Common mistakes to watch for

Ask the student to explain their method before moving to a test. If they can only guess, return to one visual model and one worked example. Short practice with feedback usually works better than a long worksheet completed without review.
