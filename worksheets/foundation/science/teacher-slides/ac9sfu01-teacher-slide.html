Living Things and External Features

Observe what can be seen, compare features, then group living things using a clear rule.

Learning goal: identify external features of plants and animals and explain a sensible grouping rule using visible evidence.

Classroom routine

Observe → Name features → Compare → Group → Explain

Key language

external feature • observe • compare • group • rule

Observe closelyName visible featuresCompareGroup by a ruleExplain evidence

Plant features

Roots, stem and leaves are external features. Flowers, fruits and seeds may also be visible.

Eileen Kummer / Unsplash

Bird features

Look for feathers, wings, beak, eyes and legs. Feathers are a body covering.

David Clode / Unsplash

Fish features

Scales, fins, eyes, mouth and tail are visible external features.

Ivan Lopatin / Unsplash

Teach

Group by what you can observe

Possible rules:

  • feathers / fur / scales
  • wings / fins / legs
  • flowers / no flowers
  • broad / narrow leaves

Different sensible rules can all be correct if the student explains the rule.

Fix misconceptions

Watch for

  • Guessing unseen features: use what can actually be observed.
  • No grouping rule: finish “I grouped them by …”
  • Colour only: also notice structural features.
Quick check

Ask

  1. Name two visible plant features.
  2. Which is a body covering: feathers, beak or wing?
  3. Give one rule for grouping a bird, fish and dog.
  4. Why can the same animals be grouped in more than one sensible way?
