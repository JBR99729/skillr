Measuring with Metric Instruments

Accurate measurement requires a suitable instrument, correct starting point, careful reading of labelled markings and a unit in the answer. This matters because start at zero and read the marking at the object's endpoint.

What students learn

Accurate measurement requires a suitable instrument, correct starting point, careful reading of labelled markings and a unit in the answer. This matters because start at zero and read the marking at the object's endpoint.

Work out the value of each interval before reading the pointer or level. Use this idea when a problem asks you to read mass and capacity scales, and explain the result with scale, interval, capacity.

Learning intention: We are learning to measure and compare objects using familiar metric units of length, mass and capacity, and instruments with labelled markings.

Success criteria

  • I can choose instruments.
  • I can read rulers.
  • I can read scales.
Key vocabulary
  • scale — the ordered markings on a measuring instrument
  • interval — the value between neighbouring scale marks
  • capacity — the amount a container can hold

Common misconceptions and quick fixes
  • Starting at ruler edge — Use the zero mark.
  • Counting marks not intervals — Read the scale values.
  • Missing unit — Every measurement needs its unit.
Teaching sequence and quick check

Quick check: Read 13 cm on a ruler.

Expected response: Begin an object at the ruler's zero mark.

If incorrect: Use the zero mark.
