Measuring with Metric Instruments

Accurate measurement requires a suitable instrument, a correct starting point, careful reading of labelled markings and a unit in the answer.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: measure and compare objects using familiar metric units of length, mass and capacity, and instruments with labelled markings.

  • Choose a ruler/tape for length, a scale for mass and a graduated container for capacity.
  • Start measurement at the zero mark rather than the physical edge of an instrument.
  • Determine the value of intervals before reading a pointer, endpoint or liquid level.
  • Compare measurements only after checking the units and scale.

Concept boundary: students read familiar labelled metric scales; formal decimal conversion and advanced unlabelled scale interpolation are not core Year 3 targets.

Key vocabulary and representations

A scale is the ordered set of markings on a measuring instrument. An interval is the value between neighbouring markings. Capacity describes how much a container can hold.

Representations include rulers and tape measures, balance/digital scales and measuring jugs. Always read the number and the unit together.

Teaching progression and worked examples
  1. Choose the instrument: match the instrument to the attribute.
  2. Find zero: align the object or starting level correctly.
  3. Read labelled marks: establish the interval value first.
  4. Record with a unit: for example, 13 cm, 750 g or 1200 mL.
  5. Compare: use the same attribute and compatible unit.

Example 1: An object begins at 0 cm and ends at the 13 cm mark, so its length is 13 cm.

Example 2: If labelled mass marks rise by 100 g and the pointer lies halfway between 700 g and 800 g on a clearly subdivided scale, read the displayed subdivision carefully and record the value with g.

Teacher language: “Where is zero? What is each interval worth? Which marking does the endpoint or pointer reach?”

Curriculum elaborations and how they are taught
  • Measure familiar classroom objects with appropriate metric instruments and compare the results.
  • Read labelled markings on rulers, scales and measuring containers, explaining how the interval value was determined.
  • Identify and correct common setup errors such as starting from the ruler edge instead of zero.
  • Repeat a measurement when a result seems inconsistent and discuss how instrument choice and reading affect accuracy.
Common misconceptions and quick fixes
  • Starting at the ruler edge: align with the zero mark.
  • Counting marks instead of reading scale values: identify what each interval represents first.
  • Missing unit: every measurement must include its unit.
  • Comparing unlike attributes: confirm both measurements describe the same attribute.
Support, Core and Extend
  • Support: use instruments with clear labelled unit intervals and physically mark the zero point.
  • Core: select an instrument, measure accurately, record the unit and compare two results.
  • Extend: diagnose a deliberately incorrect measurement setup and explain how to correct it.
Quick check and mastery evidence
  1. An object runs from 0 cm to 13 cm. Expected: 13 cm.
  2. Why is starting at the 1 cm mark without adjusting incorrect? Expected: the reading includes an extra centimetre unless the starting value is subtracted.
  3. A jug is marked every 200 mL. Explain how you would read a level. Evidence: identifies interval value, locates the level and states mL.

Mastery means choosing suitable instruments, aligning correctly, reading labelled scales and communicating measurements with units.
