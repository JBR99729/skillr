Prerequisite knowledge

Students should be able to sort information into categories, read simple tables or displays and compare counts. Revisit what each label, category and scale represents before analysing a data display.

Concept teaching

Key idea: Data collection should answer a clear question. Categorical data uses labels, while discrete numerical data uses countable numbers.

Learning routine: Ask question → Identify variable → Collect fairly → Tally → Frequency table → Check total

categorical data
information sorted into named groups
discrete numerical data
counted number data with separate values
frequency table
a table showing how often each value occurs
Worked and modelled examples

Record responses in a frequency table

TransportTallyFrequencyWalk||||4Bus||||| |6Car|||3

Each response is recorded once and the frequencies match the tallies.

  1. Read every label and identify what each quantity or feature represents.
  2. Describe the relationship shown by the model.
  3. Check that the conclusion answers the original question.

Distinguish variable types

favourite fruit = categoricalnumber of siblings = discrete numerical

both can answer survey questions

Choose a recording method that suits the variable and purpose.

Apply the same relationship to the new context, then justify the answer using the labels and evidence shown.

Common misconceptions and corrections
  • Question too vague — State exactly what data will answer.
  • Double counting — Record each observation or person once.
  • Variable types mixed — Categories are labels; discrete numbers are counts.
Guided practice

1. Class survey

Collect one categorical variable and record it in a frequency table.

fruitfrequencyapple5banana7orange4

2. Count data

Collect a discrete numerical variable such as books read.

0 books1 book2 books3 books

3. Spreadsheet entry

Enter categories and frequencies in labelled columns.

A: categoryB: frequencywalk4bus6
Independent practice

  1. Which is categorical data?

    • favourite fruit
    • number of pets
    • number of books
    • number of steps

  2. Complete the frequency.

    Prompt: A tally of ||||| || represents □.

  3. Which is discrete numerical data?

    • number of siblings
    • eye colour
    • transport type
    • favourite sport

  4. Write a clear survey question that would collect categorical data.

  5. Match the term to its meaning.

    Match: category • frequency • tally ↔ count in a group • quick recording marks • labelled group

  6. Complete the total.

    Prompt: Frequencies 4, 6 and 3 give □ responses.

Reasoning and problem-solving

  1. Plan a small investigation that collects both categorical and discrete numerical data.

  2. Design a spreadsheet layout for a survey and explain how it helps check totals.

Explain the reasoning, not only the final answer.

Assessment-style questions and review hints

  1. Explain why every response should be recorded once.

  2. A student asks 'What do you like?' for a transport survey. Rewrite the question to be precise.

Review hint: Follow the routine “Ask question → Identify variable → Collect fairly → Tally → Frequency table → Check total” and use the worked model to check whether your answer is reasonable.

Teacher and parent guidance

For teachers

Model the idea with concrete or visual representations first, then ask students to explain the relationship in words before moving to symbolic work.

For parents and carers

Ask your child to show the idea with a drawing, objects or a simple example and explain how they checked the answer.

Curriculum alignment

The content description and elaborations below show the curriculum ideas taught in this unit. Items marked as teaching context support lesson planning.

  • Content description: acquire data for categorical and discrete numerical variables to address a question of interest or purpose by observing, collecting and accessing data sets; record the data using appropriate methods including frequency tables and spreadsheets
  • E1: using efficient ways to collect and record data; for example, written surveys, online surveys, polling the class using interactive digital mediums, and representing and reporting the results of investigations
  • E2: developing questions of interest and using surveys, observations or experiments to collect categorical, discrete numerical or qualitative data sets and discussing what kind of data can be used to help inform or answer the question in a statistical investigation
  • E3: using lists, tallies, symbols and digital data tables to record and display data collected during a chance experiment for interpretation
  • E4: using different online sources to access data; for example, using online query interfaces to select and retrieve data from an online database such as weather records, Google Trends or the World Health Organization
  • E5: using software to sort and calculate data when solving problems; for example, sorting discrete numerical and categorical data in ascending or descending order and automating simple arithmetic calculations using nearby cells and the Sum function in spreadsheets to calculate total frequencies of collected data
