What students learn

Data collection should answer a clear question. Categorical data uses labels, while discrete numerical data uses countable numbers. This matters because each response is recorded once and the frequencies match the tallies.

Choose a recording method that suits the variable and purpose. Use this idea when a problem asks you to distinguish variable types, and explain the result with categorical data, discrete numerical data, frequency table.

Learning intention: We are learning to acquire data for categorical and discrete numerical variables to address a question of interest or purpose by observing, collecting and accessing data sets; record the data using appropriate methods including frequency tables and spreadsheets.

Success criteria

  • I can ask data questions.
  • I can identify variable types.
  • I can collect data.
Key vocabulary
  • categorical data — information sorted into named groups
  • discrete numerical data — counted number data with separate values
  • frequency table — a table showing how often each value occurs

Common misconceptions and quick fixes
  • Question too vague — State exactly what data will answer.
  • Double counting — Record each observation or person once.
  • Variable types mixed — Categories are labels; discrete numbers are counts.
Teaching sequence and quick check

Quick check: Give a categorical variable.

Expected response: Favourite fruit is categorical data because responses are names, not counts.

If incorrect: State exactly what data will answer.
