Choosing Metric Units and Estimating

Metric units must match the attribute and size of the item. Familiar benchmarks help make sensible estimates. This matters because choose smaller units for smaller quantities and larger units for larger quantities.

What students learn

Metric units must match the attribute and size of the item. Familiar benchmarks help make sensible estimates. This matters because choose smaller units for smaller quantities and larger units for larger quantities.

An estimate should use a known measurement, not a random guess. Use this idea when a problem asks you to estimate from a familiar benchmark, and explain the result with metric unit, attribute, estimate.

Learning intention: We are learning to identify which metric units are used to measure everyday items; use measurements of familiar items and known units to make estimates.

Success criteria

  • I can identify attributes.
  • I can choose metric units.
  • I can use benchmarks.
Key vocabulary
  • metric unit — a standard unit such as metre, kilogram or litre
  • attribute — the feature being measured, such as length, mass or capacity
  • estimate — a sensible measurement made before measuring exactly

Common misconceptions and quick fixes
  • Unit does not match attribute — Length, mass and capacity use different units.
  • Large unit for tiny object — Choose a unit that gives a useful number.
  • Estimate without benchmark — Refer to a familiar measured item.
Teaching sequence and quick check

Quick check: Choose a unit for pencil length.

Expected response: Centimetres are suitable for measuring a pencil's length.

If incorrect: Length, mass and capacity use different units.
