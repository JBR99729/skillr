Numbers Beyond 10 000

What students learn

Large numbers are organised in groups of three digits. Each digit has a place value, and the same number can be renamed without changing its total value. This matters because 42 507 is forty-two thousand five hundred and seven. The zero keeps the tens place.

Compare ten-thousands first, then thousands, hundreds, tens and ones. Use this idea when a problem asks you to compare numbers from the highest place first, and explain the result with place value, numeral, natural number.

Learning intention: We are learning to recognise, represent and order natural numbers using naming and writing conventions for numerals beyond 10 000.

Success criteria

  • I can read numbers beyond 10 000.
  • I can write number names.
  • I can use place value.
Key vocabulary
  • place value — the value a digit has because of its position
  • numeral — a written symbol or group of digits that names a number
  • natural number — a whole number used for counting

Common misconceptions and quick fixes
  • Dropping a zero — A zero can hold an empty place, as in 42 507.
  • Comparing from the ones — Start at the highest place value.
  • Reading every digit separately — Read the number in periods: thousands, then ones.
Teaching sequence and quick check

Quick check: Read 63 409 aloud.

Expected response: 42 507 means forty-two thousand five hundred and seven.

If incorrect: A zero can hold an empty place, as in 42 507.
