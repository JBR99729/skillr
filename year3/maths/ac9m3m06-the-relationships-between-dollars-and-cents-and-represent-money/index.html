Learn the skill

Small steps, clear examples

Learning goal: One dollar is 100 cents. Read amounts carefully and make the same value with different Australian coins and notes.

Before you start: Recognise common Australian denominations and count in fives, tens, twenties and fifties.

Useful words: value: the amount of money; denomination: the value printed on a coin or note; exchange: swap equal values; change: payment minus price.

1. Rename dollars and cents

Group cents into hundreds to make dollars. The two digits after the point in money notation name cents.

$1 = 100c$4.05 = 405c$4.50 = 450c

Worked example: $4.05 = 405c: four dollars and five cents. The zero shows there are no tens of cents. $4.50 is different: four dollars and fifty cents.

Write either $4.05 or 405c. Avoid attaching both symbols to one number, such as $4.05c.

Watch for this: $3.07 and $3.70 have different values.

Try it: Write 307c in dollars and cents, then read it aloud.

Check the answer and explanation

$3.07: three dollars and seven cents.

2. Count a given collection

Count the value printed on each coin or note once. Reordering by denomination can help keep track.

Worked example: $2 + $1 + 50c + 20c + 5c = $3.75. Count dollars first, then cents: 50, 70, 75.

For an unsorted collection of 20c, 5c, 50c and 20c, count 50, 70, 90, 95 cents. All four coins are included.

Watch for this: Count monetary value, not the number or physical size of coins.

Try it: Find the total of a $5 note, one $2 coin, one 20c coin and one 5c coin.

Check the answer and explanation

$7.25, or 725c.

3. Exchange coins without changing value

A valid exchange preserves the total, although the number of coins can change.

Worked example: one $2 coin is worth 200c. Exchange it for four 50c coins: 50 + 50 + 50 + 50 = 200c.

In reverse, five 20c coins can be exchanged for one $1 coin. Say both totals in a common unit to check the swap.

Watch for this: Equal value does not require equal numbers of coins.

Try it: How many 20c coins have the same value as two 50c coins?

Check the answer and explanation

Five. Two 50c coins make 100c, and 5 × 20c = 100c.

4. Make one amount in different ways

Compose the whole from different parts, then total each collection to show they are equal.

Worked example: make $1.65 as $1 + 50c + 10c + 5c. Another way is 50c + 50c + 50c + 10c + 5c.

Label each coin in a drawing. The first collection has four coins and the second five, but both total 165c.

Watch for this: Check every total instead of deciding by how similar the collections look.

Try it: Show two different coin collections worth 80c.

Check the answer and explanation

Examples: 50c + 20c + 10c; or four 20c coins. Other Australian-coin combinations totalling 80c are valid.

5. Meet a coin condition

An amount can be correct in value yet fail a rule about available coins or the exact coin count. Check every stated condition.

Worked example: make 70c using exactly three coins: 50c + 10c + 10c works. A 50c and a 20c total 70c but use only two coins, so fail this instruction.

For 90c using as few unrestricted Australian coins as possible, 50c + 20c + 20c uses three. No single coin is 90c and no available two-coin pair totals 90c.

Watch for this: A fewest-coins shortcut depends on the denominations and stock actually available.

Try it: Make 60c using exactly three Australian coins.

Check the answer and explanation

Three 20c coins, or 50c + 5c + 5c. Both total 60c and use exactly three Australian coins.

6. Show payment and check simple change

Use equivalent values in a small shopping situation. Separate the price, payment and returned amount.

Worked example: a price of $2.65 is paid with $3. Count up: 5c reaches $2.70; 30c reaches $3. Change is 35c, which can be returned as 20c + 10c + 5c.

Check $2.65 + $0.35 = $3. Exact payment would instead use a collection worth $2.65, with no change required.

Watch for this: Enough money does not mean exactly the right payment.

Try it: A $1.80 item is paid with $2. What change is due? Show it with coins.

Check the answer and explanation

20c, such as one 20c coin or two 10c coins. Price plus change equals $2.

Common mistakes and quick fixes
  • $3.07 and $3.70 have different values.
  • Count monetary value, not the number or physical size of coins.
  • Equal value does not require equal numbers of coins.
  • Check every total instead of deciding by how similar the collections look.
  • A fewest-coins shortcut depends on the denominations and stock actually available.
  • Enough money does not mean exactly the right payment.

Support: Use labelled play coins. Count in cents first and group each 100c as one dollar.
