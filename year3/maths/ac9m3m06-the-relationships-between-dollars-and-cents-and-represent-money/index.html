AC9M3M06 • Year 3 Maths

Dollars, Cents and Money Values

One dollar equals 100 cents, and the same money value can be represented with different combinations of Australian coins and notes.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: recognise the relationships between dollars and cents and represent money values in different ways.

  • Know that $1 = 100 cents.
  • Read and write amounts using dollar and cent notation.
  • Represent the same value with different combinations of coins and notes.
  • Explain equivalence by comparing total value rather than number of coins or notes.

Concept boundary: this code focuses on representing and relating money values; complex financial modelling and formal decimal operations are not the main target.

Key vocabulary and representations

A dollar is 100 cents. A cent is one hundredth of a dollar. Equivalent value means two different representations have the same total amount.

Use real or replica Australian money, value cards, tables linking dollars to cents and grouped combinations such as $2 + $1 + 50c + 20c + 5c = $3.75.

Teaching progression and worked examples
  1. Build $1 from cents in multiple ways to establish 100c = $1.
  2. Read money notation, paying attention to two digits in the cents position.
  3. Make a target value with one combination, then find another equivalent combination.
  4. Compare two representations by total value, not by the physical number or size of coins.

Example 1: $3 = 300c because each dollar is 100c.

Example 2: $3.75 can be represented as $2 + $1 + 50c + 20c + 5c. Other combinations can be equivalent.

Teacher language: “How many cents make one dollar? What is the total value? Can you make the same amount another way?”

Curriculum elaborations and how they are taught
  • Compose and decompose whole-dollar amounts using cents to reinforce 100 cents per dollar.
  • Represent selected money values with different combinations of Australian coins and notes.
  • Read and write money notation including amounts such as $4.05, distinguishing 5 cents from 50 cents.
  • Compare representations and justify equivalence using total monetary value.
Common misconceptions and quick fixes
  • Treating 50c as $50: identify cents as parts of one dollar.
  • Writing $4.5 for $4.05: discuss place value in money notation and use two cent digits.
  • Thinking more coins means more money: total the values.
  • Believing there is only one representation: deliberately make several equivalent combinations.
Support, Core and Extend
  • Support: use labelled replica money and whole-dollar targets first.
  • Core: convert simple dollar amounts to cents and represent mixed dollar-and-cent values in at least two ways.
  • Extend: find multiple efficient combinations for a target amount and justify equivalence without moving into later-year financial calculations.
Quick check and mastery evidence
  1. How many cents are in $3? Expected: 300c.
  2. Write four dollars and five cents. Expected: $4.05.
  3. Show two different ways to make $3.75. Evidence: both combinations total exactly $3.75.

Mastery means using the dollar-cent relationship accurately and recognising equivalent representations independent of coin/note count.
