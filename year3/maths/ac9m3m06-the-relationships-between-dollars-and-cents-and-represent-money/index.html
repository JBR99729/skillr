Dollars, Cents and Money Values

One dollar equals 100 cents. The same money value can be represented with different combinations of coins and notes. This matters because different combinations can total the same amount.

What students learn

One dollar equals 100 cents. The same money value can be represented with different combinations of coins and notes. This matters because different combinations can total the same amount.

Two digits after the decimal show cents. Use this idea when a problem asks you to convert between dollars and cents, and explain the result with dollar, cent, equivalent value.

Learning intention: We are learning to recognise the relationships between dollars and cents and represent money values in different ways.

Success criteria

  • I can use $1 = 100c.
  • I can convert dollars and cents.
  • I can represent values.
Key vocabulary
  • dollar — a money unit equal to 100 cents
  • cent — one hundredth of a dollar
  • equivalent value — a different representation of the same amount

Common misconceptions and quick fixes
  • Treating 50c as $50 — Cents are parts of one dollar.
  • Missing zero in $4.05 — $4.05 means 4 dollars and 5 cents.
  • Only one representation — Many combinations can have the same value.
Teaching sequence and quick check

Quick check: How many cents in $3?

Expected response: $3 equals 300 cents.

If incorrect: Cents are parts of one dollar.
