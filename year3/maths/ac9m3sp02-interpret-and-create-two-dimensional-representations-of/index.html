AC9M3SP02 • Year 3 Maths

Maps and Two-Dimensional Representations

Maps and simple plans represent familiar environments in two dimensions while preserving important relative positions between landmarks and objects.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: interpret and create two-dimensional representations of familiar environments, locating key landmarks and objects relative to each other.

Students identify landmarks, use symbols and directional language, and keep relative position consistent when interpreting or creating a simple map.

Concept boundary: focus on familiar environments and relative position; formal coordinate geometry and scale calculations are not required.

Key vocabulary and representations

Map — a two-dimensional representation of a place. Landmark — an important identifiable feature. Relative position — where one object is compared with another. Key — explains map symbols.

Teaching progression and worked examples
  1. Read a simple classroom or playground map.
  2. Locate landmarks relative to one another.
  3. Use symbols and a key.
  4. Create a map that preserves the important spatial relationships.

Example: if the library is north of the oval and the gate is east of the oval, the map must keep those relationships even if the drawing is simplified.

Curriculum elaborations and how they are taught

Use classroom plans, playground maps, route diagrams and familiar local environments to interpret symbols, landmarks and position, then create simple representations that another person can follow.

Common misconceptions and quick fixes
  • Treating picture size as real distance: focus first on relative position.
  • Moving landmarks: compare each landmark with a fixed reference point.
  • Symbols without a key: require a clear legend for unfamiliar symbols.
Support, Core and Extend
  • Support: use a partly completed map with labelled landmarks.
  • Core: interpret and create a familiar-environment map independently.
  • Extend: create two different valid representations of the same place and compare them.
Quick check and mastery evidence

Ask the student to locate one landmark relative to two others and then sketch a simple map. Mastery requires correct relative position and interpretable symbols.
