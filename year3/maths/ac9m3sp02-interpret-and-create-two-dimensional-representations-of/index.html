What students learn

A map is a two-dimensional representation viewed from above. Symbols, labels, keys and relative position language help locate landmarks and communicate routes. This matters because use rows, columns, landmarks and direction words to describe positions.

Directions must be ordered and use a consistent map orientation. Use this idea when a problem asks you to create a route between landmarks, and explain the result with representation, landmark, relative position.

Learning intention: We are learning to interpret and create two-dimensional representations of familiar environments, locating key landmarks and objects relative to each other.

Success criteria

  • I can interpret maps.
  • I can use landmarks.
  • I can use relative position.
Key vocabulary
  • representation — a drawing or model that shows a place
  • landmark — an important object or place used to locate position
  • relative position — where something is compared with something else

Common misconceptions and quick fixes
  • Drawing side view — Maps usually show familiar spaces from above.
  • No key or labels — Symbols need meanings.
  • Vague directions — Use landmarks and ordered direction words.
Teaching sequence and quick check

Quick check: What does a map key do?

Expected response: A map key explains the meaning of symbols.

If incorrect: Maps usually show familiar spaces from above.
