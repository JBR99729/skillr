Learn the skill

Small steps, clear examples

Learning goal: Read and create representations of familiar spaces. Use landmarks, keys and clear position language so someone else can locate objects or follow a route.

Before you start: Use beside, between, left and right with an agreed viewpoint; recognise familiar places.

Useful words: plan: a representation of a space; landmark: an identifiable place or object; key: explains symbols; relative position: where something is compared with something else.

1. Connect a place with different views

A top-view plan shows the arrangement from above. A street view, aerial photograph and simple plan can reveal different information about the same place.

Worked example: viewed from above, a classroom table can appear as a rectangle. From the front, its legs may be visible. Moving the viewpoint changes what you can see, not the real positions of the table and door.

Arrange a few toy objects and draw the view from above. Match each landmark in the model with the plan.

Watch for this: Do not assume every view reveals all the object’s surfaces.

Try it: Would a simple top-view classroom plan normally show the full height of a cupboard? Explain.

Check the answer and explanation

No. It mainly shows the cupboard’s footprint and location; a front or side view gives different height information.

2. Use landmarks, symbols and a key

Read the supplied key. A symbol’s meaning is defined for that map; it is not necessarily universal.

Worked example: in this school plan, L = Library, G = Garden, C = Classroom, E = Entry gate, O = Oval and H = Hall. The key explains each letter; the map shows its actual location.

A useful symbol is distinct and easy for the intended reader to recognise. Count map instances, not symbols printed in the key.

Watch for this: A key entry is an explanation, not another landmark on the map.

Try it: Use the plan: which landmark lies directly above the entry gate?

Check the answer and explanation

The library. Read the E and L symbols using the key.

3. Describe positions from an agreed orientation

Name the reference landmark and hold the viewpoint fixed. Here north is at the top of the plan.

Worked example: the garden is between the library and classroom in the top row. The hall is to the right of the oval. Reversing the reference gives “the oval is to the left of the hall”.

“Above on the plan” does not mean physically higher in the real school. If a map is turned, use its orientation arrow to re-establish directions.

Watch for this: Left and right need a stated reference and orientation.

Try it: On the supplied plan, what is directly below the classroom? What is left of the oval?

Check the answer and explanation

The hall is below the classroom; the entry gate is left of the oval.

4. Follow and communicate a route

State a start, follow connected paths and identify the destination. Check each move on the representation.

Worked example: start at the entry gate, follow the path up to the library, then right to the garden. The route ends at the garden.

From the hall, go up to the classroom and left to the garden. A different route can reach the same destination. Count or compare route segments only where their meaning is defined.

Watch for this: Do not cross a missing path or a barrier just because the destination is nearby.

Try it: Describe a two-segment route from the entry gate to the oval via the library. Is it possible on this plan?

Check the answer and explanation

No. Entry → library uses one segment, but library has no direct diagonal path to the oval. A route via library and garden needs three segments: entry → library → garden → oval.

5. Create an overhead plan

Choose a boundary and place the required landmarks in their correct relative positions. Labels and a key can support the reader.

Worked example: on a blank page representing a room, draw a door on the lower edge, a table in the centre and a bookshelf to the left of the table. Use cut-outs first so positions can be changed before drawing.

Hold a small plan of an agreed safe classroom or play area. With adult guidance where needed, locate yourself by matching two real landmarks to the plan, mark your position and move to a second named position. Check both locations against the handheld plan.

For a school floor-mat plan, place key buildings and paths, then use short step instructions to guide a toy or a programmable robot if available. The spatial arrangement must match the stated plan.

Watch for this: A neat picture fails the task if the relative positions are wrong.

Try it: Draw a small park with a gate at the bottom, a tree left of a bench and a path connecting the gate to the bench.

Check the answer and explanation

Accept a top-view plan showing all named features, the stated relative positions and a connected path. Artistic realism is not required.

6. Test, explain and improve a map

Check whether someone can actually use the map. Diagnose missing landmarks, unclear symbols, wrong positions or incomplete routes.

Worked example: hide a small object safely in a familiar space and make a plan for a partner. Ask which feature helped and which was confusing, then revise the actual map. An identifiable start and clear landmark positions matter more than decoration.

For First Nations land or cultural maps, use an authorised local resource and its own conventions to explore documented landmarks. Do not invent sacred locations or treat a simple school-map key as a universal cultural convention.

Watch for this: Feedback should identify a specific usability or spatial issue, not only say that a map is nice.

Try it: A plan has correct names but no clear start for its route. What should be improved?

Check the answer and explanation

Mark and name the start, then check that the instructions and connected path lead from it to the intended destination.

Common mistakes and quick fixes
  • Do not assume every view reveals all the object’s surfaces.
  • A key entry is an explanation, not another landmark on the map.
  • Left and right need a stated reference and orientation.
  • Do not cross a missing path or a barrier just because the destination is nearby.
  • A neat picture fails the task if the relative positions are wrong.
  • Feedback should identify a specific usability or spatial issue, not only say that a map is nice.
Check understanding and choose the next step
  1. What does a map key do?
  2. On the supplied school plan, what is between library and classroom?
  3. Name two features a useful route description needs.
Answers and next step
  1. It explains the symbols used on that map.
  2. The garden.
  3. An identifiable start and ordered moves to a destination; also respect the available paths.

If an answer is uncertain, reopen the matching focus, use its model and explain a fresh example before the test.

Support: Begin with three objects on a tray. Agree which edge is the top, then make and use a simple plan.

Extend within this topic: Create two valid routes between the same landmarks and compare them using a stated measure such as number of path segments.

An adult can read the directions aloud. Let the learner show reasoning with objects, a drawing, pointing or a spoken explanation where appropriate. For an actual measuring, creating or data-collection task, the learner still performs and records the stated skill; provide suitable supervision.
