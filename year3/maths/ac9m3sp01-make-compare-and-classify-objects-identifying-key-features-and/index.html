AC9M3SP01 • Year 3 Maths

Classifying Objects by Features and Uses

Students compare and classify objects by structural features and explain why those features make an object suitable for a particular use.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: make, compare and classify objects, identifying key features and explaining why these features make them suited to their uses.

Students use faces, edges, vertices, curved surfaces, stability and other relevant features to compare objects and justify classifications.

Concept boundary: use observable 3D features and practical reasoning; formal geometric proof is not required.

Key vocabulary and representations

Feature — an observable property. Classify — sort by a stated rule. Suitable — having features that fit a use. Use real objects, labelled drawings and sorting tables.

Teaching progression and worked examples
  1. Name and observe object features.
  2. Compare two objects using the same feature.
  3. Classify a set with a stated rule.
  4. Explain how a feature supports a use.

Example: a box has flat faces that help it stack; a ball has a curved surface that helps it roll.

Curriculum elaborations and how they are taught

Make and handle models, compare common objects, use more than one valid classification rule and connect structural features to function in familiar contexts.

Common misconceptions and quick fixes
  • Classifying only by colour: redirect to structural features relevant to the task.
  • Mixing 2D and 3D language: distinguish faces from edges and vertices.
  • Feature without purpose: require a because statement linking feature to use.
Support, Core and Extend
  • Support: sort a small set using one visible feature.
  • Core: compare and classify independently.
  • Extend: classify the same objects in two valid ways and justify both.
Quick check and mastery evidence

Name two features of a familiar object and explain how one feature supports its use. Mastery requires correct feature language and a defensible classification rule.
