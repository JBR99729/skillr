Classifying Objects by Features and Uses

What students learn

Objects can be compared and classified by features such as faces, edges, vertices, curved surfaces, strength, stability and how they are used. This matters because use observable features and purpose, not only the object's name.

A feature can make an object more suitable for a particular use. Use this idea when a problem asks you to link features to uses, and explain the result with feature, classify, suitable.

Learning intention: We are learning to make, compare and classify objects, identifying key features and explaining why these features make them suited to their uses.

Success criteria

  • I can identify 3D features.
  • I can compare objects.
  • I can classify objects.
Key vocabulary
  • feature — a property used to describe or compare an object
  • classify — sort into groups using a stated rule
  • suitable — having features that fit a particular use

Common misconceptions and quick fixes
  • Classifying only by colour — Use structural features relevant to the purpose.
  • 2D and 3D terms mixed — Faces are surfaces; edges are where faces meet.
  • Feature not linked to use — Explain why the feature is helpful.
Teaching sequence and quick check

Quick check: Name a feature of a cube.

Expected response: Flat faces help a box stack.

If incorrect: Use structural features relevant to the purpose.
