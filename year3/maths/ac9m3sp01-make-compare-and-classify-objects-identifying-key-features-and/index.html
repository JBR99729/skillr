Learning goals: what you will learn

Objects can be compared and classified by features such as faces, edges, vertices, curved surfaces, strength, stability and how they are used.

Learning routine: Observe object → Identify features → Compare → Classify → Link feature to use

Prerequisite knowledge

Students should recognise common two- and three-dimensional shapes, use positional language and interpret simple representations of familiar places. Start with a physical model or drawing before using more abstract spatial language.

Concept teaching

Key idea: Objects can be compared and classified by features such as faces, edges, vertices, curved surfaces, strength, stability and how they are used.

Learning routine: Observe object → Identify features → Compare → Classify → Link feature to use

feature
a property used to describe or compare an object
classify
sort into groups using a stated rule
suitable
having features that fit a particular use
Worked and modelled examples

Compare common three-dimensional objects

cube6 flat faces
cylinder2 flat + curved
spherecurved surface
prismmatching ends

Use observable features and purpose, not only the object's name.

  1. Read every label and identify what each quantity or feature represents.
  2. Describe the relationship shown by the model.
  3. Check that the conclusion answers the original question.

Link features to uses

ObjectUseful featureboxflat faces stackballcurved surface rollscanstable base + curved side

A feature can make an object more suitable for a particular use.

Apply the same relationship to the new context, then justify the answer using the labels and evidence shown.

Common misconceptions and corrections
  • Classifying only by colour — Use structural features relevant to the purpose.
  • 2D and 3D terms mixed — Faces are surfaces; edges are where faces meet.
  • Feature not linked to use — Explain why the feature is helpful.

Independent practice

  1. Which feature helps a box stack?

    • flat faces
    • only a curved surface
    • no faces
    • being a bright colour

  2. Complete the object description.

    Prompt: A cube has □ flat faces.

  3. Which object rolls most easily in many directions?

    • sphere
    • cube
    • rectangular prism
    • pyramid

  4. Compare a cylinder and a sphere using surfaces and movement.

  5. Match the object to a useful feature.

    Match: box • ball • can ↔ stable flat base with curved side • curved surface rolls • flat faces stack

  6. Complete the term.

    Prompt: The line where two faces meet is an □.

Reasoning and problem-solving

  1. Design an object for storing and transporting six balls. Choose features and justify them.

  2. Create two different classification systems for the same five objects and compare their usefulness.

Explain the reasoning, not only the final answer.

Curriculum alignment

The content description and elaborations below show the curriculum ideas taught in this unit. Items marked as teaching context support lesson planning.

  • Content description: make, compare and classify objects, identifying key features and explaining why these features make them suited to their uses
  • E1: classifying a collection of geometric objects, including cylinders, spheres, prisms and pyramids according to key features such as the shape and number of faces and/or surfaces, edges and vertices
  • E2: making and comparing objects built out of cubic blocks and discussing key features; for example, comparing the amount of space objects occupy by counting how many blocks it takes to build different rectangular prisms that have the same height but different bases
  • E3: making geometric objects in solid form out of connecting cubes, in skeleton form with straws, and constructing objects using dynamic geometric software, recognising, comparing and discussing the features of the objects using the different representations
  • E4: using familiar shapes and objects to build or construct models and compare the suitability of different shapes and objects for aspects of the model; for example, building rectangular towers out of connecting cubes and recognising that the taller the tower, the less stable it becomes unless the base is increased; building bridges out of straws bent into different shapes and comparing the strength of different designs
  • E5: identifying, classifying and comparing common objects found on Country/Place as cubes, rectangular prisms, cylinders, cones and spheres
  • E6: investigating and explaining how First Nations Australians’ dwellings are oriented in the environment to accommodate climatic conditions (teaching context)
