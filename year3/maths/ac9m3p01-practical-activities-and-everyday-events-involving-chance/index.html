Chance, outcomes and likelihood

Recognise when an outcome is uncertain. Describe what can happen and explain “likely”, “unlikely”, “certain” and “impossible” using the information given.

10-MINUTE HOME ACTIVITY

Rank the outcomes

Put three red counters and one blue counter in an opaque bag. Describe how likely each colour is before drawing. Change the mix to make drawing blue certain, then impossible.

Adjust the challenge: Start with one colour only. Extend by making both colours equally likely.

FAQ

Can an unlikely outcome still happen?

Yes. The single blue counter can still be drawn from a bag containing three red counters and one blue.

Learn the skill

Small steps, clear examples

Learning goal: Recognise when an outcome is uncertain. Describe what can happen and explain “likely”, “unlikely”, “certain” and “impossible” using the information given.

Before you start: Sort objects by a stated feature and explain a simple choice.

Useful words: outcome: a possible result; certain: must happen under the stated conditions; impossible: cannot happen; likely: expected more than not; unlikely: possible but not expected.

1. Identify a chance situation

A chance situation has an outcome that is not known for sure before it happens. State the conditions before making a judgement.

Worked example: a closed bag contains different-coloured counters. Mixing and drawing one without looking involves chance. Choosing a particular visible counter deliberately is a different situation.

Weather and games can involve uncertainty too, but the available information matters. A personal wish is not evidence that an event is likely.

Watch for this: An outcome can be unknown without every imagined outcome being possible.

Try it: Is the result of rolling an ordinary die uncertain before the roll? Explain.

Check the answer and explanation

Yes. Any of its six faces may finish on top; a particular face is not known beforehand.

2. Describe all possible outcomes

Use the actual model, materials or stated conditions. Name the outcome type being recorded.

Worked example: a bag contains four red counters and one blue counter, and the result is recorded by colour. Possible outcomes are red and blue. There are five physical counters but only two colour categories.

For an ordinary six-sided die recorded by face number, the possible outcomes are 1, 2, 3, 4, 5 and 6.

Watch for this: Repeated objects do not create new outcome categories when only the colour or shape is recorded.

Try it: A bag has three circles and two triangles. If you record shape, list the possible outcomes.

Check the answer and explanation

Circle and triangle. A square is not possible from the stated bag.

3. Explain certain and impossible

A certain event includes every possible result. An impossible event includes none of the possible results.

Worked example: if a bag contains only red and blue counters, drawing red or blue is certain, and drawing green is impossible, provided no counter is added or changed.

“Getting a number below 7” is certain on an ordinary die; “getting 8” is impossible. Explain the complete set of possible outcomes.

Watch for this: Very unlikely is still possible; impossible means no possible result fits.

Try it: A bag contains only yellow counters. Describe drawing yellow and drawing purple.

Check the answer and explanation

Yellow is certain and purple impossible under those conditions.

4. Explain likely and unlikely

Use the relative representation of outcomes and how the selection works. A random draw requires mixing and no deliberate choice.

Worked example: a well-mixed bag has four same-sized red counters and one same-sized blue counter. Drawing red is likely; drawing blue is unlikely but possible.

The red outcome is supported by more counters. It is not certain, because the blue counter can still be selected.

For another model, write ten different names on ten identical folded slips. Mix, draw a name, replace it and mix before drawing again. Every name remains possible at each draw. A repeated name can occur, and a name missed so far is still possible.

Watch for this: Do not turn “likely” into a promise about the next draw.

Try it: A well-mixed bag contains one green and five orange same-sized counters. Describe drawing green.

Check the answer and explanation

Unlikely but possible. There is one green counter among the six possible selections.

5. Build or change a chance model

Choose contents to make a requested event certain, impossible, likely or unlikely. Check the whole model and the selection rule.

Worked example: to make blue likely but not certain using five same-sized counters, use four blue and one red. To make blue certain, all five could be blue.

Changing the contents changes the possible outcomes or their relative representation. A different collection may also meet the same conditions.

Watch for this: A model must satisfy both parts of “unlikely but possible”.

Try it: Make a five-counter bag where yellow is unlikely but possible.

Check the answer and explanation

One valid bag has one yellow and four red same-sized counters, mixed and drawn without looking. Other correctly explained designs may work.

6. Predict, check and revise a claim

A prediction should match the model. A single surprising result does not mean the prediction language was wrong.

Worked example: with four red and one blue counter, “red is likely” is a sensible statement. If the draw is blue, that was a possible result. It does not prove that blue was certain or that the bag contents changed.

If every counter is later replaced by blue, revise the claim: blue is now certain. State what information changed.

Paper role-play: read an imaginary chatbot claim, “Blue cannot happen because there are fewer blue counters.” Ask a partner to challenge it using the supplied bag. A correct reply says blue is possible because a blue counter is present. Explain that confident computer wording must still be checked against evidence. No online account is needed.

Watch for this: One observed result does not guarantee the next result or erase other possibilities.

Try it: A blue counter was drawn from a bag with mostly red counters. Was “blue is impossible” a correct claim?

Check the answer and explanation

No. If blue was present, it was possible even if unlikely. Use the contents to justify the statement.

Common mistakes and quick fixes
  • An outcome can be unknown without every imagined outcome being possible.
  • Repeated objects do not create new outcome categories when only the colour or shape is recorded.
  • Very unlikely is still possible; impossible means no possible result fits.
  • Do not turn “likely” into a promise about the next draw.
  • A model must satisfy both parts of “unlikely but possible”.
  • One observed result does not guarantee the next result or erase other possibilities.
Check understanding and choose the next step
  1. List colour outcomes for a bag containing only red and yellow counters.
  2. Explain why green is impossible from that bag.
  3. Can an unlikely event happen?
Answers and next step
  1. Red and yellow.
  2. No green counter is present under the stated conditions.
  3. Yes; unlikely events are possible.

If an answer is uncertain, reopen the matching focus, use its model and explain a fresh example before the test.

Support: Begin with an all-one-colour bag, then introduce one contrasting same-sized counter. Say what changed and what remains possible.

Extend within this topic: Design two different bags where red is likely but not certain. Explain each design without assigning a formal numerical probability.
