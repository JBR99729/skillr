AC9M3P01 • Year 3 Maths

Chance in Everyday Events

Chance language describes how possible an event is and must be justified from the possible outcomes or conditions.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: identify practical activities and everyday events involving chance; describe possible outcomes and events as likely or unlikely and identify some events as certain or impossible, explaining reasoning.

Students list possible outcomes before using certain, likely, unlikely or impossible and explain how the conditions support the description.

Concept boundary: use qualitative chance language; numerical probability is not required.

Key vocabulary and representations

Outcome — a possible result. Certain — must happen. Impossible — cannot happen. Likely/unlikely — comparative chance language supported by the situation.

Teaching progression and worked examples
  1. Identify the chance event.
  2. List its possible outcomes.
  3. Place events on an impossible-to-certain scale.
  4. Justify the placement.

Example: a bag has 6 red counters, 2 blue and no green. Red is likely, blue is possible but less likely, and green is impossible.

Curriculum elaborations and how they are taught

Use familiar games, spinners, bags, weather-style scenarios and everyday events to identify outcomes, compare likelihood and distinguish certain and impossible events through explicit reasoning.

Common misconceptions and quick fixes
  • Likely means certain: show an event can be likely and still not occur.
  • Impossible by opinion: check the actual outcome set.
  • Ignoring conditions: show how changing the situation changes the chance description.
Support, Core and Extend
  • Support: sort event cards into certain/impossible first.
  • Core: classify and justify likely/unlikely events.
  • Extend: change one condition and explain how the chance description changes.
Quick check and mastery evidence

Ask for one certain, one impossible and one likely event with reasons. Mastery requires correct language and evidence from the outcomes.
