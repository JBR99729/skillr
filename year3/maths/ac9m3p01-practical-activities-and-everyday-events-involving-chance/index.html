Chance in Everyday Events

What students learn

Chance language describes how possible an event is. Certain events must happen, impossible events cannot happen, and likely or unlikely events depend on the situation. This matters because reasoning must use the possible outcomes or known conditions.

Red is likely, blue is possible but unlikely, and green is impossible if there are no green counters. Use this idea when a problem asks you to analyse a bag of counters, and explain the result with outcome, likely, impossible.

Learning intention: We are learning to identify practical activities and everyday events involving chance; describe possible outcomes and events as likely or unlikely and identify some events as certain or impossible explaining reasoning.

Success criteria

  • I can identify chance events.
  • I can list outcomes.
  • I can use certain/impossible.
Key vocabulary
  • outcome — a possible result of a chance event
  • likely — more likely to happen than not happen
  • impossible — an event that cannot happen

Common misconceptions and quick fixes
  • Likely means certain — Likely events can still fail to occur.
  • Impossible based on opinion — Check the actual possible outcomes.
  • No conditions stated — Chance can change when the situation changes.
Teaching sequence and quick check

Quick check: Give a certain event.

Expected response: Rolling 7 on a standard six-sided die is impossible.

If incorrect: Likely events can still fail to occur.
