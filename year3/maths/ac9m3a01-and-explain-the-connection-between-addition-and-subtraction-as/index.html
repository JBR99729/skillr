AC9M3A01: Addition and Subtraction as Inverse Operations

Addition and subtraction undo each other. Students connect a whole and two parts, write related number sentences and use inverse operations to find and check unknown values.

Topic guideTeacher SlidesWorksheetPracticeTest
What students learn in AC9M3A01

Addition and subtraction undo each other. Students connect a whole and two parts, write related number sentences and use inverse operations to find and check unknown values.

  • Identify the whole and parts in addition and subtraction situations.
  • Write fact families using the same three numbers.
  • Use subtraction to find an unknown part and addition to check.
  • Explain why addition and subtraction are inverse operations.
Key models and vocabulary
  • inverse operations — operations that undo each other
  • unknown — a value that has not yet been found
  • number sentence — a mathematical statement using numbers and symbols
  • fact family — related equations using the same numbers
Teaching progression and worked examples
  1. Use 37 + 25 = 62 to write 25 + 37 = 62, 62 − 37 = 25 and 62 − 25 = 37.
  2. Solve 29 + ? = 84 by calculating 84 − 29 = 55, then check 29 + 55 = 84.

Teacher language: Ask students to name the known fact, show the model, explain the strategy and check that the answer matches the context.

Curriculum coverage and elaborations

The content description and elaborations below show the curriculum ideas taught in this unit.

  • E1: recognising and explaining the connection between addition and subtraction as inverse operations

  • E3: finding unknown values in number sentences using inverse operations

Common mistakes to watch for
  • Using a procedure without meaning: return to the model and ask what each number represents.
  • Mixing parts from different facts: keep the same quantities across related equations.
  • Skipping the check: substitute the answer back into the original number sentence or context.
Support, core and extend
  • Support: use concrete materials, number lines and part-part-whole or array models.
  • Core: solve mixed examples and explain the selected strategy.
  • Extend: create a related problem and prove the answer with an inverse or related fact.
Quick check and mastery evidence
  1. Write the fact family for 28, 35 and 63.
  2. Find the unknown in 46 + ? = 91 and check with subtraction.

Mastery means students can choose an efficient representation, solve accurately, explain the reasoning and check the result.
