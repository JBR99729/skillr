Addition and Subtraction as Inverse Operations

Addition and subtraction undo each other. A whole and two parts create related number sentences that can solve unknown values. This matters because the same whole and parts create two addition and two subtraction facts.

What students learn

Addition and subtraction undo each other. A whole and two parts create related number sentences that can solve unknown values. This matters because the same whole and parts create two addition and two subtraction facts.

Use 84 − 29 to find the missing part, then add to check. Use this idea when a problem asks you to find an unknown part, and explain the result with inverse operations, unknown, number sentence.

Learning intention: We are learning to recognise and explain the connection between addition and subtraction as inverse operations, apply to partition numbers and find unknown values in number sentences.

Success criteria

  • I can identify whole and parts.
  • I can write fact families.
  • I can solve unknowns.
Key vocabulary
  • inverse operations — operations that undo each other
  • unknown — a value that has not yet been found
  • number sentence — a mathematical statement using numbers and symbols

Common misconceptions and quick fixes
  • Reversing subtraction freely — Addition is commutative; subtraction usually is not.
  • Using the wrong whole — The largest amount is usually the whole in a fact family.
  • No inverse check — Substitute the unknown into the original sentence.
Teaching sequence and quick check

Quick check: Write a fact family for 28, 35 and 63.

Expected response: 62 − 37 = 25 is related to 37 + 25 = 62.

If incorrect: Addition is commutative; subtraction usually is not.
