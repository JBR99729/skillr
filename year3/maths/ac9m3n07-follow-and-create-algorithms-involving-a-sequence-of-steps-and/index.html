Number Algorithms and Patterns

An algorithm is an ordered set of instructions. Decisions such as even or odd can change the next step, and recording outputs helps reveal patterns. This matters because each decision uses the current number, not the starting number.

What students learn

An algorithm is an ordered set of instructions. Decisions such as even or odd can change the next step, and recording outputs helps reveal patterns. This matters because each decision uses the current number, not the starting number.

Testing several inputs helps identify the pattern in outputs. Use this idea when a problem asks you to create an algorithm and test several inputs, and explain the result with algorithm, decision, pattern.

Learning intention: We are learning to follow and create algorithms involving a sequence of steps and decisions to investigate numbers; describe any emerging patterns.

Success criteria

  • I can follow steps.
  • I can use decisions.
  • I can repeat accurately.
Key vocabulary
  • algorithm — an ordered set of steps and decisions
  • decision — a choice that changes the next step
  • pattern — a regularity that can be noticed and described

Common misconceptions and quick fixes
  • Changing the order — Algorithms must be followed in the stated sequence.
  • Decision checked once — Recheck the decision whenever the algorithm repeats.
  • Pattern claimed from one input — Test several inputs.
Teaching sequence and quick check

Quick check: Follow: start 5, add 3, double.

Expected response: The output is 16: 5 + 3 = 8, then 8 × 2 = 16.

If incorrect: Algorithms must be followed in the stated sequence.
