AC9M3N07 • Year 3 Maths

Number Algorithms and Patterns

Algorithms are ordered steps and decisions. Students follow, create and test simple number algorithms, then describe patterns that emerge.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: follow and create algorithms involving a sequence of steps and decisions to investigate numbers; describe any emerging patterns.

Students follow steps in order, recheck decisions whenever a process repeats and record outputs so patterns can be compared across several starting numbers.

Concept boundary: keep algorithms concrete and number-based; formal programming notation is not required.

Key vocabulary and representations

Algorithm — an ordered set of steps and decisions. Decision — a condition that determines the next step. Pattern — a regularity noticed across results.

Teaching progression and worked examples
  1. Follow a short fixed sequence.
  2. Add a decision such as even/odd.
  3. Repeat the process using the current number.
  4. Test several inputs and compare outputs.

Example: start 5, add 3, then double: 5 + 3 = 8 and 8 × 2 = 16.

Teacher language: “Which step happens next? Which number are you testing now? What stays the same when you change the input?”

Curriculum elaborations and how they are taught

Students follow, debug and create simple sequences involving steps and decisions, record results in tables or diagrams, test multiple starting values and describe reliable patterns without claiming a rule from one example.

Common misconceptions and quick fixes
  • Changing the order: point to and execute one step at a time.
  • Checking a decision only once: recheck whenever the algorithm loops.
  • Pattern from one input: test several starting numbers first.
Support, Core and Extend
  • Support: use arrow cards and one decision.
  • Core: follow and create an algorithm with a decision.
  • Extend: compare outputs from several starting numbers and justify the pattern.
Quick check and mastery evidence

Give a new start value and a three-step algorithm. Mastery means the student follows the order accurately, applies decisions to the current value and explains a pattern using evidence from multiple trials.
