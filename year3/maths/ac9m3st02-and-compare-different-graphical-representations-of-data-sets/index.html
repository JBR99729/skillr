AC9M3ST02 • Year 3 Maths

Creating and Comparing Data Displays

The same data can be represented in different ways. Clear labels, scales and context help students compare displays and interpret what the data shows.

Topic GuideTeacher SlidesPractice SheetPracticeTest
What students learn

Learning intention: create and compare different graphical representations of data sets including using software where appropriate; interpret the data in terms of the context.

Students build and read simple displays, compare how two representations show the same data and explain conclusions in context.

Concept boundary: use Year 3 displays and straightforward scales; formal statistical measures are not required.

Key vocabulary and representations

Data display — a visual representation of data. Scale — how values are marked. Category — a group in the data. Use picture graphs, column-style displays, tables and software-generated equivalents where appropriate.

Teaching progression and worked examples
  1. Read title, labels and scale.
  2. Create a display from a small data table.
  3. Create a second representation of the same data.
  4. Compare what each representation makes easy to notice.

Example: a table and a column display may show the same favourite-fruit frequencies; both must preserve the same values even though they look different.

Curriculum elaborations and how they are taught

Students create displays by hand and with simple digital tools, compare alternative representations of the same data set and interpret highest, lowest, equal and difference statements in the original context.

Common misconceptions and quick fixes
  • Missing labels or scale: check title, axes/categories and value marks before reading.
  • Reading picture size instead of value: use the legend or scale.
  • Describing without interpreting: finish with a sentence about what the data means in context.
Support, Core and Extend
  • Support: complete a partly built display from a small table.
  • Core: create and interpret one suitable display independently.
  • Extend: compare two displays of the same data and evaluate which is clearer for a given question.
Quick check and mastery evidence

Provide a small data set and ask for a labelled display plus two contextual statements. Mastery requires accurate values, readable representation and correct interpretation.
