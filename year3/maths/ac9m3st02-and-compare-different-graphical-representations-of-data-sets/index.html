Prerequisite knowledge

Students should be able to sort information into categories, read simple tables or displays and compare counts. Revisit what each label, category and scale represents before analysing a data display.

Worked and modelled examples

Turn a frequency table into a column graph

4Walk
6Bus
3Car

Bar heights must match the frequencies and categories need labels.

  1. Read every label and identify what each quantity or feature represents.
  2. Describe the relationship shown by the model.
  3. Check that the conclusion answers the original question.

Compare two representations

table gives exact valuesgraph shows comparison quicklyboth use same data

choose for purpose

Interpret the display in the context, not just as isolated numbers.

Apply the same relationship to the new context, then justify the answer using the labels and evidence shown.

Common misconceptions and corrections
  • Graph changes the data — Every value must match the source.
  • No title or labels — Readers need context and scale.
  • Unequal spacing or scale — Use consistent intervals.

Independent practice

  1. What must remain the same when data moves from a table to a graph?

    • category frequencies
    • background colour
    • font size
    • page orientation

  2. Complete the comparison.

    Prompt: If Bus = 6 and Walk = 4, Bus has □ more responses.

  3. Which display usually makes bar heights easy to compare?

    • column graph
    • calendar
    • clock
    • number line

  4. Explain why a graph needs a title and labelled categories.

  5. Match the display to its strength.

    Match: frequency table • picture graph • column graph ↔ visual symbols • exact listed values • quick height comparison

  6. Complete the interpretation.

    Prompt: The tallest bar represents the □ frequency.

Reasoning and problem-solving

  1. Represent one data set in two ways and compare which is clearer for two different questions.

  2. Design a deliberately misleading graph, then explain and correct every misleading feature.

Explain the reasoning, not only the final answer.

Assessment-style questions and review hints

  1. Describe a column graph for values 3, 7, 5 and 2, including a suitable scale.

  2. A graph shows 9 for a category whose table value is 6. Explain the error.

Review hint: Follow the routine “Check data → Choose display → Label axes/key → Plot accurately → Compare → Interpret” and use the worked model to check whether your answer is reasonable.

Teacher and parent guidance

For teachers

Model the idea with concrete or visual representations first, then ask students to explain the relationship in words before moving to symbolic work.

For parents and carers

Ask your child to show the idea with a drawing, objects or a simple example and explain how they checked the answer.

Read the topic guide and use the teacher slide for instruction. Students can then use the worksheet for written work, open Practice for supported feedback, or take the Test when they are ready.
