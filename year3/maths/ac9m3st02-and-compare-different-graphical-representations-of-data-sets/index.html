Learn the skill

Small steps, clear examples

Learning goal: Show the same dataset in different ways without changing its values. Read keys and scales, create clear displays and explain what the data says in context.

Before you start: Read frequency tables, count equal steps and recognise common categories.

Useful words: picture graph: symbols show quantities; key: the value of a symbol; scale: the values along an axis; interpret: explain a display in its context.

1. Build a picture graph from data

Choose a useful title, category labels and an explicit key. Align symbols so their counts are easy to compare.

Worked example: snack votes are apple 8, banana 6 and pear 4. With one circle = two votes, draw four, three and two circles respectively.

The key changes the number of symbols, not the underlying votes. With one circle per vote, the same dataset needs eight, six and four circles.

Watch for this: Count the value of the symbols, not just how many pictures are shown.

Try it: With one symbol = two votes, how many symbols represent ten votes?

Check the answer and explanation

Five full symbols. The key must be visible with the graph.

2. Build a column or bar graph, including software

Use category labels, a quantity label, a title and equal numerical steps. Start a simple frequency axis at zero.

Worked example: use the same snack votes: apple 8, banana 6, pear 4. On an axis labelled 0, 2, 4, 6, 8, the three bars end at 8, 6 and 4.

Enter the labelled table into suitable spreadsheet software, select the category and frequency cells, then create a column graph. Check its title, labels and plotted values against the original table; a completed picture alone does not show that software was used.

Watch for this: Equal visual intervals must represent equal numerical changes.

Try it: On an axis with two-vote intervals, where should a bar for six votes end?

Check the answer and explanation

At the third interval above zero, labelled 6. Its height represents six votes, not three.

3. Read the key, labels and scale first

Identify what the graph measures and its units before reading a value. Category names alone do not identify a quantity.

Worked example: the apple bar on the supplied snack-vote graph reaches 8. It represents eight votes. On the matching picture graph, four circles also represent eight votes because each circle stands for two.

A bar ending halfway between 4 and 6 represents 5 if the scale is uniform. Read the actual scale rather than assuming each line is one.

Watch for this: Keep the units in the answer.

Try it: Use the supplied graph. How many banana votes are recorded? How many fewer pear votes than banana votes?

Check the answer and explanation

Banana 6; pear 4, so pear has 2 fewer votes.

4. Reason with totals, differences and ties

Use the values in the display to answer the stated relationship. “How many more” asks for a difference, not the total.

Worked example: apple has 8 votes and pear 4, so apple has 4 more votes. The total across all three categories is 8 + 6 + 4 = 18 votes.

If two categories tie, report the tie. Do not choose a unique largest or smallest category when the values are equal.

Watch for this: Check whether the question asks for a total, difference or category.

Try it: Use the supplied graph. How many votes are for banana or pear altogether?

Check the answer and explanation

10 votes: 6 + 4. These categories do not include apple.

5. Compare displays and choose for a purpose

Two displays can look different and still represent exactly the same data. Compare the actual values, key, scale, ordering and labels.

Worked example: the snack table gives exact frequencies at a glance; a column graph makes differences visible. A picture graph with a two-vote key uses fewer symbols than a one-vote key, while retaining 8, 6 and 4.

Choose a clear display for the reader and purpose. When examining a graph from a magazine or public source, inspect its real title, group, dates, labels and scale before interpreting it.

Watch for this: A taller-looking graph can come from a changed scale rather than larger data.

Try it: If the category order changes but the recorded values stay 8, 6 and 4, has the dataset changed?

Check the answer and explanation

No. The layout changed. Verify that each value remains attached to its correct category.

6. Make a supported contextual claim

Say what was measured, for which group and when. Keep a conclusion within the evidence.

Worked example: “Apple received the most snack votes in this eighteen-vote survey” is supported. “Everyone chose apple” is false, and “apple received more than half the votes” is false because 8 is less than half of 18.

The votes do not prove apple is healthiest or predict everyone’s future choice. If the data measures purchases rather than preference, describe purchases.

Watch for this: Most does not automatically mean more than half, all, best or a cause.

Try it: Can the supplied snack graph prove that apple is every child’s favourite fruit? Explain.

Check the answer and explanation

No. It reports votes in the stated survey, includes other choices and does not represent every child everywhere.

Common mistakes and quick fixes
  • Count the value of the symbols, not just how many pictures are shown.
  • Equal visual intervals must represent equal numerical changes.
  • Keep the units in the answer.
  • Check whether the question asks for a total, difference or category.
  • A taller-looking graph can come from a changed scale rather than larger data.
  • Most does not automatically mean more than half, all, best or a cause.
Check understanding and choose the next step
  1. A key says one symbol = five learners. What do three symbols mean?
  2. What must stay unchanged when the same data becomes a different graph?
  3. Do the most votes prove a majority?
Answers and next step
  1. 15 learners.
  2. Each category’s value and meaning, together with the dataset and recorded units.
  3. No. A majority means more than half; compare with the total.

If an answer is uncertain, reopen the matching focus, use its model and explain a fresh example before the test.

Support: Start with a one-to-one picture graph, a short table and a zero-based unit scale. Move to keys and steps of two after the relationship is secure.

Extend within this topic: Create a table, picture graph and software column graph for one small dataset. Check every value and justify which display helps with a particular question.
