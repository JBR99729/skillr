Turn a table into a faithful graph

Learning intention: Construct tables, column graphs and models that organise data, show relationships and reveal patterns.

Three soils, one consistent graph scale

Matching setups each receive 60 mL of water. The supplied data show the collected drainage water after two minutes. The column graph uses a zero baseline and equal 10 mL intervals. Its column heights must agree with the table.

Learn the skill

1. Keep labels with their values

A table organises the sample, measurement and unit. Choose an order that helps answer the question without changing the records.

Table headingWhy it matters
Soil sampleIdentifies the compared category
Water collected after 2 min (mL)States the outcome, time and unit
Try it · May we attach A’s 48 mL to C to make an attractive pattern?

No. Keep every value with its correct sample.

2. Construct equal-scale columns

Label both axes, include units, use equal intervals and make column heights proportional to the data. Here the vertical scale begins at zero.

Graph check

A = 48 mL, B = 36 mL, C = 24 mL. A’s column is twice C’s height on this zero-based scale.

Try it · Would equal-height columns show these three values faithfully?

No. The values differ, so equal heights would misrepresent them.

3. Describe a pattern and a model’s limit

In this example, A collected the most water and C the least. A physical model could use one counter for 12 mL: four counters for A, three for B and two for C.

SampleModel: 1 counter = 12 mL
A4 counters
B3 counters
C2 counters
Try it · Does a drainage model show every property of the soil?

No. It represents selected measurements, not all soil features or causes.

Common mistakes

“A graph can change the data to look smoother.” Its values must agree with the source record.

“A model is the complete real system.” State what the model shows and what it leaves out.

10-MINUTE ACTIVITY

Build and check a representation

2 minutes: read the table headings. 5 minutes: draw a labelled column graph or make the 12 mL-per-counter model. 3 minutes: check each value and explain one pattern and one limitation.

Adjust the challenge Support: use provided axes or counters. Extend: identify how a misleading scale or changed key could distort the message.

Use supplied data and age-appropriate counters. Never drink water used in soil investigations.

Three tricky questions

1. Does A, B, C on the horizontal axis mean the samples were measured at three different times?

No. They are sample labels. All three records use the same two-minute collection period.

2. Is C exactly half of A in these supplied records?

Yes. 24 mL is half of 48 mL.

3. If a record is missing, should its column be drawn as zero?

No. Missing and zero mean different things; mark the missing observation clearly.

FAQ

Why use a column graph?

It can make comparisons between categories easy to see while retaining the table for exact values.

What makes a model useful?

It shows a chosen idea or relationship clearly, with an accurate key and stated limits.

What students learn in AC9S3I04

Students learn to construct and use representations, including tables, simple column graphs and visual or physical models, to organise data and information, show simple relationships and identify patterns. They use the visual model, precise vocabulary and evidence to explain and apply the concept.

Learning routine: Observe → Model → Investigate → Record → Explain

  • Apply in a new context
  • Justify with evidence

Common misconceptions
  • Graph values differ from table — Represent the source data accurately.
  • Feature named without effect — Explain how the feature changes meaning or outcome.
  • One example treated as a rule — Test the idea with another example.
