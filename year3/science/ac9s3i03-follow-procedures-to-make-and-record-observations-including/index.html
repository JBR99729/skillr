Read the scale, record the unit

Learning intention: Follow procedures to measure with familiar scaled instruments. Record observations and use digital tools appropriately.

WORKED EXAMPLE

Three small intervals above 25°C

The model has labelled marks at 20, 25, 30 and 35°C. There are five equal intervals from 25 to 30, so each interval represents 1°C. The top of the red column is three intervals above 25: the reading is 28°C.

Learn the skill

1. Match instrument to measurement

Choose a tool with a suitable scale. Follow its procedure and record what it actually measures.

QuantitySuitable familiar tool
LengthRuler, using cm or mm
Water volumeMeasuring jug or cylinder, using mL
TemperatureThermometer, using °C
Elapsed timeTimer, using s or min
Try it · Can a thermometer tell you a strip’s length?

No. Choose a suitable length-measuring tool.

2. Work out the intervals

Find the difference between labelled values and count the equal spaces, not just the tick marks. Read the indicated level from the correct viewing position.

Scale check

25°C → five equal spaces → 30°C. Each space is 1°C.

Try it · If there are five spaces from 20 to 30, is each space 1°C?

No. That gap is 10°C, so each of the five equal spaces represents 2°C.

3. Record value, unit and context

A useful record names the object, time, value and unit. Keep descriptive observations too; a description is not automatically less useful than a number.

TimeMeasurementDescription
After 2 minWater: 28°CWater remains clear
Try it · Should a missing reading be filled with a likely number in a digital table?

No. Mark it missing and remeasure if appropriate.

Common mistakes

“A measurement does not need a unit.” A number such as 28 is unclear without the quantity and unit.

“Every small division means one unit.” Calculate the interval from the actual scale.

10-MINUTE ACTIVITY

Make a complete record from a model

2 minutes: inspect the thermometer scale. 5 minutes: explain its interval and write a complete reading with object, time and unit. 3 minutes: choose an instrument for one other measurement and justify it.

Adjust the challenge Support: count spaces between two labelled values. Extend: explain how the answer changes when the same number of spaces spans 10 units instead of 5.

Use the supplied scale or an adult-approved classroom instrument. An adult checks thermometers and liquids; avoid glass damage, hot water and sharp probes.

Three tricky questions

1. Does a side-on view always give the same reading as a face-on view?

No. Viewing angle can affect a scale reading; follow the instrument’s reading procedure.

2. A ruler’s zero mark is not aligned with the start. Can the end number alone be called the length?

No. Align correctly or account for the starting mark.

3. Can a photograph help preserve a scale reading?

Yes, if the scale, level and context are clear. It does not replace correct measurement procedure.

FAQ

What is a formal measurement?

A measurement using standard units and an appropriate scaled instrument, such as 28°C or 6 cm.

Can digital tools still give wrong records?

Yes. Wrong units, labels or entries can make a digital record misleading; check them against observations.

What students learn in AC9S3I03

Students learn to follow procedures to make and record observations, including making formal measurements using familiar scaled instruments and using digital tools as appropriate. They use the visual model, precise vocabulary and evidence to explain and apply the concept.

Learning routine: Observe → Model → Investigate → Record → Explain

Curriculum coverage and elaborations
